A1

PESS / SSEP

Completo Plantilla A 
PESS/SSEP
├─ Vía anatómica
│  ├─ N. mediano / n. tibial posterior → cordón posterior → núcleos gracilis/cuneatus
│  │  (bulbo) → lemnisco medial → tálamo (VPL) → corteza somatosensorial (S1)
│  └─ N9 (punto de Erb) — marcador de conducción periférica pura
├─ Estimulación
│  ├─ N. mediano (MMSS) / n. tibial posterior (MMII)
│  ├─ ~20-40 mA, 0.2-0.3 ms, 2.7-4.7 Hz (evitar armónicos de red)
│  └─ Confirmar twitch motor visible como control de intensidad efectiva
├─ Registro / montaje
│  ├─ Cortical: C3'/C4'-Fz (MMSS) · CPz/Cz'-Fz (MMII)
│  ├─ Subcortical: Erb's point (N9) · cervical (Cv2-Fz)
│  └─ Requiere promediado — señal pequeña, ruido de fondo alto
├─ Morfología normal
│  └─ N20 (mediano, cortical) / P37 (tibial, cortical)
│     └─ Línea base tras posicionamiento final
├─ Efecto anestesia/fisiología
│  ├─ Muy sensible a halogenados (dosis-dependiente) → preferir TIVA
│  ├─ N2O: efecto aditivo negativo con halogenados
│  ├─ Hipotensión / hipotermia / hipocapnia → ↓ amplitud, ↑ latencia
│  └─ Relajante muscular → sin efecto (vía sensitiva pura)
├─ Criterios de alarma
│  └─ Clásico: ↓ amplitud >50% o ↑ latencia >10% vs. basal
│     └─ MacDonald: criterios adaptativos más recientes
├─ Causas de cambio no quirúrgico
│  ├─ Técnico: desconexión, impedancia, artefacto de bisturí eléctrico
│  ├─ Anestésico: bolo de halogenado, cambio brusco de plano
│  └─ Sistémico: PAM, Hb, temperatura, compresión de plexo/nervio por posición
├─ Troubleshooting
│  └─ Técnico → anestésico → correlacionar con MEP/onda D si hay riesgo motor
│     → avisar a cirugía si persiste
├─ Limitaciones
│  └─ Columnas dorsales ≠ tracto corticoespinal
│     └─ SEP normal NO garantiza indemnidad motora
└─ Referencia
   └─ Nuwer2012 (AAN/ACNS) · MacDonald2019 (ISION) · Toleikis2024 (ASNM)
Ampliación — profundizar 
PESS/SSEP — ampliación
├─ Criterios adaptativos más allá del 50%/10% clásico
│  ├─ Crítica al clásico: sobrestima la latencia, no considera el drift fisiológico de
│  │  la basal ni la reproducibilidad real de la señal
│  ├─ Deriva basal benigna: la amplitud cae por debajo del 50% de la basal inicial en
│  │  ~20% de las cirugías de escoliosis SIN que sea patológico
│  └─ Criterio adaptativo real: comparar con el valor RECIENTE pre-cambio (no la basal
│     inicial), que exceda claramente la variabilidad trial-a-trial, sobre todo si el
│     cambio es abrupto y focal
├─ Reproducibilidad de la señal como base del criterio (Tabla 3.1)
│  └─ Clasificación Alta/Media/Baja/No-reproducible según % de variación entre
│     barridos → determina qué decremento es detectable como patológico (alta
│     reproducibilidad detecta caídas >30%; señal no-reproducible solo es fiable si
│     desaparece del todo)
└─ Límites reales de detección
   ├─ Anomalía de no-decusación de la vía sensitiva invalida montajes fijos — 2.3% de
   │  una serie de escoliosis en Oriente Medio, asociada a parálisis congénita de la
   │  mirada horizontal
   └─ Encuesta SRS/ESDS (51.263 cirugías de columna): 34 falsos negativos (0.063% del
      total) — pero esos 34 representan el 18.5% de los 184 pacientes con déficit
      postoperatorio real → cuantifica la limitación "SEP normal no garantiza
      indemnidad motora"
Referencia: Deletis, cap. 3 (MacDonald), §3.3.3.1 y 3.4.1-3.4.2, Tabla 3.1, pp.39-46 ·
Nuwer et al., citado en Moller2011 cap. 6, p.96
A2

PEM / MEP transcraneal (miogénico)

En progreso Plantilla A 
PEM/MEP transcraneal (miogénico)
├─ Vía anatómica
│  └─ M1 → cápsula interna → decusación piramidal bulbar → tracto corticoespinal
│     → asta anterior → n. periférico → músculo
├─ Estimulación
│  ├─ TES, electrodos C1/C2 o C3/C4 (10-20), tren de pulsos (train-of-five habitual)
│  ├─ Estimulación anodal — ánodo sobre el hemisferio a estimular
│  └─ Umbral de estimulación — parámetro clave a vigilar (↑ umbral = alerta precoz)
├─ Registro / montaje
│  ├─ EMG miogénico en músculos diana según nivel en riesgo (APB/ADM · TA/AH)
│  └─ Alternativa epidural → onda D (ver A3)
├─ Morfología normal
│  └─ Respuesta polifásica muscular
│     └─ Presencia/ausencia como criterio cualitativo principal
├─ Efecto anestesia/fisiología
│  ├─ Muy sensible a halogenados y a relajante muscular (a diferencia de SEP y onda D)
│  ├─ TIVA (propofol + opioide) de elección — evitar bolo antes de un test crítico
│  └─ Si se relaja: solo relajación parcial monitorizada (TOF), nunca bloqueo completo
├─ Criterios de alarma
│  ├─ Cualitativo: pérdida/ausencia de respuesta
│  ├─ Umbral: aumento significativo del umbral de estimulación
│  └─ Cuantitativo (más discutido): caída de amplitud — (verificar rango exacto en
│     MacDonald2013 / Legatt2016)
├─ Causas de cambio no quirúrgico
│  ├─ Anestésico: profundización brusca, bolo de relajante
│  ├─ Técnico: desplazamiento de electrodo TES, mal contacto
│  └─ Sistémico: hipotermia, hipotensión
├─ Troubleshooting
│  └─ Descartar anestesia/técnico → correlacionar con onda D (jerarquía onda D > MEP)
│     → comunicar a cirugía
├─ Limitaciones
│  └─ Alta sensibilidad a anestesia/relajación
│     └─ Riesgo de falsos positivos si el plano no está controlado
└─ Referencia
   └─ MacDonald2013 (ASNM) · Legatt2016 (ACNS) · Sloan2012 (relajantes)
Ampliación — profundizar 
PEM/MEP transcraneal — ampliación
├─ El umbral cuantitativo NO es universal
│  ├─ Columna compleja: criterio primario todo-o-nada; en eventos quirúrgicos críticos
│  │  se avisa si hay caída de amplitud del 80% en cualquier músculo
│  └─ Tronco encefálico: el todo-o-nada (habitual en tumor medular) resulta
│     insuficientemente sensible → se prefiere caída de amplitud >50% como predictor
│     de déficit irreversible
├─ Series con sensibilidad/especificidad del MEP muscular
│  ├─ Cavernoma de tronco (Shiban): sensibilidad 33%/especificidad 88% · (Sarnthein):
│  │  sensibilidad 94%/especificidad 74%
│  └─ Cirugía de cordón anclado: sensibilidad 75-100%, especificidad 25-100%,
│     VPP 63-100%, VPN 75-97% — rango amplio según la serie
└─ Parámetro técnico: ISI óptimo del tren
   ├─ ISI ~4 ms permite recuperación completa entre pulsos (duración de pulso 500 µs);
   │  con ISI 2 ms se necesitan 5 estímulos en vez de 3 por recuperación incompleta
   └─ En columna/pediatría: trenes de 5-7 pulsos de 0.5 ms, ISI ~4 ms, repetición
      1-2 Hz, intensidad habitual <200 mA, montaje C1/C2
Referencia: Deletis, cap. 2 pp.27-28 · cap. 22 (Sala/D'Amico/Bricolo) p.305 ·
cap. 27 (Pasquali/Tramontano/Sala) pp.369-370 · cap. 28 (Guiroy/Candocia/Fontes)
pp.388-389
A3

Onda D (D-wave epidural)

Completo Plantilla A 
Onda D (D-wave epidural)
├─ Vía anatómica
│  └─ Activación directa de axones piramidales rápidos del CST
│     └─ Potencial ASINÁPTICO — no depende de transmisión sináptica espinal
├─ Estimulación
│  └─ Igual que MEP (TES transcraneal)
│     └─ Interesa el registro epidural, no la respuesta muscular
├─ Registro / montaje
│  ├─ Electrodo epidural rostral a la lesión (imprescindible)
│  │  └─ ± caudal (compara amplitud proximal/distal)
│  └─ Mantener colocado hasta cierre dural completo
│     └─ El riesgo no termina con la resección: hemostasia y cierre también comprometen
├─ Morfología normal
│  └─ Onda única, robusta, amplitud relativamente estable durante el procedimiento
├─ Efecto anestesia/fisiología
│  └─ Mínimamente afectada por anestésicos y relajantes (potencial asináptico)
│     └─ Su gran ventaja frente al MEP
├─ Criterios de alarma
│  ├─ Declive gradual 20-30% → alerta precoz → protocolo tipo TIP
│  │  └─ TIP: detener disección, irrigar suero templado, ↑PAM ≥80-85 mmHg
│  └─ Caída >50% → predictor de déficit motor PERMANENTE
│     └─ Sobre todo si coincide con pérdida de MEP
├─ Jerarquía diagnóstica (discordancia con MEP)
│  ├─ Onda D estable + MEP perdido → déficit transitorio probable
│  └─ Onda D caída >50% + MEP perdido → déficit permanente probable
├─ Limitaciones
│  ├─ Poco o nada registrable en tumores del cono medular
│  │  └─ Menos axones CST + mayor longitud a nivel torácico bajo
│  └─ Señal global, no lateralizada — no sustituye al MEP para detectar asimetría
└─ Referencia
   └─ Boaro2026 · Costa2015 · MacDonald2013
Ampliación — profundizar 
Onda D — ampliación
├─ Electrodo y colocación (con datos de seguridad)
│  ├─ Catéter JX-330/JX-3002: 3 cilindros de platino-iridio de 3 mm, separados 18 mm,
│  │  doble lumen para lavado con salino
│  ├─ Colocación percutánea con aguja Tuohy 14G en T1-T2, avanzando hasta cervical bajo
│  └─ Series de seguridad: 57 y 16 pacientes sin ninguna complicación (sangrado,
│     infección, punción medular)
├─ Amplitud según nivel y desincronización — más allá de "poco registrable en cono"
│  ├─ Amplitud cervical ≥60 µV vs. torácica ~10 µV con el mismo electrodo; por debajo
│  │  de T10 (Boaro: ~metámero D11) suele no ser registrable con amplitud suficiente
│  └─ Desincronización (tumor intramedular o post-radioterapia medular): fibras CST
│     rápidas conducen a velocidades distintas entre sí → onda D de bajo voltaje/base
│     ancha o no registrable, INCLUSO con MEP muscular presente y sin déficit motor
│     mayor — mecanismo distinto de la ausencia por localización
└─ Correlación pronóstica cuantificada (Tabla 2.1) y su ambigüedad
   ├─ D-wave estable o caída 30-50% + MEP perdido → déficit transitorio · caída >50%
   │  + MEP perdido bilateral → déficit permanente — aplicado en 100 cirugías
   │  consecutivas de tumor intramedular: 0 pacientes con paraplejia postoperatoria
   └─ Ambigüedad del "50%": la misma cifra puede corresponder a una pérdida difusa
      bilateral tolerable O a una pérdida completa unilateral grave — mismo número,
      pronóstico opuesto
Referencia: Deletis, cap. 2 (Deletis), §2.4.1.1-2.4.4 y Tabla 2.1, pp.23-32 ·
Moller2011, cap. 10, pp.215-221 · Boaro2026, sección 2.3

EMG libre (free-running)

Completo Plantilla A 
EMG libre (free-running)
├─ Qué es
│  └─ Registro continuo y pasivo de actividad muscular espontánea con electrodos
│     intramusculares — sin estimulación provocada, "escucha" el músculo en tiempo
│     real durante toda la cirugía
├─ Mecanismo / fisiología
│  ├─ Detecta activación mecánica de la raíz motora (o de fibras del CST en cirugía
│  │  intramedular) por manipulación quirúrgica directa
│  ├─ Zona de mayor vulnerabilidad de la raíz: región de transición central-periférica
│  │  (raicillas sin epineuro/perineuro) y zona hipovascular del tercio proximal-medio
│  └─ En tumores intramedulares: ráfagas por irritación directa del CST, no solo de raíz
├─ Técnica / montaje
│  ├─ Electrodos intramusculares: aguja subdérmica EEG, EMG monopolar, o hilo de
│  │  teflón-plata
│  ├─ Filtro AF 10-30 kHz · filtro BF 2-30 Hz (evitar <50 Hz y >3 kHz)
│  ├─ Barrido 200 ms - 5 s según resolución deseada
│  └─ Línea de base ANTES de empezar cirugía — detecta irritación radicular preexistente
├─ Nomenclatura de la actividad espontánea
│  └─ Prass & Lüders, retomada por Romstöck, Strauss & Fahlbusch 2000 (pares craneales
│     motores en cirugía de ángulo pontocerebeloso)
│     └─ 5 patrones de onda: spikes, bursts, y trenes A, B y C
├─ Spikes
│  └─ Potencial bi/trifásico, un pico grande (≥2000 µV), inicio y fin abruptos,
│     aspecto uniforme en un canal
│     ├─ Pueden contarse miles en una cirugía larga (musculatura mimética)
│     └─ Repetitivos y de baja amplitud → irritación PREEXISTENTE (ondas positivas /
│        fibrilación-like)
├─ Bursts
│  └─ Complejo aislado de spikes superpuestos, forma de huso, hasta varios cientos de
│     ms, picos hasta 5000 µV
│     ├─ Menos frecuentes que los spikes
│     ├─ Típicos al separar plano aracnoideo tumor-nervio o al fresar/descomprimir CAI
│     └─ RARAMENTE indica lesión neural real
├─ Trains (actividad periódica sostenida, dura segundos)
│  ├─ A-train
│  │  ├─ Sinusoidal, inicio brusco, sonido agudo característico por altavoz
│  │  ├─ Amplitud típica 100-200 µV (nunca >500 µV)
│  │  ├─ Frecuencia 60-210 Hz · duración de ms a varios segundos
│  │  ├─ ÚNICO patrón con correlación alta y específica con paresia facial
│  │  │  postoperatoria (serie original: 1 FP y 3 FN sobre 30 pacientes)
│  │  ├─ La frecuencia (<150 vs ≥150 Hz) NO se correlacionó con el grado de deterioro
│  │  ├─ Mecanismo propuesto: símil de descarga repetitiva compleja — fibra muscular
│  │  │  desestabilizada actúa como marcapasos y reactiva efápticamente a las vecinas
│  │  └─ Falso positivo descrito: manipulación del n. intermediario genera A-trains sin
│  │     correlación clínica real (Prell2007)
│  ├─ B-train
│  │  ├─ Secuencia regular o irregular de componentes aislados, intervalo máximo 500 ms,
│  │  │  dura minutos u horas — inicio gradual con spikes/bursts de baja amplitud
│  │  ├─ Subtipos: BS (predominio de spikes) y BB (predominio de bursts)
│  │  └─ Morfológicamente similar a descargas mioquímicas — mecanismo NO aclarado por
│  │     los propios autores; sin correlación pronóstica establecida
│  └─ C-train
│     ├─ Actividad irregular continua, numerosos componentes solapados, amplitud
│     │  distribuida al azar entre 20 y >5000 µV
│     ├─ Aspecto de patrón de interferencia (como contracción voluntaria máxima) pese
│     │  a anestesia profunda estable — los propios autores cuestionan el mecanismo
│     └─ Sin valor predictivo establecido
├─ Patrón fásico vs. tónico (contexto de raíz espinal)
│  ├─ Fásico/burst: potencial único o salva no repetitiva, asíncrona, polifásica →
│  │  trauma directo puntual (tracción, irrigación libre, electrocauterio, torundas)
│  └─ Tónico/train: descargas repetitivas sincrónicas prolongadas (hasta minutos) →
│     tracción/compresión SOSTENIDA → patología más seria, puede ser lesión neural
├─ Contexto de pares craneales (MVD/CPA)
│  └─ fEMG = spikes + bursts + trains combinados
│     └─ Tras irrigar con suero caliente al terminar una MVD es NORMAL ver disparo
│        sostenido SIN significado clínico — no confundir con train patológico
├─ Causas de cambio no quirúrgico
│  └─ Plano anestésico superficial → actividad tipo unidad motora en TODOS los músculos
│     a la vez → sospechar esto antes que patología
├─ Qué hacer
│  ├─ Spike/burst aislado → avisar, vigilar, raramente implica lesión
│  ├─ Train sostenido (o A-train en facial) → avisar de inmediato al cirujano
│  │  (tracción/compresión mantenida)
│  └─ En IMSCT: verificar MEP y onda D antes de continuar tras ráfagas sostenidas
├─ Limitaciones
│  ├─ Señal "a posteriori" — informa de un evento ya ocurrido, no lo previene por sí sola
│  ├─ No localiza con precisión el nivel (para eso, EMG estimulado → A5)
│  └─ En pares craneales da falsos positivos/negativos relevantes → no sustituye a los
│     CoMEPs (A6) como técnica continua más precisa
└─ Referencia
   └─ Leppänen2005 / Leppänen2006 (ASNM) · Romstöck2000 (J Neurosurg 93:586-593,
      clasificación spikes/bursts/A-B-C trains) · Prell2007 (falsos positivos A-train)
      · Boaro2026 (EMG libre en IMSCT)
Ampliación — profundizar 
EMG libre — ampliación
├─ EMG libre en instrumentación pedicular/columna (contexto distinto a pares craneales)
│  ├─ Ráfagas cortas (<1 s) → generalmente no significativas, rara vez con secuela ·
│  │  trenes largos sostenidos (hasta varios minutos) → más serios, asociados a
│  │  tracción/compresión sostenida, mayor probabilidad de daño radicular
│  └─ En cordón anclado, mal predictor aislado: sensibilidad 100% pero especificidad
│     solo 19% — "nunca debe usarse como única modalidad" (cita textual del capítulo)
├─ Contraste de series + valor predictivo temporal
│  ├─ Otra serie de cordón anclado con mejor equilibrio: sensibilidad 87.5%,
│  │  especificidad 83.3%, VPP 87.5%, VPN 83.3%
│  └─ La actividad EMG sostenida suele PRECEDER el cambio en los potenciales evocados
│     — actúa como señal de alarma temprana, se anticipa al MEP en vez de solo
│     acompañarlo
└─ Base anatómica del falso positivo de Prell2007 (ya citado, aquí el mecanismo)
   └─ El n. intermedio lleva fibras motoras que inervan la musculatura perioral facial
      → explica por qué su manipulación genera A-trains sin correlación clínica real
Referencia: Deletis, cap. 10 (Fernández-Conejero) p.138 · cap. 13 (Toleikis)
pp.179-181 · cap. 27 (Pasquali/Tramontano/Sala) pp.369-371

Corticobulbares / MEP de pares craneales (CoMEPs)

En progreso Plantilla A 
Corticobulbares / MEP de pares craneales (CoMEPs)
├─ Qué es / vía anatómica
│  └─ MEP registrado en músculos inervados por pares craneales motores (facial,
│     trigémino motor, hipogloso) tras TES
│     └─ Vía corticobulbar en paralelo a la corticoespinal, pero termina en núcleos
│        de tronco, no en asta anterior medular
├─ Estimulación
│  ├─ TES igual que MEP de miembro
│  │  └─ Montaje C3(+)/Cz(-) para hemisferio izquierdo, C4(+)/Cz(-) para derecho
│  │     (Verst propone C5/C6 por mejor correspondencia con M1 corticobulbar)
│  ├─ Tren corto de 3-5 estímulos, 0.5 ms, ISI 2 ms, 2 Hz, 50-150 mA
│  └─ Estímulo único 90 ms después del tren, como control
│     └─ Solo el TREN activa la vía central; si responde al estímulo ÚNICO, la
│        respuesta es periférica por difusión de corriente
├─ Registro / montaje
│  ├─ Músculos diana: orbicularis oculi/oris y mentalis (facial) · masetero (trigémino
│  │  motor) · lengua (hipogloso)
│  └─ Electrodos de aguja o hook-wire intramusculares
├─ Pitfall característico
│  ├─ El CoMEP de orbicularis oculi puede ser en realidad un Blink Reflex R1
│  │  contaminante — misma latencia, mismo comportamiento
│  │  └─ Origen: la corriente del TES se propaga por cuero cabelludo anterior y activa
│  │     ramas del n. supraorbitario (aferentes trigeminales)
│  ├─ Estrategia: correr Blink Reflex EN PARALELO al CoMEP para diferenciar origen
│  │  cortical real de reflejo trigémino-facial (ver A9)
│  └─ Núcleo facial superior con inervación bicortical → lesión unilateral
│     cortical/subcortical no siempre da parálisis facial superior clínica, aunque
│     el CoMEP cambie
├─ Efecto anestesia/fisiología
│  └─ Igual que MEP miogénico — sensible a halogenados y relajante; TIVA de elección
├─ Criterios de alarma
│  ├─ Misma lógica que MEP de miembro (presencia/ausencia, cambio de amplitud)
│  ├─ Sin umbral numérico consolidado en las fuentes disponibles (verificar)
│  └─ Serie de 100 cirugías de base de cráneo (facial):
│     ├─ Sin cambios → sin déficit
│     ├─ Caída >80% vs. basal → déficit transitorio o ausente
│     └─ Pérdida → parálisis completa permanente (HB IV-VI)
├─ Causas de cambio no quirúrgico
│  └─ Comportamiento errático del CoMEP facial → sospechar activación periférica por
│     corriente dispersa a intensidad sub/cercana al umbral
├─ Troubleshooting
│  └─ Comprobar respuesta a estímulo único vs. tren → correlacionar con Blink Reflex
│     → pausa de manipulación + irrigación templada (puede revertir el bloqueo temporal
│     de conducción del facial)
├─ Limitaciones
│  ├─ Difícil de interpretar en infratentorial si no se corre Blink Reflex en paralelo
│  └─ Sensible a corriente dispersa por cuero cabelludo, no solo a la vía corticobulbar
└─ Referencia
   └─ Deletis&FernándezConejero (Neurophysiology in Neurosurgery 2ª ed., caps. 10 y 17)
      · Téllez2016 (activación periférica confundente)

Reflejos en IONM

En progreso Plantilla A 
Reflejos en IONM
├─ Reflejo H (espinal)
│  ├─ Arco: monosináptico Ia (huso muscular) → motoneurona alfa
│  │  └─ Análogo electrofisiológico del reflejo miotático
│  ├─ Técnica: estimulación submáxima del n. tibial en hueco poplíteo, registro en sóleo
│  └─ Utilidad: integridad del arco lumbosacro / raíz S1
│     └─ Muy sensible a profundidad anestésica y a relajación muscular
│        (verificar umbral de alarma si se usa como monitorización continua)
├─ Blink Reflex (BR)
│  ├─ Arco: aferente V1 (n. supraorbitario) → núcleo espinal del trigémino →
│  │  interneuronas de tronco → núcleo facial (VII) → orbicularis oculi
│  ├─ Componentes: R1 (oligosináptico, ipsilateral, pontino) y R2 (polisináptico,
│  │  bilateral, más tardío, ~30 ms)
│  ├─ Técnica: tren corto de estímulos sobre n. supraorbitario
│  │  └─ Bajo anestesia general se necesita TREN, no estímulo único
│  ├─ Utilidad: monitoriza el arco V-tronco-VII en cirugía de base de cráneo / ángulo
│  │  pontocerebeloso
│  │  └─ Distingue lesión de V1 de lesión del propio nervio facial, en paralelo al
│  │     CoMEP facial (A6)
│  └─ Pitfall: se pierde con planos anestésicos profundos sin que haya lesión
│     └─ Es más sensible al propofol que las otras técnicas → correlacionar con CoMEP
│        antes de dar la alarma
├─ Reflejo bulbocavernoso (RBC)
│  ├─ Arco: aferente pudendo (glande/clítoris, S2-S4) → eferente pudendo (esfínter anal
│  │  externo / bulbocavernoso)
│  ├─ Técnica: estimulación del dorso del pene/clítoris o sonda vesical, registro EMG
│  │  del esfínter anal externo
│  └─ Utilidad: cirugía de cono medular / cola de caballo
│     └─ Integridad del arco sacro, función esfinteriana y sexual
├─ Reflejo maseterino (jaw jerk / H del masetero)
│  ├─ Arco: monosináptico puro V-V
│  │  └─ Aferente propioceptivo del huso del masetero (cuerpo celular en el núcleo
│  │     MESENCEFÁLICO del trigémino, único núcleo sensitivo primario dentro del SNC)
│  │     → motoneurona V3 eferente
│  ├─ Técnica: estimulación percutánea del n. maseterino bajo el arco cigomático,
│  │  0.5 cm anterior a la ATM; registro en masetero y temporal (control)
│  │  └─ Criterios de reflejo: umbral por debajo de la respuesta M directa, y la
│  │     amplitud H disminuye al aumentar la M con estímulos más fuertes
│  ├─ Utilidad: sonda la integridad mesencéfalo-protuberancial de forma pura V-V
│  │  └─ A diferencia del Blink Reflex (V→VII), permite localizar el nivel de lesión
│  │     con más precisión si se corren ambos reflejos juntos
│  └─ Estado: método relativamente nuevo — falta validación quirúrgica y criterios de
│     alarma precisos
├─ Reflejo trigémino-cervical (TCR)
│  ├─ Arco: aferente trigeminal (n. supraorbitario / infraorbitario) → tracto y núcleo
│  │  espinal del trigémino → convergencia con motoneuronas cervicales en asta gris
│  │  C1-C2 → eferente hacia esternocleidomastoideo
│  ├─ Técnica: estimulación de n. supraorbitario o infraorbitario, registro en ECM
│  │  ipsilateral
│  │  └─ Estímulo LARGO (0.5-1.0 ms) favorece su aparición bajo anestesia general
│  ├─ Componentes: latencia corta (~15-19 ms, el más constante bajo anestesia) y
│  │  latencia larga (~65-70 ms, menos constante)
│  └─ Estado: estudio de viabilidad — se obtiene bajo anestesia general en la mayoría,
│     pero su papel práctico en MIO está por establecer
├─ Reflejo trigémino-vocal (TVcR)
│  ├─ Arco propuesto: rama mentoniana del trigémino (V3) → tracto y núcleo espinal del
│  │  trigémino → núcleo ambiguo (vía neuronas reticulares próximas, con o sin paso
│  │  previo por el núcleo del tracto solitario) → n. laríngeo recurrente → músculos
│  │  laríngeos
│  ├─ Técnica: estimulación del n. mentoniano en el foramen mandibular (pulso único o
│  │  tren de 2-4 según profundidad anestésica), registro con electrodo-tubo adhesivo
│  │  sobre cuerda vocal — mismo montaje que el LAR
│  ├─ Componentes: R1 ~30 ms (rango 17-39 ms), bilateral en la mayoría · R2 ~65 ms
│  │  (rango 56-76 ms), presente solo en la mitad, más polifásico
│  ├─ Relación con el LAR: latencia de R1 del TVcR similar a la del R1 del LAR
│  │  └─ Sugiere fibras aferentes de calibre comparable; se propone también un posible
│  │     reflejo trigémino-hipogloso emparentado
│  └─ Estado: descrito en 2025 — demuestra conectividad funcional trigémino-vagal bajo
│     anestesia, pero utilidad clínica intraoperatoria y criterios de alarma AÚN NO
│     establecidos. Hallazgo de investigación, todavía no estándar de MIO
├─ Reflejo laríngeo aductor (LAR) — relacionado, arco vago-vagal
│  ├─ Arco: mucosa supraglótica → rama interna del n. laríngeo superior → n. vago →
│  │  núcleo del tracto solitario → núcleo ambiguo ipsi y contralateral → n. laríngeo
│  │  recurrente → músculos aductores
│  ├─ Técnica: tubo endotraqueal con electrodos de superficie sobre las cuerdas vocales
│  │  └─ Amplitud media en función laríngea normal: 313.5 ± 167.4 µV
│  ├─ Criterio de alarma: caída de amplitud >60% sin recuperación al liberar el tejido
│  │  → alta probabilidad de disfunción de cuerda vocal postoperatoria
│  └─ La LATENCIA (22.4 ± 2.5 ms) es muy variable y NO sirve como parámetro de alarma
└─ Referencia
   └─ Deletis&FernándezConejero (Neurophysiology in Neurosurgery 2ª ed., caps. 15-17:
      Téllez/Ulkatan/Sinclair — LAR; Fernández-Conejero/Deletis — Blink Reflex;
      Ulkatan2017 — masetero) · LimaMedeiros2024 (TCR) · Urriza2025 (TVcR)

Reflejos en IONM — ampliación
├─ LAR — fisiología reformulada (no clásica)
│  ├─ R1 es BILATERAL (iR1 ipsilateral + cR1 contralateral), no unilateral como se
│  │  pensaba — elicitable en el 100% de los pacientes bajo TIVA a cualquier
│  │  profundidad anestésica
│  └─ R2 menos fiable: solo en un subgrupo bajo TIVA y tiende a desvanecerse durante

│     durante >90 s
├─ LAR — datos detrás del criterio ">60%"
│  ├─ Serie de 134 nervios en riesgo (cirugía tiroides/paratiroides): decremento
│  │  mediano 16.5% (máx. 56.4%) con función laríngea normal · en los 6 con lesión
│  │  inesperada del n. laríngeo recurrente, el decremento fue SIEMPRE >60%

│     actividad de campo lejano (músculo contralateral) aporta 50-100 µV
└─ Reflejo maseterino — serie de viabilidad (10 pacientes)
   ├─ H-reflejo fiable en masetero 7/10 (70%) y en temporal 3/4 (75%)

   │  paciente despierto, activa tónicamente aferentes Ia del huso)

Fosa posterior avanzado con criterios de troncoencefálico

En progreso Plantilla B 
Fosa posterior avanzado — criterios troncoencefálicos
├─ Modalidades combinadas
│  ├─ Basal SEP + BAEP + MEP corticoespinal/corticobulbar antes del abordaje
│  ├─ Mapeo del suelo del IV ventrículo antes de la incisión (colículo facial, trígono
│  │  del hipogloso)
│  └─ EMG libre continuo de pares craneales + reflejos de tronco (Blink Reflex, LAR,
│     maseterino) según el nivel afectado
│     └─ "Monitorizar solo BAEP, solo SEP o solo MEP puede ser engañoso — la integración
│        de todas las modalidades da la mejor imagen de lo que ocurre en el tronco"
├─ Fases del procedimiento
│  ├─ Mesencéfalo: vía infratentorial-supracerebelosa (tectal), transtentorial occipital,
│  │  o pterional transilviana
│  ├─ Protuberancia: retrosigmoidea (ventrolateral) o suboccipital transventricular
│  │  (dorsal), semisentada
│  ├─ Bulbo/unión cervicomedular: suboccipital baja ± laminotomía cervical, mielotomía
│  │  medial o dorsolateral
│  └─ Postoperatorio: extubación guiada por CoMEP intraoperatorio, UCI ≥24h, TC a 3-4h
├─ Riesgo neurológico específico
│  ├─ Núcleos motores de pares craneales — mesencéfalo (III/IV), protuberancia (V/VI/VII),
│  │  bulbo (IX-XII) — y las vías largas que los atraviesan
│  ├─ Momento de mayor riesgo de dañar núcleos: cerca del final de la resección, cuando ya
│  │  están desplazados ventralmente por el tumor
│  └─ Riesgo autonómico por manipulación/estimulación del suelo del IV ventrículo
│     └─ Descrito: PVC transitoria y ↑TA reversibles durante mapeo de IX/X (caso humano);
│        en animal, >2 mA → bradicardia/hipotensión transitoria, 3 mA → apnea (verificar
│        extrapolación directa a la práctica clínica humana)
├─ Posicionamiento
│  ├─ Semisentada: estándar para tumores dorsales de protuberancia/mesencéfalo ventral
│  │  por vía transcerebelomedular (cabeza flectada, expone fosa romboidea sin dividir
│  │  el vermis)
│  ├─ Electrodos SEP (CP5/6, T3/4) menos afectados por aire intracraneal tras apertura
│  │  dural en sedestación que otras derivaciones
│  └─ Monitorización de embolismo aéreo venoso (Doppler precordial, ETCO2) (verificar —
│     no encontrado en las fuentes del proyecto, es manejo anestésico estándar de la
│     sedestación pero falta cita propia)
├─ Jerarquía de alarma
│  ├─ El criterio "todo o nada" de médula espinal es insuficiente a nivel de tronco →
│  │  usar variación de amplitud (umbral práctico 50-80%)
│  ├─ BAEP: ↓50% amplitud onda V + ↑latencia >0.5 ms = alarma · abolición de onda V →
│  │  ~30% de esos pacientes con hipoacusia postoperatoria
│  ├─ BAEP diferencial: peak III estable + peak V cambia → sugiere afectación de tronco o
│  │  isquemia, no lesión periférica del nervio auditivo
│  ├─ MEP/SEP con sensibilidad-especificidad variable entre series (Shiban: MEP 33%/88% ·
│  │  Sarnthein: MEP 94%/74%) — no hay criterio único validado a nivel de tronco
│  └─ Se añade monitorización según el nivel: unión cervicomedular → pares bajos (IX-XII)
│     · pontino → SEP+BAEP+mapeo suelo IV ventrículo · mesencefálico → + pedúnculo cerebral
├─ Protocolo de reacción
│  ├─ Pérdida de Blink Reflex + decremento simultáneo de CoMEP → pausar manipulación
│  │  (serie: 8/21 pacientes con esa combinación, 5 recuperaron tras pausar, 3 no y
│  │  tuvieron déficit)
│  ├─ LAR: caída >50% → avisar y liberar tejido · caída >60% sin recuperación → alta
│  │  probabilidad de disfunción vagal/laríngea permanente
│  └─ BAEP: mantener registro hasta el cierre de PIEL, no solo hasta cierre dural (caso
│     descrito de pérdida auditiva no detectada por suspender el registro antes de tiempo)
├─ Técnica de mapeo específica
│  ├─ Suelo del IV ventrículo: sonda monopolar de mano (punta 0.75-1 mm), onda cuadrada
│  │  monofásica 0.2 ms, 1 Hz (hasta 4 Hz), intensidad de búsqueda 2.0 mA → reducir hasta
│  │  umbral real (0.2-2.0 mA según distancia núcleo-lesión)
│  ├─ Márgenes de seguridad: intensidad máxima 2 mA, duración máxima 400 µs, frecuencia
│  │  máxima 10 Hz
│  ├─ Localización: triángulo suprafacial ≈20 mm del obex y 2-4 mm de línea media ·
│  │  triángulo infrafacial 7-16 mm del obex, 2-4 mm de línea media
│  ├─ Técnica de barrido: la sonda no permanece >5 s en un punto, se desplaza cada 1 mm
│  ├─ Registro: orbicularis oculi/oris (VII) · borde lateral de la lengua (XII) · pared
│  │  faríngea posterior/cricotiroideo (IX/X, no rutinario)
│  └─ Momento del mapeo según localización: tumores pontinos → mapeo de CN VII posible y
│     necesario ANTES de resecar · tumores bulbares/cervicomedulares → mapeo de núcleos
│     bajos (IX/X/XII) casi siempre solo AL FINAL, en el fondo de la cavidad tumoral
└─ Referencia
   └─ Deletis (Neurophysiology in Neurosurgery 2ª ed. — cap. 11 Morota/Deletis/Epstein:
      mapeo suelo IV ventrículo · cap. 21 Szelényi/Neuloh: BAEP · cap. 22 Sala/D'Amico/
