# C3 — TIVA y farmacología anestésica en MIO

```
TIVA y farmacología anestésica en MIO
├─ Concepto central
│  └─ La anestesia general persigue 4 metas conductuales — amnesia, inconsciencia,
│     antinocicepción, inmobilidad — logradas combinando fármacos con mecanismos
│     distintos y efectos aditivos/sinérgicos. El reto específico de MIO es lograr las
│     4 metas manteniendo señales monitorizables, sobre todo con mMEP
├─ A qué modalidades afecta
│  └─ Clasificación en 4 grupos según sensibilidad a halogenados (HAA) y a bloqueo
│     neuromuscular (NMB):
│     · Grupo 1 (insensible a ambos): BAEP, onda D, SEP subcortical (A3, A7)
│     · Grupo 2 (sensible a HAA, no a NMB): SEP cortical, EEG (A1, A8)
│     · Grupo 3 (sensible a NMB, no a HAA): EMG libre y estimulado (A4, A5 — ver C4)
│     · Grupo 4 (sensible a ambos, el más exigente): mMEP (A2, A6)
├─ Parámetros clave
│  ├─ Halogenados (isoflurano/sevoflurano/desflurano): SEP cortical cae 0.5-1 MAC;
│  │  mMEP se pierde por encima de 0.5 MAC, con curva dosis-efecto muy pronunciada
│  │  ("todo o nada" cerca del umbral)
│  ├─ Propofol: pérdida de mMEP por encima de 60-70% de dosis; efecto aditivo/
│  │  sinérgico con halogenados; curva dosis-respuesta más plana (más fácil encontrar
│  │  dosis que preserve señal)
│  ├─ Etomidato: efecto PARADÓJICO — aumenta amplitud de SEP cortical y mMEP a dosis
│  │  bajas-moderadas (desinhibición cortical), deprime a dosis altas (bifásico); uso
│  │  reducido por riesgo de supresión adrenal
│  ├─ Ketamina: aumenta amplitud de SEP, mMEP y reflejo H (antagonista NMDA,
│  │  excitatoria); a dosis altas bloquea conducción axonal espinal — combinación
│  │  ketamina+opioide es adyuvante valioso de TIVA cuando hay que preservar mMEP
│  ├─ N2O: efecto aditivo/sinérgico NEGATIVO con halogenados en SEP
│  ├─ Opioides: mínimo efecto en infusión continua sobre todas las modalidades; bolo
│  │  produce depresión transitoria — de elección para antinocicepción por esto
│  └─ Dexmedetomidina: mínimo efecto en SEP; puede inhibir mMEP con infusión
│     prolongada/dosis altas; NO es amnésico fiable por sí sola (necesita midazolam
│     adyuvante) · midazolam: amnésico excelente, depresión leve de SEP a dosis de
│     inducción
├─ Aplicación práctica
│  └─ TIVA estándar para mMEP: propofol + opioide en infusión continua, evitando
│     bolos antes de un test crítico (A2) · si se usa halogenado, limitar a ≤0.5 MAC ·
│     cualquier cambio de plano anestésico debe hacerse TEMPRANO, antes de la ventana
│     de riesgo neural, y mantenerse estable durante ella
├─ Errores frecuentes
│  ├─ Bolo de cualquier agente justo antes de un test crítico — mimetiza caída
│  │  patológica de amplitud
│  ├─ Usar halogenado >1 MAC cuando se necesita SEP cortical
│  └─ Confiar en dexmedetomidina sola para mMEP en infusión prolongada, o asumir
│     amnesia garantizada sin adyuvante amnésico
├─ Conexión con otros nodos
│  └─ A1 (efecto anestesia SEP), A2-Ampliación ("TIVA de elección", aquí la base
│     farmacológica completa), A4/A5 (Grupo 3, sensibles a NMB → ver C4), A8 (EEG,
│     Grupo 2), C4 (la otra cara farmacológica: relajación)
└─ Referencia
   └─ Deletis, cap. 40 (Sloan & Koht), "Principles of anesthesia", §40.1-40.5,
      Tabla 40.1, Figs. 40.1-40.5, pp.567-576 · Moller2011, cap. 16, "Anesthesia and
      Its Constraints in Monitoring Motor and Sensory Systems", pp.321-327
```
