# PE-M2 — Estimulación eléctrica transcraneal: técnica y monitorización intraoperatoria

```
Estimulación eléctrica transcraneal (TCES)
├─ LAS CUATRO TÉCNICAS DE REGISTRO DE PEM, Y POR QUÉ SOLO UNA SIRVE EN QUIRÓFANO
│  ├─ 1. Estimulación medular ROSTRAL con registro desde nervio periférico
│  ├─ 2. Estimulación MAGNÉTICA transcraneal
│  ├─ 3. Estimulación ELÉCTRICA transcraneal (TCES) — la de este tema
│  └─ 4. Estimulación eléctrica DIRECTA de la corteza motora, reservada a cirugías próximas a
│     la región perirrolándica
├─ POR QUÉ SE ABANDONÓ LA ESTIMULACIÓN MEDULAR ROSTRAL — el razonamiento completo
│  ├─ La introdujo Owen y col. (1988) para monitorizar la integridad de las vías motoras
│  │  descendentes de la médula, estimulando la médula rostral y registrando de los nervios
│  │  periféricos de las piernas. Después se demostró que el procedimiento FALLABA en detectar
│  │  el daño de las vías motoras
│  ├─ EL PROBLEMA DE FONDO: la estimulación no solo activa ORTODRÓMICAMENTE las vías motoras
│  │  descendentes, sino también ANTIDRÓMICAMENTE la columna dorsal, es decir la vía sensitiva
│  │  ├─ La asimetría que lo decide: las fibras de la columna dorsal son continuación DIRECTA
│  │  │  de las fibras sensitivas del nervio periférico, SIN sinapsis interpuesta
│  │  └─ Mientras que las fibras corticoespinales hacen contacto SINÁPTICO con la motoneurona
│  │     inferior, cuyos axones continúan como fibras motoras en el nervio periférico
│  ├─ CONSECUENCIA: los llamados "potenciales evocados neurogénicos descendentes" (DNEP)
│  │  registrados desde el nervio periférico se deben ESENCIALMENTE a la conducción antidrómica
│  │  por la columna dorsal (Toleikis y col., 2000). Y bajo anestesia, que deprime la
│  │  transmisión sináptica, la activación del corticoespinal puede no contribuir de forma
│  │  significativa al potencial registrado
│  │  └─ Confirmación clínica: se publicaron FALSOS NEGATIVOS con estimulación medular rostral
│  │     —déficits motores desarrollados pese a respuestas preservadas— (Minahan y col., 2001)
│  ├─ ¿Y REGISTRAR DEL MÚSCULO en lugar del nervio? Tampoco resuelve el problema: las
│  │  motoneuronas espinales reciben input sináptico no solo de las fibras corticoespinales
│  │  sino también input EXCITATORIO de las aferentes primarias al ascender por las columnas
│  │  dorsales, de modo que la respuesta muscular puede reflejar ambas cosas (Su y col., 1992)
│  ├─ LA REGLA QUE SE DEDUCE, y que justifica toda la técnica transcraneal: la ÚNICA forma de
│  │  monitorizar selectivamente las vías motoras es estimular el neuroeje ROSTRAL a los
│  │  núcleos sensitivos del bulbo, porque las sinapsis de esos núcleos impiden
│  │  INEQUÍVOCAMENTE la transmisión retrógrada por la columna dorsal
│  └─ MATIZ HONESTO: la popularidad de la estimulación medular rostral ha caído mucho, pero
│     algunos la siguen usando registrando sobre el ciático en la fosa poplítea con buen
│     resultado postquirúrgico (Emerson, 2012). Sus dos argumentos
│     ├─ Permite el BLOQUEO NEUROMUSCULAR, lo que mejora la calidad del SEP
│     └─ Y aunque SEP y DNEP monitoricen vías espinales similares, miden señales DISTINTAS con
│        electrodos distintos, lo que aporta cierto grado de REDUNDANCIA
├─ Fisiología de la respuesta — lo imprescindible para manejar los parámetros
│  ├─ La TCES por electrodos C1 y C2 del sistema 10-20 genera corrientes orientadas
│  │  RADIALMENTE, que estimulan preferentemente las células piramidales de la corteza motora y
│  │  producen así una activación eficaz de las fibras corticoespinales y corticobulbares
│  │  descendentes
│  ├─ El ÁNODO es el electrodo bajo el que se estimula la corteza —al revés que en el nervio
│  │  periférico, donde estimula el cátodo—, y en las derivaciones que se escriben abajo el
│  │  PRIMER electrodo es siempre el ánodo
│  ├─ Cada pulso genera una onda D (activación DIRECTA, no sináptica, de las piramidales)
│  │  seguida de ondas I (activación indirecta, transináptica, vía interneuronas corticales)
│  ├─ POR QUÉ HACE FALTA UN TREN: bajo anestesia, un pulso único no logra despolarizar la
│  │  motoneurona inferior, porque la anestesia deprime tanto las sinapsis corticales como las
│  │  sinapsis de las fibras corticoespinales sobre esa motoneurona. El resultado es onda D
│  │  registrable en la médula y NINGUNA respuesta muscular
│  │  └─ El tren produce una onda D por cada pulso, seguida de múltiples ondas I, y esa serie
│  │     consigue la SUMACIÓN TEMPORAL de potenciales postsinápticos excitatorios que
│  │     despolariza la motoneurona inferior
│  └─ Y la respuesta es MOTORA PURA: la descarga sensitiva antidrómica que también genera el
│     estímulo se disipa a nivel TALÁMICO, en la sinapsis entre las fibras lemniscales y las
│     neuronas talámicas
├─ ANESTESIA — el requisito previo a cualquier parámetro
│  ├─ La anestesia TOTAL INTRAVENOSA es la más apropiada y el patrón oro para registrar PEM
│  │  musculares: infusiones de propofol y opioide, evitando bolos en lo posible
│  ├─ Los agentes INHALATORIOS son subóptimos por cuatro razones encadenadas: causan mayor
│  │  supresión de la transmisión sináptica, reducen la excitabilidad de la motoneurona
│  │  inferior, producen variabilidad marcada del PEM muscular, y obligan habitualmente a
│  │  estimulación de alta intensidad
│  │  └─ Y esa gran variabilidad de respuesta lleva a mayor incidencia de cambios FALSOS
│  │     POSITIVOS
│  ├─ Aviso que se pasa por alto: incluso dosis PEQUEÑAS de anestésico gaseoso usadas en la
│  │  INDUCCIÓN pueden dar PEM musculares pobres durante un tiempo inusualmente largo, antes de
│  │  que su efecto se disipe y las respuestas se hagan consistentes de trial a trial
│  └─ BLOQUEO NEUROMUSCULAR: debe omitirse por completo. Algunos prefieren un bloqueo PARCIAL
│     para "limpiar" el SEP monitorizado a la vez, pero un nivel de bloqueo parcial es muy
│     difícil de mantener — y la calidad del SEP debería ser óptima incluso sin relajantes si
│     se emplean técnicas adecuadas
├─ Estimulación: parámetros
│  ├─ NÚMERO DE PULSOS: típicamente de 3 a 9, y un buen punto de partida son CINCO
│  │  ├─ En pacientes con déficit motor puede hacer falta un número MAYOR
│  │  └─ Y en algunos bastan TRES, particularmente para los PEM corticobulbares
│  ├─ INTERVALO INTERESTÍMULO (ISI): ha variado entre 1 y 5 ms, y el compromiso tiene dos
│  │  extremos malos
│  │  ├─ Si es demasiado CORTO, las ondas D posteriores al primer pulso se ATENÚAN por el
│  │  │  periodo REFRACTARIO de las fibras corticoespinales, y además hace falta una intensidad
│  │  │  de estímulo mucho más alta
│  │  │  └─ Contrapunto que hay que conocer: la amplitud del PEM muscular es, sin embargo,
│  │  │     MAYOR con estimulación de alta intensidad e ISI corto
│  │  ├─ Si es demasiado LARGO, se impide una sumación temporal eficaz en la motoneurona
│  │  │  inferior
│  │  └─ ÓPTIMO PRÁCTICO: un ISI de 3-4 ms parece el mejor en la mayoría de procedimientos, y
│  │     asegura PEM musculares consistentes con menor intensidad de estímulo
│  ├─ DURACIÓN DE PULSO — donde la práctica va por detrás de la evidencia
│  │  ├─ En Estados Unidos los estimuladores usan 0,05 ms o 0,075 ms (50 o 75 microsegundos),
│  │  │  como en el trabajo original de Merton y Morton (1980). Algunos han usado pulsos más
│  │  │  largos, de 0,5 ms
│  │  ├─ El compromiso: los pulsos CORTOS exigen corriente de intensidad mucho mayor; los
│  │  │  LARGOS requieren intensidad relativamente menor para obtener PEM musculares fiables
│  │  ├─ El objetivo último es usar parámetros que entreguen la MENOR ENERGÍA necesaria para
│  │  │  generar PEM consistentes, siendo la energía E = I² × D × R (I corriente, D duración,
│  │  │  R resistencia)
│  │  ├─ Abalkhail y col. (2017) demostraron experimentalmente que la energía entregada es
│  │  │  MÍNIMA con una duración de pulso de 0,2 ms y un ISI de 3 o 4 ms
│  │  └─ Y aquí está el desfase: 0,2 ms TODAVÍA NO está disponible en los estimuladores
│  │     actuales de monitorización intraoperatoria, aunque hay trabajo en curso sobre nueva
│  │     instrumentación que ampliará las opciones
│  └─ INTENSIDAD DE ESTÍMULO: la TCES se entrega con estimulador de VOLTAJE CONSTANTE, y el
│     voltaje necesario varía según la impedancia tisular y la derivación empleada
│     ├─ Rango que da el texto del capítulo: habitualmente 100-500 V, con intensidad MAYOR
│     │  necesaria en NIÑOS
│     └─ ⚠️ DISCREPANCIA INTERNA de la fuente: la Tabla 5.2 del mismo capítulo cifra la
│        intensidad en 250-750 V, mientras que el texto dice 100-500 V. La regla operativa que
│        ambos comparten es la misma —la suficiente para producir PEM consistentes— pero
│        conviene saber que el rango numérico no coincide **(verificar sobre el original)**
├─ ELECTRODOS Y DERIVACIONES DE ESTIMULACIÓN
│  ├─ ELECTRODOS: se colocan en el scalp sobre la corteza motora usando el array C3, C1, Cz,
│  │  C2, C4 y Fz del sistema 10-10
│  │  ├─ Otros usan sitios situados 1 cm ANTERIORES a esos, designados M3, M1, Mz, M2 y M4 para
│  │  │  especificarlos como sitios MOTORES. Ambas colocaciones son igual de eficaces
│  │  ├─ El electrodo ANÓDICO es el sitio de estimulación cortical
│  │  └─ Tipo: copas de EEG, y agujas o SACACORCHOS. Los sacacorchos tienen las impedancias
│  │     MÁS BAJAS y es improbable que se desprendan durante la cirugía
│  ├─ (i) HEMISFÉRICA — C3-Cz o C4-Cz, con el primer electrodo como ánodo
│  │  ├─ Estimula la corteza motora de UN lado, con PEM registrados en el lado contralateral
│  │  └─ Su utilidad propia: CONFIRMAR LA DECUSACIÓN MOTORA. Si las vías motoras son
│  │     congénitamente NO cruzadas, se eliciten respuestas IPSILATERALES
│  ├─ (ii) PARASAGITAL INTERHEMISFÉRICA — C1-C2 o C2-C1
│  │  └─ Es la derivación MÁS USADA en monitorización que requiera PEM de brazo y pierna
│  ├─ (iii) LATERAL INTERHEMISFÉRICA — C3-C4 o C4-C3
│  │  ├─ Permite que pase MÁS corriente por el cerebro y que se derive MENOS por el scalp que
│  │  │  con las parasagitales. La corriente llega además más PROFUNDA, hasta la cápsula
│  │  │  interna o incluso por debajo con estimulación intensa
│  │  ├─ Como se estimulan a la vez las áreas motoras del brazo y de la pierna, se obtienen PEM
│  │  │  robustos de músculos de las cuatro extremidades
│  │  ├─ PRECIO QUE SE PAGA: se asocia a mayor incidencia de movimientos del paciente, y es la
│  │  │  ÚNICA derivación con lesiones por MORDEDURA descritas
│  │  └─ Por eso se recomienda SOLO si la parasagital C1/C2 falla en proporcionar PEM óptimos
│  └─ (iv) LÍNEA MEDIA — Cz-Fz
│     ├─ Elicita PEM simétricos de AMBAS piernas, pero NO consigue respuestas adecuadas de la
│     │  musculatura de las extremidades superiores
│     └─ Puede ser IDEAL para cirugía de fosa posterior realizada en posición SENTADA
├─ Registro y montaje
│  ├─ MÚSCULOS: la mayoría usa electrodos de AGUJA en los músculos diana
│  │  ├─ Habitualmente NO hace falta promediar, aunque algunos usan unos pocos barridos
│  │  │  superpuestos para asegurar que la respuesta es reproducible
│  │  ├─ Extremidades SUPERIORES: deltoides, bíceps y tríceps, musculatura del antebrazo y
│  │  │  abductor corto del pulgar; como alternativa, primer interóseo dorsal o abductor del
│  │  │  meñique
│  │  ├─ Extremidades INFERIORES: cuádriceps, tibial anterior, gastrocnemio medial y abductor
│  │  │  del hallux
│  │  └─ POR QUÉ SE PREFIEREN LOS DISTALES: la inervación corticoespinal es más PROFUSA para
│  │     los músculos distales, y además los distales tienden a producir PEM más CONSISTENTES
│  ├─ PARÁMETROS DE REGISTRO MUSCULAR: tiempo de análisis de 100 ms, filtro de baja frecuencia
│  │  de 10-100 Hz y filtro de alta frecuencia de 1,5-3,0 kHz
│  └─ ONDA D — solo unos pocos centros la monitorizan
│     ├─ Electrodos EPIDURALES colocados por el cirujano tras la apertura, o por el
│     │  anestesiólogo antes de la cirugía
│     └─ Parámetros típicos: base de tiempos de 10-20 ms, promedios de 5 a 20 barridos, filtro
│        de baja frecuencia de 0,2-2 Hz y de alta frecuencia de 1,5-3 kHz
├─ Criterios de alarma
│  ├─ ONDA D — el criterio es sencillo, y conviene entender POR QUÉ lo es
│  │  ├─ Tres propiedades la hacen fiable: es NO SINÁPTICA, tiene relación LINEAL con la
│  │  │  intensidad del estímulo, y muestra POCA variabilidad intraoperatoria
│  │  └─ De ahí el criterio bien aceptado: caída de amplitud MAYOR DEL 50%
│  └─ PEM MUSCULAR — el criterio es difícil, y por las razones inversas
│     ├─ Son POLISINÁPTICOS (más afectados por anestésicos y factores sistémicos), NO lineales,
│     │  y muestran variabilidad muy grande durante la monitorización. Por eso es difícil fijar
│     │  un basal apropiado contra el que valorar el cambio
│     ├─ CRITERIO DEFINITIVO, en el que todo el mundo coincide: la DESAPARICIÓN TOTAL del PEM
│     │  muscular
│     │  └─ Y el dato que le da valor: una desaparición PERSISTENTE pese a las medidas
│     │     correctoras apropiadas —irrigación con suero, subir la tensión arterial, deshacer
│     │     algún aspecto de la cirugía, papaverina— se CORRELACIONA con el desarrollo de un
│     │     déficit motor nuevo tras la cirugía
│     ├─ CRITERIO "BLANDO": una reducción de amplitud mayor del 80% se ha considerado un
│     │  criterio posible, pero debe usarse SOLO si excede el grado de variabilidad ESPONTÁNEA
│     │  observada antes del momento del cambio
│     ├─ CRITERIO MENOS USADO: una elevación del umbral de 100 V o más. Su problema es que
│     │  siempre existe alguna variabilidad de umbral, de modo que su uso SÍ aumenta los
│     │  resultados falsos positivos
│     └─ CRITERIO CUESTIONABLE: la simplificación de la morfología del PEM
├─ ONDA D FRENTE A PEM MUSCULAR — las nueve diferencias que deciden cuál usar
│  ├─ 1. LOGÍSTICA: el registro epidural exige una incisión quirúrgica adicional hecha por el
│  │  cirujano; los PEM musculares los registra fácilmente el técnico con agujas
│  ├─ 2. ANESTESIA: para el PEM muscular hay que evitar relajantes tras la inducción y se
│  │  prefiere la anestesia intravenosa total a los halogenados — y con ese régimen los
│  │  movimientos inducidos son una preocupación que obliga a cronometrar el estímulo. Para la
│  │  onda D pueden usarse relajantes y las opciones anestésicas son mucho más liberales
│  ├─ 3. ESTÍMULO: el PEM muscular requiere tren de pulsos; para la onda D basta el pulso
│  │  ÚNICO. Como la onda D es de amplitud relativamente baja, su registro puede requerir unos
│  │  pocos promedios (20 o menos)
│  ├─ 4. VARIABILIDAD: como la población de motoneuronas espinales activada VARÍA de un tren al
│  │  siguiente, el PEM muscular muestra gran variabilidad de amplitud y de complejidad — por
│  │  eso solo una atenuación marcada (la ausencia) se acepta como cambio significativo. La
│  │  onda D es muy consistente y robusta, y por eso basta un cambio del 50%
│  ├─ 5. LÍMITE ANATÓMICO DE LA ONDA D: su amplitud DECRECE desde la región cervical baja hasta
│  │  la torácica baja, por la disminución progresiva del número de axones corticoespinales.
│  │  Por eso suele ser difícil de registrar por debajo de la región torácica media, y la
│  │  monitorización con onda D es habitualmente INADECUADA por debajo del nivel espinal T10.
│  │  El PEM muscular no tiene esa limitación
│  ├─ 6. QUÉ EXPLORA CADA UNO: el PEM valora la integridad del tracto corticoespinal, de las
│  │  motoneuronas espinales Y de estructuras neurales periféricas; la onda D monitoriza SOLO
│  │  el tracto corticoespinal
│  │  └─ Consecuencia clínica: como las motoneuronas espinales son MÁS SENSIBLES A LA ISQUEMIA
│  │     que los tractos de fibras, el PEM muscular puede ser más sensible para detectar lesión
│  │     isquémica de esas motoneuronas. Y además puede mostrar disfunción de raíces y de
│  │     nervios periféricos
│  ├─ 7. TUMOR MEDULAR: en tumores de la médula la onda D puede ser NO registrable por debajo
│  │  de la lesión, por conducción ASINCRÓNICA en los tractos corticoespinales, aunque los PEM
│  │  musculares sigan siendo registrables y permitan monitorizar durante la resección
│  ├─ 8. LATERALIDAD: la onda D epidural NO puede distinguir entre lesión medular unilateral y
│  │  bilateral, cosa que el PEM muscular sí puede
│  └─ 9. PREFERENCIA Y COMBINACIÓN: por su facilidad de registro, el PEM muscular es la técnica
│     preferida en Estados Unidos; su desventaja mayor son las limitaciones de relajante y de
│     agente anestésico
│     └─ Pocos han usado los DOS métodos juntos para valorar mejor la integridad tanto de las
│        vías piramidales como de las motoneuronas espinales. La monitorización combinada es
│        particularmente útil en la resección de tumor intramedular y en la reparación de
│        aneurisma de aorta descendente, donde la afectación DISOCIADA de las dos respuestas
│        puede aportar información pronóstica valiosa
├─ Seguridad
│  ├─ La TCES está establecida como procedimiento SEGURO, y las complicaciones serias son muy
│  │  raras. El daño cerebral y el fenómeno de kindling son altamente improbables
│  ├─ CRISIS inducidas por TCES en tren: RARAS, 0,03%, por lo breve del estímulo y por la
│  │  anestesia
│  │  ├─ La historia de epilepsia podría predisponer, pero los estudios NO lo han apoyado
│  │  └─ Generalmente la TCES se considera una contraindicación en epilepsia crónica, pero se
│  │     ha utilizado en pacientes espinales de muy alto riesgo sin inducir crisis
│  ├─ MORDEDURAS (laceraciones de lengua o labio, y raras fracturas mandibulares): son la
│  │  complicación MÁS COMÚN, con incidencia estimada del 0,2%
│  │  ├─ Y el dato de montaje: TODOS los casos publicados han ocurrido con la derivación
│  │  │  estimulante C3/C4
│  │  └─ Son prevenibles usando bloques de mordida BLANDOS y limitando la estimulación C3/C4
│  │     únicamente a cuando sea absolutamente imprescindible
│  ├─ Arritmia cardiaca rara y despertar intraoperatorio: pueden ser COINCIDENTES
│  ├─ Quemaduras menores del scalp y complicaciones de los electrodos epidurales: extremadamente
│  │  raras
│  ├─ LESIONES POR MOVIMIENTO inducido por el tren: es una preocupación quirúrgica reconocida,
│  │  aunque no se han publicado eventos adversos. Ante movimientos significativos hay que
│  │  estimular guiándose por el VÍDEO del campo quirúrgico y por la comunicación con el
│  │  cirujano
│  └─ CONTRAINDICACIONES RELATIVAS: epilepsia, lesiones corticales, defectos craneales de la
│     convexidad, hipertensión intracraneal, cardiopatía, medicación o anestésicos
│     proconvulsivantes, electrodos o shunts intracraneales, marcapasos cardiacos y otros
│     dispositivos biomédicos implantados
│     └─ Pero muchos centros han monitorizado con TCES a numerosos pacientes con esas
│        condiciones sin efectos indeseados
├─ APLICACIÓN INTRAOPERATORIA — cómo se combina con el SEP
│  ├─ La aplicación mayor de los PEM por TCES es la monitorización durante cirugía espinal y de
│  │  fosa posterior, para evaluar la integridad de las vías motoras descendentes. En Estados
│  │  Unidos se aprobó en 2002 y su uso ha crecido de forma continua en las dos décadas
│  │  siguientes
│  ├─ LA DIFERENCIA DE CADENCIA, que es lo que hay que interiorizar: el SEP se monitoriza de
│  │  forma más o menos CONTINUA durante la parte crítica de la cirugía, mientras que los PEM se
│  │  adquieren PERIÓDICAMENTE, por instrucción y con conocimiento del cirujano
│  │  └─ La razón es evitar cualquier compromiso por movimiento inducido mientras el cirujano
│  │     está operando activamente
│  ├─ COMPARACIÓN SEP FRENTE A PEM, punto por punto
│  │  ├─ ANESTESIA: el SEP es mucho menos restrictivo; el PEM, mucho más
│  │  ├─ BLOQUEO NEUROMUSCULAR: permitido en el SEP —donde incluso puede MEJORAR la calidad—,
│  │  │  evitado total o parcialmente en el PEM
│  │  ├─ MOVIMIENTO DEL PACIENTE: ninguno con SEP, precisamente por el uso de relajante;
│  │  │  posible con TCES
│  │  ├─ FRECUENCIA: el SEP puede monitorizar casi continuamente durante las partes críticas;
│  │  │  el PEM se usa de forma INTERMITENTE por los posibles movimientos
│  │  ├─ CRITERIOS DE ALARMA: muy bien definidos en SEP, MENOS bien definidos en PEM
│  │  ├─ TIEMPO POR TEST: 0,5-2 minutos para el SEP, porque requiere de 100 a 500 promedios;
```
