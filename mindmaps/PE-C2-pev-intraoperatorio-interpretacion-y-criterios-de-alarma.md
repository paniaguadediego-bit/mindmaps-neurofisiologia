# PE-C2 — PEV intraoperatorio: interpretación, criterios de alarma y rendimiento

```
PEV intraoperatorio: interpretación, criterios de alarma y rendimiento
├─ La pregunta que responde
│  ├─ ¿Está la maniobra quirúrgica que se está haciendo AHORA comprometiendo la vía visual
│  │  anterior, de forma todavía reversible?
│  └─ Contexto: cirugía de lesiones paraselares, intraorbitarias y aneurismas de carótida
│     interna, con PEV por flash bajo TIVA, LED sobre párpado cerrado y ERG simultáneo
├─ QUÉ SE MIDE
│  ├─ La onda del PEV intraoperatorio está compuesta por varios picos negativos y positivos
│  ├─ La AMPLITUD del PEV se define como la diferencia de voltaje entre el pico en torno a
│  │  75 ms y el pico de mayor amplitud en torno a 100 ms — medición pico-pico
│  │  └─ Aviso de nomenclatura: el capítulo etiqueta esos dos picos como "N1" (el de
│  │     ~75 ms, al que llama positivo) y "P2" (el de ~100 ms, al que llama negativo). Las
│  │     etiquetas y las polaridades declaradas son internamente incoherentes en el texto
│  │     original; lo operativo y no ambiguo es que se mide pico a pico entre el componente
│  │     de ~75 ms y el mayor de ~100 ms **(verificar la polaridad y las etiquetas contra
│  │     otra fuente antes de darlas por buenas)**
│  └─ Es el pico de mayor amplitud en torno a los 100 ms el que se utiliza para monitorizar
├─ CRITERIO DE ALARMA
│  ├─ Cambio significativo = reducción del 50% de la amplitud pico-pico respecto al basal
│  ├─ Se monitoriza la AMPLITUD, no la latencia
│  │  └─ Razón explícita: en quirófano la amplitud es un indicador más fiable de daño
│  │     neural que la latencia, porque la latencia se ve más afectada por la anestesia
│  ├─ Matiz importante en el paciente con déficit visual previo
│  │  ├─ La función visual previamente alterada atenúa por sí sola la amplitud pico-pico,
│  │  │  sin que haya ocurrido nada quirúrgico
│  │  ├─ Con una amplitud basal pequeña, un criterio del 50% se vuelve poco discriminativo
│  │  └─ Recomendación: prestar más atención a cambios SUTILES en relación con la
│  │     manipulación quirúrgica (experiencia personal de los autores, datos no publicados)
│  └─ Antes de dar la alarma, comprobar el ERG (ver rama de diagnóstico diferencial)
├─ CADENCIA DE REGISTRO Y PROTOCOLO DE REACCIÓN
│  ├─ Los PEV deben registrarse en CADA PASO QUIRÚRGICO
│  ├─ No hace falta registro continuo durante todo el procedimiento, pero sí de forma más
│  │  consistente en los momentos de ALTO RIESGO para el sistema visual
│  ├─ Ante un cambio significativo, el neurofisiólogo avisa de inmediato al cirujano
│  └─ En ese momento debe producirse una PAUSA QUIRÚRGICA para evaluar las causas
│     potenciales del cambio
├─ DIAGNÓSTICO DIFERENCIAL ELECTROFISIOLÓGICO — el ERG como discriminador
│  ├─ El ERG simultáneo existe para una sola cosa: garantizar que el flash está llegando
│  │  de verdad a la retina
│  ├─ PEV atenuado + ERG ausente o caído → el problema es de ESTÍMULO, no del paciente:
│  │  desplazamiento de las gafas, intensidad insuficiente, luz interceptada por el
│  │  colgajo cutáneo
│  ├─ PEV atenuado + ERG estable → el problema está en la vía visual, de la retina hacia
│  │  atrás: es una alarma real
│  ├─ PEV no registrable desde el principio + ERG bueno → sospechar déficit visual previo
│  │  grave (agudeza visual <0.1 y/o defecto campimétrico mayor que hemianopsia), no fallo
│  │  técnico
│  ├─ PEV y ERG caen SINCRÓNICAMENTE → apunta a isquemia RETINIANA (el ERG es el que
│  │  delata que el problema está por delante del nervio óptico)
│  └─ Impacto medible de incluir el ERG: el poder predictivo de deterioro visual
│     postoperatorio pasó del 60% al 100%
├─ HALLAZGOS TÍPICOS Y SU SIGNIFICADO
│  ├─ Caída TRANSITORIA con recuperación → en la serie, ningún paciente despertó con
│  │  déficit visual
│  ├─ Caída PERMANENTE >50% al final de la cirugía → riesgo real, aunque no certeza
│  ├─ PEV PLANO → indicador de disturbio visual postoperatorio grave
│  │  ├─ En la mayoría de los casos es sobre todo caída de la AGUDEZA visual sin
│  │  │  alteración del campo
│  │  └─ En algunos casos aparece como deterioro campimétrico mayor aislado, o combinado
│  │     con deterioro de agudeza y campo
│  └─ Asimetría de dificultad interpretativa: los cambios causados por manipulación
│     MECÁNICA de las estructuras ópticas son más difíciles de analizar que los cambios
│     por eventos ISQUÉMICOS (experiencia personal del autor)
├─ RENDIMIENTO — la serie de referencia
│  ├─ 152 cirugías (304 lados) en Nagano Municipal Hospital y Shinshu University Hospital,
│  │  de 2005 a marzo de 2018: 3 lesiones intraorbitarias, 125 paraselares y 24 corticales
│  ├─ Registrabilidad: PEV obtenibles en 295 de 304 lados (97%)
│  │  └─ PEV estables en todos los pacientes con agudeza visual corregida >0.03. No se
│  │     registró en 1 lado con agudeza de 0.03 y en 2 lados de un paciente en el que se
│  │     usó sevoflurano
│  ├─ Recuento crudo de resultados
│  │  ├─ Caída transitoria en 19 lados → 0 déficits postoperatorios
│  │  ├─ Caída permanente >50% en 18 lados → defecto campimétrico con agudeza preservada
│  │  │  en 6 · deterioro de agudeza con campo preservado en 1 · ambos en 3 · SIN déficit
│  │  │  en 8
│  │  └─ De 258 lados con amplitud sin cambios → deterioro de agudeza en 1 lado y defecto
│  │     campimétrico menor en otro lado
│  ├─ Cifras publicadas en el capítulo: "sensibilidad 99% (256/258) y especificidad 55%
│  │  (10/18)"
│  └─ CORRECCIÓN NECESARIA — esas dos etiquetas están cambiadas respecto a la definición
│     estándar, y conviene saberlo antes de citar la cifra
│     ├─ 256/258 = 99% es en realidad el VALOR PREDICTIVO NEGATIVO: de los lados sin
│     │  cambio del PEV, cuántos quedaron sin déficit
│     ├─ 10/18 = 55% es el VALOR PREDICTIVO POSITIVO: de los lados con cambio permanente,
│     │  cuántos tuvieron déficit
│     ├─ Recalculando a partir de los recuentos publicados: sensibilidad = 10/12 ≈ 83% y
│     │  especificidad = 256/264 ≈ 97% **(cálculo propio sobre las cifras del capítulo, no
│     │  aparece así en la fuente)**
│     └─ Lectura clínica que sobrevive a la corrección: un PEV que no cambia es muy
│        tranquilizador (VPN 99%); un PEV que cae permanentemente acierta solo la mitad de
│        las veces (VPP 55%) — casi la mitad de las alarmas permanentes no se tradujeron en
│        déficit
├─ CASOS QUE ENSEÑAN EL PATRÓN
│  ├─ Caso 1 — Oclusión temporal de ACI cervical (aneurisma paraclinoideo C2)
│  │  ├─ A los 2 min de la oclusión cervical, caída SINCRÓNICA de amplitudes de ERG y PEV;
│  │  │  recuperación completa de ambas 5 min después de liberar. Sin déficit postoperatorio
│  │  └─ Enseñanza: la retina se nutre de la arteria central de la retina, rama de la
│  │     oftálmica; como la oftálmica tiene muchas anastomosis con la carótida externa, la
│  │     oclusión proximal rara vez causa isquemia retiniana — pero el grado de colateral
│  │     varía en cada caso y NO es evaluable preoperatoriamente. El ERG es lo que permite
│  │     detectar esa isquemia retiniana en el momento
│  ├─ Caso 2 — Oclusión de la arteria hipofisaria superior (AHS)
│  │  ├─ Oclusión temporal de una AHS gruesa que nacía de la cúpula aneurismática y
│  │  │  terminaba en nervio óptico y quiasma → PEV derecho PLANO en menos de 5 min →
│  │  │  recuperación al liberar → atenuación REPRODUCIBLE al repetir la oclusión
│  │  ├─ Decisión: se obliteró el aneurisma preservando el flujo de la AHS. Sin déficit
│  │  └─ Enseñanza que cambia el dogma: no había informes de disfunción visual por oclusión
│  │     de UNA rama de la AHS, porque muchas ramas irrigan el aparato óptico — este caso
│  │     demuestra que la oclusión de una sola rama SÍ puede bastar
│  ├─ Caso 3 — Aneurisma paraclinoideo gigante (25 mm), PEV plano persistente
│  │  ├─ Caída progresiva del PEV ipsilateral durante 30 min de disección silviana hasta
│  │  │  quedar plano, con ERG y PEV contralateral ESTABLES (es decir, alarma real)
│  │  ├─ Tras clinoidectomía anterior y apertura del canal óptico, el PEV reapareció 30 min
│  │  │  después → la lesión previa a la descompresión NO era permanente
│  │  ├─ Nueva caída tras el clipaje, sin recuperar el 50% del basal hasta el final →
│  │  │  el ojo quedó ciego
│  │  └─ Enseñanza: la evolución TEMPORAL del PEV permite atribuir causa. Aquí, la primera
│  │     caída se explicó por compresión del nervio óptico (aneurisma + estiramiento por
│  │     descenso cerebral tras salida de LCR y posición de la cabeza), y la segunda por
│  │     lesión mecánica directa u obstrucción de la AHS durante el clipaje
│  └─ Caso 4 — Adenoma hipofisario por vía transesfenoidal endoscópica
│     ├─ Tras la resección, el empaquetado de la cavidad produjo caída del PEV → se retiró
│     │  por completo el material y se reconfirmó la hemostasia → el PEV volvió al basal →
│     │  se reempaquetó SUELTO bajo monitorización
│     ├─ La agudeza visual del ojo monitorizado mejoró de 0.03 a 0.06 postoperatoriamente
│     └─ Enseñanza: la compresión del nervio óptico y el quiasma por SOBREEMPAQUETADO de la
│        cavidad es detectable y, por tanto, una complicación evitable — incluso operando
│        con endoscopio 2D, donde la percepción de profundidad es peor
├─ LA VERSIÓN ESCÉPTICA — y por qué no está simplemente equivocada
│  ├─ Los informes clásicos sobre PEV intraoperatorio fueron "en general desalentadores":
│  │  resultados mucho menos claros que con otras modalidades sensitivas, y TODOS los
│  │  investigadores describieron falsos positivos y falsos negativos
│  ├─ Raudzens: registró cambios convincentes del PEV durante manipulación del quiasma y
│  │  durante episodios de hipotensión SIN patología postoperatoria; pero también encontró
│  │  que cuando el PEV se mantenía sin cambios durante toda la cirugía no había deterioro
│  │  visual — y que pacientes con defectos visuales preoperatorios podían tener PEV
│  │  intraoperatorios normales
│  ├─ Otro grupo concluyó que el valor del PEV intraoperatorio para preservar función
│  │  visual útil es pequeño; los cambios del PEV no correlacionan bien con isquemia de la
│  │  corteza occipital ni con lesiones de la vía visual
│  ├─ Para isquemia de circulación anterior, la monitorización de PESS es SUPERIOR a la de
│  │  PEV; el PEM también es valioso como indicador de isquemia cerebral
│  ├─ Incluso con TIVA, en un estudio la fiabilidad no pareció aumentar y los registros
│  │  estables fueron difíciles de obtener
│  └─ Cómo se concilian las dos versiones: la literatura escéptica es anterior a la
│     combinación de TIVA sistemática + LED de alta intensidad + ERG simultáneo de control.
│     Fíjate en que el hallazgo de Raudzens (PEV sin cambios = sin deterioro) es exactamente
│     el VPN alto de la serie moderna: en lo que ambas épocas coinciden es en que el valor
│     del PEV está en su capacidad de TRANQUILIZAR, no en la especificidad de su alarma
├─ Errores de interpretación
│  ├─ Dar la alarma sin haber mirado antes el ERG — la causa más frecuente de caída del PEV
│  │  es que el estímulo ha dejado de llegar a la retina
│  ├─ Aplicar el criterio del 50% sin corregir por una amplitud basal ya pequeña en el
│  │  paciente con déficit visual previo
│  ├─ Vigilar la latencia como si fuera el PESS: en quirófano la latencia del PEV es rehén
│  │  de la anestesia
│  ├─ Citar "sensibilidad 99%" del capítulo sin advertir que ese 99% es en realidad el
│  │  valor predictivo negativo
│  ├─ Interpretar una deriva lenta de amplitud en cirugía larga como daño, sin considerar
│  │  desplazamiento progresivo de las gafas o adaptación retiniana
│  └─ Tratar un PEV estable como garantía de campo visual intacto: se documentaron
│     cuadrantanopsia y defecto campimétrico menor con PEV sin cambios
├─ Limitaciones
│  ├─ Disfunción visual preoperatoria grave → PEV reducido o no registrable → no permite
│  │  monitorización fiable, justo en el paciente de más riesgo
│  ├─ El paciente puede despertar con un defecto campimétrico menor sin cambio significativo
│  │  del PEV ni de la agudeza visual
│  ├─ La caída de amplitud del PEV por flash representa sobre todo alteración de la AGUDEZA
│  │  visual, y detecta defectos campimétricos solo si son mayores que una hemianopsia
│  ├─ Con la metodología actual, los cambios del PEV NO permiten discriminar
│  │  intraoperatoriamente un cambio visual pequeño de un defecto campimétrico mayor
│  └─ La limitación mayor hoy es la RESOLUCIÓN TEMPORAL de la técnica
└─ Referencia
   └─ Deletis cap.4 (Kodama & Goto) pp.57-62 — criterios de alarma §4.4.6, resultados §4.5
      con la serie de 152 cirugías, casos 1-4 §4.5.1 (Figs. 4.6-4.9), conclusión §4.8 ·
      Moller2011 cap.8 pp.163-165 (revisión escéptica, Raudzens, falsos positivos y
      negativos, TIVA) · cap.5 (PESS superior al PEV para isquemia de circulación anterior)
```
