# PE-V3 — PEV normal: componentes N75-P100-N145 y medición

```
PEV normal: componentes y medición
├─ Morfología normal
│  ├─ Con cuadros grandes (~1°) el PEV normal tiene una forma de onda SIMPLE de tres
│  │  picos, y la respuesta más prominente se registra en el electrodo medio-occipital
│  ├─ N75 — pico negativo precoz, latencia media ~75 ms
│  ├─ P100 — el más prominente, onda positiva grande, latencia media ~100 ms
│  ├─ N145 — pico negativo redondeado, MÁS VARIABLE que los dos anteriores
│  └─ Convenio de polaridad (igual que en EEG): si el primer electrodo del canal se hace
│     más negativo que el segundo, la deflexión va hacia ARRIBA — por eso N75 y N145 van
│     hacia arriba y el P100 traza una gran deflexión hacia ABAJO
├─ Por qué el P100 es el componente clínicamente relevante
│  ├─ Es el de mayor amplitud
│  ├─ Tiene menor variabilidad entre sujetos
│  ├─ Tiene mínima asimetría interocular en un sujeto normal dado
│  ├─ Tiene mínima variación a lo largo de periodos de tiempo largos
│  └─ Su latencia sigue una distribución normal (gaussiana) en la población normal, lo
│     que permite definir el límite de normalidad estadísticamente
├─ El N100 frontal — el componente del cuarto canal
│  ├─ El canal MF-A1 registra habitualmente una onda ancha, de baja amplitud y polaridad
│  │  NEGATIVA, con latencia media en torno a 100 ms
│  ├─ Pese a tener latencias medias parecidas, el P100 occipital y el N100 frontal NO se
│  │  deben a un único generador orientado horizontalmente: se comportan de forma
│  │  INDEPENDIENTE
│  │  ├─ El N100 frontal puede ocurrir ligeramente antes, simultáneamente o ligeramente
│  │  │  después del P100
│  │  └─ El N100 frontal puede estar AUSENTE con P100 registrable, y viceversa
│  └─ TRAMPA CRÍTICA: si el P100 falta y el N100 se conserva, la derivación MO-MF
│     mostrará un pico hacia abajo que puede confundirse con un P100. Por eso es
│     imprescindible registrar la actividad de MF con la derivación MF-A1 y compararla
│     con la del canal medio-occipital
├─ El P100 es una SUMA, no un componente único
│  ├─ Aunque el PEV de campo completo tiene una morfología simple de tres componentes,
│  │  es en realidad la sumación de múltiples respuestas aportadas por: (1) hemicampos
│  │  izquierdo y derecho, (2) mitades superior e inferior del campo, y (3) campo
│  │  periférico y central
│  ├─ Son por tanto OCHO divisiones mayores del campo completo, cada una con su propio
│  │  potencial evocado, cuya suma produce la respuesta final
│  ├─ Y las divisiones NO contribuyen por igual: el N100 lo genera en gran medida la
│  │  mitad SUPERIOR del campo visual, mientras que el P100 lo aporta sobre todo la
│  │  mitad INFERIOR
│  └─ De ahí que quepa esperar varias variantes de morfología normal
├─ Topografía normal
│  ├─ Anteroposterior (línea media): el P100 es máximo en amplitud en MO
│  │  └─ Variante normal: P100 de baja amplitud en MO por DESPLAZAMIENTO hacia arriba
│  │     (hacia MP) o hacia abajo (hacia inion) — se detecta con el montaje de línea
│  │     media (MF, MP, MO e inion referidos a A1+A2)
│  ├─ Lateral: comparando RO, MO y LO, el P100 es casi siempre de mayor amplitud en MO
│  │  que en los occipitales laterales
│  ├─ Con campo completo el P100 es normalmente SIMÉTRICO en amplitud y latencia entre
│  │  RO y LO, porque las respuestas de los dos hemicampos se compensan
│  └─ Lateralización paradójica: la estimulación de un hemicampo activa la corteza
│     estriada contralateral, pero el vector neto de la excitación se dirige
│     contralateralmente, con lo que la respuesta de mayor amplitud se registra
│     IPSILATERAL al hemicampo estimulado
│     ├─ Hemicampo izquierdo → corteza occipital medial derecha → máxima en MO y LO
│     ├─ Hemicampo derecho → corteza occipital medial izquierda → máxima en MO y RO
│     └─ Campo completo = suma matemática de las dos → máxima en MO, con respuestas
│        simétricas de menor amplitud en LO y RO
├─ Dominancia del campo central
│  ├─ Con campo visual grande (>15°) la respuesta del campo CENTRAL domina: el P100 de
│  │  MO está contribuido casi enteramente por la estimulación del campo central
│  ├─ Al ocluir progresivamente la visión central (escotoma central artificial) la
│  │  amplitud cae y el P100 DESAPARECE cuando se bloquean 5° de visión central
│  ├─ El campo periférico sí genera respuestas propias (picos P75, N105 y P135), pero no
│  │  suelen verse en LO, MO y RO porque el área grande del polo occipital excitada por
│  │  el campo central domina esos electrodos
│  │  └─ Los electrodos temporales (LT, RT) sí pueden mostrarlas
│  └─ En un escotoma central, esos picos periféricos pueden hacerse registrables incluso
│     en MO, precisamente por la ausencia del P100
├─ Medición — qué se mide siempre
│  ├─ Latencias de P100, N75 y N145, medidas con cursor en el canal medio-occipital
│  │  (MO-MF)
│  └─ Amplitud del P100 en la derivación medio-occipital, medida del pico de N75 al
│     pico de P100
├─ Medición — qué se mide además, según el caso
│  ├─ Diferencia de latencia de P100 entre los dos ojos, medida en las derivaciones MO
│  │  (diferencia interocular de P100)
│  ├─ Razón de amplitud del P100 entre los dos ojos, medida en MO (razón interocular)
│  └─ Razón de amplitud del P100 entre RO y LO (razón interhemisférica) para cada
│     estimulación monocular
├─ Cómo medir bien la latencia del P100
│  ├─ Se mide en la derivación MO, porque LO y RO muestran mayor variabilidad
│  ├─ Lo más sencillo es tomarla en el punto de máxima positividad, es decir el punto
│  │  más bajo del P100 en el canal MO-MF — válido cuando las ramas descendente y
│  │  ascendente son bastante simétricas, el trazado no es ruidoso y la onda no está
│  │  distorsionada
│  ├─ Si las dos ramas son ASIMÉTRICAS, algunos prefieren tomar la latencia como el
│  │  promedio de las latencias de inicio y de fin de la onda
│  ├─ Si el pico es ancho y complejo, se trazan tangentes a las pendientes descendente y
│  │  ascendente y se toma la latencia donde ambas se cortan
│  └─ PRECAUCIÓN: si la estimulación de un ojo genera un P100 asimétrico, la asimetría
│     interocular puede superar artificialmente los 10 ms y hacer que la prueba se
│     interprete como anormal. Hay que ser cauto al leer una anormalidad de latencia o
│     de diferencia interocular cuando el P100 no tiene forma simétrica
├─ Cómo medir la amplitud del P100 — y por qué hay menos acuerdo
│  ├─ Métodos posibles: voltaje absoluto · desde la línea de base del PE al pico ·
│  │  del pico de N75 al pico de P100 · del pico de P100 al de N145 · promedio de
│  │  N75-P100 y P100-N145
│  ├─ Todos tienen problemas. Determinar la línea de base exacta o el potencial cero
│  │  suele ser difícil
│  ├─ Si el paciente tiene un N75 prominente, el pico de P100 puede quedar cerca de la
│  │  línea de base o incluso en territorio negativo absoluto, lo que hace que los dos
│  │  primeros métodos representen mal el tamaño real del P100
│  ├─ La mayoría mide del pico de N75 al pico de P100: cuando las dos ramas son
│  │  simétricas y el N75 es identificable, es el mejor reflejo de la amplitud
│  └─ Cuando el N75 falta, o cuando la medida N75-P100 difiere mucho de la P100-N145,
│     el quinto método (promediar ambas) es probablemente la mejor opción
├─ Valores de referencia — ejemplo de un laboratorio, NO para copiar
│  ├─ Con cuadros de 55′: N75 media 72.9 ms (DE 3.15) · P100 media 100.58 ms (DE 3.21) ·
│  │  N145 media 139.75 ms (DE 9.95) · N100 frontal media 100.9 ms (DE 4.15) · amplitud
│  │  P100 media 8.92 µV (DE 3.88)
│  ├─ Con cuadros de 30′: N75 77.71 (DE 3.76) · P100 102.35 (DE 4.02) · N145 141.37
│  │  (DE 9.44) · N100 101.55 (DE 3.54) · amplitud 7.54 µV (DE 3.32)
│  ├─ Con cuadros de 15′: N75 81.87 (DE 5.21) · P100 105.08 (DE 6.17) · N145 142.30
│  │  (DE 10.11) · N100 104.09 (DE 4.52) · amplitud 4.41 µV (DE 1.98)
│  ├─ Lectura del patrón: al reducir el tamaño de cuadro las latencias SUBEN y la
│  │  amplitud BAJA — en estos normativos el P100 aumenta 4.5 ms en total de 55′ a 15′
│  └─ Según el laboratorio, media + 3 DE para la latencia del P100 queda en 115-120 ms
│     con cuadro grande (~1°)
├─ Por qué no se pueden tomar prestados los normativos
│  └─ Cada laboratorio debe recoger sus propios valores en unos 30 sujetos normales con
│     su propio equipo. Es especialmente crítico en PEV frente a PEATC y PESS, porque
│     estos últimos muestran menos variabilidad interlaboratorio cuando se usan
│     parámetros similares
├─ Variantes de morfología que siguen siendo normales
│  ├─ N75 mal definido o ausente
│  ├─ N75 prominente
│  ├─ Ramas descendente y ascendente del P100 asimétricas
│  ├─ Componente N145 prominente
│  └─ P100 de baja amplitud en MO por desplazamiento hacia MP o hacia inion
└─ Referencia
   └─ Markand2020 cap.3 pp.90-97 (Figs. 3.5-3.9, Tablas 3.4-3.5)
```
