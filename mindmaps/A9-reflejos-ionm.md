# A9 — Reflejos en IONM

> Pendiente: criterios de alarma del reflejo H como monitorización continua. TCR y TVcR
> son técnicas de descripción reciente (2024/2025) en fase de viabilidad: sin criterios
> de alarma validados ni papel establecido en la práctica rutinaria.

```
Reflejos en IONM
├─ Reflejo H (espinal)
│  ├─ Arco: monosináptico Ia (huso muscular) → motoneurona alfa
│  │  └─ Análogo electrofisiológico del reflejo miotático
│  ├─ Técnica: estimulación submáxima del n. tibial en hueco poplíteo, registro en sóleo
│  └─ Utilidad: integridad del arco lumbosacro / raíz S1
│     └─ Muy sensible a profundidad anestésica y a relajación muscular
│        (verificar umbral de alarma si se usa como monitorización continua)
├─ Blink Reflex (BR)
│  ├─ Arco: aferente V1 (n. supraorbitario) → núcleo espinal del trigémino →
│  │  interneuronas de tronco → núcleo facial (VII) → orbicularis oculi
│  ├─ Componentes: R1 (oligosináptico, ipsilateral, pontino) y R2 (polisináptico,
│  │  bilateral, más tardío, ~30 ms)
│  ├─ Técnica: tren corto de estímulos sobre n. supraorbitario
│  │  └─ Bajo anestesia general se necesita TREN, no estímulo único
│  ├─ Utilidad: monitoriza el arco V-tronco-VII en cirugía de base de cráneo / ángulo
│  │  pontocerebeloso
│  │  └─ Distingue lesión de V1 de lesión del propio nervio facial, en paralelo al
│  │     CoMEP facial (A6)
│  └─ Pitfall: se pierde con planos anestésicos profundos sin que haya lesión
│     └─ Es más sensible al propofol que las otras técnicas → correlacionar con CoMEP
│        antes de dar la alarma
├─ Reflejo bulbocavernoso (RBC)
│  ├─ Arco: aferente pudendo (glande/clítoris, S2-S4) → eferente pudendo (esfínter anal
│  │  externo / bulbocavernoso)
│  ├─ Técnica: estimulación del dorso del pene/clítoris o sonda vesical, registro EMG
│  │  del esfínter anal externo
│  └─ Utilidad: cirugía de cono medular / cola de caballo
│     └─ Integridad del arco sacro, función esfinteriana y sexual
├─ Reflejo maseterino (jaw jerk / H del masetero)
│  ├─ Arco: monosináptico puro V-V
│  │  └─ Aferente propioceptivo del huso del masetero (cuerpo celular en el núcleo
│  │     MESENCEFÁLICO del trigémino, único núcleo sensitivo primario dentro del SNC)
│  │     → motoneurona V3 eferente
│  ├─ Técnica: estimulación percutánea del n. maseterino bajo el arco cigomático,
│  │  0.5 cm anterior a la ATM; registro en masetero y temporal (control)
│  │  └─ Criterios de reflejo: umbral por debajo de la respuesta M directa, y la
│  │     amplitud H disminuye al aumentar la M con estímulos más fuertes
│  ├─ Utilidad: sonda la integridad mesencéfalo-protuberancial de forma pura V-V
│  │  └─ A diferencia del Blink Reflex (V→VII), permite localizar el nivel de lesión
│  │     con más precisión si se corren ambos reflejos juntos
│  └─ Estado: método relativamente nuevo — falta validación quirúrgica y criterios de
│     alarma precisos
├─ Reflejo trigémino-cervical (TCR)
│  ├─ Arco: aferente trigeminal (n. supraorbitario / infraorbitario) → tracto y núcleo
│  │  espinal del trigémino → convergencia con motoneuronas cervicales en asta gris
│  │  C1-C2 → eferente hacia esternocleidomastoideo
│  ├─ Técnica: estimulación de n. supraorbitario o infraorbitario, registro en ECM
│  │  ipsilateral
│  │  └─ Estímulo LARGO (0.5-1.0 ms) favorece su aparición bajo anestesia general
│  ├─ Componentes: latencia corta (~15-19 ms, el más constante bajo anestesia) y
│  │  latencia larga (~65-70 ms, menos constante)
│  └─ Estado: estudio de viabilidad — se obtiene bajo anestesia general en la mayoría,
│     pero su papel práctico en MIO está por establecer
├─ Reflejo trigémino-vocal (TVcR)
│  ├─ Arco propuesto: rama mentoniana del trigémino (V3) → tracto y núcleo espinal del
│  │  trigémino → núcleo ambiguo (vía neuronas reticulares próximas, con o sin paso
│  │  previo por el núcleo del tracto solitario) → n. laríngeo recurrente → músculos
│  │  laríngeos
│  ├─ Técnica: estimulación del n. mentoniano en el foramen mandibular (pulso único o
│  │  tren de 2-4 según profundidad anestésica), registro con electrodo-tubo adhesivo
│  │  sobre cuerda vocal — mismo montaje que el LAR
│  ├─ Componentes: R1 ~30 ms (rango 17-39 ms), bilateral en la mayoría · R2 ~65 ms
│  │  (rango 56-76 ms), presente solo en la mitad, más polifásico
│  ├─ Relación con el LAR: latencia de R1 del TVcR similar a la del R1 del LAR
│  │  └─ Sugiere fibras aferentes de calibre comparable; se propone también un posible
│  │     reflejo trigémino-hipogloso emparentado
│  └─ Estado: descrito en 2025 — demuestra conectividad funcional trigémino-vagal bajo
│     anestesia, pero utilidad clínica intraoperatoria y criterios de alarma AÚN NO
│     establecidos. Hallazgo de investigación, todavía no estándar de MIO
├─ Reflejo laríngeo aductor (LAR) — relacionado, arco vago-vagal
│  ├─ Arco: mucosa supraglótica → rama interna del n. laríngeo superior → n. vago →
│  │  núcleo del tracto solitario → núcleo ambiguo ipsi y contralateral → n. laríngeo
│  │  recurrente → músculos aductores
│  ├─ Técnica: tubo endotraqueal con electrodos de superficie sobre las cuerdas vocales
│  │  └─ Amplitud media en función laríngea normal: 313.5 ± 167.4 µV
│  ├─ Criterio de alarma: caída de amplitud >60% sin recuperación al liberar el tejido
│  │  → alta probabilidad de disfunción de cuerda vocal postoperatoria
│  └─ La LATENCIA (22.4 ± 2.5 ms) es muy variable y NO sirve como parámetro de alarma
└─ Referencia
   └─ Deletis&FernándezConejero (Neurophysiology in Neurosurgery 2ª ed., caps. 15-17:
      Téllez/Ulkatan/Sinclair — LAR; Fernández-Conejero/Deletis — Blink Reflex;
      Ulkatan2017 — masetero) · LimaMedeiros2024 (TCR) · Urriza2025 (TVcR)
```
