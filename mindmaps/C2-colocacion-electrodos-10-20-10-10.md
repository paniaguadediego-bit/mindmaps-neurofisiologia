# C2 — Colocación de electrodos 10-20 / 10-10

> Pendiente: la técnica exacta de medición (nasion-inion, % de circunferencia craneal)
> es conocimiento clínico estándar `(verificar)` — las fuentes del proyecto dan el
> sistema por conocido y solo especifican derivaciones concretas por modalidad.

```
Colocación de electrodos 10-20 / 10-10
├─ Concepto central
│  └─ Sistema estandarizado (IFCN) de localización de electrodos de cuero cabelludo
│     mediante porcentajes de distancias craneales fijas (nasion-inion,
│     preauriculares) — da reproducibilidad entre pacientes de distinto tamaño de
│     cráneo. El 10-10 es una malla más densa derivada del 10-20 clásico
├─ A qué modalidades afecta
│  └─ SEP cortical (C3'/C4'-Fz, CPz/Cz'-Fz — A1) · MEP TES (C1/C2 o C3/C4 — A2) ·
│     CoMEP (C3/C4 o C5/C6 — A6) · EEG multicanal bihemisférico (A8) · BAEP
│     (vértex-nuca, referencia a Cz — A7)
├─ Parámetros clave
│  └─ C3'/C4' = 2 cm POSTERIOR a C3/C4 del sistema 10-20 — definición explícita de la
│     derivación cortical de SEP de miembro superior
├─ Aplicación práctica
│  └─ En SEP de MMSS, activo en parietal contralateral (C3'/C4') con referencia
│     frontal o no-cefálica (hombro/esternón) para mejorar componentes subcorticales
│     tempranos · comparación bihemisférica obligatoria en EEG (A8)
├─ Errores frecuentes
│  ├─ El montaje de TES elegido determina el riesgo de lesión por mordedura: TODAS las
│  │  lesiones bucales/linguales reportadas ocurrieron con montaje C3/C4 — no hay
│  │  casos descritos con C1/C2 ni C3-Cz/C4-Cz, probablemente por la proximidad de
│  │  C3/C4 al nervio trigémino y al temporal → reservar C3/C4 para cuando su mayor
│  │  potencia sea realmente necesaria, y usar bite block blando siempre
│  └─ Electrodo auricular de BAEP colocado en ambos oídos + estimulación aplicada por
│     error al lado NO operado — la forma de onda es indistinguible entre lados, el
│     error pasa inadvertido y produce un falso negativo TOTAL (ver C6)
├─ Conexión con otros nodos
│  └─ A1, A2, A6, A7, A8 (cada uno usa una derivación concreta de este sistema) · C6
│     (electrodo mal colocado/mal conectado como causa técnica de falsa alarma)
└─ Referencia
   └─ Moller2011, cap. 6, Fig. 6.1, p.97 · Deletis, cap. 41 (MacDonald/Seidel/Shils),
      §41.3.6.1, pp.590-591
```
