# A5 — EMG estimulado — umbral de tornillo pedicular

```
EMG estimulado — umbral de tornillo pedicular
├─ Qué evalúa y por qué esta técnica y no otra
│  ├─ Estimulación INDIRECTA de la raíz nerviosa a través del hueso o de la instrumentación,
│  │  para valorar si un tornillo pedicular ha roto la cortical medial del pedículo
│  ├─ Descrita por Calancie en 1992 como forma OBJETIVA de avisar al cirujano cuando la
│  │  colocación parece haber violado la cortical y podría lesionar una raíz
│  ├─ Antes se intentó con PESS de nervio mixto, PESS dermatómicos y medición de impedancia
│  │  tisular; solo las técnicas basadas en actividad miógena espontánea y evocada cumplen
│  │  los requisitos y por eso son las que se han generalizado
│  └─ Los CUATRO requisitos que debe cumplir una técnica para valorar tornillos
│     ├─ PRÁCTICA: sin equipo ni experiencia especiales, con el material que ya se usa para
│     │  monitorizar, fácil de ejecutar y sin requisitos anestésicos excepcionales
│     ├─ EFECTIVA con inmediatez: indicación instantánea de irritación radicular, para
│     │  prevenir la lesión o el daño ulterior de una raíz ya irritada
│     ├─ Capaz de detectar un tornillo malcolocado que AÚN NO está irritando la raíz, pero
│     │  que tiene potencial de hacerlo
│     └─ Coste-efectiva y con resultados precisos que cambien el desenlace del paciente
├─ VÍA ANATÓMICA Y RIESGO POR REGIÓN
│  ├─ Raíz nerviosa lumbosacra en riesgo por brecha pedicular — es la situación clásica,
│  │  porque la mayoría de los tornillos se colocan en la región lumbosacra
│  ├─ CAMBIO DE RIESGO EN REGIÓN TORÁCICA: a diferencia del lumbosacro, donde solo está en
│  │  juego la función RADICULAR, un tornillo torácico desplazado demasiado medialmente
│  │  puede producir LESIÓN MEDULAR
│  │  ├─ La detección de tornillos torácicos malcolocados medialmente con técnicas de PULSO
│  │  │  ÚNICO ha resultado muy variable
│  │  └─ Solución desarrollada: trenes de CUATRO PULSOS de alta frecuencia, corriente
│  │     constante e intensidad variable, aplicados al trayecto pedicular. Cuando hay brecha
│  │     medial, la estimulación acaba estimulando DIRECTAMENTE LA MÉDULA, y aparecen
│  │     respuestas EMG en la musculatura de las extremidades inferiores
│  └─ La monitorización de tornillos torácicos se describió por primera vez en 2001, con
│     éxito desigual desde entonces
├─ MIOTOMAS Y MÚSCULOS DIANA (Tabla 13.1)
│  ├─ CERVICAL: C2-C4 → trapecio y esternocleidomastoideo · C5-C6 → bíceps y deltoides ·
│  │  C6-C7 → tríceps y flexor radial del carpo · C8-T1 → abductor corto del pulgar y
│  │  abductor del meñique
│  ├─ TORÁCICO: T1-T4 → intercostales · T5-T6 → recto abdominal superior e intercostales ·
│  │  T7-T8 → recto abdominal medio e intercostales · T9-T11 → recto abdominal inferior e
│  │  intercostales · T12 → recto abdominal inferior e intercostales
│  ├─ LUMBAR: L1 → psoas · L2-L3 → aductor mayor · L3-L4 → vasto medial · L4-L5 → tibial
│  │  anterior · L5-S1 → peroneo largo
│  ├─ SACRO: S1-S2 → gastrocnemio medial · S2-S4 → esfínter anal externo
│  └─ Matiz que evita errores de atribución: los músculos reciben inervación de VARIOS
│     niveles espinales, aunque uno predomina en cantidad de inervación
├─ ESTIMULACIÓN
│  ├─ CÁTODO: sonda de punta de bola —por ejemplo un electrodo nasofaríngeo— colocada dentro
│  │  del orificio del tornillo o sobre la instrumentación
│  ├─ ÁNODO: aguja colocada en músculo cerca del campo quirúrgico, que da el camino de
│  │  retorno a la corriente
│  ├─ Parámetros históricos publicados: frecuencias de 1 a 5 Hz con duraciones de pulso de
│  │  50 a 300 µs. El protocolo original de Calancie fue 3.1 Hz, 200 µs y máximo 40 mA
│  ├─ Procedimiento: subir la intensidad GRADUALMENTE desde 0 mA hasta alcanzar el umbral en
│  │  que se elicita una respuesta EMG FIABLE Y REPETIBLE en al menos uno de los músculos
│  │  monitorizados, o hasta llegar al máximo preestablecido (40 o 50 mA)
│  └─ CORRIENTE CONSTANTE mejor que voltaje constante — y la razón es física, no de gusto
│     ├─ El voltaje es la fuerza que impulsa la carga a través de la resistencia del tejido,
│     │  pero lo que despolariza la raíz es el FLUJO de carga por unidad de área: la
│     │  DENSIDAD DE CORRIENTE
│     ├─ Con voltaje constante, la densidad de corriente VARÍA con los cambios de impedancia
│     │  tisular; con corriente constante, NO
│     ├─ Al testar un tornillo, la impedancia incluye la del pedículo y el cuerpo vertebral
│     │  además de músculo, tejido vascular y sangre. Las últimas son relativamente
│     │  constantes entre individuos, pero la DENSIDAD ÓSEA —y por tanto la impedancia del
│     │  hueso— varía por osteoporosis y otros factores
│     └─ Consecuencia: hace falta más o menos voltaje para producir la misma corriente en
│        distintos individuos, así que el voltaje constante es más variable. Varios
│        investigadores ya lo han reportado
├─ REGISTRO
│  ├─ Electrodos INTRAMUSCULARES preferibles a los de superficie para registrar los CMAP
│  ├─ Banda de paso ancha: 30 Hz - 3 kHz, con amplificación diferencial
│  ├─ Modo FREE-RUN con barrido típico de 1 segundo, que permite visualizar y evaluar
│  │  fácilmente cualquier actividad elicitada
│  └─ Monitorizar varios canales simultáneos: seis o más
├─ MORFOLOGÍA NORMAL — cuánto cuesta excitar una raíz sana
│  ├─ La intensidad media necesaria para excitar directamente una raíz normal es de unos
│  │  2 mA, pero con un rango MUY amplio
│  └─ En la serie de Calancie el rango de estimulación directa de raíz normal fue de
│     1.2 a 3.8 mA
├─ LOS SEIS FACTORES QUE DETERMINAN SI UN ESTÍMULO EXCITA LA RAÍZ
│  ├─ 1. DISTANCIA entre el electrodo (o el tornillo) y la raíz
│  │  ├─ Obedece a la ley de Coulomb o ley del inverso del cuadrado: I = a + kd², donde I es
│  │  │  la corriente necesaria para elicitar respuesta, a es el mínimo valor de I con la
│  │  │  punta en contacto con la raíz, k una constante que varía con cada electrodo y raíz,
│  │  │  y d la distancia entre raíz y tornillo
│  │  ├─ La distancia entre las paredes pediculares lumbares medial o inferior y la raíz
│  │  │  proximal es de aproximadamente 1.5 a 2.8 mm
│  │  └─ Por tanto, cuando hay brecha, la distancia entre tornillo y raíz puede ir de 0 mm
│  │     (contacto directo) a 2.8 mm
│  ├─ 2. TAMAÑO del electrodo estimulante o de la superficie de tornillo expuesta
│  │  └─ En contacto directo (d=0), un electrodo GRUESO requiere MÁS corriente que uno fino
│  │     para evocar respuesta, porque el fino da mayor densidad de corriente. Es decir, la
│  │     cantidad de tornillo expuesta influye en el umbral
│  ├─ 3. Propiedades eléctricas de la raíz estimulada
│  ├─ 4. ORIENTACIÓN del electrodo o del tornillo respecto a la raíz
│  ├─ 5. Resistividad del tejido que contiene al electrodo y a la raíz
│  └─ 6. Patrón de flujo de la corriente de estimulación
├─ LA ANCHURA DE PULSO EXPLICA POR QUÉ LOS UMBRALES PUBLICADOS NO COINCIDEN
│  ├─ Comparando dos estímulos de igual intensidad pero con anchuras de 50 y 200 µs, el de
│  │  200 µs produce el DOBLE de densidad de corriente
│  ├─ Para producir el mismo efecto, el estímulo de 50 µs necesitaría el DOBLE de intensidad
│  └─ Esto explica probablemente que unos investigadores usen umbrales de alarma más altos y
│     otros más bajos: comparar cifras de mA sin comparar la anchura de pulso no significa
│     nada
├─ CUÁNTA BRECHA TOLERA UNA RAÍZ
│  ├─ Un tornillo puede violar la pared pedicular con seguridad al menos 2 mm, e incluso
│  │  hasta 4 mm, SIN secuelas postoperatorias
│  ├─ Intrusiones de 4 mm o más se ha reportado que producen SIEMPRE deterioro funcional de
│  │  la raíz
│  └─ Probablemente en el rango de 2-4 mm, y con certeza por encima de 4 mm, el tornillo está
│     en contacto con la raíz. A partir de ahí la distancia deja de ser el factor y entran en
│     juego los demás
├─ CRITERIOS DE ALARMA — el 10 mA y lo que realmente significa
│  ├─ CRITERIO ORIGINAL DE CALANCIE: si la estimulación del tornillo NO produce respuesta
│  │  EMG a 10 mA (con pulso de 200 µs), es compatible con un tornillo bien alojado dentro de
│  │  cortical íntegra
│  │  └─ Con respuesta por debajo de ese umbral de alarma, se aconsejaba retirar el tornillo
│  │     y reexaminar el orificio con sonda; a veces eso descubría perforaciones no detectadas
│  ├─ Variante de Rose (técnica PEPSI): 20 V de voltaje constante como criterio para
│  │  distinguir pedículo íntegro de pedículo violado
│  ├─ Otros umbrales recomendados oscilan entre 6 y 11 mA
│  ├─ ESTRATIFICACIÓN DE RIESGO REAL (Toleikis), que es lo que cambia la conducta
│  │  ├─ >7 mA → asociado a ninguna brecha aparente, o solo pedículo fisurado, o exposición
│  │  │  medial ligera de una o dos roscas. Sugiere que el tornillo está lo bastante lejos de
│  │  │  la raíz como para no amenazarla → generalmente se dejan colocados
│  │  ├─ 5-7 mA → en inspección visual, aproximadamente la MITAD se dejaron colocados; de
│  │  │  esos, solo UNO se asoció a un déficit postoperatorio nuevo → es improbable que estén
│  │  │  en contacto con la raíz y es improbable que dejen secuela
│  │  └─ ≤5 mA → son los que en inspección visual suponen la mayor amenaza para la función
│  │     neurológica, y típicamente se retiran
│  │     └─ Matiz honesto: incluso con valores tan bajos, dos tornillos con umbrales de 4 y
│  │        5 mA se dejaron colocados sin ningún cambio neurológico nuevo. Puede ocurrir si
│  │        el tornillo no está en contacto con la raíz pero la densidad de corriente aún
│  │        basta para excitarla
│  └─ CONCLUSIÓN QUE REORDENA EL CRITERIO: el umbral de 10 mA probablemente solo sirve para
│     indicar que hay BRECHA en la pared pedicular. Un umbral MUCHO MÁS BAJO es el adecuado
│     para indicar cuándo la lesión radicular es una posibilidad real — hay quien propone
│     fijarlo al menos en 8 mA, pero varios trabajos coinciden en que solo los tornillos con
│     umbral cercano a 5 mA suponen peligro verdadero
├─ FALSOS POSITIVOS
│  ├─ Definición en este contexto: respuesta EMG elicitada por debajo de 10 mA con el
│  │  tornillo alojado por completo en hueso y sin evidencia de brecha cortical
│  ├─ Tanto con la técnica de Calancie como con la de Rose se subrayó que NO había falsos
│  │  positivos: toda actividad EMG evocada por debajo de 10 mA o de 20 V se asoció SIEMPRE
│  │  a una brecha de la cortical pedicular
│  └─ Por qué Calancie no bajó el umbral pese a los avisos de más: reducirlo habría reducido
│     los falsos positivos, pero habría AUMENTADO el riesgo de pasar por alto una perforación
│     real (falso negativo), que sí puede producir déficit → prefirió errar por precaución
├─ FALSOS NEGATIVOS — las cuatro causas
│  ├─ 1. GRADO DE RELAJACIÓN MUSCULAR, el factor más crítico
│  │  ├─ Un bloqueo excesivo eleva ARTIFICIALMENTE el umbral de estimulación y lleva a
│  │  │  hallazgos falsamente negativos: un tornillo malcolocado que parece bien colocado
│  │  ├─ Criterio mínimo reportado: presencia de una CUARTA sacudida en el tren de cuatro.
│  │  │  Algunos grupos usan una razón de amplitud T4/T1 de al menos 0.1-0.2, y se ha
│  │  │  propuesto que una razón de CMAP postinducción/preinducción en músculo de la mano
│  │  │  mayor de 0.8 es mejor medida
│  │  ├─ El TOF debe hacerlo el equipo de neurofisiología en musculatura de la PIERNA, no
│  │  │  fiarse del de anestesia hecho en mano o cara: los músculos de la pierna reaccionan
│  │  │  de forma distinta a los niveles de relajante
│  │  └─ CASO ILUSTRATIVO: con una sola sacudida grande en el TOF, el test de un tornillo dio
│  │     50 mA. Se esperó a que apareciera una cuarta sacudida pequeña y el MISMO tornillo
│  │     dio 12 mA
│  ├─ 2. SHUNTING DE CORRIENTE: si el tornillo está en contacto con sangre, LCR u otro
│  │  fluido, solo una fracción de la corriente aplicada pasa por el tornillo → umbrales
│  │  elevados (12-20 mA) y posible falso negativo
│  ├─ 3. FACTORES FISIOLÓGICOS: radiculopatía crónica, diabetes u osteoporosis elevan el
│  │  umbral basal — en raíces crónicamente comprimidas puede superar los 20 mA
│  └─ 4. FACTORES TÉCNICOS: tornillo de titanio o cabeza poliaxial mal conductores
├─ TROUBLESHOOTING
│  ├─ Confirmar el TOF adecuado ANTES de testear, no al principio del caso
│  ├─ Si se sospecha radiculopatía crónica, estimular la raíz DIRECTAMENTE (2-5 mA) para
│  │  confirmar que la respuesta es normal antes de interpretar el umbral del tornillo
│  ├─ Secar el campo si se sospecha shunting por sangre o LCR
│  └─ Comparar siempre umbrales obtenidos con la MISMA anchura de pulso
├─ EMG ESPONTÁNEO COMO COMPLEMENTO
│  ├─ Se registra en modo free-run durante todo el procedimiento
│  ├─ Se obtiene con al menos UNA sacudida en el tren de cuatro, aunque es deseable tener más
│  ├─ Ráfagas cortas (<1 s): comunes, asociadas a descompresión radicular, tracción y
│  │  desplazamiento, irrigación, electrocauterio, contacto metal-metal o torundas empapadas.
│  │  Hay que prestarles atención pero normalmente NO son causa de alarma y rara vez indican
│  │  agresión neural
│  ├─ Trenes largos (hasta varios minutos): más serios, relacionados con tracción y
│  │  compresión SOSTENIDAS. Cuanto más sostenida la actividad, mayor la probabilidad de daño
│  │  radicular → avisar al cirujano para tomar medidas correctoras de inmediato
│  ├─ Diferencia entre raíz sana y raíz lesionada: aplicar fuerzas mecánicas estáticas o
│  │  rápidas a una raíz SANA no induce actividad, o induce trenes de impulsos de corta
│  │  duración; las mismas fuerzas sobre una raíz LESIONADA o en regeneración inducen largos
│  │  periodos de impulsos repetitivos
│  ├─ Con irritación radicular PREEXISTENTE, el registro basal ya muestra actividad de baja
│  │  amplitud y baja frecuencia incluso antes de cualquier manipulación
│  └─ RENDIMIENTO LIMITADO: el EMG espontáneo es relativamente INSENSIBLE a la lesión de raíz
│     espinal. Se recomienda usarlo como procedimiento COMPLEMENTARIO y nunca como modalidad
│     única para monitorizar raíces
│     ├─ En cirugía de cordón anclado, la actividad espontánea continua fue mal predictor:
│     │  sensibilidad 100% pero especificidad de solo 19%
│     └─ Cuando su significado es dudoso, adquirir MEP corrobora: la indicación para obtener
│        un MEP es la pérdida sostenida o súbita de actividad EMG
├─ LIMITACIONES
│  ├─ La definición de "brecha real" varía entre estudios (algunos exigen >25% del diámetro
│  │  del tornillo expuesto) → sensibilidad y especificidad muy dispersas entre series
│  ├─ La radiografía como método de verificación puede ENGAÑAR: hay casos en que sugería
│  │  colocación adecuada y, al testar, umbrales bajos llevaron a inspección visual o TC
│  │  postoperatoria que demostraron que había que revisar la colocación
│  ├─ Un umbral bajo indica brecha, pero no indica de forma fiable que vaya a haber déficit
│  └─ La técnica sigue cuestionándose sobre la base de medidas de sensibilidad y
│     especificidad, precisamente porque esas medidas dependen de qué se defina como brecha

      distancias pediculares y estratificación 5/7 mA, §13.2.3 falsos positivos, §13.2.4
```
