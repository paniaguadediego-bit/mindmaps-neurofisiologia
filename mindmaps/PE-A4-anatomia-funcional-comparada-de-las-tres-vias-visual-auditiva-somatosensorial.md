Anatomía funcional comparada de las tres vías
├─ Definición y alcance
│  └─ Las tres vías sensitivas cuyos PE de latencia corta se usan en clínica y en
│     quirófano: visual (PEV), auditiva (PEATC) y somatosensorial de columna
│     dorsal-lemnisco (PESS). El objetivo del tema es poder COMPARARLAS: qué tienen en
│     común y, sobre todo, en qué se diferencian de forma que cambie la interpretación
├─ VÍA VISUAL
│  ├─ Retina — tres niveles neuronales
│  │  ├─ Neuronas primarias: fotorreceptores de la capa nuclear externa (conos y
│  │  │  bastones, pero para el PEV principalmente CONOS)
│  │  ├─ Neuronas secundarias: células bipolares y horizontales
│  │  ├─ Neuronas terciarias: células ganglionares y amacrinas
│  │  ├─ El NERVIO ÓPTICO está constituido por los axones de las células ganglionares
│  │  ├─ Tres tipos de fotopigmento en los conos (azul, verde, rojo) → visión en color y
│  │  │  fotópica; los bastones son más sensibles y dan la visión escotópica
│  │  ├─ Gran parte del procesamiento visual ocurre YA en la red neural de la retina:
│  │  │  hay fibras con campos excitatorios pequeños rodeados de áreas inhibitorias, y
│  │  │  otras con centro inhibitorio rodeado de área excitatoria
│  │  ├─ La ADAPTACIÓN de los fotorreceptores es la forma principal de control
│  │  │  automático de ganancia del ojo; la pupila aporta algo más
│  │  └─ (verificar) capas retinianas clásicas y división magnocelular/parvocelular: no
│  │     están en las fuentes del proyecto
│  ├─ Del ojo a la corteza — los cuatro hechos anatómicos
│  │  ├─ Punto de partida: por el cruce de la luz en el cristalino, el hemicampo visual
│  │  │  DERECHO estimula la retina TEMPORAL y el hemicampo IZQUIERDO la retina NASAL
│  │  ├─ Hecho 1: toda la entrada visual de un ojo, tanto por hemicampo derecho como
│  │  │  izquierdo, discurre por el NERVIO ÓPTICO IPSILATERAL
│  │  ├─ Hecho 2: la entrada visual de un ojo se DIVIDE EN EL QUIASMA y viaja
│  │  │  BILATERALMENTE por detrás de él
│  │  │  └─ Las fibras de retina NASAL cruzan; las de retina TEMPORAL siguen
│  │  │     ipsilaterales
│  │  ├─ Hecho 3: la entrada por excitación del hemicampo DERECHO de cada ojo llega a la
│  │  │  corteza estriada IZQUIERDA, y la del hemicampo izquierdo a la derecha
│  │  ├─ Hecho 4: la representación MACULAR ocupa un área cortical grande — todo el polo
│  │  │  occipital representa la visión macular o central
│  │  ├─ Relevo: los axones hacen sinapsis en el núcleo geniculado lateral, cuyos axones
│  │  │  forman las radiaciones ópticas que terminan en la corteza estriada
│  │  │  └─ (verificar) asa de Meyer: no aparece en las fuentes del proyecto
│  │  ├─ La mayoría de las neuronas del CGL reciben información de UN SOLO OJO; la
│  │  │  síntesis de la información de ambos ojos ocurre primariamente en la CORTEZA
│  │  ├─ Atajos anatómicos: las áreas 18 y 19 reciben entrada directa del CGL saltándose
│  │  │  la radiación óptica, y entrada del colículo superior y del pulvinar saltándose
│  │  │  el CGL
│  │  └─ Gran parte de la corteza visual primaria humana está embebida en la SUPERFICIE
│  │     MEDIAL del lóbulo occipital — dato del que se derivan casi todas las rarezas
│  │     topográficas del PEV
│  ├─ Organización retinotópica
│  │  ├─ El campo visual CENTRAL activa la mácula y su proyección excita el POLO
│  │  │  occipital, con un área de representación mucho mayor que la del campo periférico
│  │  ├─ El campo PERIFÉRICO se proyecta a la corteza occipital mesial y profunda a lo
│  │  │  largo de la cisura calcarina
│  │  ├─ El campo visual SUPERIOR se proyecta por DEBAJO de la cisura calcarina y el
│  │  │  campo INFERIOR a la porción SUPERIOR de la calcarina
│  │  └─ Consecuencia electrofisiológica cuantificada: con campo visual grande (>15°) la
│  │     respuesta del campo central domina, de forma que el P100 registrado en medio-
│  │     occipital está contribuido casi enteramente por la estimulación del campo
│  │     central — al ocluir progresivamente la visión central el P100 DESAPARECE cuando
│  │     se bloquean 5° de visión central
│  └─ Cómo se traduce en el registro
│     ├─ PEV normal por damero: tres picos, N75, P100 y N145, el más prominente en el
│     │  electrodo medio-occipital. N75 ≈ 75 ms · P100 = onda positiva grande de latencia
│     │  media ≈100 ms · N145 = pico negativo redondeado, más variable que los otros dos
│     ├─ Convenio de registro igual que en EEG: si el primer electrodo se hace más
│     │  negativo que el segundo, la deflexión va hacia ARRIBA — por eso N75 y N145 van
│     │  hacia arriba y el P100 hacia abajo
│     └─ LATERALIZACIÓN PARADÓJICA: la estimulación del hemicampo derecho activa la
│        corteza estriada izquierda y viceversa, PERO el vector neto de la excitación
│        cortical se dirige contralateralmente, con lo que la respuesta de mayor amplitud
│        se registra IPSILATERALMENTE
│        ├─ Estimular hemicampo izquierdo → activa occipital medial derecha → respuesta
│        │  máxima en medio-occipital y en occipital IZQUIERDO
│        ├─ Estimular hemicampo derecho → activa occipital medial izquierda → máxima en
│        │  medio-occipital y en occipital DERECHO
│        └─ La estimulación de campo completo es la suma matemática de las dos → máxima
│           en medio-occipital, con respuestas simétricas menores en ambos laterales
├─ VÍA AUDITIVA
│  ├─ Cadena anatómica
│  │  ├─ El nervio coclear está compuesto por los procesos CENTRALES de las neuronas
│  │  │  bipolares del ganglio espiral, cuyos procesos periféricos se originan en el
│  │  │  órgano de Corti
│  │  ├─ Cuatro núcleos de relevo mayores: núcleos cocleares (ventral y dorsal),
│  │  │  complejo olivar superior, colículo inferior y cuerpo geniculado medial
│  │  ├─ Las fibras del nervio coclear entran en el tronco y terminan en los núcleos
│  │  │  cocleares ventral y dorsal, en la protuberancia dorsolateral baja
│  │  ├─ Las fibras de SEGUNDO orden se originan en los núcleos cocleares y hacen
│  │  │  sinapsis en las neuronas de tercer orden del complejo olivar superior y del
│  │  │  núcleo del cuerpo trapezoide
│  │  ├─ Las proyecciones de esos núcleos CRUZAN al otro lado y ascienden por el
│  │  │  lemnisco lateral contralateral; ALGUNAS fibras ascienden por el lemnisco lateral
│  │  │  ipsilateral. El lemnisco lateral contralateral recibe además fibras de los
│  │  │  núcleos cocleares dorsales
│  │  ├─ Las fibras auditivas cruzadas en la protuberancia ventral constituyen el CUERPO
│  │  │  TRAPEZOIDE; algunas fibras del núcleo coclear terminan incluso en el complejo
│  │  │  olivar CONTRALATERAL
│  │  ├─ La mayoría de las fibras del lemnisco lateral hacen sinapsis en el núcleo del
│  │  │  lemnisco lateral o ascienden directamente al colículo inferior
│  │  ├─ El COLÍCULO INFERIOR es el núcleo de relevo clave: solo una pequeña proporción
│  │  │  de fibras del núcleo coclear o del lemnisco lateral lo atraviesa para terminar
│  │  │  directamente en el cuerpo geniculado medial
│  │  └─ El colículo inferior proyecta al núcleo geniculado medial del tálamo, que
│  │     proyecta por las radiaciones talámicas al giro de Heschl del lóbulo temporal
│  │     (área 41 de Brodmann, profunda en la cisura lateral)
│  ├─ Detalle del núcleo coclear
│  │  ├─ Es el primer núcleo de relevo y TODAS las fibras del nervio auditivo se
│  │  │  interrumpen en él
│  │  ├─ Tiene tres divisiones: dorsal (DCN), ventral posterior (PVCN) y ventral anterior
│  │  │  (AVCN)
│  │  └─ Cada fibra del nervio coclear se BIFURCA para terminar en PVCN y AVCN, y las que
│  │     llegan al PVCN mandan colaterales al DCN → todas las fibras alcanzan células en
│  │     las tres divisiones
│  ├─ Datos cuantitativos con consecuencia electrofisiológica
│  │  ├─ Longitud del nervio auditivo humano ≈ 26 mm, frente a 8 mm en el gato — los
│  │  │  tractos de la vía ascendente son más largos en humanos, lo que alarga el tiempo
│  │  │  de tránsito y las latencias de los componentes del PEATC
│  │  ├─ Velocidad de conducción del nervio auditivo ≈ 20 m/s (2 cm/ms), inusualmente
│  │  │  BAJA frente a los 40-60 m/s típicos de nervios sensitivos y motores periféricos
│  │  └─ El tiempo de tránsito de los 2.6 cm del oído al tronco es por tanto poco más de
│  │     1 ms
│  ├─ Organización tonotópica: las fibras del nervio auditivo y las células de los
│  │  núcleos de la vía ascendente clásica están dispuestas anatómicamente según la
│  │  frecuencia a la que su umbral es más bajo — todas las estructuras neurales de la
│  │  vía clásica pueden mapearse a la frecuencia a la que responden mejor
│  ├─ Vías no clásicas (extralemniscales): proyectan a cortezas secundarias y de
│  │  asociación SALTÁNDOSE la corteza auditiva primaria, usando el tálamo DORSAL
│  │  mientras las clásicas usan los núcleos talámicos ventrales. Muchas de sus neuronas
│  │  responden a otras modalidades sensoriales. La monitorización intraoperatoria no las
│  │  involucra hasta donde se sabe
│  ├─ Vías descendentes: son MÁS ABUNDANTES que las ascendentes pero se conocen mucho
│  │  peor. Las fibras eferentes del haz olivococlear se originan en el complejo olivar
│  │  superior y terminan sobre todo en las células ciliadas externas; viajan en la
│  │  porción VESTIBULAR del VIII par desde el tronco hasta la anastomosis de Oort, en la
│  │  profundidad del meato acústico interno, donde pasan a la porción coclear
│  └─ Dónde se hace bilateral — el punto discutido
│     ├─ Formulación clásica: la onda I es del nervio auditivo periférico ipsilateral y
│     │  la onda II se genera en estructuras IPSILATERALES al oído estimulado
│     ├─ Según Markand la transición está en la ONDA III: contribuyen tanto las vías
│     │  pontinas ipsilaterales como las contralaterales, y todo componente posterior a
│     │  la onda II debe representar activación de estructuras de ambos lados
│     │  └─ Ojo, tensión interna en esa misma fuente: la tabla de generadores agrupa I,
│     │     II y III como ipsilaterales, mientras el texto atribuye contribución bilateral
│     │     a la III
│     ├─ Según Møller la transición está en la ONDA IV: los picos I, II y III reciben
│     │  aferencia SOLO del lado ipsilateral, el pico IV es probablemente el primer pico
│     │  positivo con contribuciones contralaterales, y el pico V recibe sus
│     │  contribuciones MAYORES de estructuras contralaterales
│     └─ Lo que sí es común a ambas: el sistema auditivo en el colículo inferior y por
│        encima es funcionalmente CONTRALATERAL, pero la correlación clínico-patológica
│        humana muestra que las ondas del PEATC se generan predominantemente por
│        estructuras IPSILATERALES al oído estimulado
├─ VÍA SOMATOSENSORIAL (columna dorsal-lemnisco medial)
│  ├─ Es una vía de TRES NEURONAS
│  │  ├─ Primer orden: cuerpos celulares en los GANGLIOS DE LA RAÍZ DORSAL, neuronas
│  │  │  unipolares cuyas ramas periféricas son los axones de gran diámetro que inervan
│  │  │  los receptores de músculos, articulaciones y piel
│  │  │  ├─ Las ramas centrales entran en la médula en la región lumbosacra (MMII) y
│  │  │  │  cervicodorsal (MMSS)
│  │  │  └─ Tras entrar dan COLATERALES a la sustancia gris del asta dorsal y hacen un
│  │  │     giro ascendente para subir por el fascículo GRÁCIL (fibras de MMII, medial) y
│  │  │     el fascículo CUNEIFORME (fibras de MMSS, lateral)
│  │  ├─ Segundo orden: proyecciones de los núcleos grácil y cuneiforme, situados en la
│  │  │  porción superior del bulbo raquídeo. CRUZAN en la DECUSACIÓN SENSITIVA DEL BULBO
│  │  │  SUPERIOR y ascienden por el lemnisco medial CONTRALATERAL hasta el núcleo
│  │  │  posterolateral del tálamo (VPL)
│  │  └─ Tercer orden: los axones talámicos atraviesan la porción posterior de la CÁPSULA
│  │     INTERNA y la corona radiada, y terminan en la corteza somatosensorial primaria,
│  │     en el labio posterior de la cisura central
│  ├─ Qué fibras se estimulan realmente
│  │  ├─ La intensidad de estímulo usada activa predominantemente fibras sensitivas de
│  │  │  GRAN DIÁMETRO y conducción rápida: aferentes musculares del grupo IA y aferentes
│  │  │  cutáneas del grupo II
│  │  ├─ Hay controversia sobre la proporción relativa de aferentes musculares vs.
│  │  │  cutáneas que contribuyen al PESS con estimulación de nervio mixto
│  │  ├─ Los estudios animales con ablación selectiva de la columna dorsal producen
│  │  │  atenuación marcada o desaparición del PESS
│  │  └─ El ESPINOTALÁMICO NO se explora con el PESS rutinario: las fibras de pequeño
│  │     diámetro (térmica y dolorosa) tienen su segunda neurona en el asta dorsal, cruzan
│  │     en la médula a nivel próximo a la entrada y ascienden por los espinotalámicos
│  │     contralaterales en la porción ventral → NO hay alteración del PESS asociada a
│  │     lesiones del sistema espinotalámico
│  ├─ Detalle de la columna dorsal
│  │  ├─ Es una estructura puramente ANATÓMICA con muchos tipos de fibra, NO un tracto
│  │  │  funcional único
│  │  ├─ La mayoría son aferentes primarias y colaterales de aferentes primarias, pero
│  │  │  contiene además la "vía de la columna dorsal de segundo orden", originada en
│  │  │  cuerpos celulares del asta dorsal (lámina IV en la intumescencia cervical,
│  │  │  láminas V y VI en la médula lumbosacra), activada en gran parte por receptores
│  │  │  articulares y musculares
│  │  ├─ Las aferentes primarias median tacto fino (receptores cutáneos) y propiocepción
│  │  │  inconsciente (husos y órganos tendinosos)
│  │  └─ Núcleo Z: ligeramente rostral y medial a los núcleos de las columnas dorsales,
│  │     recibe fibras propioceptivas del hemicuerpo inferior; sus fibras cruzan la línea
│  │     media y se unen al lemnisco medial
│  ├─ Ramificación de las raíces dorsales y su consecuencia clínica
│  │  ├─ Las raíces dorsales se ramifican varias veces y hacen sinapsis en distintas
│  │  │  partes del asta dorsal del segmento de entrada Y de varios segmentos adyacentes
│  │  ├─ La eficacia de esas sinapsis decrece con la distancia al segmento de entrada;
│  │  │  las de segmentos distantes normalmente no logran activar células
│  │  └─ Esas sinapsis "dormidas" pueden DESENMASCARARSE al activarse la plasticidad
│  │     neural (p. ej. tras sección de la raíz o reducción del input) → una lesión de un
│  │     nervio sensitivo puede tener un efecto amplio sobre la excitabilidad de las
│  │     neuronas del asta dorsal y causar difusión anormal de la actividad sensitiva a
│  │     más segmentos de lo normal
│  ├─ Corteza somatosensorial
│  │  ├─ S1 recibe del VPL; los axones viajan por el brazo posterior de la cápsula
│  │  │  interna y se distribuyen sobre el giro postcentral de forma SOMATOTÓPICA, con
│  │  │  las PIERNAS representadas más cerca de la línea media, seguidas lateralmente por
│  │  │  tronco, antebrazo y mano
│  │  ├─ S1 recibe también aferencia propioceptiva inconsciente, en zonas distintas de
│  │  │  las que reciben el input consciente
│  │  └─ S2 recibe de S1 y aferencia BILATERAL del tálamo, con homúnculo similar
│  ├─ Dónde decusa exactamente
│  │  ├─ En la decusación sensitiva del BULBO SUPERIOR, a la salida de los núcleos grácil
│  │  │  y cuneiforme — es decir, DESPUÉS del primer relevo
│  │  ├─ Antes de la decusación toda la vía es IPSILATERAL (raíz dorsal → columna dorsal
│  │  │  ipsilateral → núcleos grácil/cuneiforme ipsilaterales)
│  │  ├─ Después es enteramente CONTRALATERAL (lemnisco medial → VPL → S1)
│  │  └─ Contraste: el espinotalámico cruza EN LA MÉDULA, cerca del nivel de entrada
│  └─ Cómo se traduce en el registro — el detalle topográfico que más engaña
│     ├─ Por qué el tibial da positividad inicial y el mediano negatividad inicial: la
│     │  activación cortical del PIE ocurre a lo largo de la cara MEDIAL de la corteza
│     │  somatosensorial, dentro de la cisura interhemisférica. La negatividad profunda
│     │  (un sumidero activo) resulta en una positividad superficial (una fuente pasiva),
│     │  y por eso el electrodo medial del scalp registra un potencial electropositivo
│     ├─ LATERALIZACIÓN PARADÓJICA del P37: si el área pie/pierna está en el borde
│     │  superficial de la cisura interhemisférica, el dipolo es VERTICAL y la positividad
│     │  es máxima en línea media; si el área está MÁS PROFUNDA, el dipolo es HORIZONTAL y
│     │  la positividad inicial se registra IPSILATERAL al lado estimulado, porque el
│     │  vector neto se dirige al lado opuesto
│     └─ Por contraste, el N20 del mediano es SIEMPRE máximo en el centroparietal
│        contralateral, porque la activación cortical es superficial y queda justo bajo
│        ese electrodo
├─ COMPARACIÓN — número de relevos sinápticos
│  ├─ Somatosensorial: vía de TRES neuronas, con razón sináptica casi 1:1, lo que
│  │  proporciona una localización y discriminación mucho más precisas
│  ├─ Auditiva: CUATRO núcleos de relevo mayores, pero con atajos — hay fibras cruzadas
│  │  del núcleo coclear que alcanzan el colículo inferior SIN interrupción sináptica, y
│  │  solo una pequeña proporción atraviesa el colículo para ir directa al geniculado
│  │  medial → el número efectivo de sinapsis VARÍA ENTRE FIBRAS
│  └─ Visual: tres niveles neuronales dentro de la retina + un relevo talámico (CGL) +
│     corteza estriada, también con atajos (áreas 18-19 reciben del CGL saltándose la
│     radiación óptica, y del colículo superior/pulvinar saltándose el CGL)
├─ COMPARACIÓN — nivel de decusación
│  ├─ Somatosensorial: punto ÚNICO y bien definido, la decusación sensitiva del bulbo
│  │  superior. Ipsilateral por debajo, contralateral por encima
│  ├─ Auditiva: NO hay un punto único — la vía es cruzada Y no cruzada a la vez desde el
│  │  primer relevo. Cruzan la estría acústica dorsal, la estría acústica ventral y el
│  │  cuerpo trapezoide, y además hay conexiones del núcleo coclear al colículo inferior
│  │  que NO cruzan. Tanto fibras cruzadas como no cruzadas constituyen las vías
│  │  auditivas centrales, pero funcionalmente dominan las contralaterales
│  └─ Visual: decusación PARCIAL en un punto único, el quiasma — cruzan solo las fibras
│     nasales. El resultado no es "ipsi vs. contra" sino HEMICAMPO vs. HEMICAMPO: por
│     detrás del quiasma la organización es por hemicampo, no por ojo
├─ COMPARACIÓN — representación uni o bilateral
│  ├─ Somatosensorial: estrictamente UNILATERAL (contralateral) por encima del bulbo — el
│  │  N20 solo se registra desde un área pequeña del scalp parietal contralateral
│  │  └─ Excepciones: el N18 lo generan estructuras BILATERALES del tronco y se registra
│  │     sobre amplias regiones del scalp; y S2 recibe aferencia bilateral del tálamo
│  ├─ Auditiva: BILATERAL desde el tronco — cada oído proyecta a estructuras de ambos
│  │  lados, con el punto de transición discutido entre la onda III y la onda IV
│  └─ Visual: bilateral desde el quiasma, pero organizada POR HEMICAMPO, no por ojo. La
│     síntesis de la información de ambos ojos ocurre primariamente en la corteza
├─ COMPARACIÓN — qué lateraliza y qué no (la consecuencia práctica)
│  ├─ PESS: LATERALIZA LIMPIAMENTE. Un PESS cortical anormal tras estimular un lado
│  │  indica lesión contralateral por encima del bulbo e ipsilateral por debajo. Es la
│  │  única de las tres con esa limpieza — salvo en la no decusación
│  ├─ PEATC: NO lateraliza de forma simple. Al ser bilateral desde el tronco, una lesión
│  │  unilateral puede dar anormalidades en ambas estimulaciones monoaurales, sobre todo
│  │  a nivel mesencefálico
│  │  ├─ La regla empírica que sí funciona: las anormalidades son IPSILATERALES al oído
│  │  │  estimulado, y en ningún caso descrito una lesión unilateral produjo anormalidad
│  │  │  aislada contralateral
│  │  ├─ Localiza mejor en el eje ROSTROCAUDAL que en el transversal: I-III prolongado →
│  │  │  lesión pontina · III-V prolongado → lesión mesencefálica
│  │  └─ Complejo IV/V asimétrico → lesión mesencefálica ipsilateral al oído que produce
│  │     mayor atenuación
│  └─ PEV: NO lateraliza con campo completo, y encima lo que se ve está INVERTIDO
│     ├─ Un PEV monocular anormal con campo completo indica defecto prequiasmático de ese
│     │  ojo, pero no dice nada de lateralidad hemisférica
│     ├─ La lateralización paradójica hace que el registro de mayor amplitud aparezca
│     │  ipsilateral al hemicampo estimulado
│     ├─ Una asimetría interhemisférica similar con ambos ojos sugiere defecto
│     │  postquiasmático contralateral al lado de menor amplitud, pero solo se establece
│     │  firmemente con estimulación de HEMICAMPOS
│     └─ El P100 de campo completo es la suma de ocho divisiones del campo con
│        contribuciones desiguales, de modo que un P100 anormal no localiza por sí solo
│        qué división está afectada
├─ El hilo común: la lateralización paradójica
│  └─ PEV y PESS de MMII la comparten, y por la MISMA razón física: corteza activada en
│     profundidad (interhemisférica o medial) → vector neto dirigido al lado opuesto →
│     mayor amplitud registrada IPSILATERAL. El PESS de MMSS no la tiene porque su
│     activación cortical es superficial
├─ Errores y confusiones frecuentes
│  ├─ ASUMIR la decusación en PESS: la no decusación existe (parálisis de la mirada
│  │  horizontal con escoliosis progresiva; 2.3% en una serie de escoliosis de Oriente
│  │  Medio) y se pierde con las derivaciones tradicionales
│  ├─ Leer la lateralización del PEV al revés por desconocer la lateralización paradójica
│  ├─ Leer la lateralización del P37 al revés por desconocer que el área del pie está en
│  │  la cara medial
│  └─ Esperar del PEATC una lateralización tipo PESS: la bilateralidad temprana de la vía
│     auditiva lo impide
└─ Referencia

      cap.4 §4.3 pp.54-55

## Ampliación — profundizar

```
Anatomía comparada de las tres vías — ampliación
├─ Sistema trigeminal (la "cuarta vía" somatosensorial)
│  ├─ Cuerpos celulares en el ganglio trigeminal (de Gasser o semilunar); las ramas
│  │  centrales entran en el núcleo sensitivo trigeminal, que se extiende desde el
│  │  mesencéfalo hasta la parte alta de la médula espinal
│  ├─ Las fibras ascendentes de ese núcleo se unen al lemnisco medial CONTRALATERAL y
│  │  llegan al VPM, que proyecta al giro postcentral lateral a la proyección de la mano
│  └─ La porción ROSTRAL del núcleo se ocupa de tacto, calor y frío; la porción más
│     CAUDAL (núcleo espinal del trigémino) se ocupa principalmente de dolor y de
│     sensaciones de frío y calor, y está implicada en la neuralgia del trigémino
├─ Tipos de fibra sensitiva y su velocidad
│  └─ Receptores cutáneos de bajo umbral inervados por fibras Aβ (6-12 µm, 30-70 m/s) ·
│     fibras propioceptivas de husos, órganos tendinosos y receptores articulares son Aα
│     (grandes) · las fibras del dolor son las mielínicas más pequeñas (Aδ) · las
│     amielínicas (C) también median dolor
├─ Comparación de precisión entre sistemas somatosensoriales
│  └─ El sistema de columna dorsal comunica tacto fino con razón sináptica casi 1:1, lo
│     que da localización y discriminación muy precisas; el sistema anterolateral se
│     ocupa de sensación táctil menos localizada y más general
└─ Criterios de anormalidad del PEV que se derivan de esta anatomía
   ├─ Latencia del P100 prolongada: es el parámetro menos variable y más sensible, la
   │  medida más útil. Según laboratorio, media+3SD para P100 = 115-120 ms con damero
   │  grande (~1°)
   ├─ Diferencia interocular de P100 anormal habitualmente >10 ms (el anormal es el ojo
   │  con el P100 más largo)
   ├─ Amplitud del P100 muy variable en normales (2-20 µV): la amplitud absoluta tiene
   │  poca significación clínica por sí sola; se usa la razón interocular ≥2
   ├─ Asimetría interhemisférica: preocupa si la razón es >3, pero es el criterio de
   │  amplitud MÁS DÉBIL por la gran variabilidad del P100 en los electrodos occipitales
   │  laterales
   └─ P100 en "W" (bifid): 14% de los casos. Causas: variante normal (a menudo se
      resuelve cambiando el tamaño de damero) · P100 y N100 asincrónicos · dos picos por
      defecto de conducción en la vía de un hemicampo, el primero por la vía normal y el
      segundo por la lenta
Referencia: Markand2020 cap.3 pp.91, 97-99 · Moller2011 cap.5 pp.60-65
```
