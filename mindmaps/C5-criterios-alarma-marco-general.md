# C5 — Marco general de criterios de alarma

```
Marco general de criterios de alarma
├─ El dilema, planteado sin rodeos
│  ├─ ¿La información que da la monitorización debe usarse SOLO como AVISO —una alarma
│  │  que implica que, si no se interviene, hay probabilidad de déficit neurológico
│  │  permanente— o debe transmitirse al cirujano TODO cambio de función detectado?
│  └─ No es una discusión de estilo: las dos posturas producen conductas distintas en el
│     mismo quirófano y ante la misma señal
├─ POR QUÉ EL ENFOQUE DE UMBRAL PURO NO SE SOSTIENE
│  ├─ Si solo se comunica lo que se presume que indica alto riesgo, habría que SABER
│  │  cuánto cambio puede permitirse sin causar daño permanente detectable — y esa
│  │  pregunta sigue, en gran medida, SIN RESPONDER
│  ├─ Tres factores influyen probablemente en el desenlace, y el peso de cada uno es en
│  │  gran parte desconocido: el GRADO del cambio, la NATURALEZA del cambio y el TIEMPO
│  │  que ha persistido el efecto adverso
│  ├─ A eso se suma la variación individual en la susceptibilidad a las agresiones
│  │  quirúrgicas: la disposición del individuo, su estado homeostático y quizá el propio
│  │  efecto de la anestesia
│  ├─ Conclusión explícita de la fuente: NO es posible definir reglas generales sobre qué
│  │  nivel de cambio carece de probabilidad de causar efectos permanentes. Es decir, NO
│  │  es posible saber qué cambios son "seguros"
│  └─ El argumento decisivo, que es de lógica quirúrgica y no de estadística
│     ├─ Si la información se RETIENE hasta alcanzar el nivel de alarma, al cirujano le
│     │  resulta difícil determinar QUÉ PASO del procedimiento causó el efecto adverso
│     ├─ Y sin saber qué paso lo causó, no puede intervenir apropiadamente
│     └─ Además pierde la libertad de retrasar su acción, porque para cuando se le avisa
│        el problema ya ha alcanzado niveles peligrosos
├─ EL ENFOQUE ALTERNATIVO: INFORMACIÓN, NO AVISOS
│  ├─ Si se informa de cualquier cambio apreciable, ya no hace falta saber cuánto cambio
│  │  se puede permitir antes de actuar — el problema epistemológico desaparece
│  ├─ Criterio operativo concreto: deben reportarse al cirujano los cambios MAYORES que
│  │  las (pequeñas) variaciones normales que se ven habitualmente en esos registros,
│  │  siempre que haya certeza razonable de que se relacionan con maniobras quirúrgicas
│  ├─ Formulación que resume la filosofía: la monitorización intraoperatoria proporciona
│  │  INFORMACIÓN más que AVISOS
│  ├─ Qué gana el cirujano: la opción de alterar su curso de acción en un rango AMPLIO de
│  │  tiempo
│  │  ├─ Si el cambio es pequeño, es probable que pueda revertirlo con una modificación
│  │  │  ligera del abordaje o evitando seguir manipulando ese tejido
│  │  └─ O puede decidir NO cambiar la técnica, si las maniobras que causaron el cambio
│  │     son esenciales para hacer la operación como estaba prevista — y aun en ese caso,
│  │     saber que el procedimiento está afectando la función de forma MEDIBLE es
│  │     valioso, y la monitorización continua le permite decidir sobre la marcha
│  └─ Beneficio adicional, docente y de sistema: informar en cuanto el cambio es
│     detectable le dice al cirujano exactamente qué pasos de la operación pueden producir
│     déficit. Con ese conocimiento se pueden modificar operaciones futuras para evitar
│     lesiones similares — la monitorización contribuye así a desarrollar métodos
│     quirúrgicos más seguros y a formar residentes
├─ REGISTRO COMUNICATIVO: ORIENTACIÓN FRENTE A AVISO
│  ├─ Al comunicar cambios PRECOCES hay que dejar CLARO al cirujano que se le está dando
│  │  información de ORIENTACIÓN (guidance), no un aviso
│  ├─ El AVISO propiamente dicho está justificado en dos situaciones
│  │  ├─ Cuando hay un cambio SÚBITO y GRANDE de los potenciales evocados
│  │  └─ Cuando el cirujano ha desatendido la necesidad de revertir una maniobra que está
│  │     causando un cambio LENTO y progresivo
│  └─ Manejar bien esa distinción es lo que evita el desgaste: si todo se comunica con
│     tono de alarma, la alarma deja de significar nada
├─ LA REGLA DE SECUENCIA — avisar primero, comprobar el equipo después
│  ├─ Hay que informar al cirujano de la posibilidad de lesión quirúrgica INCLUSO cuando
│  │  el cambio (o la desaparición total de los potenciales) pudiera deberse a fallo del
│  │  equipo o de un electrodo
│  ├─ Solo DESPUÉS de asumir que el problema es de naturaleza BIOLÓGICA se considera el
│  │  fallo de equipo como causa posible
│  ├─ El troubleshooting del equipo es una acción SECUNDARIA
│  ├─ Las dos posturas publicadas, y por qué gana una
│  │  ├─ Algunos autores defienden que ante cambios súbitos grandes se descarten primero
│  │  │  los problemas técnicos y después se notifique
│  │  ├─ Otros defienden notificar de inmediato y comprobar el equipo a continuación
│  │  └─ Aritmética del riesgo que zanja el debate: los problemas técnicos son RAROS. Si
│  │     tras avisar resulta ser un fallo de equipo, la única pérdida son unos minutos del
│  │     tiempo del cirujano. Si el cambio era funcional y se retrasó el aviso buscando
│  │     una causa técnica, se ha perdido tiempo precioso, se ha perdido la oportunidad de
│  │     identificar la causa, y el cambio ha tenido margen para progresar
│  ├─ El cirujano NO debe esperar a que termine la comprobación del equipo: debe empezar
│  │  inmediatamente su propia investigación para determinar si ha ocurrido una lesión
│  ├─ Dato que hace viable esta regla: las características de los cambios causados por
│  │  problemas técnicos son habitualmente TAN DISTINTAS de las causadas por lesión que un
│  │  neurofisiólogo experimentado las distingue con facilidad
│  └─ CONTRAPARTIDA OBLIGATORIA: aceptar esta forma de trabajar exige hacer todo lo
│     posible para reducir al mínimo absoluto los fallos técnicos capaces de mimetizar un
│     cambio quirúrgico. Con equipo de alta calidad los fallos son muy infrecuentes, y con
│     electrodos de aguja bien colocados los fallos de electrodo son raros
├─ FALSOS POSITIVOS Y FALSOS NEGATIVOS — por qué las definiciones clásicas no valen
│  ├─ Definición clásica: falso positivo es que el test muestre enfermedad donde no la
│  │  hay; falso negativo, que el test no detecte la enfermedad existente. En clínica y en
│  │  cribado, los falsos negativos son más graves
│  ├─ Estas definiciones NO son trasladables a la monitorización intraoperatoria. Razón de
│  │  fondo: el propósito de la MIO no es detectar cuándo una maniobra CAUSARÁ un déficit
│  │  permanente, sino informar de que puede existir un RIESGO apreciable de que ocurra
│  ├─ Hecho que lo confirma: en la MAYORÍA de los casos en que la monitorización muestra
│  │  cambios que indican riesgo, NO se produce déficit permanente — y no hay
│  │  consecuencias serias asociadas a ese tipo de "falsos positivos"
│  ├─ QUÉ ES UN VERDADERO FALSO POSITIVO: haber alertado al cirujano por un cambio que
│  │  después se demostró debido a un FALLO TÉCNICO, o a un cambio inocuo del sistema
│  │  nervioso, en lugar de a la manipulación quirúrgica
│  └─ Los FALSOS NEGATIVOS —que un riesgo serio ocurra sin ser advertido— sí representan
│     un fallo en alcanzar el objetivo de la monitorización, y pueden tener consecuencias
│     graves. La asimetría es total: el falso positivo cuesta minutos, el falso negativo
│     cuesta función
├─ EL MARCO FORMAL DE EXACTITUD DIAGNÓSTICA — el vocabulario de contingencia
│  ├─ Por qué convive con lo anterior sin contradecirlo: la postura de "información, no
│  │  avisos" describe cómo COMUNICAR en tiempo real; el marco de exactitud diagnóstica
│  │  (DTA, diagnostic test accuracy) describe cómo se MIDE a posteriori el rendimiento de
│  │  una modalidad en una serie publicada. Son dos preguntas distintas, y mezclar las dos
│  │  definiciones de "falso positivo" es la fuente habitual de confusión
│  ├─ LAS DOS PIEZAS QUE DEFINEN CUALQUIER TEST
│  │  ├─ TEST ÍNDICE (index test): el dato neurofisiológico registrado para predecir la
│  │  │  presencia o ausencia de la condición clínica diana
│  │  └─ PATRÓN DE REFERENCIA (reference standard): una herramienta de evaluación clínica
│  │     bien validada que determina si existe lesión neural postoperatoria. Ejemplo
│  │     habitual: una escala motora postoperatoria de seis puntos
│  ├─ LAS CUATRO CELDAS, DEFINIDAS EN CLAVE INTRAOPERATORIA (no en clave de laboratorio)
│  │  ├─ VERDADERO POSITIVO: se cumple el criterio de alerta y NO mejora hasta el final de
│  │  │  la cirugía → el paciente despierta con déficit nuevo referible al elemento neural
│  │  │  testado
│  │  ├─ VERDADERO NEGATIVO: no se cumple el criterio de alerta en toda la cirugía → el
│  │  │  paciente despierta sin déficit referible a ese elemento
│  │  ├─ FALSO NEGATIVO: no se cumple el criterio de alerta → el paciente despierta CON
│  │  │  déficit nuevo referible a ese elemento
│  │  └─ FALSO POSITIVO: se cumple el criterio de alerta y no mejora → el paciente
│  │     despierta SIN déficit referible a ese elemento
│  │     └─ Detalle que se pasa por alto siempre: las cuatro definiciones exigen que el
│  │        cambio PERSISTA hasta el final de la cirugía. El cambio que se recupera no
│  │        entra en ninguna de las cuatro celdas — es la categoría aparte de más abajo
│  ├─ LAS MÉTRICAS, CON SU FÓRMULA EXACTA
│  │  ├─ SENSIBILIDAD = VP / (VP + FN) — aciertos entre todos los casos en que la
│  │  │  condición diana SÍ está presente
│  │  ├─ ESPECIFICIDAD = VN / (FP + VN) — aciertos entre todos los casos en que la
│  │  │  condición diana NO está presente
│  │  ├─ VALOR PREDICTIVO POSITIVO = VP / (VP + FP) — fracción de alarmas que son ciertas.
│  │  │  Es lo que de verdad le importa al cirujano tras una alarma, y es engañoso en
│  │  │  procedimientos de riesgo relativamente bajo
│  │  ├─ VALOR PREDICTIVO POSITIVO FALSO = FP / (VP + FP)
│  │  ├─ TASA DE FALSOS POSITIVOS = FP / (FP + VN), que es 1 − especificidad
│  │  ├─ CRITERIO DE ALERTA (alert criterion): el valor de corte o umbral que el clínico
│  │  │  ELIGE para separar normalidad de anormalidad. No es una propiedad del test: es
│  │  │  una decisión
│  │  ├─ PROBABILIDAD PREVIA (Pprior): el riesgo pretest de lesión neural intraoperatoria
│  │  │  —o prevalencia de la condición diana— en la cirugía para la que se monitoriza
│  │  ├─ PROBABILIDAD REVISADA (Prevised) = sensibilidad × Pprior / [sensibilidad × Pprior
│  │  │  + (1 − especificidad) × (1 − Pprior)] — el riesgo postest actualizado
│  │  └─ COCIENTE DE VEROSIMILITUD = sensibilidad / (1 − especificidad). Su ventaja
│  │     práctica: permite ordenar la probabilidad de que una alarma exija cambiar el
│  │     manejo del caso AUNQUE NO SE CONOZCA la probabilidad previa
│  ├─ LA CURVA ROC Y EL CRITERIO QUE "DESLIZA"
│  │  ├─ Todo test diagnóstico se ajusta a una curva ROC, que representa la sensibilidad
│  │  │  en el eje y frente a 1 − especificidad (tasa de falsos positivos) en el eje x
│  │  │  según varía el umbral de alerta
│  │  ├─ En MIO el sesgo es evitar el falso negativo a toda costa → se prioriza un test
│  │  │  muy sensible a costa de exceso de informes falsos positivos
│  │  ├─ Trampa estadística que hay que tener interiorizada: cuando el riesgo neurológico
│  │  │  previo es MUY BAJO (por ejemplo 1% de probabilidad), la proporción de informes
│  │  │  falsos positivos aumenta INCLUSO SI EL TEST ES MUY EXACTO
│  │  ├─ El clínico puede adherirse al criterio publicado o, tras discutirlo con el
│  │  │  cirujano, DESLIZARLO hacia más sensibilidad o más especificidad
│  │  │  ├─ MEP medular: el criterio de "desaparición" es el que tiene respaldo en la
│  │  │  │  literatura; se puede deslizar hacia el 80% o incluso el 60% de pérdida de
│  │  │  │  amplitud — más sensible, menos específico
│  │  │  └─ Tornillo pedicular: conociendo las tasas significativas de falsos positivos de
│  │  │     los umbrales tan citados de 10-15 mA, puede elegirse en su lugar un valor más
│  │  │     específico (y menos sensible) de 5-8 mA
│  │  └─ En el estudio que ilustra el capítulo, el máximo de (sensibilidad + especificidad)
│  │     para la amplitud del MEP cae en el 12.3% de amplitud preservada, es decir un 87.7%
│  │     de reducción
│  ├─ EL CAMBIO DE SEÑAL REVERSIBLE (RSC) — el agujero del marco 2×2
│  │  ├─ Definición: se cumple el criterio de alerta durante la cirugía, posiblemente
│  │  │  indicando la presencia real de la condición diana, pero REVIERTE a un resultado
│  │  │  basal antes de terminar la intervención
│  │  ├─ La paradoja: no puede afirmarse con certeza que ese positivo sea "verdadero",
│  │  │  porque en el momento de la alarma es IMPOSIBLE aplicar el patrón de referencia y
│  │  │  saber si la condición diana está presente o ausente
│  │  ├─ Los RSC se han clasificado en la literatura como VP, FP, VN o simplemente
│  │  │  indeterminados, y NINGUNA de esas categorías es satisfactoria sin más análisis
│  │  ├─ Y sin embargo la secuencia pérdida de señal → intervención → retorno de señal es
│  │  │  EXACTAMENTE el paradigma que justifica la mayor parte de la MIO: el paciente
│  │  │  estuvo expuesto a una lesión medida por la pérdida de señal, y la lesión se evitó
│  │  ├─ PRIMER ABORDAJE PARA CATEGORIZARLO: el CONTEXTO QUIRÚRGICO, cuantificado
│  │  │  ├─ Base conceptual: los criterios de causalidad de A.B. Hill — acontecimientos
│  │  │  │  temporalmente relacionados y repetibles
│  │  │  ├─ Se calcula una TASA DE CAMBIO: velocidad del cambio durante la maniobra lesiva
│  │  │  │  (o durante su reversión) dividida entre la velocidad de cambio esperable sin
│  │  │  │  lesión, es decir la variación normal del registro
│  │  │  ├─ Si ese cociente SUPERA 5-10, se puede tener bastante más certeza de que el
│  │  │  │  cambio fue "verdadero"
│  │  │  ├─ Ejemplo trabajado del capítulo (deformidad; MEP normal pero variable durante
│  │  │  │  180 min, compresión sobre una osteotomía torácica baja que reduce la amplitud
│  │  │  │  un 90% en 3 min, liberación de la instrumentación con retorno a nivel de no
│  │  │  │  alerta en 5 min): tasa de compresión 1/3/0,5/180 = 117 y tasa de liberación
│  │  │  │  1/5/0,5/120 = 48 — muy por encima del corte, luego se categoriza como
│  │  │  │  verdadero positivo (se usa 0,5 cuando se registran "0" eventos)
│  │  │  └─ Uso práctico: RSC con contexto quirúrgico que cumple el criterio → VP; RSC
│  │  │     "sin contexto quirúrgico" o ambiguo → FP
│  │  └─ SEGUNDO ABORDAJE: EFECTO DOSIS, también de A.B. Hill. Con una tabla de
│  │     contingencia 3×2 (sin cambio / cambio irreversible / RSC), la evidencia inicial
│  │     muestra lo esperable: el RSC predice mucha mejor probabilidad de buen resultado
│  │     que el cambio irreversible... pero NO tan buena como el registro sin cambios
│  ├─ LA SERIE QUE HAY QUE CONOCER: Langeloo y Journée 2003, 145 deformidades con MEP
│  │  ├─ Por qué es ejemplar: los autores decidieron avisar SOLO de eventos ocurridos
│  │  │  dentro de la herida. El troubleshooting técnico y la optimización de anestesia o
│  │  │  de tensión arterial NO se contaron como avisos al cirujano
│  │  │  └─ De los 10 pacientes con MEP transcraneal de baja amplitud atribuida a problema
│  │  │     anestésico o sistémico, NINGUNO desarrolló déficit neurológico nuevo
│  │  ├─ Criterio usado DURANTE la cirugía: pérdida del 80% de amplitud del MEP en UNO de
│  │  │  los seis músculos registrados en MMII → sensibilidad 100%, especificidad 91%,
│  │  │  VPP 61%
│  │  ├─ Criterio más específico aplicado post hoc: alerta en DOS de los seis músculos →
│  │  │  sensibilidad 81%, especificidad 97%, VPP 76%
│  │  ├─ Lección directa: incluso con avisos anclados al contexto quirúrgico, un registro
│  │  │  muy sensible produce exceso de falsos positivos; y al revés, un criterio más
│  │  │  específico es menos sensible. No hay forma de tener las dos cosas a la vez
│  │  └─ Admisión honesta de los propios autores sobre sus RSC: las amplitudes podrían
│  │     haberse recuperado espontáneamente sin la intervención quirúrgica subsiguiente, de
│  │     modo que su definición pudo generar más diagnósticos de evento neurológico de los
│  │     que realmente ocurrieron. Traducción: categorizar los RSC como VP SOBREESTIMA la
│  │     exactitud de nuestros tests
│  ├─ SESGO EN LAS SERIES PUBLICADAS — cómo se juzga si un número es creíble
│  │  ├─ QUADAS-2 es la herramienta para valorar la calidad de los estudios de exactitud
│  │  │  diagnóstica; ROBINS-I sirve para estudios de intervención, no para estos
│  │  ├─ Sus cuatro dominios: selección de pacientes, test índice, patrón de referencia y
│  │  │  flujo/tiempos del paciente desde el test índice hasta el patrón de referencia
│  │  ├─ El dominio MÁS PERTINENTE en MIO es el de flujo y tiempos, por una razón
│  │  │  estructural: el cirujano INTERVIENE tras la alerta, y esa intervención se
│  │  │  interpone entre el test y la evaluación del patrón de referencia. Ese sesgo es
│  │  │  INEVITABLE con cualquier método que se use para caracterizar la exactitud de la
│  │  │  MIO
│  │  ├─ Sesgo de exclusión que hay que saber detectar: algunas series excluyen de la tabla
│  │  │  de contingencia a pacientes con mal resultado alegando fallos en la metodología de
│  │  │  monitorización. Debe evitarse
│  │  ├─ Supuesto oculto de todo el marco: se asume que el patrón de referencia es 100%
│  │  │  exacto, lo que atribuye toda discrepancia a la inexactitud del test índice — y en
│  │  │  varias series revisadas falta un patrón de referencia ciego, fiable, cuantificable
│  │  │  y bien pegado en el tiempo al final de la cirugía
│  │  └─ GRADE aporta la calidad global de la evidencia también para tests diagnósticos:
│  │     riesgo de sesgo, diseño del estudio, indirectness, imprecisión, heterogeneidad
│  │     inexplicada y sesgo de publicación, con posibilidad de SUBIR la calificación por
│  │     efecto dosis, estimaciones grandes de exactitud o confusión residual plausible
│  └─ EXACTITUD NO ES EFICACIA — el aviso final, y el más incómodo
│     ├─ Es falso asumir que una predicción exacta se traduce directamente en mejor
│     │  resultado clínico frente a no monitorizar
│     ├─ Tres formas concretas de que un test exacto no sirva de nada
│     │  ├─ El test y la condición diana no casan bien: MEP de pares craneales bajos
│     │  │  íntegros en un abordaje de fosa posterior, con función voluntaria de lengua y
│     │  │  faringe normal después, pero reflejo nauseoso y tusígeno reducidos e ineficaces
│     │  ├─ La pérdida de señal se asocia a una condición NO reversible: coagulación
│     │  │  inadvertida de la arteria auditiva interna, pérdida del PEATC y sordera
│     │  │  permanente — el test acertó y no había nada que hacer
│     │  └─ El fallo desconcertante en iniciar un cambio de manejo potencialmente eficaz
│     │     tras la alarma — el error "no forzado", el más evitable de los tres, y el que
│     │     se combate con planificación prequirúrgica, checklists y una cultura de equipo
│     │     realmente colaborativa y situacionalmente consciente
│     └─ Dato general que sitúa el problema: al revisar los ensayos aleatorizados que
│        comparan pacientes testados frente a no testados en escenarios clínicos diversos,
│        solo el 18% respaldaba el test índice — y la exactitud del test NO se
│        correlacionaba con la efectividad clínica (el test de sangre oculta en heces, muy
│        poco específico, y la ecografía abdominal de aneurisma de aorta, de sensibilidad y
│        especificidad casi del 100%, tuvieron efectividad clínica similar)
├─ LA INCOMODIDAD QUE NO SE PUEDE ESCONDER
│  ├─ Algunos pacientes sufrirán déficit neurológico con cambios POR DEBAJO de cualquier
│  │  nivel de alarma
│  ├─ Cuanto más se conoce el efecto de la manipulación mecánica sobre los nervios, más
│  │  evidente parece que incluso cambios LIGEROS de las medidas de actividad eléctrica
│  │  (como el potencial de acción compuesto) pueden ser signos de lesión permanente
│  ├─ Los estudios que relacionan cambios de potenciales evocados con cambios morfológicos
│  │  y con la función postoperatoria siguen siendo RAROS
│  ├─ Se sabe relativamente poco, en términos cuantitativos, sobre cuánto puede estirarse,
│  │  calentarse o privarse de oxígeno un nervio antes de que la lesión sea permanente — y
│  │  distintos nervios responden de forma distinta a la manipulación mecánica y al calor
│  └─ Aún menos se conoce sobre la relación entre los cambios de potenciales sensitivos y
│     motores y los déficits por privación de oxígeno
├─ EL UMBRAL DEBE ADAPTARSE A LA REPRODUCIBILIDAD DE LA SEÑAL
│  ├─ La reproducibilidad basal de una señal determina qué magnitud de reducción hace
│  │  falta para que sea claramente NO aleatoria
```
