# C5 — Marco general de criterios de alarma

```
Marco general de criterios de alarma
├─ Concepto central
│  └─ Debate no resuelto entre dos filosofías: avisar solo al alcanzar un UMBRAL DE
│     ALARMA predefinido (alto riesgo de déficit permanente) vs. comunicar CUALQUIER
│     CAMBIO por encima de la variabilidad normal y dejar que el cirujano decida — el
│     enfoque dominante hoy (TIP, alerta precoz-gradual en B3/B8) se decanta por
│     avisar pronto y de forma graduada, porque solo así el cirujano puede identificar
│     qué maniobra causó el cambio y revertirla a tiempo
├─ A qué modalidades afecta
│  └─ Todas — cada modalidad tiene su criterio cuantitativo propio (compilados en
│     A1/A2/A3/A5/A7/A8/A9), pero el marco conceptual (falsos positivos/negativos,
│     jerarquía entre modalidades, cuándo avisar) es transversal a todas ellas
├─ Parámetros clave
│  ├─ Los conceptos de falso positivo/negativo de un test diagnóstico clásico NO se
│  │  trasladan igual a MIO: la mayoría de "falsos positivos" (avisos que no terminan
│  │  en déficit) son en realidad el resultado esperado de una intervención quirúrgica
│  │  EXITOSA tras el aviso, no un fallo del sistema
│  └─ Jerarquía entre modalidades ante discordancia: onda D > MEP como predictor de
│     pronóstico motor medular (A3/B3, Tabla 2.1); el criterio "todo o nada" es válido
│     en médula pero insuficiente en tronco, donde se usa variación de amplitud
│     50-80% (B8)
├─ Aplicación práctica
│  ├─ Regla de secuencia: ante cambio brusco, AVISAR PRIMERO al cirujano y comprobar
│  │  el equipo DESPUÉS, nunca al revés — el coste de una falsa alarma técnica es
│  │  unos minutos; el coste de retrasar el aviso mientras se descarta lo técnico,
│  │  ante una lesión real, es tiempo de reacción irrecuperable
│  ├─ Protocolo tipo TIP (Time-Irrigation-Pressure) como respuesta estandarizada a la
│  │  alerta precoz/reversible en cirugía medular (B3)
│  └─ Basales antes Y después del posicionamiento definitivo para poder atribuir
│     correctamente un cambio (B3)
├─ Errores frecuentes
│  ├─ Tratar el criterio "todo o nada" como universal — falla en tronco (B8)
│  ├─ Aplicar el mismo umbral cuantitativo (p. ej. 50%) en todos los contextos sin
│  │  ajustar por la reproducibilidad basal de la señal (A1-Ampliación, Tabla 3.1)
│  └─ Retrasar el aviso al cirujano mientras se descarta causa técnica
├─ Conexión con otros nodos
│  └─ A1 (criterios adaptativos), A3 (Tabla 2.1, jerarquía onda D/MEP), B3/B8
│     (jerarquía de alarma aplicada por contexto), C6 (troubleshooting — causas no
│     quirúrgicas de cambio, la contraparte técnica de este marco)
└─ Referencia
   └─ Moller2011, cap. 2, "Basis of Intraoperative Neurophysiological Monitoring",
      secciones "When to Inform the Surgeon", "False Alarms", "Nonsurgical Causes of
      Changes in Recorded Potentials", pp.14-18
```
