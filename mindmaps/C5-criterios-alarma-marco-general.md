# C5 — Marco general de criterios de alarma

```
Marco general de criterios de alarma
├─ El dilema, planteado sin rodeos
│  ├─ ¿La información que da la monitorización debe usarse SOLO como AVISO —una alarma
│  │  que implica que, si no se interviene, hay probabilidad de déficit neurológico
│  │  permanente— o debe transmitirse al cirujano TODO cambio de función detectado?
│  └─ No es una discusión de estilo: las dos posturas producen conductas distintas en el
│     mismo quirófano y ante la misma señal
├─ POR QUÉ EL ENFOQUE DE UMBRAL PURO NO SE SOSTIENE
│  ├─ Si solo se comunica lo que se presume que indica alto riesgo, habría que SABER
│  │  cuánto cambio puede permitirse sin causar daño permanente detectable — y esa
│  │  pregunta sigue, en gran medida, SIN RESPONDER
│  ├─ Tres factores influyen probablemente en el desenlace, y el peso de cada uno es en
│  │  gran parte desconocido: el GRADO del cambio, la NATURALEZA del cambio y el TIEMPO
│  │  que ha persistido el efecto adverso
│  ├─ A eso se suma la variación individual en la susceptibilidad a las agresiones
│  │  quirúrgicas: la disposición del individuo, su estado homeostático y quizá el propio
│  │  efecto de la anestesia
│  ├─ Conclusión explícita de la fuente: NO es posible definir reglas generales sobre qué
│  │  nivel de cambio carece de probabilidad de causar efectos permanentes. Es decir, NO
│  │  es posible saber qué cambios son "seguros"
│  └─ El argumento decisivo, que es de lógica quirúrgica y no de estadística
│     ├─ Si la información se RETIENE hasta alcanzar el nivel de alarma, al cirujano le
│     │  resulta difícil determinar QUÉ PASO del procedimiento causó el efecto adverso
│     ├─ Y sin saber qué paso lo causó, no puede intervenir apropiadamente
│     └─ Además pierde la libertad de retrasar su acción, porque para cuando se le avisa
│        el problema ya ha alcanzado niveles peligrosos
├─ EL ENFOQUE ALTERNATIVO: INFORMACIÓN, NO AVISOS
│  ├─ Si se informa de cualquier cambio apreciable, ya no hace falta saber cuánto cambio
│  │  se puede permitir antes de actuar — el problema epistemológico desaparece
│  ├─ Criterio operativo concreto: deben reportarse al cirujano los cambios MAYORES que
│  │  las (pequeñas) variaciones normales que se ven habitualmente en esos registros,
│  │  siempre que haya certeza razonable de que se relacionan con maniobras quirúrgicas
│  ├─ Formulación que resume la filosofía: la monitorización intraoperatoria proporciona
│  │  INFORMACIÓN más que AVISOS
│  ├─ Qué gana el cirujano: la opción de alterar su curso de acción en un rango AMPLIO de
│  │  tiempo
│  │  ├─ Si el cambio es pequeño, es probable que pueda revertirlo con una modificación
│  │  │  ligera del abordaje o evitando seguir manipulando ese tejido
│  │  └─ O puede decidir NO cambiar la técnica, si las maniobras que causaron el cambio
│  │     son esenciales para hacer la operación como estaba prevista — y aun en ese caso,
│  │     saber que el procedimiento está afectando la función de forma MEDIBLE es
│  │     valioso, y la monitorización continua le permite decidir sobre la marcha
│  └─ Beneficio adicional, docente y de sistema: informar en cuanto el cambio es
│     detectable le dice al cirujano exactamente qué pasos de la operación pueden producir
│     déficit. Con ese conocimiento se pueden modificar operaciones futuras para evitar
│     lesiones similares — la monitorización contribuye así a desarrollar métodos
│     quirúrgicos más seguros y a formar residentes
├─ REGISTRO COMUNICATIVO: ORIENTACIÓN FRENTE A AVISO
│  ├─ Al comunicar cambios PRECOCES hay que dejar CLARO al cirujano que se le está dando
│  │  información de ORIENTACIÓN (guidance), no un aviso
│  ├─ El AVISO propiamente dicho está justificado en dos situaciones
│  │  ├─ Cuando hay un cambio SÚBITO y GRANDE de los potenciales evocados
│  │  └─ Cuando el cirujano ha desatendido la necesidad de revertir una maniobra que está
│  │     causando un cambio LENTO y progresivo
│  └─ Manejar bien esa distinción es lo que evita el desgaste: si todo se comunica con
│     tono de alarma, la alarma deja de significar nada
├─ LA REGLA DE SECUENCIA — avisar primero, comprobar el equipo después
│  ├─ Hay que informar al cirujano de la posibilidad de lesión quirúrgica INCLUSO cuando
│  │  el cambio (o la desaparición total de los potenciales) pudiera deberse a fallo del
│  │  equipo o de un electrodo
│  ├─ Solo DESPUÉS de asumir que el problema es de naturaleza BIOLÓGICA se considera el
│  │  fallo de equipo como causa posible
│  ├─ El troubleshooting del equipo es una acción SECUNDARIA
│  ├─ Las dos posturas publicadas, y por qué gana una
│  │  ├─ Algunos autores defienden que ante cambios súbitos grandes se descarten primero
│  │  │  los problemas técnicos y después se notifique
│  │  ├─ Otros defienden notificar de inmediato y comprobar el equipo a continuación
│  │  └─ Aritmética del riesgo que zanja el debate: los problemas técnicos son RAROS. Si
│  │     tras avisar resulta ser un fallo de equipo, la única pérdida son unos minutos del
│  │     tiempo del cirujano. Si el cambio era funcional y se retrasó el aviso buscando
│  │     una causa técnica, se ha perdido tiempo precioso, se ha perdido la oportunidad de
│  │     identificar la causa, y el cambio ha tenido margen para progresar
│  ├─ El cirujano NO debe esperar a que termine la comprobación del equipo: debe empezar
│  │  inmediatamente su propia investigación para determinar si ha ocurrido una lesión
│  ├─ Dato que hace viable esta regla: las características de los cambios causados por
│  │  problemas técnicos son habitualmente TAN DISTINTAS de las causadas por lesión que un
│  │  neurofisiólogo experimentado las distingue con facilidad
│  └─ CONTRAPARTIDA OBLIGATORIA: aceptar esta forma de trabajar exige hacer todo lo
│     posible para reducir al mínimo absoluto los fallos técnicos capaces de mimetizar un
│     cambio quirúrgico. Con equipo de alta calidad los fallos son muy infrecuentes, y con
│     electrodos de aguja bien colocados los fallos de electrodo son raros
├─ FALSOS POSITIVOS Y FALSOS NEGATIVOS — por qué las definiciones clásicas no valen
│  ├─ Definición clásica: falso positivo es que el test muestre enfermedad donde no la
│  │  hay; falso negativo, que el test no detecte la enfermedad existente. En clínica y en
│  │  cribado, los falsos negativos son más graves
│  ├─ Estas definiciones NO son trasladables a la monitorización intraoperatoria. Razón de
│  │  fondo: el propósito de la MIO no es detectar cuándo una maniobra CAUSARÁ un déficit
│  │  permanente, sino informar de que puede existir un RIESGO apreciable de que ocurra
│  ├─ Hecho que lo confirma: en la MAYORÍA de los casos en que la monitorización muestra
│  │  cambios que indican riesgo, NO se produce déficit permanente — y no hay
│  │  consecuencias serias asociadas a ese tipo de "falsos positivos"
│  ├─ QUÉ ES UN VERDADERO FALSO POSITIVO: haber alertado al cirujano por un cambio que
│  │  después se demostró debido a un FALLO TÉCNICO, o a un cambio inocuo del sistema
│  │  nervioso, en lugar de a la manipulación quirúrgica
│  └─ Los FALSOS NEGATIVOS —que un riesgo serio ocurra sin ser advertido— sí representan
│     un fallo en alcanzar el objetivo de la monitorización, y pueden tener consecuencias
│     graves. La asimetría es total: el falso positivo cuesta minutos, el falso negativo
│     cuesta función
├─ LA INCOMODIDAD QUE NO SE PUEDE ESCONDER
│  ├─ Algunos pacientes sufrirán déficit neurológico con cambios POR DEBAJO de cualquier
│  │  nivel de alarma
│  ├─ Cuanto más se conoce el efecto de la manipulación mecánica sobre los nervios, más
│  │  evidente parece que incluso cambios LIGEROS de las medidas de actividad eléctrica
│  │  (como el potencial de acción compuesto) pueden ser signos de lesión permanente
│  ├─ Los estudios que relacionan cambios de potenciales evocados con cambios morfológicos
│  │  y con la función postoperatoria siguen siendo RAROS
│  ├─ Se sabe relativamente poco, en términos cuantitativos, sobre cuánto puede estirarse,
│  │  calentarse o privarse de oxígeno un nervio antes de que la lesión sea permanente — y
│  │  distintos nervios responden de forma distinta a la manipulación mecánica y al calor
│  └─ Aún menos se conoce sobre la relación entre los cambios de potenciales sensitivos y
│     motores y los déficits por privación de oxígeno
├─ EL UMBRAL DEBE ADAPTARSE A LA REPRODUCIBILIDAD DE LA SEÑAL
│  ├─ La reproducibilidad basal de una señal determina qué magnitud de reducción hace
│  │  falta para que sea claramente NO aleatoria
│  ├─ El clásico 50% es apropiado para señales de reproducibilidad BAJA
│  ├─ Pero con reproducibilidad media-alta, ese 50% arriesga FALSOS NEGATIVOS: descensos
│  │  patológicos menores del 50% que resultan evidentes precisamente porque la señal era
│  │  muy estable
│  └─ Y con señales NO reproducibles, el 50% arriesga FALSOS POSITIVOS: señales que en
│     realidad tienen que desaparecer para significar algo
├─ CAUSAS NO QUIRÚRGICAS QUE HAY QUE TENER EN LA CABEZA
│  ├─ Cambios del NIVEL DE ANESTESIA
│  ├─ Cambios de la PRESIÓN ARTERIAL del paciente
│  ├─ Cambios de la TEMPERATURA corporal
│  └─ Obligación derivada: quien monitoriza debe conocer cómo afectan estos factores a los
│     potenciales que está registrando, y mantener comunicación CONSISTENTE Y FRECUENTE
│     con el anestesiólogo para estar al tanto de cualquier cambio del plano o del régimen
│     anestésico
├─ RAPIDEZ DE INTERPRETACIÓN — por qué es el parámetro crítico
│  ├─ No se puede insistir bastante en la importancia de detectar un cambio de función lo
│  │  antes posible
│  └─ La interpretación rápida es lo que permite al cirujano identificar CON EXACTITUD el
│     paso de la operación que causó el cambio, y eso es PRERREQUISITO para una
│     intervención quirúrgica apropiada y a tiempo
├─ CÓMO SE PRESENTA LA INFORMACIÓN
│  ├─ Con EMG suele ser ventajoso hacer la respuesta AUDIBLE, para que el neurofisiólogo y
│  │  el cirujano puedan oírla y hacer cada uno su propia interpretación
│  └─ Por lo demás, las posibilidades de presentar los potenciales directamente al cirujano
│     son pocas y es discutible que sea ventajoso: pocos cirujanos son fisiólogos, y la
│     mayoría prefieren los resultados en forma DESCRIPTIVA antes que datos crudos
├─ LA MIO NO SOLO EVITA DÉFICIT: TAMBIÉN GUÍA
│  ├─ En su forma más simple, identificar la localización anatómica exacta de un nervio que
│  │  no se puede identificar visualmente
│  ├─ Identificar en qué punto de un nervio periférico se ha producido un bloqueo de
│  │  conducción; en cirugía de reparación de nervio periférico, el diagnóstico
│  │  intraoperatorio de la naturaleza y la localización exacta de la lesión ha mejorado
│  │  los resultados
│  ├─ Espasmo hemifacial: la respuesta muscular anormal desaparece cuando el nervio facial
│  │  queda adecuadamente descomprimido → permite identificar el vaso o los vasos causantes
│  │  y confirmar que la descompresión es suficiente
│  └─ Cirugía funcional: la guía electrofisiológica para colocar lesiones en ganglios
│     basales y tálamo es absolutamente esencial para el éxito, y lo mismo vale hoy para
│     guiar la colocación de electrodos de estimulación cerebral profunda
├─ EVALUACIÓN DE RESULTADOS
│  ├─ Para valorar el éxito en evitar déficits hay que explorar y testar a los pacientes
│  │  adecuadamente ANTES y DESPUÉS de la cirugía, de forma que los cambios puedan
│  │  verificarse cuantitativamente
│  └─ Algunas lesiones solo son detectables con pruebas neurológicas específicas; otras
│     producen alteración sensitiva que el paciente nota; otras son evidentes para el
│     paciente y para su entorno en la vida diaria
├─ Errores y confusiones frecuentes
│  ├─ Retrasar el aviso al cirujano mientras se descarta la causa técnica
│  ├─ Comunicar todo con tono de alarma, sin distinguir orientación de aviso
│  ├─ Aplicar un umbral del 50% sin ajustarlo a la reproducibilidad basal de esa señal en
│  │  ese paciente
│  ├─ Contabilizar como "falsos positivos" los avisos seguidos de intervención exitosa: en
│  │  MIO eso es el sistema funcionando, no fallando
│  ├─ Tratar un criterio cuantitativo desarrollado para un contexto como si fuera universal
│  └─ No preguntar al anestesiólogo antes de interpretar un cambio lento y global
├─ Limitaciones
│  ├─ No existe, y probablemente no puede existir, una regla general sobre qué cambio es
│  │  seguro
│  ├─ La evidencia que relaciona magnitud de cambio con desenlace morfológico y funcional
│  │  es escasa
│  ├─ Un cambio por debajo del umbral no excluye lesión permanente
│  └─ Toda la estrategia de "avisar primero" depende de un supuesto que hay que ganarse a
│     diario: que los fallos técnicos capaces de imitar una lesión se han reducido al
│     mínimo
└─ Referencia
   └─ Moller2011 cap.2 pp.13-18 — "When to Inform the Surgeon" (el dilema, imposibilidad de
      definir cambios seguros, información frente a avisos, orientación frente a aviso),
      "False Alarms" (por qué no valen las definiciones clásicas, qué es un verdadero falso
      positivo), "Nonsurgical Causes of Changes in Recorded Potentials" (regla de secuencia,
      anestesia, presión arterial y temperatura), "How to Evaluate Neurological Deficits",
      "Aiding the Surgeon in the Operation" · Deletis cap.3 (MacDonald) pp.39-46, Tabla 3.1
      — criterios adaptativos según la reproducibilidad de la señal, riesgo de falso
      negativo y de falso positivo del umbral fijo del 50%
```
