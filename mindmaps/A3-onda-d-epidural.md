# A3 — Onda D (D-wave epidural)

```
Onda D (D-wave epidural)
├─ Vía anatómica
│  └─ Activación directa de axones piramidales rápidos del CST
│     └─ Potencial ASINÁPTICO — no depende de transmisión sináptica espinal
├─ Estimulación
│  └─ Igual que MEP (TES transcraneal)
│     └─ Interesa el registro epidural, no la respuesta muscular
├─ Registro / montaje
│  ├─ Electrodo epidural rostral a la lesión (imprescindible)
│  │  └─ ± caudal (compara amplitud proximal/distal)
│  └─ Mantener colocado hasta cierre dural completo
│     └─ El riesgo no termina con la resección: hemostasia y cierre también comprometen
├─ Morfología normal
│  └─ Onda única, robusta, amplitud relativamente estable durante el procedimiento
├─ Efecto anestesia/fisiología
│  └─ Mínimamente afectada por anestésicos y relajantes (potencial asináptico)
│     └─ Su gran ventaja frente al MEP
├─ Criterios de alarma
│  ├─ Declive gradual 20-30% → alerta precoz → protocolo tipo TIP
│  │  └─ TIP: detener disección, irrigar suero templado, ↑PAM ≥80-85 mmHg
│  └─ Caída >50% → predictor de déficit motor PERMANENTE
│     └─ Sobre todo si coincide con pérdida de MEP
├─ Jerarquía diagnóstica (discordancia con MEP)
│  ├─ Onda D estable + MEP perdido → déficit transitorio probable
│  └─ Onda D caída >50% + MEP perdido → déficit permanente probable
├─ Limitaciones
│  ├─ Poco o nada registrable en tumores del cono medular
│  │  └─ Menos axones CST + mayor longitud a nivel torácico bajo
│  └─ Señal global, no lateralizada — no sustituye al MEP para detectar asimetría
└─ Referencia
   └─ Boaro2026 · Costa2015 · MacDonald2013
```

## Ampliación — profundizar

```
Onda D — ampliación
├─ Electrodo y colocación (con datos de seguridad)
│  ├─ Catéter JX-330/JX-3002: 3 cilindros de platino-iridio de 3 mm, separados 18 mm,
│  │  doble lumen para lavado con salino
│  ├─ Colocación percutánea con aguja Tuohy 14G en T1-T2, avanzando hasta cervical bajo
│  └─ Series de seguridad: 57 y 16 pacientes sin ninguna complicación (sangrado,
│     infección, punción medular)
├─ Amplitud según nivel y desincronización — más allá de "poco registrable en cono"
│  ├─ Amplitud cervical ≥60 µV vs. torácica ~10 µV con el mismo electrodo; por debajo
│  │  de T10 (Boaro: ~metámero D11) suele no ser registrable con amplitud suficiente
│  └─ Desincronización (tumor intramedular o post-radioterapia medular): fibras CST
│     rápidas conducen a velocidades distintas entre sí → onda D de bajo voltaje/base
│     ancha o no registrable, INCLUSO con MEP muscular presente y sin déficit motor
│     mayor — mecanismo distinto de la ausencia por localización
└─ Correlación pronóstica cuantificada (Tabla 2.1) y su ambigüedad
   ├─ D-wave estable o caída 30-50% + MEP perdido → déficit transitorio · caída >50%
   │  + MEP perdido bilateral → déficit permanente — aplicado en 100 cirugías
   │  consecutivas de tumor intramedular: 0 pacientes con paraplejia postoperatoria
   └─ Ambigüedad del "50%": la misma cifra puede corresponder a una pérdida difusa
      bilateral tolerable O a una pérdida completa unilateral grave — mismo número,
      pronóstico opuesto
Referencia: Deletis, cap. 2 (Deletis), §2.4.1.1-2.4.4 y Tabla 2.1, pp.23-32 ·
Moller2011, cap. 10, pp.215-221 · Boaro2026, sección 2.3
```
