# B9 — Descompresión microvascular de pares craneales

```
Descompresión microvascular de pares craneales
├─ QUÉ ES Y POR QUÉ ES DISTINTA A TODO LO DEMÁS DEL BLOQUE B
│  ├─ La MIO aquí tiene DOS objetivos separados, y conviene no mezclarlos nunca
│  │  ├─ OBJETIVO TERAPÉUTICO: demostrar que la descompresión ha sido suficiente — es decir,
│  │  │  confirmar el ÉXITO de la cirugía en tiempo real. Ninguna otra cirugía del bloque B
│  │  │  pide esto
│  │  └─ EVITAR COMPLICACIONES: lo habitual — hipoacusia, paresia facial, lesión de pares
│  │     bajos, lesión por posicionamiento
│  ├─ Principio quirúrgico: separar el conflicto neurovascular apartando el vaso ofensor del
│  │  nervio y colocando un cojín de fieltro entre ambos, de forma que el vaso no pueda
│  │  rebotar sobre el nervio
│  ├─ Para mejorar la tasa de curación el cirujano visualiza TODO el trayecto cisternal del
│  │  par craneal e identifica el sitio —o los sitios— de conflicto
│  └─ Existe tratamiento farmacológico (anticonvulsivantes para las neuralgias, toxina
│     botulínica para el espasmo hemifacial), pero el tratamiento etiológico y
│     potencialmente CURATIVO es la descompresión microvascular
├─ EL MECANISMO DE FONDO: por qué aparece con la edad
│  ├─ Varios trastornos neurológicos están causados por compresión vascular PULSÁTIL de
│  │  pares craneales CENTRALMENTE MIELINIZADOS
│  ├─ Los síntomas aparecerían porque las arterias de la base del cerebro se ALARGAN y forman
│  │  BUCLES con la edad hasta impactar sobre los nervios
│  └─ Y porque el cerebro además desciende CAUDALMENTE en la fosa posterior con la edad, lo
│     que contribuye a la compresión pulsátil tanto arterial como VENOSA
├─ LAS CUATRO PATOLOGÍAS
│  ├─ NEURALGIA DEL TRIGÉMINO (TGN)
│  │  ├─ Episodios recurrentes de dolor súbito, intenso, lancinante, tipo descarga eléctrica,
│  │  │  en la distribución de una o más ramas del V. Lo más frecuente, V2 y/o V3
│  │  ├─ Desencadenantes: cualquier tacto o estimulación de la cara — masticar, afeitarse,
│  │  │  maquillarse, incluso una brisa fría
│  │  ├─ TÍPICA frente a ATÍPICA: la típica es el síndrome lancinante clásico que dura de
│  │  │  segundos a pocos minutos; la atípica es dolor QUEMANTE CONSTANTE, mucho menos grave
│  │  ├─ CLÁSICA frente a SECUNDARIA: "clásica" son los casos relacionados con compresión
│  │  │  vascular; "secundaria", los causados por enfermedad subyacente como esclerosis
│  │  │  múltiple o un tumor a lo largo del trigémino
│  │  └─ Epidemiología: mujeres más afectadas que hombres, incidencia estimada de 4 a 13 por
│  │     100.000 al año. Suele manifestarse por encima de los 50 años, aunque se ha descrito a
│  │     cualquier edad
│  ├─ ESPASMO HEMIFACIAL (HFS) — la patología que da sentido a toda la neurofisiología de
│  │  este tema
│  │  ├─ Contracción intermitente de la musculatura facial, que habitualmente EMPIEZA en el
│  │  │  orbicular de los párpados
│  │  ├─ Curso implacable: con el tiempo progresa hacia abajo por la cara hasta afectar a
│  │  │  todos los músculos mayores del lado ipsilateral. Puede llegar a incluir el frontal,
│  │  │  el platisma y el ESTAPEDIO
│  │  │  └─ La afectación del estapedio es inusual y el paciente la refiere como un CHASQUIDO
│  │  │     extraño
│  │  ├─ La fatiga y las actividades estresantes exacerban los síntomas. Y aunque el espasmo
│  │  │  es involuntario, los movimientos VOLUNTARIOS —hablar, sonreír— desencadenan
│  │  │  contracciones
│  │  ├─ FENÓMENO DE TONUS: los paroxismos pueden llegar a ser tan graves que el paciente
│  │  │  desarrolla periodos de CONTRACTURA TÓNICA, que pueden asociarse a paresia de la
│  │  │  musculatura facial
│  │  ├─ No es solo un problema estético: es discapacidad FUNCIONAL. El cierre repetitivo de
│  │  │  los párpados, sobre todo con fenómeno de tonus, puede impedir la visión y limitar la
│  │  │  actividad laboral y de ocio
│  │  │  └─ Las tres limitaciones más citadas por los pacientes —CONDUCIR, LEER y estar
│  │  │     cómodo en situaciones sociales— se usan como medidas de resultado en el
│  │  │     seguimiento tras la descompresión
│  │  ├─ Epidemiología: incidencia de 0,78 por 100.000. Ligera predilección femenina (1,9:1).
│  │  │  El lado IZQUIERDO se afecta con más frecuencia que el derecho. Incidencia máxima
│  │  │  entre los 50 y los 79 años
│  │  └─ DIAGNÓSTICO DIFERENCIAL, que hay que resolver ANTES de plantear cirugía
│  │     ├─ SINCINESIA POSTPARALÍTICA: imita el HFS y aparece tras traumatismo del facial o
│  │     │  parálisis de Bell. NO responde a la descompresión microvascular
│  │     │  └─ Cómo se distingue: por la historia, y porque se desencadena con el MOVIMIENTO
│  │     │     facial y NO ocurre en reposo
│  │     └─ Otros cuadros confundibles: blefaroespasmo, tics faciales, mioquimia facial y
│  │        síndrome de Meige
│  ├─ NEURALGIA DEL GLOSOFARÍNGEO (GPN)
│  │  ├─ Dolor paroxístico en las áreas inervadas por el IX, que puede abarcar también los
│  │  │  territorios de las ramas auricular y faríngea del VAGO: oído, fosa amigdalina, base
│  │  │  de la lengua, o por debajo del ángulo mandibular
│  │  ├─ Similar a la neuralgia del trigémino en calidad, en temporalidad y en su capacidad
│  │  │  de desencadenarse por estímulos: deglutir, masticar, toser, bostezar, hablar o
│  │  │  sabores concretos
│  │  ├─ DATO QUE PUEDE MATAR: en torno al 20% de los casos el dolor se acompaña de SÍNCOPE
│  │  │  por bradicardia e hipotensión, o incluso de ASISTOLIA
│  │  │  └─ Mecanismo propuesto: los impulsos del glosofaríngeo hacia el tracto solitario
│  │  │     estimularían el núcleo motor dorsal del vago
│  │  ├─ Rara: incidencia estimada de 0,2-0,7 por 100.000 en población general
│  │  └─ Formas idiopática y secundaria. Además de la compresión vascular del IX, las causas
│  │     secundarias incluyen lesiones desmielinizantes, aneurismas carotídeos, absceso
│  │     periamigdalino, tumores malignos orofaríngeos y lesiones de la base del cráneo
│  └─ OTROS SÍNDROMES POR CONFLICTO NEUROVASCULAR, infrecuentes
│     ├─ VESTIBULOCOCLEAR → vértigo y acúfeno (también se cita la enfermedad de Ménière)
│     ├─ ACCESORIO → tortícolis espasmódica
│     └─ NERVIO INTERMEDIO de forma selectiva → NEURALGIA GENICULADA, con ataques breves y
│        recurrentes de dolor intenso en la PROFUNDIDAD del conducto auditivo
├─ FISIOPATOLOGÍA — las dos hipótesis, y por qué la neurofisiología apoya la segunda
│  ├─ HIPÓTESIS 1, periférica: la compresión vascular crónica lesiona los axones del par
│  │  craneal, produciendo hiperexcitabilidad del nervio y "crosstalk" o TRANSMISIÓN EFÁPTICA
│  │  entre fibras, con aumento de actividad espontánea e interacción entre fibras
│  │  individuales en la porción lesionada
│  ├─ HIPÓTESIS 2, nuclear: el daño al par craneal afecta a su NÚCLEO de tal modo que las
│  │  neuronas del núcleo se REORGANIZAN
│  └─ LOS DOS HALLAZGOS NEUROFISIOLÓGICOS QUE APOYAN LA HIPÓTESIS NUCLEAR
│     ├─ La latencia del AMR (ver abajo) es de 10-12 ms, y esa latencia NO es compatible con
│     │  una transmisión cruzada en el sitio de la compresión vascular. Parece que la
│     │  actividad ANTIDRÓMICA elicita el AMR cruzando a la otra rama A NIVEL DEL NÚCLEO a
│     │  través de interneuronas, de forma similar a una respuesta F
│     └─ Al estimular el supraorbitario para obtener el BLINK REFLEX en el lado del espasmo
│        también hay sincinesia; y aunque el blink suele estar SUPRIMIDO por la anestesia,
│        en el paciente con HFS PERSISTE en el lado del espasmo — apoyo adicional a la
│        hiperexcitabilidad de las motoneuronas nucleares
├─ RADIOLOGÍA — lo que la imagen sí resuelve y lo que no
│  ├─ Es esencial una RM preoperatoria de CORTE FINO como parte de la evaluación inicial del
│  │  posible conflicto neurovascular
│  ├─ Tradicionalmente, RM y TC NO sirven para identificar la proximidad de los vasos a los
│  │  nervios: se usan sobre todo para descartar lesiones ocupantes de espacio
│  ├─ Qué aumenta el valor diagnóstico
│  │  ├─ El contacto o compresión vascular INCIDENTAL es un hallazgo frecuente en pacientes
│  │  │  ASINTOMÁTICOS — por sí solo no significa nada
│  │  ├─ Lo que sí es infrecuente en pacientes sin TGN ni HFS es la DISTORSIÓN VASCULAR o la
│  │  │  ATROFIA del nervio
│  │  └─ La compresión del trigémino en su ZONA DE ENTRADA DE RAÍZ aumenta la especificidad y
│  │     el valor predictivo positivo para TGN
│  ├─ Técnica: secuencias multiplanares de sección fina, fuertemente potenciadas en T2 y
│  │  exploradas en TRES planos, que dan excelente resolución de contraste entre el LCR y los
│  │  tejidos blandos adyacentes. El DTI y la tractografía muestran alteraciones estructurales
│  └─ LA ADVERTENCIA QUE JUSTIFICA LA MIO: un vaso de CUALQUIER tamaño puede comprimir, según
│     la sensibilidad del nervio y del núcleo. Y aunque la RM muestre un vaso grande, eso NO
│     significa que sea el único que comprime — hace falta una búsqueda guiada
│     NEUROFISIOLÓGICAMENTE
├─ Modalidades combinadas
│  ├─ PARA EL OBJETIVO TERAPÉUTICO (solo en HFS): respuesta muscular anormal (AMR) o
│  │  respuesta de difusión lateral (lateral spread, LSR). Es la modalidad central del tema
│  ├─ PARA EVITAR COMPLICACIONES
│  │  ├─ PEATC (BAEP) — la modalidad que previene la complicación más frecuente y más temida
│  │  ├─ Potencial de acción compuesto del nervio auditivo (AN-CAP), como recurso cuando el
│  │  │  BAEP no es utilizable
│  │  ├─ EMG libre y estimulado de los músculos inervados por trigémino, facial,
│  │  │  glosofaríngeo y vago
│  │  └─ SEP y MEP transcraneal, para el riesgo de vías largas y de posicionamiento
│  └─ RESPUESTAS ALTERNATIVAS al AMR, todas de valor secundario: componente R1 del Blink
│     Reflex, onda F facial y respuesta Z-L
├─ Fases del procedimiento
│  ├─ INCISIÓN: planificada medial al surco digástrico de la apófisis mastoides y
│  │  habitualmente medial a la línea del pelo. Se aceptan incisiones aproximadamente
│  │  paralelas al seno transverso o al sigmoide. Se socava el plano muscular exponiendo el
│  │  hueso occipital y se retraen los tejidos blandos
│  ├─ APERTURA ÓSEA, y depende de qué par craneal se persiga
│  │  ├─ Pares craneales ALTOS (trigémino, vestibulococlear) → exponer la INTERSECCIÓN de los
│  │  │  senos transverso y sigmoide
│  │  ├─ Pares craneales BAJOS (facial, glosofaríngeo, vago) → exponer el BORDE del seno
│  │  │  sigmoide
│  │  └─ Regla de Jannetta para los pares bajos: apertura ósea "BAJA Y LATERAL"
│  ├─ APERTURA DURAL Y DRENAJE DE LCR: se recomienda drenaje EXPEDITIVO del LCR para evitar
│  │  el desplazamiento cerebral a través de la dura, que limitaría la exposición segura de
│  │  los pares craneales. Se drena de la cisterna cerebelomedular o de la supracerebelosa,
│  │  con o sin ayuda de un retractor fijo
│  │  └─ Dato de resultado: se ha demostrado reducción de la hipoacusia de ALTA FRECUENCIA
│  │     con modificaciones técnicas, entre ellas hacer el procedimiento SIN retracción fija
│  ├─ IDENTIFICACIÓN DEL CONFLICTO — dónde está la compresión según el nervio
│  │  ├─ TRIGÉMINO: en la mitad PROXIMAL del segmento cisternal —la porción centralmente
│  │  │  mielinizada—, entre el porus trigeminus y el punto de entrada del nervio en la
│  │  │  protuberancia
│  │  ├─ FACIAL: a lo largo del llamado "segmento adherido", que es la porción centralmente
│  │  │  mielinizada del nervio hacia la protuberancia
│  │  └─ GLOSOFARÍNGEO: en los primeros milímetros desde la entrada o salida del nervio en el
│  │     bulbo
│  ├─ LOS VASOS OFENSORES MÁS FRECUENTES, por patología
│  │  ├─ TGN: cerebelosa superior (SCA) o cerebelosa anteroinferior (AICA). Menos veces, un
│  │  │  complejo vertebrobasilar ECTÁSICO o tributarias de la vena petrosa superior
│  │  ├─ FACIAL: la PICA es la más común; también AICA, arteria vertebral y arterias
│  │  │  perforantes
│  │  └─ Zona de entrada de raíz de GLOSOFARÍNGEO y VAGO: la PICA
│  ├─ DESCOMPRESIÓN: movilización del vaso seguida de colocación de un injerto interposicional
│  │  (fieltro de PTFE) o transposición permanente del vaso mediante alguna técnica de "sling"
│  └─ CIERRE: dural estanco. El uso de cemento de FOSFATO CÁLCICO en la última década ha
│     reducido drásticamente la tasa de fístula de LCR
├─ Riesgo neurológico específico
│  ├─ HIPOACUSIA — la complicación que domina la monitorización de este procedimiento
│  │  ├─ Tasas publicadas por patología: 2-20% en HFS · 1-23,8% en TGN · 1,5-4,2% en GPN ·
│  │  │  22% en neuralgia geniculada
│  │  ├─ MECANISMO MÁS COMÚN de hipoacusia neurosensorial postoperatoria: la RETRACCIÓN en el
│  │  │  ángulo pontocerebeloso para descomprimir el par craneal, que ESTIRA el nervio coclear
│  │  └─ Otros mecanismos: trauma directo por instrumentos · compresión del coclear por el
│  │     propio fieltro de Teflon interpuesto · daño térmico por electrocoagulación cercana ·
│  │     isquemia por manipulación de la AICA y/o de la arteria laberíntica
│  ├─ PARESIA FACIAL: complicación rara pero dramática de la cirugía del ángulo pontocerebeloso
│  │  ├─ La debilidad facial postoperatoria INMEDIATA suele atribuirse a una maniobra
│  │  │  intraoperatoria concreta: calentamiento del nervio por el bipolar, estiramiento o
│  │  │  retracción, trauma directo con el aspirador, o compresión indebida por el propio
│  │  │  material descompresivo (el fieltro)
│  │  └─ La debilidad facial DIFERIDA —a veces llamada parálisis de Bell diferida— es un
│  │     fenómeno bien descrito, y sigue sin estar claro si es simplemente coincidente con el
│  │     espasmo hemifacial del paciente o consecuencia directa de la cirugía
│  ├─ LESIÓN DE PARES BAJOS durante la disección para exponer el complejo VII/VIII o el propio
│  │  IX — por eso se monitoriza el estilofaríngeo (IX) y la musculatura laríngea (X)
│  ├─ LESIÓN DEL TRONCO: durante la descompresión hay que evitar la lesión mecánica o térmica
│  │  de pares craneales, raicillas del tronco y VASOS PERFORANTES, y evitar la tensión sobre
│  │  los perforantes tanto al movilizar el vaso como al colocar el implante
│  └─ COMPLICACIONES NO NEUROFISIOLÓGICAS o solo parcialmente vigilables
│     ├─ Lesión cerebelosa (hemorragia y contusión por retracción) y fístula de LCR: la
│     │  monitorización NO puede necesariamente predecirlas ni prevenirlas
│     └─ Infarto de tronco y lesión de plexo braquial por malposición: el riesgo de estas dos
│        posiblemente SÍ se reduce con monitorización de vías largas (SEP y/o MEP
│        transcraneal), aunque al ser complicaciones raras no está claro que añadir esas
│        modalidades sea coste-efectivo
├─ Posicionamiento
│  ├─ Decúbito LATERAL o posición de "park bench"
│  ├─ Fijación craneal habitualmente de TRES PUNTOS, aunque los autores han pasado
│  │  recientemente a operar con soporte en HERRADURA sin cabezal de Mayfield
│  ├─ Cabeza rotada aproximadamente 30 grados ALEJÁNDOSE del lado afectado
│  ├─ LA REGLA DEL VÉRTEX, que cambia según el par craneal diana
│  │  ├─ Para pares craneales BAJOS: el vértex se baja 15 grados hacia el suelo, para elevar
│  │  │  la zona de salida de raíz dorsal del VII y llevarla a una posición más HORIZONTAL —
│  │  │  es la posición ideal para exponer el complejo de pares bajos
│  │  └─ Para exponer el V: el vértex se mantiene PARALELO al suelo
│  ├─ Hay que poner atención cuidadosa al posicionar para evitar lesiones de nervio periférico
│  │  y de PLEXO BRAQUIAL
│  └─ Los SEP han demostrado ser una técnica útil para minimizar las lesiones neurológicas
│     por posicionamiento durante la descompresión microvascular
├─ EL OBJETIVO TERAPÉUTICO: LA RESPUESTA MUSCULAR ANORMAL (AMR / lateral spread)
│  ├─ QUÉ ES: al estimular percutáneamente UNA rama del facial y registrar EMG estimulado de
│  │  varios músculos faciales, en el paciente con HFS responden no solo los músculos
│  │  inervados por esa rama sino también OTROS que no lo están
│  │  └─ Ejemplo canónico: se estimula la rama CIGOMÁTICA y responde el orbicular de los
│  │     párpados (que sí inerva) y además el MENTONIANO (que no)
│  ├─ MORFOLOGÍA: potencial EMG TRIFÁSICO seguido de una serie de potenciales de POSDESCARGA,
│  │  típicamente con una amplitud en torno al 10% de la respuesta muscular directa
│  │  (respuesta M) y con una latencia de 10-12 ms
│  ├─ MONTAJE
│  │  ├─ REGISTRO: par bipolar de agujas sobre el ORBICULAR DE LOS PÁRPADOS y otro sobre el
│  │  │  MENTONIANO
│  │  ├─ ESTIMULACIÓN: otro par de agujas separadas aproximadamente 1 cm sobre la RAMA
│  │  │  CIGOMÁTICA del facial
│  │  └─ Referencia anatómica para colocar el estimulador, con variación interindividual: el
│  │     PUNTO MEDIO de una línea imaginaria entre el TRAGO del pabellón auricular y el CANTO
│  │     EXTERNO del ojo. El mapeo preoperatorio de las ramas del facial ayuda a afinarlo
│  ├─ PARÁMETROS: estímulo ÚNICO de corriente constante, 0,2 ms de duración, a 5 Hz, con
│  │  intensidad un 20-30% por encima del umbral máximo — eso da típicamente un AMR estable
│  ├─ POLARIDAD, donde hay una discrepancia viva
│  │  ├─ Descripción tradicional del LSR: cátodo PROXIMAL, de modo que los impulsos
│  │  │  CENTRÍPETOS viajen hacia el tronco
│  │  └─ Propuesta reciente: INVERTIR cátodo y ánodo, generando estimulación CENTRÍFUGA hacia
│  │     fuera del tronco, mejoraría la eficacia de la monitorización del AMR frente al método
│  │     convencional
│  ├─ CÓMO CONFIRMAR QUE LO QUE SE VE ES REALMENTE UN AMR — por la LATENCIA
│  │  ├─ La respuesta directa (CMAP) del orbicular de los párpados debe tener latencia de
│  │  │  inicio de 2-4 ms, dada la proximidad del músculo al punto de estimulación
│  │  └─ El AMR tendrá SIEMPRE una latencia distinguiblemente MÁS LARGA, típicamente por
│  │     encima de 8 ms de inicio
│  ├─ LA LECTURA INTRAOPERATORIA
│  │  ├─ Tras exponer el facial y apartar el vaso ofensor, protegiéndolo de recomprimir el
│  │  │  nervio, el AMR desaparece típicamente EN SEGUNDOS
│  │  ├─ Esa desaparición tiene una correlación MUY ALTA con buen resultado clínico a largo
│  │  │  plazo
│  │  └─ Si la respuesta PERSISTE, o si solo cambia la amplitud o la morfología, puede indicar
│  │     que hay compresión vascular adicional sobre el nervio y que hace falta más exploración
│  ├─ LA TRAMPA DEL ABORDAJE: a veces el AMR desaparece DURANTE EL ABORDAJE, antes de
│  │  cualquier descompresión directa, por un movimiento del vaso ofensor relacionado con la
│  │  apertura dural, la derivación de LCR o la retracción del cerebelo
│  │  └─ En la experiencia de los autores, es frecuente que REAPAREZCA una vez abierta la
│  │     aracnoides e identificada la patología ofensora
│  ├─ RENDIMIENTO DIAGNÓSTICO — la asimetría que hay que tener clara antes de fiarse
│  │  ├─ ESPECIFICIDAD ALTA: cuando el lateral spread se abole, una alta proporción de
│  │  │  pacientes quedará libre de espasmo
│  │  ├─ SENSIBILIDAD BAJA: la persistencia intraoperatoria del AMR predice solo MODESTAMENTE
│  │  │  la persistencia del espasmo
│  │  └─ Lo verdaderamente útil es el VALOR PREDICTIVO NEGATIVO: es muy tranquilizador respecto
│  │     a que se ha logrado una descompresión adecuada, y evita tiempo quirúrgico innecesario
│  ├─ QUÉ SIGNIFICA UN AMR RESIDUAL: podría deberse a desmielinización focal grave, con o sin
│  │  hiperactividad aumentada del núcleo facial, que no puede revertirse de inmediato tras la
│  │  descompresión. De ahí que en algunos pacientes el espasmo se resuelva de forma DIFERIDA,
│  │  a medida que remieliniza el área dañada y el núcleo facial recupera su excitabilidad
│  │  normal
│  ├─ AVISO SOBRE TOXINA BOTULÍNICA PREVIA: la amplitud del AMR basal es MAYOR en pacientes
│  │  tratados antes con toxina, probablemente por reinervación, y esa mayor amplitud puede
│  │  REDUCIR la sensibilidad del marcador para indicar una descompresión total. Se recomienda
│  │  esperar 8-10 meses desde el último tratamiento antes de operar
│  └─ La técnica en profundidad —facilitación tetánica y por qué se abandonó, las tres
│     respuestas alternativas (blink R1, onda F y respuesta Z-L), y las series de AMR
│     residual y de toxina botulínica— se amplía en `A10`
├─ EVITAR LA HIPOACUSIA: EL PEATC (BAEP)
│  ├─ EL DATO QUE JUSTIFICA HACERLO: comparando los procedimientos previos a 1990 —antes del
│  │  uso rutinario de BAEP en la Universidad de Pittsburgh— con los posteriores, las tasas de
│  │  hipoacusia se redujeron significativamente, del 1,98% al 0,8% (P<0,01). Hoy la mayoría
│  │  de cirujanos han adoptado su uso rutinario
│  ├─ GENERADORES, que hay que tener presentes para leer los cambios: ondas I, II, III, IV y V
│  │  originadas respectivamente en el nervio coclear DISTAL, el núcleo coclear, el complejo
│  │  olivar superior, el lemnisco lateral y el colículo inferior
│  ├─ POR QUÉ SE USA LA ONDA V Y SOLO LA ONDA V
│  │  ├─ Es la forma de onda más ROBUSTA y CONSISTENTE registrada durante la descompresión
│  │  ├─ Aunque la lesión relacionada con la cirugía afecta al segmento PROXIMAL de la vía
│  │  │  auditiva, monitorizar la onda V es una medida fiable de la conducción a lo largo de
│  │  │  toda la vía auditiva del tronco
│  │  ├─ Qué reflejan sus cambios: daño de aferentes ascendentes CONVERGENTES, cuya integración
│  │  │  sináptica produce un potencial postsináptico menor por reducción de la fuerza global
│  │  │  de los inputs y de su SINCRONÍA, efecto que se acumula a lo largo de varias sinapsis
│  │  └─ Las ondas I y III también reflejan función del nervio coclear, pero el grupo ha
│  │     mostrado que la utilidad de la onda III como sustituto es significativamente MENOS
│  │     eficaz que la de la onda V — por eso usan EXCLUSIVAMENTE la V para decidir
│  ├─ PARÁMETROS DE REGISTRO
│  │  ├─ Estimulación a 17,5 Hz, aplicada de forma INDEPENDIENTE en el lado derecho o
│  │  │  izquierdo, con al menos 85 dB SPL, usando clics ALTERNANTES de rarefacción y
│  │  │  condensación
│  │  ├─ Enmascaramiento del oído contralateral con RUIDO BLANCO a 65 dB SPL
│  │  ├─ Ventana de observación de 12 ms, promediando al menos 256 respuestas
│  │  ├─ Montaje de tres canales: (1) mastoides izquierda a vértex, A1/Cz · (2) mastoides
│  │  │  derecha a vértex, A2/Cz · (3) cervical C2 a vértex, Cv2/Cz
│  │  └─ Paso de banda del amplificador de 100 a 1000 Hz en todos los canales
│  ├─ LA REGLA DEL BASAL, que es lo más importante de todo este apartado
│  │  ├─ Las primeras respuestas se registran tras la inducción anestésica y el
│  │  │  posicionamiento, PERO el basal que se usará para comparar durante la descompresión
│  │  │  debe REESTABLECERSE EN LA APERTURA DURAL, no fijarse al principio del procedimiento
│  │  └─ Razón: existen variaciones significativas de latencia del BAEP ANTES de cualquier
│  │     manipulación relevante, de modo que reestablecer el basal en ese momento reduce las
│  │     alertas innecesarias, es decir, los FALSOS POSITIVOS
│  ├─ VENTAJA ANESTÉSICA: a diferencia de SEP y MEP, los BAEP tienen BAJA susceptibilidad al
│  │  anestésico volátil y a la tensión arterial — aunque la HIPOTERMIA sí prolonga su latencia
│  ├─ CRITERIOS DE ALARMA históricamente adoptados para la descompresión microvascular:
│  │  descenso del 50% de la amplitud de la onda V y/o aumento PERSISTENTE de la latencia
│  │  absoluta del pico de la onda V mayor de 1 ms
│  └─ CÓMO SE LEE EL PATRÓN — tres firmas distintas
│     ├─ Prolongación PROGRESIVA de la latencia o descenso progresivo de amplitud → lesión
│     │  MECÁNICA o TÉRMICA
│     ├─ Pérdida SÚBITA de la onda V → debe hacer sospechar un evento ISQUÉMICO
│     └─ Pérdida de TODOS los componentes, INCLUIDA LA ONDA I → casi siempre indica un FALLO
│        TÉCNICO del sistema de estimulación
│        ├─ Causas típicas: acodamiento del tubo del estimulador, desplazamiento o mal
│        │  funcionamiento del transductor, o acumulación de fluido en el conducto auditivo
│        │  externo
│        ├─ Prevención: comprobar siempre el sistema antes de usarlo y asegurar un sellado
│        │  adecuado alrededor del inserto auricular
│        └─ Y el matiz que cierra el razonamiento: la pérdida de la onda I RARAMENTE ocurre de
│           forma secundaria a isquemia coclear inducida por manipulación vascular
├─ AN-CAP — el recurso cuando el BAEP no es utilizable
│  ├─ Qué es: potencial de acción compuesto del nervio auditivo, evocado también por estímulo
│  │  auditivo pero REGISTRADO con un electrodo colocado directamente sobre el nervio auditivo
│  │  proximal expuesto, o muy cerca de él
│  ├─ Su ventaja decisiva: forma de onda TRIFÁSICA con amplitud MUCHO MAYOR que la del BAEP,
│  │  de modo que hace falta poco o ningún promediado — feedback rápido
│  ├─ SUS CUATRO INCONVENIENTES, que impiden usarlo de rutina
│  │  ├─ Solo es registrable DESPUÉS de exponer el VIII, y la porción proximal solo se alcanza
│  │  │  tras la disección — momento en el que el nervio puede estar YA dañado
│  │  ├─ Exige un electrodo especial DENTRO del campo quirúrgico, que puede interferir con la
│  │  │  cirugía
│  │  ├─ Pequeños desplazamientos cambian los registros, y hay que comprobar la posición del
│  │  │  electrodo a menudo
│  │  └─ No hay criterios de alarma establecidos sistemáticamente
│  └─ El criterio de consenso, a falta de otro: la mayoría de autores coinciden en que una
│     pérdida del 50% de la amplitud es un cambio significativo y debe reportarse, una vez
│     confirmada la posición de registro del electrodo
├─ EMG LIBRE Y ESTIMULADO
│  ├─ EMG LIBRE: registro CONTINUO de actividad espontánea caracterizada por spikes, bursts y
│  │  trenes, relacionada con estimulación mecánica, térmica o irritativa, que da feedback
│  │  inmediato al equipo quirúrgico
│  │  ├─ La descarga SOSTENIDA de trenes de alta frecuencia (descarga NEUROTÓNICA) puede
│  │  │  señalar una perturbación en curso del nervio, y se ha mostrado que augura peores
│  │  │  resultados
│  │  └─ FALSO POSITIVO QUE HAY QUE ANTICIPAR: tras completar la descompresión, el campo se
│  │     irriga habitualmente con SUERO TEMPLADO, y eso precipita generalmente descarga
│  │     sostenida SIN significado clínico
│  ├─ EMG ESTIMULADO: aplicación de un estímulo eléctrico cerca o directamente sobre el tronco
│  │  de un nervio motor o mixto para elicitar CMAP en los músculos correspondientes
│  │  ├─ Sirve para IDENTIFICAR el nervio y para informar de su INTEGRIDAD a través de la
│  │  │  latencia, la amplitud y el umbral de estimulación
│  │  └─ Los cambios intraoperatorios de esos parámetros se han propuesto como predictores del
│  │     resultado funcional postoperatorio en cirugía de tumores del ángulo pontocerebeloso
│  └─ Músculos que hay que cubrir: los inervados por trigémino y facial, más el ESTILOFARÍNGEO
│     (IX) y la musculatura LARÍNGEA (X), estos dos últimos por el riesgo durante la disección
│     para exponer el complejo VII/VIII o el propio IX
├─ Jerarquía de alarma
│  ├─ BAEP, criterio histórico: caída del 50% de la amplitud de la onda V y/o aumento
│  │  persistente de la latencia absoluta del pico de la onda V mayor de 1 ms
│  ├─ BAEP, criterio OPERATIVO de los autores, que es más exigente: se reporta en cuanto se
│  │  observa un retraso de 0,5 ms, y se reporta cualquier fluctuación de amplitud
│  │  └─ La razón de adelantarse: la pérdida de BAEP es un biomarcador ESPECÍFICO de hipoacusia
│  │     perioperatoria, pero para PREVENIRLA hace falta un criterio sensible que pueda
│  │     comunicarse ANTES de que la lesión sea irreversible. Esperar al criterio tradicional
│  │     es esperar demasiado
│  ├─ AN-CAP: pérdida del 50% de amplitud, una vez confirmada la posición del electrodo
│  ├─ AMR: no es un criterio de alarma sino de ÉXITO — la desaparición confirma descompresión
│  │  adecuada; la persistencia o la reaparición obligan a reexplorar
│  └─ POR QUÉ LA ESPECIFICIDAD DEL BAEP SALE BAJA EN LAS SERIES, y no es un defecto: las
│     especificidades bajas se deben comúnmente a las propias INTERVENCIONES TERAPÉUTICAS de
│     la descompresión —pausa quirúrgica, relajación del retractor— hechas en respuesta a los
│     cambios de BAEP. Es decir, el sistema funcionando cuenta estadísticamente como falso
│     positivo
├─ Protocolo de reacción
│  ├─ ANTE CAMBIO DE BAEP
│  │  ├─ Reportar dinámicamente latencia y amplitud de la onda V para mantener al equipo al
│  │  │  tanto de los cambios PROGRESIVOS, de modo que al alcanzar el criterio tradicional —o
│  │  │  antes— la acción correctora sea inmediata
│  │  ├─ Según las condiciones quirúrgicas y la severidad del retraso o de la caída de
│  │  │  amplitud, se toma una PAUSA QUIRÚRGICA hasta que los BAEP vuelvan hacia su amplitud y
│  │  │  latencia basales
│  │  ├─ Atención especial durante la RETRACCIÓN CEREBELOSA, que a menudo produce cambios. Sin
│  │  │  retractor fijo, atender a la plenitud del cerebelo, a la derivación de LCR y a la
│  │  │  retracción manual con el vástago del aspirador
│  │  └─ PÉRDIDA SÚBITA: sospechar perturbación VASCULAR. Además de la pausa, irrigación con
│  │     PAPAVERINA y suero templado si se sospecha vasoespasmo
│  ├─ CUÁNDO ABORTAR: si ha habido múltiples cambios significativos de amplitud y la respuesta
│  │  NO vuelve al basal, hay que considerar abortar la descompresión, particularmente si se
│  │  sospecha que la descompresión ya es adecuada
│  │  └─ Razonamiento: proseguir en ese punto tiene mayor riesgo de inducir hipoacusia
│  │     significativa. Cerrar, evaluar la patología del paciente y quizá VOLVER a los pocos
│  │     días —antes de que se forme cicatriz y tras dar tiempo al VIII a recuperarse— ha
│  │     resultado útil
│  ├─ ANTE AMR PERSISTENTE: se persiguen vasos, INDEPENDIENTEMENTE DE SU TAMAÑO, hasta reducir
│  │  el AMR a niveles casi indetectables. Si persiste, se reexplora la mielina central del
│  │  facial y las áreas de alrededor buscando vasos ofensores adicionales
│  └─ ANTE AMR QUE REAPARECE AL CERRAR: si el AMR desapareció tras la descompresión y reaparece
│     al retirar el retractor e iniciar el cierre dural, puede reexplorarse buscando fieltro
│     MIGRADO o, más comúnmente, VENAS ofensoras — las venas también pueden ser causa
│     etiológica de la neuropatía por compresión
│     └─ Pero si el cirujano confía en que el nervio está adecuadamente descomprimido, se
│        continúa cerrando incluso con AMR residual: no es infrecuente que desaparezca de forma
│        DIFERIDA durante el cierre, y un AMR residual de PEQUEÑA amplitud sigue augurando buen
│        alivio del espasmo
├─ IMPLEMENTACIÓN PRÁCTICA — la secuencia completa, que es la mitad del valor del capítulo
│  ├─ PREOPERATORIO
│  │  ├─ Todo paciente con HFS diagnosticado por historia, exploración y radiología se remite
│  │  │  para test de AMR PREoperatorio
│  │  └─ Batería rutinaria previa: BAEP basales, EMG faciales y AUDIOGRAMA — para confirmar el
│  │     marcador electrofisiológico del HFS y la calidad de la audición previa, y para permitir
│  │     comparaciones intra y postoperatorias
│  ├─ EN QUIRÓFANO, ANTES DE POSICIONAR
│  │  ├─ Registro basal de SEP PRE-posición, y colocación de TODOS los electrodos de
│  │  │  estimulación y registro
│  │  ├─ Es importante conseguir un AMR útil ANTES de posicionar: resolver problemas de
│  │  │  colocación de electrodos se vuelve difícil después de posicionar y CASI IMPOSIBLE tras
│  │  │  colocar el campo
│  │  └─ Para poder adquirir el AMR tan pronto, solo debe usarse relajante de ACCIÓN CORTA para
│  │     la intubación. La respuesta del orbicular de los párpados sirve como control de la
│  │     presencia de relajante
│  ├─ YA POSICIONADO: SEP y BAEP postposición, registro de EMG y, en el HFS, AMR otra vez
│  │  └─ Cuidado con los insertos de espuma del BAEP: que el tubo NO se acode al colocar el
│  │     campo, y que haya sellado ESTANCO sobre la oreja (un apósito transparente funciona
│  │     bien) para evitar que entre líquido —sobre todo la solución de preparación— en el
│  │     conducto. Y que la cinta o el apósito no sobresalgan del borde de la oreja invadiendo
│  │     el campo quirúrgico
│  ├─ TRAS INCISIÓN, EXPOSICIÓN Y APERTURA DURAL: resetear el basal de BAEP, particularmente si
│  │  su morfología, latencia o amplitud difieren apreciablemente del basal registrado tras
│  │  posicionar y antes de incidir
│  ├─ DURANTE TODO EL PROCEDIMIENTO: comunicación BIDIRECCIONAL estrecha entre neurocirugía y
│  │  neurofisiología, tanto sobre los hallazgos de la monitorización como sobre LA ETAPA en
│  │  que va la descompresión
│  │  └─ Solución organizativa concreta de los autores: un monitor de vídeo con la vista del
│  │     microscopio y las constantes del paciente, disponible EXCLUSIVAMENTE para el equipo de
│  │     monitorización
│  └─ POSTOPERATORIO
│     ├─ Aproximadamente DOS TERCIOS de los pacientes tienen alivio completo o casi completo
│     │  del espasmo inmediatamente tras la cirugía
│     ├─ Algunos conservan cierto grado de espasmo que se resuelve en ORDEN INVERSO al que se
│     │  originó — es decir, el ORBICULAR DE LOS PÁRPADOS es el último en resolverse
│     ├─ Si a las 72 HORAS el espasmo no ha cambiado significativamente respecto al estado
│     │  preoperatorio, ese paciente tiene mayor riesgo de fracaso final del procedimiento
│     │  └─ Conducta: repetir los EMG faciales, y si la actividad eléctrica, la morfología y el
│     │     crosstalk siguen igual que antes de operar, puede reexplorarse DENTRO DE LA PRIMERA
│     │     SEMANA, antes de que se forme cicatriz
│     └─ Todos los pacientes intervenidos llevan AUDIOGRAMA postoperatorio, lo que permite
│        indexar con exactitud cualquier cambio auditivo y cuantificar la morbilidad si ocurre
├─ Técnica de mapeo específica
│  ├─ En rigor, en esta cirugía no hay un mapeo de localización como en columna o en tronco:
│  │  lo que hay es un MAPEO DEL CONFLICTO, guiado por la respuesta
│  ├─ El AMR es la herramienta que dice si el vaso que se acaba de apartar era EL vaso, y si
│  │  quedan más — porque un vaso de cualquier tamaño puede ser el responsable y la RM no lo
│  │  resuelve
│  ├─ La respuesta Z-L es el mapeo más literal del capítulo: se estimula la PARED del vaso
│  │  sospechoso cerca del punto de compresión y se busca respuesta muscular facial
│  └─ El EMG estimulado identifica el nervio y da su umbral cuando la anatomía está distorsionada
├─ Errores y confusiones frecuentes
│  ├─ Fijar el basal de BAEP al inicio del procedimiento en lugar de reestablecerlo en la
│  │  APERTURA DURAL — genera alertas innecesarias por variaciones de latencia previas a
│  │  cualquier manipulación
│  ├─ Interpretar como lesión la desaparición del AMR durante el abordaje, cuando puede deberse
│  │  al desplazamiento del vaso por la apertura dural, el drenaje de LCR o la retracción
│  ├─ Dar por buena una descompresión porque el AMR desapareció, sin volver a comprobarlo tras
│  │  retirar el retractor: puede reaparecer al iniciar el cierre
│  ├─ Confundir la respuesta directa con el AMR: la directa del orbicular de los párpados va a
│  │  2-4 ms, el AMR por encima de 8 ms
│  ├─ Interpretar la descarga neurotónica que sigue a la IRRIGACIÓN CON SUERO TEMPLADO al final
│  │  de la descompresión como lesión en curso
│  ├─ Perseguir una causa biológica ante la pérdida de TODAS las ondas del BAEP incluida la I,
│  │  cuando eso es casi siempre un fallo del sistema de estimulación
│  ├─ Usar la onda III como sustituto de la V para decidir
│  ├─ Operar a un paciente con toxina botulínica reciente y fiarse del AMR: la amplitud basal
│  │  aumentada por reinervación puede reducir la sensibilidad del marcador
│  └─ Colocar los electrodos de AMR después de posicionar al paciente, cuando ya es difícil
│     corregirlos, o imposible tras colocar el campo
├─ Limitaciones
│  ├─ El AMR tiene sensibilidad BAJA: su persistencia predice solo modestamente que el espasmo
│  │  persista. Su valor está en el lado negativo, no en el positivo
│  ├─ La diferencia en alivio del espasmo entre desaparición y persistencia del AMR se observa
│  │  en el postoperatorio inmediato y al alta, pero NO se mantiene en el seguimiento a largo
│  │  plazo
│  ├─ Puede haber hipoacusia postoperatoria CON BAEP intraoperatorio preservado, por factores
│  │  ajenos al bloqueo de conducción del nervio auditivo o a la lesión coclear: daño de
│  │  tractos auditivos de orden superior, o isquemia troncoencefálica postoperatoria que no se
│  │  manifiesta durante el procedimiento
│  ├─ Los cambios del BAEP NO sirven para predecir la hipoacusia de ALTA FRECUENCIA tras la
│  │  descompresión — la que deteriora los componentes de alta frecuencia del habla, como las
│  │  consonantes, y dificulta entender con ruido de fondo. Puede deberse al ruido del fresado
│  │  y/o a la pérdida transitoria de LCR
│  ├─ El blink reflex como índice de descompresión suficiente no está adecuadamente estudiado, y
│  │  la onda F no es específica del espasmo hemifacial
│  ├─ El AN-CAP llega tarde por definición: solo se registra tras exponer el VIII, cuando el
│  │  nervio puede estar ya dañado
│  └─ La lesión cerebelosa y la fístula de LCR no son prevenibles con monitorización, y no está
│     claro que añadir SEP y MEP sea coste-efectivo para complicaciones tan raras
└─ Referencia
   └─ Deletis cap.33 (Ferreira/Thirumala/Crammond/Sekula/Balzer, "Intraoperative
      neurophysiological monitoring during microvascular decompression of cranial nerves")
      pp.457-470 — §33.1 historia (Dandy 1929, Gardner, Jannetta) y mecanismo del

      diferencial del espasmo hemifacial, §33.3 consideraciones radiológicas, §33.4 las dos
      hipótesis fisiopatológicas y las dos pruebas neurofisiológicas a favor de la nuclear,
      §33.5 tratamiento quirúrgico, posicionamiento y técnica con los vasos ofensores por
      patología, §33.6.1.1 AMR / lateral spread — montaje, parámetros, polaridad, latencias de
      2-4 ms y >8 ms, facilitación abandonada, metaanálisis del grupo, serie de 235 pacientes y
      estudio de 282 procedimientos con toxina botulínica (Figs. 33.1-33.3), §33.6.1.2 blink
      R1, onda F y respuesta Z-L, §33.6.2.1 BAEP — generadores, por qué solo la onda V,
```
