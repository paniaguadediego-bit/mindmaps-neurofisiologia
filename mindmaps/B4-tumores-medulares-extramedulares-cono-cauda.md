```
Tumores medulares extramedulares / cono-cola de caballo
├─ Modalidades combinadas
│  ├─ SEP + MEP muscular + EMG libre de raíces lumbosacras + reflejo bulbocavernoso
│  │  (RBC) — arco y técnica completos en A9, aquí solo su rol dentro del paquete
│  ├─ Aquí el MAPEO predomina sobre la monitorización pasiva: identificar estructuras
│  │  neurales funcionales que deben preservarse de raicillas vestigiales/bandas
│  │  fibrosas seccionables — a diferencia de B3, donde domina la vigilancia continua
│  │  de vías
│  └─ D-wave: raramente registrable en tumores de cono (igual mecanismo que B3); en
│     tumores estrictamente extramedulares no aplica al no haber CST expuesto
├─ Fases del procedimiento
│  ├─ Laminectomía/hemilaminectomía → apertura dural → identificación del plano
│  │  tumor-raíces/tumor-cono → disección con mapeo continuo de raíces en riesgo →
│  │  resección → cierre — SIN mielotomía, el tumor está fuera del parénquima
│  ├─ A diferencia de IMSCT, aquí se han visto cambios de MEP ya durante la propia
│  │  laminectomía — compresión añadida a una médula ya comprimida, sobre todo en
│  │  tumores firmes/calcificados
│  ├─ Retracción medular extensa para tumores anterolaterales: el cambio de MEP sirve
│  │  de "gauge" para limitar cuánto retraer
│  └─ Filum/lipomas terminales: puede bastar con seccionar el filum tras confirmar por
│     mapeo que no hay respuesta muscular al estimularlo
├─ Riesgo neurológico específico
│  ├─ Diferencia conceptual con B3: el riesgo no es de tractos largos difusos, sino de
│  │  RAÍCES INDIVIDUALES identificables — la pregunta pasa de "¿qué tracto daño?" a
│  │  "¿qué raíz puedo sacrificar sin consecuencia funcional?"
│  ├─ Sacrificar una raíz funcional creyéndola vestigial: en cauda equina/cono, el
│  │  sacrificio de UNA SOLA raíz puede tener consecuencias funcionales graves
│  ├─ Distribución asimétrica e IMPREDECIBLE de aferentes pudendos entre S1-S3: en el
│  │  7.6% de una serie pediátrica, TODA la actividad aferente pudenda dependía de una
│  │  única raíz S2
│  └─ Falso positivo por dispersión de corriente en LCR/campo húmedo: puede simular
│     respuesta muscular en una estructura no funcional — exige campo seco al estimular
├─ Posicionamiento
│  ├─ Prono, similar a B1/B3 — sin matiz propio distinto en las fuentes (verificar)
│  └─ Nota anestésica: en cirugía pediátrica de cono/cauda, en <6 años a veces se
│     reduce/elimina propofol añadiendo ketamina para mejorar la monitorabilidad del
│     MEP transcraneal (78%→96% en >6 años, hasta 86% en <6 años)
├─ Jerarquía de alarma
│  ├─ Mapeo por estimulación directa (triggered EMG): <10 mA (habitualmente 1-5 mA) =
│  │  respuesta por raíz funcional; CMAP solo con >25 mA = estructura lejos de ser
│  │  funcional
│  ├─ Regla de oro: NUNCA sacrificar una raíz "no funcional" sin haber demostrado que
│  │  la misma función está cubierta por otra raíz
│  ├─ RBC: sensibilidad/especificidad 100%/70.6% para disfunción urinaria/intestinal
│  │  postoperatoria en desanclaje pediátrico · monitorabilidad reportada 59-94% según
│  │  la serie — sin criterio de alarma numérico consolidado, la alteración de
│  │  duración/amplitud puede ANTICIPAR la desaparición
│  ├─ Monitorabilidad de otras señales en esta región (factibilidad, no alarma): SEP
│  │  pudendo 84% · MEP de esfínter anal externo 74%
│  └─ SEP: mismo criterio clásico (>50% amplitud, >10% latencia) — limitación propia
│     de la región: el solapamiento de raíces adyacentes puede enmascarar la lesión de
│     una raíz aislada
├─ Protocolo de reacción
│  ├─ Regla de oro del filum/estructura ambigua: primero fijar el umbral fisiológico
│  │  estimulando una raíz motora NORMAL conocida (típicamente 0.05-0.5 mA), y solo
│  │  después interpretar la estructura dudosa con ese umbral como referencia
│  ├─ Si aparece respuesta al estimular una estructura que se iba a sacrificar →
│  │  investigación microquirúrgica adicional para identificar y preservar la
│  │  raicilla, NUNCA cortar directamente
│  ├─ Campo quirúrgico seco durante la estimulación — evita falsos positivos
│  └─ Ante cambio de MEP durante laminectomía/retracción (a diferencia de B3, donde el
│     riesgo mayor es en la disección del plano): reducir la retracción y reevaluar
└─ Técnica de mapeo específica
   ├─ Triggered EMG raíz-por-raíz de cauda equina: sonda bipolar manual, 0.01-3 mA,
   │  1 Hz, 200 µs, registro de CMAP en músculos diana segmentarios L1-S4
   ├─ Mapeo del filum terminale: estimular primero raíz normal conocida para fijar
   │  umbral → estimular estructura dudosa hasta 3 mA sin respuesta → si negativo,
   │  seccionar con seguridad; si hay respuesta, inspeccionar la cara VENTRAL en busca
   │  de raicillas adheridas no visibles desde el abordaje posterior
   └─ DRAP (potenciales de acción de raíz dorsal): electrodo de gancho bipolar sobre
      la raíz levantada fuera del canal, tras estimular el nervio pudendo — mapea la
      contribución aferente de cada raíz sacra individual
└─ Referencia
   └─ Deletis, cap. 26 (Frank/Kothbauer), pp.356-361 · cap. 27 (Pasquali/Tramontano/
      Sala), pp.365-378, esp. §27.6-27.7 · cap. 6 (Vodusek/Deletis), pp.87-99 ·
      Moller2011, cap. 6, pp.112-114
```

## Ampliación — profundizar

```
Extramedulares / cono-cola de caballo — ampliación
├─ Serie de mapeo DRAP en rizotomía dorsal selectiva (114 niños): S1 aportó el 4% de
│  la actividad aferente pudenda global, S2 el 60.5%, S3 el 35.5% — distribución
│  asimétrica entre lados en el 56% de los pacientes, confinada a un solo NIVEL en el
│  18% y a una sola RAÍZ en el 7.6% · 0 complicaciones vesicales/intestinales a largo
│  plazo en los 105 pacientes mapeados con éxito
├─ Histopatología del filum que responde a estimulación: 6 subtipos descritos — el
│  subtipo con fascículos de nervio periférico (37% de los casos) no mostró deterioro
│  neurológico en ningún paciente, sugiriendo fibras probablemente no funcionales pese
│  a estar anatómicamente presentes; aun así, la regla de oro se mantiene — nunca
│  sacrificar sin verificación funcional intraoperatoria
└─ El mapeo raíz-por-raíz de cauda equina se usa desde inicios de los años 80 — más
   antiguo que la monitorización continua con MEP/RBC (añadida a finales de los 90):
   el mapeo, no la monitorización, fue la técnica fundacional en esta región
Referencia: Deletis, cap. 6, pp.93-98 · cap. 27, pp.368, 373-375
```
