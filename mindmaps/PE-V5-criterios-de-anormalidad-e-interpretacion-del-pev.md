# PE-V5 — Criterios de anormalidad e interpretación del PEV

```
Criterios de anormalidad e interpretación del PEV
├─ Los cuatro criterios principales
│  ├─ 1. AUSENCIA TOTAL de PEV, estimulando no solo con cuadros de 1° sino incluso con
│  │  cuadros mayores (~40′)
│  ├─ 2. Latencia de P100 ANORMALMENTE PROLONGADA
│  ├─ 3. Diferencia INTEROCULAR de latencia de P100 de al menos 10 ms
│  └─ 4. Razón INTEROCULAR de amplitud de P100 mayor de 2 (grande/pequeña)
├─ Cómo se fija el límite de latencia del P100
│  ├─ Se considera anormal habitualmente 2.5 o 3 DE por encima de la media de la
│  │  población normal estudiada en ese laboratorio
│  ├─ Más apropiado: usar LÍMITES DE TOLERANCIA — el límite superior del P100 se fija en
│  │  el límite de tolerancia del 99% con nivel de confianza del 95%
│  ├─ Estadística de UNA SOLA COLA, porque solo las latencias prolongadas son
│  │  clínicamente relevantes
│  ├─ Regla práctica: con 30 sujetos para establecer media y DE, la media + 3 DE da el
│  │  límite de tolerancia del 99%
│  └─ Orden de magnitud según laboratorio: media + 3 DE para el P100 queda en 115-120 ms
│     con cuadro grande (~1°)
├─ Por qué el P100 y no N75 o N145
│  ├─ La latencia del P100 es el parámetro MENOS VARIABLE y MÁS SENSIBLE: la medida más
│  │  útil por sí sola para detectar anormalidad en la vía visual
│  ├─ Medir N75 o N145 añade poca utilidad: cuando están prolongados, el P100 suele ser
│  │  ya anormal
│  ├─ Excepción útil: si las ramas del P100 son asimétricas, un N75 simultáneamente
│  │  prolongado hace MÁS CREÍBLE la anormalidad de latencia del P100
│  └─ Al revés hay que ser prudente: si N75 o N145 están prolongados pero el P100 es
│     normal, no conviene interpretar la prueba como anormal — esos picos tienen más
│     variabilidad individual que el P100
├─ Diferencia interocular de latencia
│  ├─ Se considera anormal por encima de 10 ms
│  ├─ El ojo anormal es el que muestra la latencia de P100 MÁS LARGA
│  └─ Cautela obligada: si el P100 de un ojo tiene ramas ascendente y descendente
│     asimétricas, la diferencia interocular puede cruzar artificialmente los 10 ms y la
│     prueba leerse como anormal sin serlo
├─ Criterios de amplitud y su fiabilidad
│  ├─ La amplitud del P100 es MUCHO más variable en normales: va desde 2 µV hasta 20 µV
│  │  └─ Por eso la amplitud ABSOLUTA del P100 tiene poca significación clínica por sí
│  │     misma
│  ├─ Razón interocular en MO ≥2 (grande/pequeña) = anormal
│  │  └─ Gana peso si se asocia a latencia de P100 aumentada en el ojo que genera la
│  │     amplitud menor
│  ├─ Cautela: una razón de amplitud anormal debe interpretarse con prudencia si hay
│  │  agudeza visual asimétrica, nistagmo, problemas de enfoque, error refractivo u
│  │  opacidad de medios
│  ├─ Razón INTERHEMISFÉRICA (RO frente a LO) — preocupa si es >3 (grande/pequeña)
│  │  ├─ Es el criterio de amplitud MÁS DÉBIL, por la gran variabilidad del P100 en los
│  │  │  electrodos occipitales laterales frente al medio-occipital
│  │  ├─ Causas banales a descartar primero: colocación asimétrica de RO y LO, asimetría
│  │  │  anatómica de los polos occipitales
│  │  ├─ Si la asimetría lateral es SIMILAR con la estimulación de ambos ojos, cabe un
│  │  │  defecto de conducción POSTquiasmático en el lado OPUESTO al del electrodo
│  │  │  occipital de menor amplitud
│  │  └─ Solo se establece firmemente con estimulación por HEMICAMPOS. Otras causas
│  │     posibles: lesión del quiasma, o incluso múltiples lesiones prequiasmáticas
│  └─ Formas de onda aberrantes del P100: no son infrecuentes, reportadas en el 14%
├─ El P100 en "W" (bífido) — cuatro explicaciones posibles
│  ├─ Variante NORMAL, que a menudo se resuelve cambiando el tamaño de cuadro
│  ├─ P100 ausente por defecto de campo CENTRAL, que deja al descubierto los componentes
│  │  P75 y P125/P135 aportados en gran parte por el campo periférico
│  ├─ P100 y N100 ASINCRÓNICOS, siendo uno de los dos picos el P100 y el otro el N100
│  ├─ DOS picos P100 por defecto de conducción en la vía de UN hemicampo: el primer pico
│  │  por la vía que conduce normal y el segundo por la lenta
│  └─ Si la forma en "W" no se resuelve, hace falta estimulación por hemicampos o campos
│     parciales, o usar otro tamaño de cuadro, para determinar su significado clínico
├─ Interpretación con estimulación de campo completo
│  ├─ Anormalidad del P100 SOLO con la estimulación de UN ojo → disfunción ANTERIOR AL
│  │  QUIASMA de ese lado
│  │  ├─ Puede ser del nervio óptico, de la retina o de otras estructuras intraoculares
│  │  │  (córnea, cristalino)
│  │  ├─ Una vez excluida la patología intraocular por examen clínico y oftalmológico,
│  │  │  la prolongación monocular de la latencia del P100 es el signo MÁS FIABLE de
│  │  │  lesión del nervio óptico ipsilateral
│  │  └─ Pero la lesión del nervio óptico no es necesariamente desmielinizante, aunque
│  │     sea la causa más frecuente: neuropatía óptica isquémica, compresión tumoral y
│  │     ambliopía tóxico-nutricional dan hallazgos similares
│  ├─ Lesión RETROQUIASMÁTICA unilateral, incluso con hemianopsia homónima densa, NO
│  │  produce un PEV asimétrico en MO con estimulación monocular de campo completo — la
│  │  vía intacta del otro hemicampo da un PEV normal en MO-MF
│  ├─ PEV prolongado pero bastante SIMÉTRICO con ambos ojos → disfunción bilateral de la
│  │  vía visual, que NO puede localizarse sin pruebas adicionales
│  │  └─ Causas posibles: degeneración retiniana bilateral, lesiones bilaterales del
│  │     nervio óptico, lesión del quiasma, lesiones retroquiasmáticas bilaterales,
│  │     glaucoma bilateral, neuritis óptica bilateral, tumor hipofisario, glioma del
│  │     esplenio del cuerpo calloso, causas tóxico-nutricionales, déficit de vitamina
│  │     B12, leucodistrofias genéticas
│  └─ PEV anormal con ambos ojos pero con diferencia INTEROCULAR anormal → afectación
│     bilateral con al menos una de las lesiones probablemente ANTERIOR al quiasma, del
│     lado de la latencia más larga
│     └─ Como toda la entrada visual de ambos ojos atraviesa un área pequeña en el
│        quiasma, las lesiones desmielinizantes asimétricas en esa localización producen
│        con frecuencia anormalidades asimétricas del PEV
├─ Qué significa el patrón según el mecanismo lesional
│  ├─ Desmielinización focal segmentaria (esclerosis múltiple): la conducción pasa de
│  │  saltatoria rápida a continua lenta. Si los axones quedan intactos, la anormalidad
│  │  es sobre todo de LATENCIA PROLONGADA con amplitud preservada
│  ├─ Procesos compresivos, isquémicos o degenerativos del nervio óptico: producen
│  │  BLOQUEO DE CONDUCCIÓN, con AMPLITUD DISMINUIDA y efecto variable sobre la latencia
│  │  └─ Incluso en la desmielinización puede coexistir bloqueo axonal significativo, y
│  │     entonces hay anormalidad de latencia Y de amplitud
│  └─ Pérdida axonal pura: teóricamente solo baja la amplitud del P100, sin prolongación
│     significativa de la latencia
├─ Lo que un PEV NORMAL no descarta
│  ├─ Un PEV normal de campo completo NO implica necesariamente que la vía visual
│  │  funcione con normalidad
│  ├─ La pérdida de campos visuales periféricos, o los escotomas periféricos, pueden no
│  │  asociarse a un PEV anormal
│  ├─ Incluso en la rara situación de ceguera cortical con suficiente polo occipital
│  │  conservado y algo de campo central preservado, el PEV puede salir esencialmente
│  │  normal
│  └─ En cambio, ante pérdida importante de agudeza visual con exploración ocular normal,
│     un PEV normal apoya con fuerza un origen PSICÓGENO (trastorno conversivo)
├─ Advertencia general de especificidad
│  └─ Las condiciones patológicas que producen anormalidades del PEV son diversas y NO
│     hay nada específico en las anormalidades en sí mismas: el PEV dice que hay un
│     defecto de conducción, no de qué enfermedad se trata
├─ Resumen del significado clínico por patrón
│  ├─ Prolongación de latencia de P100 con un ojo → disfunción prequiasmática
│  ├─ Diferencia interocular de latencia ≥10 ms → disfunción prequiasmática del lado de
│  │  la latencia prolongada
│  ├─ Amplitud de P100 disminuida con un ojo → disfunción prequiasmática
│  ├─ Latencias prolongadas con ambos ojos, simétricas → disfunción bilateral, sin
│  │  localización anteroposterior precisa
│  ├─ Latencias prolongadas con ambos ojos, asimétricas → disfunción bilateral con al
│  │  menos una lesión prequiasmática
│  └─ PEV normal con cuadro grande pero anormal con cuadro pequeño → interpretar con
│     cautela: comúnmente se debe a causas intraoculares
└─ Referencia
   └─ Markand2020 cap.3 pp.94-102 (Tablas 3.4 y 3.6, Figs. 3.10-3.12); criterios
      discutidos en detalle en la Guideline 9B de la ACNS (2008)
```
