# C6 — Troubleshooting general

```
Troubleshooting general
├─ Concepto central
│  ├─ Ante un cambio de señal, las causas posibles son técnicas, anestésico-fisiológicas o
│  │  quirúrgicas reales — pero el orden en que se COMUNICA no es el orden en que se
│  │  DESCARTA
│  ├─ REGLA DE SECUENCIA: se avisa al cirujano primero y se comprueba el equipo después.
│  │  El troubleshooting es una acción SECUNDARIA
│  │  ├─ Justificación aritmética: los problemas técnicos son raros. Si tras avisar
│  │  │  resulta ser un fallo de equipo, la única pérdida son unos minutos del tiempo del
│  │  │  cirujano. Si el cambio era funcional y se retrasó el aviso buscando la causa
│  │  │  técnica, se pierde tiempo irrecuperable, se pierde la oportunidad de identificar
│  │  │  qué maniobra lo causó, y el cambio tiene margen para progresar
│  │  ├─ Solo DESPUÉS de asumir que el problema es biológico se considera el fallo de
│  │  │  equipo
│  │  └─ El cirujano no debe esperar a que termine la comprobación: empieza en paralelo su
│  │     propia investigación
│  ├─ Lo que hace viable esa regla: las características de los cambios de causa técnica
│  │  suelen ser TAN distintas de las de una lesión que un neurofisiólogo experimentado
│  │  las distingue con facilidad
│  └─ Contrapartida obligatoria: aceptar esta forma de trabajar exige haber reducido al
│     mínimo absoluto los fallos técnicos capaces de imitar un cambio quirúrgico. Todo
│     este tema va de eso
├─ LA LEY DE MURPHY COMO PUNTO DE PARTIDA
│  ├─ Los errores son un fenómeno natural que solo puede evitarse haciéndolos FÍSICAMENTE
│  │  IMPOSIBLES — a diferencia de las leyes humanas, esta no se puede incumplir
│  ├─ Puede ocurrir 1 de cada 10 veces o 1 de cada millón, pero todo lo que puede salir
│  │  mal saldrá mal tarde o temprano
│  └─ Corolario de diseño: cuando un error no se puede hacer imposible, hay que hacerlo lo
│     más improbable posible
├─ EL ERROR CANÓNICO: el auricular en los dos oídos
│  ├─ Si se monitoriza el nervio auditivo en cirugía de ángulo pontocerebeloso, el sonido
│  │  debe entregarse al oído DEL LADO OPERADO
│  ├─ Si se colocan auriculares en AMBOS oídos, siempre existe el riesgo de seleccionar
│  │  por error el lado no operado — al conectar el auricular al estimulador, o al
│  │  conmutar el estímulo por error durante la intervención
│  ├─ Lo que lo hace letal: el error NO es evidente mirando el BAEP registrado, porque en
│  │  la mayoría de las personas las formas de onda de ambos lados son SIMILARES, sea cual
│  │  sea el oído estimulado
│  ├─ Consecuencia: es imposible detectar ningún cambio de función del nervio auditivo del
│  │  lado operado. Los registros con estimulación contralateral no cambiarán aunque el
│  │  nervio auditivo se lesione — ni siquiera aunque se SECCIONE
│  └─ Veredicto de la fuente: esa monitorización es PEOR QUE NO MONITORIZAR, porque
│     proporciona una falsa sensación de seguridad
├─ CÓMO REDUCIR LOS ERRORES
│  ├─ CHECKLIST, con el modelo de la aviación
│  │  ├─ Cubre montaje del equipo, colocación de electrodos y material a llevar al
│  │  │  quirófano, incluido el de repuesto. Reduce el riesgo de olvidar elementos
│  │  │  esenciales y de fijar mal los parámetros de estimulación y registro
│  │  ├─ El argumento que desarma la objeción habitual: el comandante repasa una checklist
│  │  │  en vuelos cortos y largos, en aerolíneas grandes y pequeñas, y también los pilotos
│  │  │  privados. NO la usan porque no sepan volar — la usan para no OLVIDAR algo que ya
│  │  │  saben. Saber hacer el trabajo no es razón para no usar checklist
│  │  └─ Las aerolíneas tienen además checklists de ACTUACIÓN ante fallo de equipo y
│  │     emergencias; se ganaría mucho teniendo algo equivalente en monitorización
│  ├─ RUTINA CONSTANTE: adherirse a las mismas rutinas siempre que sea posible, y
│  │  monitorizar igual en cirugías similares en vez de ir cambiando el procedimiento
│  ├─ CONECTAR DE UNO EN UNO: si se colocan muchos electrodos, el riesgo de error al
│  │  conectarlos es MUCHO menor si cada electrodo se conecta al box justo tras colocarlo
│  │  y antes de colocar el siguiente, en vez de colocarlos todos y conectarlos al final
│  ├─ PRINCIPIO KISS (Keep It Simple and Stupid)
│  │  ├─ El riesgo de que algo salga mal aumenta con la complejidad del equipo y del método
│  │  ├─ Registrar en muchos canales rara vez aporta más información útil de la que se
│  │  │  obtiene con unos pocos canales cuidadosamente seleccionados, pero sí añade
│  │  │  complejidad
│  │  └─ Es más difícil diseñar un sistema simple que uno complejo, pero compensa —
│  │     "la simplicidad es la máxima sofisticación"
│  └─ PENSAR POR ADELANTADO
│     ├─ Considerar los problemas esperables ANTES de que empiece la cirugía, para estar
│     │  preparado al menos para los más comunes
│     ├─ Tener disponible en muy poco tiempo equipo de respaldo, cables, electrodos y
│     │  conectores de repuesto en el propio quirófano
│     └─ Colocar electrodos REDUNDANTES en el paciente, particularmente en las zonas
│        propensas a manipulación durante la cirugía
├─ AUSENCIA DE RESPUESTA — el diagnóstico diferencial
│  ├─ Comprobación previa que evita el ridículo: con el sonido ya encendido, quien coloca
│  │  el auricular debe ESCUCHARLO inmediatamente antes de introducirlo en el oído del
│  │  paciente. Asegura que entrega sonido al menos al principio de la cirugía
│  ├─ Patología del propio paciente: causa común de ausencia de respuestas. Hipoacusia o
│  │  neuropatía periférica son las típicas
│  │  ├─ Los tests preoperatorios evitan la sorpresa
│  │  └─ Si no los hay, empezar a recoger los potenciales LO ANTES POSIBLE y no esperar al
│  │     momento en que hace falta monitorizar: empezar pronto deja tiempo para comprobar
│  │     equipo y colocación de electrodos, y quizá elegir una colocación mejor
│  │     └─ Ejemplo: en SEP de MMII la mejor estimulación es el tibial posterior en el pie;
│  │        como alternativa, el peroneo común en la rodilla (trayecto periférico más
│  │        corto) si hay neuropatía grave, porque la neuropatía afecta en mayor grado a
│  │        las porciones más DISTALES del nervio
│  ├─ Ausencia INESPERADA de respuesta muscular a la estimulación de un nervio: a menudo
│  │  causada por que el equipo de anestesia ha paralizado al paciente. Otra causa, fallo
│  │  en estimular el nervio adecuadamente
│  ├─ Fallo en obtener respuesta muscular a la estimulación CORTICAL: a menudo por exceso
│  │  de anestésico, o por una selección inadecuada de los agentes anestésicos
│  └─ Monitorizar también durante los periodos en que no hace falta, recogiendo y guardando
│     los datos, permite detectar fallos que ocurran en ese tiempo muerto. Si se para la
│     monitorización y algo se estropea mientras tanto, puede no ser posible reanudarla
│     cuando haga falta, y puede ser difícil averiguar qué ha pasado
├─ FALLO DE EQUIPO
│  ├─ Cada vez más raro, pero si ocurre o se resuelve muy rápido o la cirugía continúa sin
│  │  monitorización — no hay opción de reprogramar como en el laboratorio
│  ├─ La mayoría de los problemas de los equipos modernos son de SOFTWARE
│  ├─ Gran fuente de "fallo": el ERROR DEL OPERADOR por conocimiento insuficiente del
│  │  equipo y, sobre todo, de su software
│  └─ Remedio elemental que resuelve muchos fallos por software: reiniciar el ordenador
├─ INTERFERENCIA — las cinco vías de entrada
│  ├─ La interferencia eléctrica solo es un problema cuando LLEGA al equipo de registro.
│  │  Llega de dos formas: como campos eléctricos por acoplamiento capacitivo ("por el
│  │  aire") o por medios conductores (conducción galvánica)
│  ├─ 1. Campos eléctricos captados por cables de electrodo SIN APANTALLAR (acoplamiento
│  │  capacitivo) desde fuentes de interferencia cercanas
│  ├─ 2. Señales inyectadas en el sistema de registro por una VÍA COMÚN, como los bucles
│  │  de tierra (acoplamiento galvánico)
│  ├─ 3. Corriente conducida galvánicamente al paciente vía otros electrodos de registro o
│  │  estimulación colocados sobre él (equipos de monitorización de anestesia), vía líneas
│  │  de infusión, o vía dispositivos en contacto galvánico con el paciente como los
│  │  CABEZALES
│  ├─ 4. Interferencia captada por acoplamiento capacitivo AL PACIENTE, por ejemplo desde
│  │  mantas térmicas o mesas de quirófano motorizadas
│  └─ 5. Señales que se filtran directamente a los amplificadores fisiológicos por la LÍNEA
│     DE ALIMENTACIÓN
├─ LA VÍA MÁS COMÚN, Y LA MÁS FÁCIL DE ARREGLAR
│  ├─ La entrada más frecuente es a través de los CABLES DE ELECTRODO
│  └─ Remedio: TRENZAR o entrelazar los cables, mantenerlos CORTOS y alejarlos del equipo
│     que genera interferencia
├─ LOS SOSPECHOSOS HABITUALES
│  ├─ CALENTADORES DE SANGRE y BOMBAS DE INFUSIÓN: la corriente de sus circuitos
│  │  electrónicos se conduce al paciente a través del fluido infundido
│  │  ├─ Las bolsas de infusión colgadas muy por encima del paciente actúan como ANTENAS
│  │  │  eficaces: captan interferencia y la inyectan directamente en el paciente por el
│  │  │  fluido conductor, desde donde alcanza los amplificadores por los electrodos
│  │  ├─ Los calentadores de sangre son NOTORIOS: los modelos de quirófano suelen elegirse
│  │  │  por ser los más baratos, y sus reguladores de potencia baratos causan interferencia
│  │  │  severa
│  │  └─ Por eso esta interferencia "aparece de la nada" a mitad de cirugía: cuando se
│  │     enciende el calentador o se añaden bolsas nuevas
│  ├─ CABEZALES: en contacto con la mesa, que puede estar puesta a tierra por seguridad —
│  │  y esa tierra de seguridad puede crear un BUCLE DE TIERRA con la frecuencia de red
│  ├─ MANTAS TÉRMICAS conectadas a la red y MESAS DE QUIRÓFANO controladas eléctricamente:
│  │  fuentes frecuentes, aunque no estén conectadas directamente al paciente
│  ├─ El TOF del anestesiólogo: la estimulación eléctrica de músculos de la mano para
│  │  testar el nivel de parálisis puede causar interferencia eléctrica SÚBITA
│  ├─ ELECTROCOAGULACIÓN: interferencia intermitente tan fuerte que en la mayoría de casos
│  │  hace imposible registrar. No se puede evitar; la única forma de reducir su efecto es
│  │  EXCLUIR los registros mientras se coagula
│  │  └─ La interferencia excede casi invariablemente el rango dinámico de los
│  │     amplificadores, lo que puede exigir precauciones especiales además del rechazo de
│  │     artefacto habitual del equipo
│  └─ EQUIPO MAL PUESTO A TIERRA: no solo es un riesgo de seguridad; la carcasa deja de
│     actuar como PANTALLA eléctrica y se convierte en fuente
│     └─ Trampa: el funcionamiento del equipo NO se afecta si el cable de tierra se
│        desconecta, así que la desconexión accidental pasa desapercibida. La única
│        indicación puede ser el aumento de interferencia en los registros
├─ INTERFERENCIA MAGNÉTICA
│  ├─ Causada sobre todo por equipo que contiene TRANSFORMADORES, que generan un campo
│  │  magnético relacionado con la frecuencia de red
│  ├─ Las bobinas de deflexión de los monitores de vídeo antiguos emiten campos de ALTA
│  │  frecuencia
│  ├─ Las fuentes de luz potentes de los microscopios quirúrgicos generan campos magnéticos
│  │  capaces de interferir — en la figura del capítulo, la fuente resultó ser exactamente
│  │  esa
│  └─ El campo magnético como tal no afecta al registro: lo que interfiere es la CORRIENTE
│     ELÉCTRICA que ese campo induce en los cables
├─ LA FIRMA DE CADA INTERFERENCIA — diagnóstico por la forma de onda
│  ├─ La firma más importante es la FRECUENCIA: una interferencia con la frecuencia de red
│  │  (60 Hz en Norteamérica, 50 Hz en Europa) tiene que estar generada por la red de una u
│  │  otra manera
│  ├─ La corriente de red es casi sinusoidal, pero en los registros la interferencia de red
│  │  no siempre aparece como sinusoide
│  ├─ La interferencia de red conducida MAGNÉTICAMENTE suele ser RICA EN ARMÓNICOS
│  │  superiores
│  │  └─ Doble filo: los armónicos ayudan mucho a identificar la fuente, pero hacen la
│  │     interferencia más molesta porque pueden solaparse con el rango de frecuencias de
│  │     los potenciales que se registran
│  ├─ Interferencia de red con ESPIGAS agudas superpuestas a la sinusoide, con la misma
│  │  frecuencia de red o con el DOBLE: procede de equipos con reguladores de potencia que
│  │  "trocean" la onda. El equipo barato es el peor infractor, y los calentadores de
│  │  sangre son notorios en esto
│  ├─ Equipo DIGITAL (calentadores, bombas de infusión, ordenadores): radia señales de
│  │  frecuencia MUCHO MÁS ALTA que la de red, además de la propia interferencia de red.
│  │  Algunos generan impulsos aleatorios o dependientes de su funcionamiento
│  └─ Si la onda de interferencia es compleja, un ANÁLISIS ESPECTRAL de los potenciales
│     registrados puede ayudar a identificar la fuente
├─ CÓMO LOCALIZAR LA FUENTE
│  ├─ Apagar el equipo sospechoso de uno en uno y ver si desaparece — viable ANTES de la
│  │  cirugía, normalmente no durante
│  ├─ Examinar el quirófano cuando NO está en uso es la forma eficiente, porque el equipo
│  │  puede moverse y encenderse y apagarse libremente. Debe hacerse un barrido de todos
│  │  los quirófanos antes de monitorizar en una sala desconocida, sin prisa (por ejemplo,
│  │  la tarde anterior)
│  ├─ ANTENA para interferencia eléctrica: se conecta un cable a una de las dos entradas
│  │  diferenciales de un amplificador estándar, con la otra entrada a tierra y una
│  │  resistencia de unos 100 kΩ entre la tierra y la entrada de la antena. Al acercar la
│  │  antena al equipo que "fuga", la amplitud de la señal captada AUMENTA en la pantalla
│  ├─ LAZO para interferencia magnética: un cable en forma de lazo conectado a los DOS
│  │  terminales de entrada, uno de ellos a tierra. El campo magnético induce corriente en
│  │  el lazo, y al acercarlo a la fuente la amplitud aumenta
│  │  └─ La ORIENTACIÓN del lazo es determinante: hay que rotarlo para mantenerlo
│  │     óptimamente orientado respecto al campo, o se puede no ver una fuente que está ahí
│  ├─ Confirmación: si la forma de onda y la frecuencia captadas por el lazo coinciden con
│  │  las de la interferencia observada al registrar del paciente, ese equipo es
│  │  seguramente la fuente, y su localización es donde la señal captada es más intensa
│  ├─ VOLUNTARIO en la mesa, en la misma posición que tendrá el paciente, con electrodos
│  │  conectados a los amplificadores: con todo el resto del equipo apagado no debería
│  │  haber interferencia; después se enciende el equipo de anestesia y demás UNO A UNO
│  ├─ Si persiste interferencia con todo apagado salvo el equipo de monitorización, la
│  │  genera el propio equipo de registro o la INSTALACIÓN ELÉCTRICA de la sala: cables del
│  │  suelo y las paredes, iluminación. Las líneas de potencia del suelo o el techo son
│  │  fuentes "ocultas" comunes
│  └─ Lo que NO puede simularse con un voluntario: las líneas de fluido en contacto con el
│     paciente, y los cambios de conexión del equipo de anestesia que se hacen durante la
│     cirugía
├─ CÓMO REDUCIR EL EFECTO
│  ├─ Dos vías, y conviene atacar las dos: reducir la EMISIÓN de la señal en su fuente, y
│  │  reducir la capacidad del sistema de registro para CAPTARLA
│  ├─ Todo el equipo en contacto galvánico con el paciente debería alimentarse de tomas
│  │  suministradas por el MISMO transformador de aislamiento que el equipo de
│  │  monitorización — la interferencia es peor cuando están en transformadores distintos
│  │  └─ No siempre es fácil averiguar qué transformador alimenta cada toma; a menudo es
│  │     más práctico simplemente probar tomas distintas
│  └─ Los cables entre el electrode box y los amplificadores también captan interferencia
│     eléctrica y magnética, pero la tecnología lo ha reducido: con el conversor A/D dentro
│     del propio electrode box, la señal que viaja es DIGITAL y es esencialmente resistente
│     a la interferencia magnética. Los enlaces por FIBRA ÓPTICA y por USB no son sensibles
│     ni a interferencia eléctrica ni magnética
├─ INTERFERENCIA BIOLÓGICA
│  ├─ El EEG en curso y la actividad muscular pueden oscurecer los potenciales evocados
│  ├─ Si el plano anestésico baja lo suficiente aparecen contracciones musculares
│  │  espontáneas, cuyo EMG contamina el registro si lo captan los electrodos de PE
│  └─ Hay que saber DISTINGUIR interferencia eléctrica externa de interferencia de origen
│     biológico — y para eso hay que estar mirando los potenciales CRUDOS, no solo los
│     promediados
├─ EL OTRO TROUBLESHOOTING: EL ERROR HUMANO Y EL SESGO DEL EQUIPO
│  ├─ Por qué está en este tema y no en otro: un montaje impecable y un quirófano sin
│  │  interferencia no sirven de nada si tras la alarma nadie actúa. El fallo de decisión
│  │  es un modo de fallo del sistema tan real como un electrodo suelto, y es el más
│  │  frecuente de los dos
│  ├─ EL PUNTO DE PARTIDA: LAS AEROLÍNEAS, OTRA VEZ
│  │  ├─ Tras el informe del Institute of Medicine que atribuyó hasta 98.000 muertes
│  │  │  anuales en EEUU a errores médicos, se abrió el foco sobre la causa del error. Hasta
│  │  │  DOS TERCIOS de todos los errores resultaron nacer de dinámicas de equipo
│  │  │  disfuncionales, NO de una asistencia incompetente
│  │  ├─ Datos más recientes en EEUU: 100.000 muertes al año, 19.500 millones de dólares de
│  │  │  coste anual y 4,6 días más de estancia hospitalaria atribuibles a error médico
│  │  ├─ Dos décadas antes de ese informe ya se sabía que los accidentes aéreos
│  │  │  catastróficos venían en gran parte de comunicación defectuosa y decisiones erróneas
│  │  │  entre tripulantes. La industria abrió la comunicación y APLANÓ las jerarquías de
│  │  │  decisión en vuelo, con el entrenamiento "crew resource management"
│  │  ├─ Fórmula concreta que enseña United Airlines, y que sirve igual en quirófano:
│  │  │  "estoy preocupado, estoy incómodo, esto es inseguro"
│  │  └─ Las dos precondiciones críticas para reducir errores: CONCIENCIA SITUACIONAL —
│  │     definida como el diálogo que mantiene a los miembros del equipo al día de qué está
│  │     pasando y de cómo responderán si la situación cambia— y LENGUAJE CRÍTICO
│  ├─ LOS DOS MECANISMOS DE DISEÑO QUE YA TIENE LA MIO
│  │  ├─ DISEÑO INDULGENTE (forgiving design): la reversibilidad de la pérdida de señal tras
│  │  │  una maniobra quirúrgica de riesgo. El sistema perdona el error si se detecta a
│  │  │  tiempo
│  │  └─ REDUNDANCIA DEL SISTEMA: la tasa de error baja cuando se aplican VARIOS tests al
│  │     MISMO sistema neural. Ejemplo canónico, el suelo del IV ventrículo — el núcleo del
│  │     facial puede vigilarse por estimulación directa, por MEP corticobulbar y por EMG
│  │     libre a la vez
│  ├─ LOS SESGOS COGNITIVOS QUE ARRUINAN UNA ALARMA CORRECTA
│  │  ├─ CIERRE PREMATURO: el cirujano usa heurísticas (reglas de pulgar) construidas con
│  │  │  años de experiencia, y habitualmente le funcionan muy bien. Pero bajo el estrés de
│  │  │  una crisis emergente —hemorragia masiva, lesión medular— aferrarse a la heurística
│  │  │  puede CORTAR el acceso a toda la paleta de opciones disponibles
│  │  ├─ HEURÍSTICA DE DISPONIBILIDAD: la decisión del cirujano tras una alarma al cerrar
│  │  │  una osteotomía puede quedar indebidamente teñida por un informe falso positivo
│  │  │  RECIENTE del mismo equipo, en vez de por una valoración analítica y probabilística
│  │  ├─ SESGO DE CONFIRMACIÓN O DE EXPECTATIVA: tendencia a interpretar lo que se oye de
│  │  │  forma que confirme lo que ya se creía, o a devaluar el dato que choca con lo
│  │  │  esperado. Formulación clásica del fenómeno: la información neurofisiológica es
│  │  │  bienvenida mientras tranquiliza al neurocirujano de que todo va bien, y mucho menos
│  │  │  bienvenida cuando el cambio implicaría detener o incluso abandonar la cirugía
│  │  ├─ DESPRECIO DE LA PROBABILIDAD (base-rate bias), que afecta a los DOS lados y en
│  │  │  direcciones opuestas
│  │  │  ├─ Con riesgo basal muy bajo, el NEUROFISIÓLOGO puede sobrerreaccionar a un cambio
│  │  │  │  de señal con contexto pobre → informe falso positivo
│  │  │  └─ Y el CIRUJANO, tras un positivo fuertemente anclado al contexto, puede
│  │  │     infrarreaccionar → oportunidad perdida de cambiar el manejo y mejorar el
│  │  │     resultado
│  │  └─ SESGO AUTOSERVIDOR Y CHIVO EXPIATORIO: la MIO NO es la lectura estática de una
```
