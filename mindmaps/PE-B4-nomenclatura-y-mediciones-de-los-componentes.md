# PE-B4 — Nomenclatura y mediciones de los componentes

```
Nomenclatura y mediciones de los componentes
├─ Definición y alcance
│  ├─ Dos operaciones distintas que se confunden con facilidad: NOMBRAR un componente
│  │  (identificarlo y etiquetarlo) y MEDIRLO (asignarle latencia y amplitud)
│  ├─ Nombrar mal un componente invalida la medición aunque el cursor esté bien puesto —
│  │  el error más caro de todo el informe
│  └─ Solo se miden los componentes OBLIGADOS: los presentes de forma constante en todos
│     los sujetos normales, que son los clínicamente relevantes
├─ Los tres sistemas de nomenclatura
│  ├─ 1. ORDINAL: numerales romanos. Se usa sobre todo para el PEATC — onda I, onda II,
│  │  onda III...
│  ├─ 2. POLARIDAD-ORDINAL: N1, P1, N2, P2. La letra indica la polaridad (N negativa,
│  │  P positiva) y el número el orden de aparición
│  ├─ 3. POLARIDAD-LATENCIA: N9, P37, P100. La letra indica la polaridad y el número la
│  │  LATENCIA MEDIA en milisegundos
│  ├─ Problema común de los dos primeros sistemas
│  │  ├─ Si los componentes iniciales faltan por patología o por problema técnico, la
│  │  │  identificación se DESPLAZA: si falta el P1, el P2 puede tomarse por un P1
│  │  │  retrasado — y el informe sale con una latencia prolongada inexistente
│  │  └─ Además, los numerales 1, 2... no aportan ninguna información sobre la latencia
│  │     del componente: solo denotan su orden o secuencia de aparición
│  ├─ El convenio PREFERIDO es el de polaridad-latencia, porque aporta a la vez la
│  │  polaridad y la latencia media del componente
│  ├─ Problema residual del sistema preferido: la latencia que da nombre al componente no
│  │  es fija. La latencia del P37 registrado en el scalp depende de la edad, la talla y
│  │  el sitio de estimulación (tobillo frente a rodilla)
│  └─ Nomenclatura por la fuente generadora, que convive con las tres anteriores:
│     "potencial de plexo braquial" o "potencial de Erb" para el N9 del PESS de mediano,
│     "potencial poplíteo" para el N7 del PESS de tibial posterior
├─ La polaridad NO es una propiedad absoluta del componente
│  ├─ La polaridad de un componente puede depender de la DERIVACIÓN de registro
│  ├─ Ejemplo canónico: el mismo componente es N13 (negativo) registrado desde un
│  │  electrodo sobre la apófisis espinosa de C5 con estimulación de mediano en muñeca, y
│  │  P13 (positivo) registrado desde un electrodo sobre el cuello anterior
│  ├─ Por eso, conocer la derivación de registro es IMPRESCINDIBLE para que la polaridad
│  │  signifique algo
│  └─ Recordatorio del amplificador diferencial: la salida es solo la diferencia entre
│     las dos entradas y no prueba la polaridad de la señal — el canal se designa siempre
│     escribiendo primero el electrodo del terminal 1
├─ Convenios de visualización (por qué una misma onda "sube" o "baja")
│  ├─ No existe un convenio universal sobre cómo se muestran los PE en pantalla o en papel
│  └─ Lo más frecuente: en PEATC la positividad en el vértex genera una onda hacia ARRIBA;
│     en PEV la positividad en los electrodos occipitales genera una traza hacia ABAJO
│     (de ahí que el P100 sea la gran deflexión descendente); en PESS la negatividad en
│     los electrodos sobre corteza somatosensorial genera una onda hacia ARRIBA
├─ Recomendación de la ACNS que no cuajó
│  └─ Usar una BARRA HORIZONTAL sobre el nombre del componente para indicar que se trata
│     de un componente teórico. No ha ganado mucha aceptación
├─ Cuáles son los componentes obligados de cada modalidad
│  ├─ PEATC: ondas I, III y V. Las ondas II, IV, VI y VII son inconstantes incluso en
│  │  normales y no se usan para interpretación clínica
│  │  └─ En un tercio de los normales las ondas IV y V no se reconocen separadas y se
│  │     designan "complejo IV/V", con latencia intermedia
│  ├─ PESS de mediano: N9, N13/P13, P14, N18 y N20
│  ├─ PESS de tibial posterior: N7, N22, P31, N34 y P37
│  ├─ PEV por damero: N75, P100 y N145 — el clínicamente relevante es el P100, por su
│  │  mayor amplitud, menor variabilidad interindividual y mínima asimetría interocular
│  └─ Por qué importa la distinción: si falta un componente NO obligado, eso no es una
│     anormalidad
├─ MEDICIONES — cómo se hacen
│  ├─ Una vez adquirido el PE se determinan, por técnica de CURSOR: la latencia de los
│  │  componentes obligados, las latencias interpico y la amplitud de los componentes
│  │  principales
│  ├─ LATENCIA ABSOLUTA
│  │  ├─ Tiempo en ms entre el momento de presentación del estímulo y el componente del
│  │  │  PE, habitualmente su PICO
│  │  └─ Está influida por multitud de factores que no se pueden controlar (edad, sexo,
│  │     talla, temperatura, intensidad de estímulo, déficit periférico)
│  ├─ LATENCIA INTERPICO (IPL)
│  │  ├─ Intervalo en ms que separa dos picos
│  │  ├─ Es la medición RECOMENDADA para valorar anormalidades clínicamente relevantes,
│  │  │  porque se afecta mucho menos por esos factores y mide conducción CENTRAL
│  │  └─ Ejemplos operativos: IPL I-III, III-V y I-V en PEATC; N9-N13, N9-P14 y N13-N20
│  │     en PESS de mediano, donde el N13(P14)-N20 mide la conducción central y su límite
│  │     superior normal habitual es 7 ms
│  ├─ AMPLITUD
│  │  ├─ Se mide en µV, pero su medición NO está adecuadamente estandarizada: ¿respecto a
│  │  │  la línea de base (a menudo indefinible), respecto al pico anterior o al posterior?
│  │  ├─ Método alternativo: ÁREA bajo el componente. Se usa rara vez, porque exige
│  │  │  medición por ordenador y porque es difícil identificar correctamente el área
│  │  │  total a medir
│  │  ├─ Convenio práctico consolidado
│  │  │  ├─ En PEATC y PESS la amplitud del componente se mide hasta el pico SIGUIENTE
│  │  │  └─ En PEV la amplitud se mide hasta el pico ANTERIOR (el N75)
│  │  └─ En PEATC en concreto: la amplitud de las ondas I y V se mide desde el punto más
│  │     positivo de la onda hasta el valle negativo subsiguiente
│  └─ Jerarquía de fiabilidad: la amplitud es en general MENOS útil que la latencia,
│     porque su variabilidad intersujeto en población normal es mucho mayor
│     └─ Una diferencia significativa de amplitud entre los dos lados constituye, como
│        mucho, una anormalidad "blanda" (soft)
├─ Qué se mide en la práctica, modalidad por modalidad
│  ├─ PEATC: latencias de pico de las ondas I, III y V; IPL I-III, III-V y I-V;
│  │  amplitudes de las ondas I y V para calcular la RAZÓN V/I
│  ├─ PESS: latencias absolutas de los componentes obligados e IPL entre ellos; amplitudes
│  │  con comparación interlado
│  └─ PEV: latencia del P100 de cada ojo, diferencia interocular de latencia, y amplitud
│     del P100 medida al N75 previo
├─ Aplicación práctica
│  ├─ El intérprete debe comprobar SIEMPRE que el técnico ha colocado el cursor en el
│  │  punto correcto de la onda antes de aceptar el valor de latencia — la medición de
│  │  latencia no plantea problemas una vez que los picos están correctamente
│  │  identificados, y todo el problema está en identificarlos
│  ├─ Trabajar siempre sobre ≥2 réplicas superpuestas: la superposición es lo que permite
│  │  identificar con exactitud qué picos están relacionados con el estímulo
│  ├─ Cuando un componente falta, nombrar los siguientes por su latencia esperada y no
│  │  por su orden, para no arrastrar el error
│  └─ Ante un componente de polaridad "inesperada", revisar la derivación antes de
│     pensar en patología
├─ Errores y confusiones frecuentes
│  ├─ Deriva del sistema ordinal: tomar el P2 por un P1 retrasado cuando el P1 falta
│  ├─ Interpretar la polaridad sin conocer la derivación (N13 frente a P13)
│  ├─ Suponer que el número del nombre es la latencia real del paciente: el "100" del
│  │  P100 o el "37" del P37 son latencias MEDIAS de referencia, no valores fijos
│  ├─ Medir la amplitud del P100 al pico siguiente por analogía con el PEATC, en vez de
│  │  al N75 anterior
│  ├─ Llamar anormal la ausencia de un componente no obligado (onda IV, VI o VII del
│  │  PEATC)
│  └─ Basar el informe en la amplitud absoluta de un componente, que tiene variabilidad
│     intersujeto enorme
├─ Limitaciones
│  ├─ La medición de amplitud carece de estándar aceptado, lo que limita la comparación
│  │  entre laboratorios y entre estudios
│  ├─ El sistema polaridad-latencia, aun siendo el preferido, arrastra nombres cuya
│  │  latencia varía con edad, talla y punto de estimulación
│  └─ Ninguna nomenclatura resuelve el problema de fondo: identificar el pico correcto en
│     un registro ruidoso o con componentes ausentes sigue dependiendo del criterio del
│     intérprete y de la calidad del registro
└─ Referencia
   └─ Markand2020 cap.1 pp.11-12 (nomenclatura, sistemas, polaridad y derivación,
      mediciones, Fig. 1.9), p.22 (convenios de visualización) · cap.2 pp.34-35 (qué se
      mide en PEATC, amplitud de I y V, razón V/I) · cap.4 pp.167-168 (IPL en PESS,
      conducción central N13-N20 con límite de 7 ms) · cap.3 pp.90-91 (componentes del PEV
      y medición de amplitud al N75)
```
