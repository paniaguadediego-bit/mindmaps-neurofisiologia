# C8 — Seguridad por procedimiento y rendimiento esencial

```
Seguridad por procedimiento y rendimiento esencial
├─ Concepto central
│  ├─ Además de los peligros genéricos del equipo —shock, quemaduras, fuego— cada TÉCNICA
│  │  concreta tiene sus propios problemas de seguridad, y este tema los recorre uno por uno
│  ├─ Y hay un segundo nivel de seguridad que no es eléctrico ni infeccioso y que puede ser el
│  │  MÁS IMPORTANTE de todos: el RENDIMIENTO ESENCIAL, es decir, que la información
│  │  diagnóstica que se entrega sea correcta y llegue a tiempo
│  ├─ El esquema mental es siempre el mismo: identificar el PELIGRO propio de la técnica y
│  │  enumerar sus MEDIOS DE PROTECCIÓN
│  └─ Marco general que conviene tener presente antes de entrar en detalle: entender los
│     peligros y aplicar la protección adecuada minimiza el riesgo y hace la neurofisiología
│     intraoperatoria suficientemente segura para uso clínico EN MANOS EXPERTAS — la
│     experiencia no es un adorno del sistema de seguridad, es parte de él
├─ TÉCNICAS INVASIVAS — la regla de la indicación justificable
│  ├─ Los electrodos SUBDURALES, EPIDURALES o INTRAPARENQUIMATOSOS conllevan riesgos pequeños
│  │  pero potencialmente serios de complicaciones HEMORRÁGICAS, INFECCIOSAS o TRAUMÁTICAS
│  ├─ Por eso es aconsejable limitar su uso a INDICACIONES JUSTIFICABLES, entendiendo por tal
│  │  que NO exista una forma no invasiva adecuada de obtener la información necesaria
│  ├─ Todos los electrodos invasivos deben ser ESTÉRILES y estrictamente de UN SOLO USO
│  ├─ LAS TRES INDICACIONES MÁS COMÚNMENTE JUSTIFICABLES
│  │  ├─ Electrocorticografía y mapeo o monitorización cortical durante cirugía de epilepsia u
│  │  │  otra cirugía cerebral
│  │  ├─ Procedimientos de estimulación cerebral profunda
│  │  └─ Monitorización de onda D epidural espinal durante cirugía de tumor medular
│  │     intramedular
│  └─ EJEMPLOS DE INDICACIÓN MENOS JUSTIFICABLE: la monitorización medular invasiva en cirugía
│     aórtica o de escoliosis, que se monitorizan adecuadamente de forma NO invasiva y en las
│     que las ondas D epidurales son menos útiles o incluso potencialmente ENGAÑOSAS
├─ ESTIMULACIÓN CORTICAL DIRECTA — el problema es la crisis
│  ├─ La inducción de crisis intraoperatorias es la preocupación específica de esta técnica
│  ├─ Las crisis inducidas, focales o secundariamente generalizadas, son generalmente
│  │  autolimitadas o se abortan con facilidad mediante IRRIGACIÓN FRÍA, con o sin
│  │  anticonvulsivantes intravenosos
│  ├─ Hasta ahora NO hay secuelas clínicas publicadas, pero una crisis podría teóricamente
│  │  causar daño cerebral u otras complicaciones, y puede impedir completar la cirugía de
│  │  forma satisfactoria. Por eso es aconsejable evitarlas o minimizarlas, y TENER PREPARADAS
│  │  la irrigación fría y los anticonvulsivantes
│  ├─ La evidencia sobre profilaxis anticonvulsivante preoperatoria electiva para reducir el
│  │  riesgo de crisis intraoperatoria es CONTRADICTORIA
│  ├─ ESTIMULACIÓN TRADICIONAL DE 50-60 Hz, la más epileptógena
│  │  ├─ Los trenes de 50-60 Hz evocan regularmente patrones de crisis en la
│  │  │  electrocorticografía, en corteza NO estimulada, adyacente o distante de la estimulada
│  │  ├─ Se llaman INTRADESCARGAS si no sobreviven al estímulo, y POSDESCARGAS si sí lo hacen
│  │  ├─ Las posdescargas pueden ceder espontáneamente, pero evolucionan a CRISIS CLÍNICA en el
│  │  │  5-20% de los pacientes sometidos a esta técnica. La historia de crisis preoperatorias
│  │  │  parece ser un factor de riesgo
│  │  ├─ Mantener la intensidad POR DEBAJO del umbral de posdescarga puede evitarlas o
│  │  │  minimizarlas
│  │  ├─ Y hay una SEGUNDA razón, independiente de la seguridad, por la que las posdescargas
│  │  │  importan: DESCALIFICAN las respuestas del paciente, porque su propagación a corteza
│  │  │  elocuente no estimulada podría causar arresto del habla, movimiento o sensación
│  │  │  FALSAMENTE localizadores si no se reconocen
│  │  └─ Por esas dos razones juntas, la electrocorticografía CONCURRENTE es un adyuvante de
│  │     seguridad aconsejable con esta técnica
│  ├─ ESTIMULACIÓN CORTICAL DIRECTA PARA MEP — la opción más segura
│  │  ├─ Los trenes breves de alta frecuencia inducen crisis clínicas en menos del 5-6% de los
│  │  │  pacientes, lo que hace de este método la elección MÁS SEGURA para el test corticomotor
│  │  ├─ Los tumores —especialmente meningiomas o gliomas de bajo grado— pueden ser factores de
│  │  │  riesgo. Pero, sorprendentemente, la historia de crisis preoperatorias NO parece
│  │  │  aumentar el riesgo con esta técnica
│  │  └─ También puede evocar posdescargas que lleguen a crisis clínica, pero aquí la
│  │     electrocorticografía es OPCIONAL, por dos motivos: las crisis motoras inducidas son
│  │     evidentes en los propios canales de MEP muscular, y las posdescargas NO arriesgan
│  │     falsa localización porque las respuestas positivas son MEP time-locked y no signos
│  │     clínicos
│  ├─ QUÉ HACER TRAS UNA CRISIS INDUCIDA: continuar o no depende de las circunstancias
│  │  quirúrgicas. Puede ayudar reducir la intensidad, la duración o la frecuencia del estímulo
│  │  —por ejemplo bajar a 5 o 10 Hz— o reducir la frecuencia de entrega del tren
│  └─ REGLA ABSOLUTA: NUNCA aplicar directamente sobre la corteza los estimuladores potentes de
│     estimulación eléctrica transcraneal, porque podrían ajustarse accidentalmente a una salida
│     peligrosamente excesiva
├─ ESTIMULACIÓN SUBCORTICAL DIRECTA
│  ├─ La relación de 1 mA de umbral por cada 1 mm de distancia entre la sonda y el tracto
│  │  corticoespinal se estableció PRINCIPALMENTE con duración de pulso de 0,5 ms
│  ├─ CONSECUENCIA QUE HAY QUE RESPETAR: usar pulsos de 0,2 ms, como sí se sugiere para los MEP
│  │  por estimulación cortical directa, sería INAPROPIADO aquí
│  │  ├─ Primer motivo: alteraría de forma INSEGURA la relación umbral/distancia en una
│  │  │  magnitud indefinida — se perdería la referencia sin saber en cuánto
│  │  └─ Segundo motivo: la cronaxia del MEP subcortical —la duración de pulso a la que la
│  │     corriente umbral es el doble de la reobase, y que es la duración teóricamente más
│  │     segura— todavía NO se ha evaluado
│  │     └─ Por tanto esta técnica sigue requiriendo pulsos de 0,5 ms, a la espera de más
│  │        estudios
│  └─ ESTIMULACIÓN "DINÁMICA" CONTINUA a través de aspirador quirúrgico o aspirador ultrasónico:
│     evoca patrones de crisis en EEG o electrocorticografía en el 4% de los pacientes
│     ├─ Es un dato CONTRAINTUITIVO: uno esperaría que las crisis fueran más probables con
│     │  estimulación cortical que subcortical
│     └─ Los patrones descritos se terminaron con facilidad sin interrumpir la cirugía, y el
│        EEG o la electrocorticografía pueden ser adyuvantes de seguridad razonables
├─ ESTIMULACIÓN DIRECTA DE TRONCO Y DE MÉDULA
│  ├─ TRONCO ENCEFÁLICO: la difusión del estímulo directo a núcleos AUTONÓMICOS puede alterar
│  │  la frecuencia cardiaca o la tensión arterial
│  │  └─ Esas alteraciones normalmente se disipan al detener o pausar la estimulación, y hasta
│  │     ahora no se conocen secuelas
│  └─ MÉDULA ESPINAL DIRECTA: la estimulación invasiva de ALTA FRECUENCIA (16 Hz) puede causar
│     ACIDOSIS LÁCTICA por las contracciones de la musculatura paraespinal
│     ├─ Por eso esta técnica infrecuente, si se usa por alguna razón justificable, exige
│     │  BLOQUEO NEUROMUSCULAR COMPLETO
│     └─ La estimulación medular de pulso único o de tren a menor frecuencia puede ser más
│        segura, y está justificada para MAPEO — pero menos justificada para monitorización
│        siempre que los métodos no invasivos resulten satisfactorios
├─ ESTIMULACIÓN ELÉCTRICA TRANSCRANEAL (TES) — cinco problemas propios
│  ├─ MORDEDURA
│  │  ├─ Es el efecto adverso MÁS COMÚN de la TES, aunque sigue siendo infrecuente: 0,2% o menos
│  │  ├─ Mecanismo triple: contracción de la musculatura masticatoria por la vía motora
│  │  │  CORTICOBULBAR, por el nervio TRIGÉMINO, y por estimulación MUSCULAR DIRECTA
│  │  ├─ DATO DE MONTAJE QUE VALE ORO: TODAS las lesiones publicadas hasta ahora ocurrieron con
│  │  │  TES en C3/C4, posiblemente por la proximidad de los electrodos a los nervios trigéminos
│  │  │  y a los músculos temporales. NO hay ninguna lesión publicada con C1/C2 ni con C3-Cz y
│  │  │  C4-Cz
│  │  ├─ EL ESPECTRO DE GRAVEDAD, que va mucho más allá de una herida en la lengua
│  │  │  ├─ Las laceraciones de labio o lengua suelen curar solas, pero pueden requerir
│  │  │  │  reparación quirúrgica o retrasar la extubación hasta que ceda el edema lingual
│  │  │  ├─ Fractura DENTARIA o incluso MANDIBULAR
│  │  │  └─ Y la peor: ROTURA DEL TUBO ENDOTRAQUEAL, con riesgo vital, que exige reintubación
│  │  │     intraoperatoria de emergencia
│  │  └─ MEDIOS DE PROTECCIÓN
│  │     ├─ Los bloques de mordida BLANDOS son OBLIGATORIOS y son la protección principal —
│  │     │  pero no previenen todas las complicaciones
│  │     ├─ Pueden consistir en gasa quirúrgica enrollada u otro acolchado adecuado, asegurado
│  │     │  entre los MOLARES DE CADA LADO, manteniendo la lengua en el centro de la boca y
│  │     │  lejos de los dientes
│  │     ├─ Los bloques DUROS protegen MENOS
│  │     └─ Y es aconsejable RESERVAR el montaje C3/C4 para los pacientes que necesiten su mayor
│  │        potencia, usando otros montajes siempre que sean suficientemente eficaces
│  ├─ CRISIS
│  │  ├─ Son RARAS con TES: del 0,0% al 0,2%, incluso en pacientes con historia de epilepsia. El
│  │  │  tumor cerebral de bajo grado podría ser un ligero factor de riesgo
│  │  ├─ Las pocas publicadas ocurrieron con TRENES de pulsos y NO con estímulos únicos, no
│  │  │  tuvieron secuelas clínicas, y podrían haberse debido a otras causas como reacciones
│  │  │  anestésicas o electrocirugía
│  │  └─ CONDUCTA: es aconsejable que el personal de quirófano esté preparado para la
│  │     posibilidad, y parece prudente CESAR la TES si ocurre una crisis posiblemente
│  │     relacionada. Pero optar por CONTINUAR puede ser justificable si la necesidad quirúrgica
│  │     de los MEP es grande, porque las crisis múltiples parecen extremadamente raras
│  ├─ MOVIMIENTO
│  │  ├─ Cierto grado de sacudida del paciente es INEVITABLE con la TES de trenes
│  │  ├─ Normalmente no es un problema en cirugía ortopédica de columna ni de aorta descendente,
│  │  │  pero los movimientos inesperados pueden ser intrusivos o potencialmente peligrosos en
│  │  │  neurocirugía o en cirugía de cabeza y cuello — aunque hasta ahora no hay lesiones
│  │  │  publicadas inducidas por movimiento
│  │  ├─ Los movimientos son MÁS FUERTES con C3/C4 que con C1/C2 o con C3-Cz y C4-Cz
│  │  ├─ LOS TRES MEDIOS DE PROTECCIÓN: usar montajes distintos de C3/C4 cuando sean
│  │  │  suficientemente eficaces · evitar intensidades por encima de las necesarias para
│  │  │  respuestas adecuadas · y cronometrar cuidadosamente los estímulos, guiándose por el
│  │  │  vídeo del campo quirúrgico y por la comunicación con el cirujano
│  │  ├─ EL BLOQUEO NEUROMUSCULAR PARCIAL para amortiguar el movimiento es CONTROVERTIDO: no
│  │  │  elimina el movimiento por completo, complica la interpretación y podría causar falsos
│  │  │  positivos
│  │  └─ Y LA ADVERTENCIA QUE CIERRA EL APARTADO: la adquisición de MEP NO debe espaciarse
│  │     demasiado por miedo al movimiento, porque eso RETRASARÍA de forma insegura la detección
│  │     del compromiso del sistema motor. En algunos casos puede ser necesario NEGOCIAR PAUSAS
│  │     quirúrgicas para poder adquirir con suficiente frecuencia
│  ├─ OTROS EFECTOS ADVERSOS
│  │  ├─ Alteración transitoria de la tensión arterial, o ARRITMIA cardiaca — que hay que
│  │  │  diferenciar de los artefactos de TES en el ECG. Puede estar indicado pausar la
│  │  │  estimulación
│  │  ├─ Explicación posible: estimulación de centros autonómicos profundos
│  │  └─ Explicación ALTERNATIVA, con una consecuencia práctica muy concreta: una corriente
│  │     "parásita" que va del cuero cabelludo a los electrodos de la pierna a través del
│  │     headbox y vuelve a la cabeza ATRAVESANDO EL CORAZÓN
│  │     └─ Por eso es aconsejable usar HEADBOXES SEPARADOS para las entradas del tren superior
│  │        y del tren inferior del cuerpo
│  └─ CONTRAINDICACIONES RELATIVAS — cómo ha evolucionado la lista
│     ├─ Las contraindicaciones relativas iniciales eran: epilepsia, lesiones corticales,
│     │  defectos craneales, electrodos intracraneales, clips vasculares o shunts, e implantes
│     │  biomédicos
│     ├─ Hoy, muchos pacientes con una o más de esas condiciones han sido monitorizados de forma
│     │  aparentemente segura. Cada contraindicación relativa debe SOPESARSE frente al riesgo de
│     │  omitir los MEP, y el análisis riesgo-beneficio suele favorecer proceder, con
│     │  consentimiento informado del paciente
│     ├─ MARCAPASOS: hay un caso publicado de interferencia fácilmente manejable con un
│     │  dispositivo automático de TES buscador de umbral, pero habitualmente no parece ocurrir.
│     │  Para poner las cosas en perspectiva: la ELECTROCIRUGÍA también puede interferir con un
│     │  marcapasos
│     ├─ IMPLANTES COCLEARES: se ha hecho monitorización con MEP por TES sin incidencias y sin
│     │  daño del implante
│     └─ ESTIMULACIÓN CEREBRAL PROFUNDA implantada: el dispositivo tiene protección de circuito
│        que hace improbable que la TES lo altere. Pero quedan dos riesgos
│        ├─ Los electrodos de SACACORCHOS podrían dañar los cables del dispositivo, que van
│        │  enrollados bajo el cuero cabelludo cerca de los sitios de TES
│        ├─ Y el acoplamiento inductivo en esos cables podría teóricamente conducir corriente de
│        │  TES hasta estructuras cerebrales profundas. No hay mediciones de corriente inducida
│        │  ni casos adversos publicados
│        └─ Conducta aconsejable: LOCALIZAR los cables por palpación del cuero cabelludo y tratar
│           de mantener los electrodos de TES lejos de ellos. Y parece prudente APAGAR los
│           dispositivos implantados durante la monitorización siempre que sea seguro hacerlo
├─ SEP, PEATC Y PEV — muy seguros, con excepciones concretas
│  ├─ Los SEP no invasivos son generalmente MUY seguros, incluida la estimulación supramáxima
│  │  de nervio distal en muñecas y tobillos
│  ├─ LA EXCEPCIÓN QUE HAY QUE CONOCER: la estimulación supramáxima del PERONEO o del TIBIAL EN
│  │  LA RODILLA puede causar SÍNDROME COMPARTIMENTAL ANTERIOR, por las contracciones
│  │  repetitivas fuertes del tibial anterior
│  │  └─ Esa técnica concreta puede ser más segura usando intensidad de UMBRAL MOTOR o con
│  │     bloqueo neuromuscular
│  ├─ Los electrodos de BARRA RÍGIDA pueden ser desaconsejables para monitorización
│  │  intraoperatoria porque podrían causar necrosis cutánea por presión sostenida; si se usan,
│  │  hay que evitar cuidadosamente la presión excesiva
│  ├─ Teóricamente, un error de conexión de los cables de estimulación —por ejemplo muñeca
│  │  izquierda con muñeca derecha— podría conducir corriente de estímulo TRANSTORÁCICA a través
│  │  del corazón y arriesgar arritmia. No hay casos publicados, pero hay que asegurar las
│  │  conexiones correctas del estimulador
│  ├─ PEATC: los estímulos auditivos NO deben exceder el límite de seguridad de 125 dB por
│  │  encima del umbral auditivo
│  │  └─ Y un cuidado mecánico: la inserción del tubo auditivo en el conducto auditivo externo
│  │     debe hacerse con cuidado, con el borde externo de espuma A RAS de la apertura del
│  │     conducto, para evitar una inserción demasiado profunda que dañe la MEMBRANA TIMPÁNICA
│  └─ PEV: no hay evidencia de que los estímulos de flash por LED sean peligrosos. Pero la
│     presión inadvertida sobre las GAFAS de LED podría causar traumatismo periorbitario, y los
│     discos adhesivos de silastic sobre los párpados cerrados pueden ser más seguros
├─ EMG — el riesgo es la aguja, y dónde se clava
│  ├─ Es generalmente segura, aparte de las consideraciones generales sobre electrodos de aguja
│  │  (quemaduras por electrocirugía y por resonancia, y control de infección)
│  └─ Lo específico: evitar inserciones EXCESIVAMENTE PROFUNDAS, que podrían causar hematoma
│     muscular, lesión nerviosa o incluso NEUMOTÓRAX en las inserciones en intercostales,
│     diafragma o punto de Erb
├─ RENDIMIENTO ESENCIAL — la parte menos técnica y la más importante
│  ├─ DEFINICIÓN formal: es la "salida correcta de información diagnóstica de la que
│  │  probablemente se dependa para determinar el tratamiento, cuando una información incorrecta
│  │  podría conducir a un tratamiento inapropiado que presentaría un riesgo inaceptable"
│  ├─ Se aplica a DOS cosas distintas: al DISPOSITIVO y a la PRÁCTICA
│  ├─ RENDIMIENTO ESENCIAL DEL DISPOSITIVO
│  │  ├─ Ejemplos de fallo: corrupción o pérdida de datos, visualización inexacta de la señal,
│  │  │  salida de estímulo inexacta, u otros fallos que lleven a un riesgo inaceptable
│  │  ├─ El dispositivo debe satisfacer especificaciones de la organización internacional de
│  │  │  normalización que aseguren que la probabilidad de perder el rendimiento esencial sea
│  │  │  suficientemente baja
│  │  └─ El personal de monitorización debe esforzarse en evitar el manejo brusco, el mal uso y
│  │     los accidentes previsibles que puedan degradar el rendimiento del equipo
│  ├─ RENDIMIENTO ESENCIAL DE LA PRÁCTICA — más difícil de definir y posiblemente EL PROBLEMA
│  │  DE SEGURIDAD MÁS IMPORTANTE DE TODOS
│  │  ├─ Requisito básico: proporcionar información diagnóstica CORRECTA y a TIEMPO
│  │  ├─ Sus dos modos de fallo son exactamente esos dos, cada uno por su lado:
│  │  │  retroalimentación excesivamente LENTA e interpretación INCORRECTA
│  │  └─ La experiencia reduce la probabilidad de fallo; y la FALTA de experiencia —por formación
│  │     inadecuada, o por confiar en sistemas AUTOMATIZADOS sin personal experto— la aumenta
│  ├─ FALLO 1 — RETROALIMENTACIÓN EXCESIVAMENTE LENTA
│  │  ├─ Un aviso demasiado lento, aunque sea CORRECTO, puede dejar al paciente con un déficit
│  │  │  que se habría podido revertir de haberse detectado antes
│  │  ├─ NO hay estándares establecidos sobre la rapidez del aviso quirúrgico, y hay
│  │  │  limitaciones prácticas: el tiempo de promediado y las interrupciones externas como la
│  │  │  electrocirugía
│  │  ├─ EL PRINCIPIO BÁSICO: elegir métodos que MINIMICEN el tiempo de promediado, y adquirir
│  │  │  datos tan rápido como permita el contexto quirúrgico SIN sacrificar la reproducibilidad
│  │  │  del potencial evocado
│  │  ├─ LA CIFRA CONCRETA QUE DA EL CAPÍTULO: adquisición de MEP y SEP de las CUATRO
│  │  │  extremidades cada 1-3 minutos de media es un objetivo razonable para la mayoría de las
│  │  │  cirugías ortopédicas de columna y de aorta descendente
│  │  │  └─ Su justificación: el deterioro ABRUPTO del potencial con restauración RÁPIDA tras
│  │  │     intervención inmediata ocurre dentro de ese marco temporal
│  │  ├─ Qué se pierde si se va más lento: se reduce la probabilidad de una intervención
│  │  │  exitosa, porque la compresión, la tracción o la isquemia neural pueden iniciar daño
│  │  │  estructural DEPENDIENTE DEL TIEMPO antes del siguiente registro
│  │  ├─ MATIZ HONESTO: las lesiones neurales inherentemente IRREVERSIBLES —coagulación,
│  │  │  laceración— no se benefician directamente de una retroalimentación rápida. Pero
│  │  │  aprender cuáles son los momentos peligrosos puede ayudar INDIRECTAMENTE a que el
│  │  │  cirujano evite lesionar a pacientes posteriores
│  │  └─ Las cirugías con electrocirugía frecuente u otros obstáculos aumentan necesariamente
│  │     los intervalos de registro: el equipo debe adaptarse, pero seguir buscando la máxima
│  │     rapidez posible para esa situación
│  ├─ FALLO 2 — INTERPRETACIÓN INCORRECTA
│  │  ├─ Una interpretación incorrecta, aunque sea RÁPIDA, puede causar riesgo inaceptable al
│  │  │  provocar una acción quirúrgica inapropiada o una INACCIÓN inapropiada
│  │  ├─ Los tres modos concretos
│  │  │  ├─ LOCALIZACIÓN ERRÓNEA → excisión inapropiada de tejido funcional, o fallo en resecar
│  │  │  │  tejido patológico
│  │  │  ├─ FALSOS POSITIVOS → intervención innecesaria que perjudica el tratamiento quirúrgico
```
