# PE-V2 — PEV por damero: técnica y parámetros de registro

```
PEV por damero (PRVEP): técnica y parámetros
├─ Por qué el damero y no el flash
│  ├─ El flash se usa desde los años 50, pero el PEV por damero (Halliday 1972) fue lo
│  │  que convirtió al PEV en prueba clínica útil
│  ├─ Flash: forma de onda compleja, variabilidad inter e intraindividual MARCADA,
│  │  insensible al deterioro visual leve — solo da anormalidades con disfunción grave
│  ├─ Damero: morfología simple, forma de onda consistente entre y dentro de sujetos, y
│  │  extremadamente sensible — detecta anormalidades sutiles o "subclínicas", sobre
│  │  todo prequiasmáticas
│  └─ Precio a pagar: el damero EXIGE cooperación plena — alerta mantenida y fijación
│     continua en el patrón. El flash no la necesita, y por eso sigue vivo para quien no
│     puede colaborar
├─ Manejo del paciente
│  ├─ Sentado o semirreclinado cómodo, con el monitor a la altura de los ojos
│  ├─ SIN colirios midriáticos ni mióticos antes de la prueba
│  ├─ Si usa gafas o lentes de contacto correctoras, DEBE llevarlas puestas durante el
│  │  registro
│  ├─ Determinar agudeza visual de cada ojo por optotipo de Snellen a 20 pies y/o
│  │  tarjeta de lectura a 9-12 pulgadas
│  ├─ Anotar si hay anisocoria significativa, tamaño pupilar extremo (midriasis o
│  │  miosis) o defecto campimétrico llamativo
│  ├─ Instrucción: mirar el punto del CENTRO del damero durante todo el registro
│  ├─ Vigilancia activa: si se adormece o pierde la fijación, el técnico debe hablarle
│  │  para reenfocar la atención en el punto central — la fijación continua es
│  │  imprescindible para un PEV fiable
│  ├─ Estimulación MONOCULAR, con el ojo no estimulado tapado con parche opaco y
│  │  estanco a la luz
│  └─ Postura cómoda para reducir artefacto muscular y de movimiento: mejora la relación
│     señal/ruido de partida y hace falta promediar menos
├─ Parámetros de estimulación
│  ├─ Distancia: monitor a ≥70 cm de los ojos; habitual 100 cm, rango 75-150 cm, medida
│  │  exactamente con cinta métrica desde el nasion a la pantalla
│  ├─ Estímulo: damero de cuadros blancos y negros que se INVIERTEN bruscamente (los
│  │  negros pasan a blancos y viceversa)
│  ├─ Contraste: alto, contraste de Michelson recomendado >80%
│  │  └─ Michelson = (Lmax − Lmin)/(Lmax + Lmin) × 100%
│  ├─ Frecuencia de inversión: <4 inversiones/s, que equivale a <2 ciclos/s (cada ciclo
│  │  incluye dos inversiones)
│  ├─ Luminancia media de la pantalla >50 cd/m² (recomendación práctica 40-60 cd/m²),
│  │  MANTENIDA CONSTANTE
│  │  ├─ No debe haber ningún cambio de luminancia total durante la inversión: se
│  │  │  garantiza con igual número de cuadros blancos y negros en la pantalla
│  │  └─ Variabilidad centro-periferia de la pantalla <30%
│  ├─ Tamaño de cuadro: se especifica por el ÁNGULO VISUAL que subtiende, no en cm
│  │  ├─ Fórmula: tamaño (grados) = arco tangente W/D, con W = lado del cuadro y D =
│  │  │  distancia al ojo. Para ángulos pequeños: W × 57.3/D en grados y W × 3438/D en
│  │  │  minutos
│  │  ├─ Se usan DOS tamaños en cada ojo: cuadros grandes de 40-60′ (~1°) y pequeños de
│  │  │  10-15′
│  │  └─ Si solo puede usarse uno, se recomienda 0.5°
│  ├─ Tamaño de campo total: ≥15°. No hace falta campo perfectamente cuadrado mientras
│  │  la razón anchura/altura no pase de 4:3 y la dimensión menor sea ≥15°
│  ├─ Punto de fijación: debe verse claramente como un "punto" en el centro del damero
│  └─ Iluminación ambiental: sala moderadamente iluminada (estado fotópico, visión
│     dominada por conos); evitar luz brillante en la visión directa del paciente
├─ Parámetros de registro
│  ├─ Banda de paso del sistema: 1-300 Hz (−3 dB). Caída del filtro ≤12 dB/octava para
│  │  el de baja frecuencia y ≤24 dB/octava para el de alta
│  ├─ Tiempo de análisis: habitualmente 250 ms
│  │  └─ En lactantes y niños, o en pacientes con latencias prolongadas, subir hasta
│  │     500 ms — y entonces hay que bajar la frecuencia de inversión a <2/s
│  ├─ Promedios por réplica: 100-300 según la relación señal/ruido (habitualmente
│  │  bastan 100-200)
│  ├─ Réplicas: AL MENOS DOS, para demostrar reproducibilidad
│  └─ Electrodos: de disco, copa dorada o plata-cloruro de plata, fijados con pasta o
│     colodión como en un EEG de rutina
│     └─ Impedancias <5 kΩ y diferencia entre electrodos lo más baja posible (<1 kΩ)
│        para asegurar una buena razón de rechazo en modo común
├─ Montaje — dos sistemas en competencia
│  ├─ La ACNS (2006) recomienda la colocación Queen Square; la ISCEV (2016) recomienda
│  │  el sistema internacional 10-20
│  │  └─ Las diferencias entre ambos son menores, pero se ha demostrado cierta
│  │     SUPERIORIDAD del Queen Square al investigar defectos de hemicampo
│  ├─ Posiciones del sistema Queen Square
│  │  ├─ MO (medio-occipital): 5 cm por encima del inion
│  │  ├─ LO y RO (occipitales izquierdo y derecho): 5 cm a cada lado de MO
│  │  ├─ LT y RT (temporales): 5 cm desde LO y RO respectivamente — se usan casi
│  │  │  exclusivamente para el estudio por hemicampos
│  │  ├─ MP (medio-parietal): 5 cm por encima de MO
│  │  ├─ MF (medio-frontal): 12 cm por encima del nasion
│  │  └─ I (inion): sobre la protuberancia occipital externa · tierra en cualquier punto
│  │     del scalp, habitualmente el vértex
│  ├─ Montaje de 4 canales para campo completo
│  │  ├─ Canal 1: LO-MF · Canal 2: MO-MF · Canal 3: RO-MF · Canal 4: MF-A1
│  │  ├─ El PEV más robusto se registra en el CANAL 2 (MO-MF)
│  │  └─ El canal 4 (MF-A1) registra el N100 frontal: onda ancha, de baja amplitud y
│  │     polaridad negativa, con latencia media en torno a 100 ms
│  └─ Montaje de línea media alternativo, si el P100 está ausente o es de baja amplitud
│     — para asegurar que el P100 no está simplemente DESPLAZADO por encima o por debajo
│     de MO: MF-A1+A2 · MP-A1+A2 · MO-A1+A2 · Inion-A1+A2
├─ Convenio de polaridad
│  └─ Igual que en EEG convencional: si el primer electrodo del canal se hace más
│     NEGATIVO que el segundo, la deflexión va hacia ARRIBA; más positividad en el
│     primero da una onda hacia ABAJO
│     └─ Por eso N75 y N145 van hacia arriba y el P100 traza una gran deflexión hacia
│        abajo
├─ Variante técnica: pattern onset/offset
│  ├─ El damero se sustituye bruscamente por un fondo gris difuso, con la MISMA
│  │  luminancia media para que no haya cambio de luminancia al conmutar
│  ├─ Estándar ISCEV: duración de onset de 200 ms separada por 400 ms de fondo difuso —
│  │  así se obtiene la respuesta de onset sin contaminación por la de offset
│  ├─ Morfología: tres picos, C1 positivo ~75 ms, C2 negativo grande ~125 ms y C3
│  │  positivo ~150 ms
│  │  └─ La secuencia típica C1-C2-C3 se obtiene con cuadros de 1° y en mayores de 40
│  │     años; con cuadros de 15′ el C2 negativo es más prominente y C1/C2 acortan
│  │     latencia
│  ├─ NO se usa en la práctica clínica rutinaria por su gran variabilidad intersujeto
│  └─ Sí tiene utilidad en pérdida visual psicógena y en nistagmo, porque las respuestas
│     de onset/offset se afectan mucho menos por mala fijación, movimientos oculares o
│     desenfoque deliberado
├─ Errores y problemas frecuentes de la técnica
│  ├─ Dejar que el paciente se adormezca o pierda la fijación — la causa más común de
│  │  registro malo, y no se arregla promediando más
│  ├─ No hacer llevar las gafas correctoras, o instilar colirios antes de la prueba
│  ├─ Colocación asimétrica de LO y RO: produce asimetría interhemisférica artefactual
│  ├─ Cambiar de monitor CRT a LCD sin rehacer los normativos: el P100 se retrasa de
│  │  forma significativa con LCD (con monitores de 2 ms de tiempo de respuesta, 8 ms
│  │  más de latencia usando cuadros de 32′)
│  └─ Usar datos normativos de otro laboratorio: en PEV es especialmente inaceptable,
│     porque la variabilidad interlaboratorio es mucho mayor que en PEATC y PESS; la
│     luminancia variable del monitor es por sí sola una razón de peso
├─ Limitaciones de la técnica
│  ├─ Requiere cooperación plena: inservible en el paciente que no colabora, en el
│  │  lactante inquieto o en el comatoso
│  ├─ Con agudeza visual <20/400 puede no obtenerse un PEV por damero fiable — el paso
│  │  siguiente es flash o LED
│  └─ Cada laboratorio DEBE recoger sus propios valores normales en unos 30 sujetos con
│     su propio equipo de estimulación y registro
└─ Referencia
   └─ Markand2020 cap.3 pp.83-90 (Tablas 3.1-3.3, Figs. 3.2-3.4), pp.104-105
      (onset/offset, CRT vs LCD), p.94 (normativos propios)
```
