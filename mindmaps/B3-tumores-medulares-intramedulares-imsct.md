# B3 — Tumores medulares intramedulares (IMSCT)

```
Tumores medulares intramedulares (IMSCT)
├─ Modalidades combinadas
│  ├─ Marco conceptual: MONITORIZACIÓN (SEP, MEP, D-wave, EMG libre — vigilancia
│  │  continua) vs. MAPEO (localización funcional para guiar el abordaje) —
│  │  complementarias, no intercambiables
│  ├─ Estándar: SEP + MEP muscular + onda D epidural + EMG libre continuo
│  │  ├─ SEP: mediano en muñeca y tibial posterior en tobillo, pulsos de 0.2 ms a
│  │  │  frecuencia no divisible en 50 ni 60 Hz (en torno a 4.7-5.1 Hz), con controles
│  │  │  periféricos en fosa cubital y poplítea
│  │  ├─ MEP muscular: tren de 5-7 pulsos de 0.5 ms con ISI en torno a 4 ms, montaje
│  │  │  C1/C2 para MMII y C3/C4 para MMSS, registrando de abductor corto del hallux y
│  │  │  tibial anterior en MMII y abductor corto del pulgar en MMSS
│  │  └─ Onda D: pulso ÚNICO transcraneal con registro epidural por catéter de tres
│  │     cilindros; amplitud de 60 µV o más sobre médula cervical frente a unos 10 µV
│  │     sobre segmentos torácicos, y con 2 Hz bastan 2-4 respuestas promediadas, lo que
│  │     da actualización cada segundo
│  ├─ Jerarquía de interpretación: si la D-wave es monitorizable, el MEP se interpreta
│  │  solo como presencia/ausencia; si NO lo es, entonces también cuentan las caídas de
│  │  amplitud del MEP como alarma
│  └─ 100 cirugías consecutivas: 92/100 con estado motor normal/leve preoperatorio
│     tenían MEP basal registrable; los 8 con déficit severo previo NO tenían MEP
│     registrable en ninguna extremidad
├─ Fases del procedimiento
│  ├─ Laminotomía/laminectomía → apertura de dura/aracnoides → electrodo epidural de
│  │  D-wave CAUDAL a la lesión (única técnica cuya basal se toma a mitad de cirugía,
│  │  no al inicio)
│  ├─ Mielotomía en línea media guiada por mapeo de columnas dorsales (DCM) →
│  │  resección "inside-out" a trozos (piecemeal): debulking + disección del plano
│  │  tumor-médula sana
│  ├─ Fase más desafiante: los BORDES del tumor, donde D-wave y MEP son críticos
│  └─ D-wave monitorizada hasta cierre dural COMPLETO — el riesgo no termina con la
│     resección
├─ Riesgo neurológico específico
│  ├─ Mielotomía mal localizada: lesiona columnas dorsales sanas si el tumor ha
│  │  distorsionado/rotado el rafe medio posterior real
│  ├─ Disección del plano tumor-médula: mayor riesgo en los POLOS craneal/caudal y en
│  │  la interfase tumor-médula; caídas SÚBITAS y simultáneas de D-wave y MEP sugieren
│  │  compromiso VASCULAR más que manipulación mecánica directa
│  ├─ Coagulación bipolar: evitarla cerca del rafe anterior/interfase con médula sana;
│  │  el aspirador ultrasónico solo es seguro sobre tejido ya desprendido
│  └─ DOS RAZONES DISTINTAS POR LAS QUE PUEDE NO HABER ONDA D, y no confundirlas con un
│     fallo técnico
│     ├─ POR LOCALIZACIÓN: por debajo del nivel óseo T10 no hay suficientes fibras del
│     │  CST para registrar una amplitud aceptable, así que en tumores del CONO medular
│     │  la onda D rara vez es registrable
│     └─ POR DESINCRONIZACIÓN: en tumores que afectan a unos pocos segmentos, y en
│        pacientes que han recibido radioterapia medular, las fibras rápidas del CST
│        conducen a VELOCIDADES DISTINTAS ENTRE SÍ sobre la lesión, de modo que la onda
│        se desincroniza. Se ve como onda de baja amplitud y BASE ANCHA, o directamente
│        no registrable — y puede ocurrir con MEP musculares presentes y sin déficit
│        motor mayor
│        └─ Consecuencia práctica: esos pacientes son GRUPO DE ALTO RIESGO, porque solo
│           pueden monitorizarse con MEP muscular y, si este desaparece, no se puede
│           distinguir intraoperatoriamente déficit transitorio de permanente
├─ Posicionamiento
│  ├─ Prono, abordaje posterior estándar
│  ├─ Cervical/torácico alto: cabezal de Mayfield — anticipar su colocación al poner
│  │  los electrodos de cuero cabelludo, avisar a anestesia antes de aplicarlo
│  ├─ Torácico medio-bajo: donut acolchado, brazos en posición "superman"
│  └─ Basales antes Y después del posicionamiento definitivo — permite diferenciar si
│     un cambio de señal se debe al propio posicionamiento
├─ Jerarquía de alarma
│  ├─ LA TABLA DE INTERPRETACIÓN COMBINADA, que es el eje de toda la decisión quirúrgica
│  │  (los MEP musculares se refieren al tibial anterior)
│  │  ├─ Onda D SIN CAMBIOS o con descenso del 30-50% + MEP muscular PRESERVADO → estado
│  │  │  motor sin cambios
│  │  ├─ Onda D sin cambios o con descenso del 30-50% + MEP muscular PERDIDO uni o
│  │  │  bilateralmente → déficit motor TRANSITORIO → se puede continuar aplicando TIP
│  │  └─ Onda D con descenso MAYOR DEL 50% + MEP muscular perdido BILATERALMENTE →
│  │     déficit motor A LARGO PLAZO → cese inmediato
│  ├─ REGLAS OPERATIVAS que se derivan de esa tabla
│  │  ├─ CON onda D registrable caudal a la lesión y MEP presentes al inicio: se puede
│  │  │  continuar hasta que los MEP musculares desaparezcan por completo Y la onda D baje
│  │  │  al 50% del basal
│  │  └─ SIN onda D registrable al inicio pero con MEP musculares: parar de inmediato al
│  │     primer signo de declive de los MEP, porque sin onda D no se puede saber si la
│  │     desaparición del MEP anuncia déficit transitorio o permanente
│  ├─ Resultado de aplicar estos criterios: en una serie de 100 cirugías consecutivas de
│  │  tumor intramedular NO hubo un solo paciente parapléjico postoperatorio
│  ├─ Declive gradual D-wave 20-30% o ↑umbral de MEP → alerta precoz/insulto reversible
│  │  → protocolo TIP · caída súbita D-wave + pérdida bilateral MEP → sospecha vascular
│  ├─ Deterioro de SEP durante el mapeo de columnas dorsales → riesgo de déficit
│  │  propioceptivo → pausar/desplazar la mielotomía
│  ├─ Fenómeno "build-up": con estimulación rápida repetida (1-2 Hz) la amplitud del
│  │  MEP aumenta en respuestas sucesivas — un único estímulo sin respuesta puede ser
│  │  falso negativo, monitorizar siempre en secuencia rápida
│  └─ Serie con IONM (SEP+MEP+D-wave): discapacidad postoperatoria grave 3%, frente al
│     11.7% de una serie de ependimomas sin monitorizar
├─ Protocolo de reacción
│  ├─ TIP (Time, Irrigation, Pressure): detener disección, irrigar suero templado, PAM
│  │  ≥80-85 mmHg — estrategia "stop-and-go", suele revertir en minutos
│  ├─ Si el MEP no se recupera: en 9/10 casos queda asegurado un déficit motor
│  │  transitorio; con D-wave inalterada se puede decidir continuar sabiendo que el
│  │  déficit esperado será reversible
│  ├─ Pérdida UNILATERAL de MEP → déficit unilateral, que SIEMPRE se recupera
│  └─ "Punto vulnerable" focal: redirigir la disección al extremo opuesto donde la
│     vulnerabilidad funcional puede ser menor
├─ MONITORIZACIÓN FRENTE A MAPEO — la distinción que ordena todo lo que sigue
│  ├─ La MONITORIZACIÓN valora de forma continua la integridad funcional de los tractos de
│  │  sustancia blanca y de los circuitos sinápticos de sustancia gris, con criterios de
│  │  interpretación y alarma establecidos
│  └─ Pero la monitorización solo puede identificar PÉRDIDA o PRESENCIA de integridad: NO
│     dice nada de la LOCALIZACIÓN ni de la somatotopía de los tractos largos. Para eso hace
│     falta MAPEO, y los métodos de mapeo de tractos largos medulares están mucho menos
│     desarrollados que los de monitorización
├─ POTENCIALES ESPINALES: CONDUCIDOS FRENTE A SEGMENTARIOS
│  ├─ Sobre la superficie medular, tras estimular nervios o raíces periféricas, se distinguen
│  │  con facilidad dos tipos de potencial, y confundirlos invalida el mapeo
│  ├─ POTENCIALES CONDUCIDOS (ondas viajeras)
│  │  ├─ Registrados de la superficie DORSAL, consisten principalmente en ondas NEGATIVAS que
│  │  │  reflejan los potenciales de acción compuestos que viajan por las fibras de la columna
│  │  │  dorsal
│  │  ├─ Su amplitud DISMINUYE de caudal a rostral, por dispersión de los volleys aferentes
│  │  │  debida a las distintas velocidades de conducción entre fibras
│  │  ├─ NO se reducen de forma significativa a frecuencias altas de estimulación
│  │  └─ Registrados de la superficie VENTRAL su polaridad NO cambia → el generador está
│  │     orientado a lo largo del eje LONGITUDINAL del cordón, con el polo negativo caudal y
│  │     el positivo craneal
│  ├─ POTENCIALES SEGMENTARIOS (ondas estacionarias)
│  │  ├─ Representan la actividad sumada de las células de la sustancia GRIS (asta dorsal) con
│  │  │  actividad de raicillas entremezclada
│  │  ├─ Tienen amplitud MÁXIMA a los niveles correspondientes a la entrada medular de las
│  │  │  fibras estimuladas, y decrecen tanto caudal como cranealmente
│  │  ├─ Sus tres componentes
│  │  │  ├─ P1: onda rápida predominantemente positiva = potencial de acción compuesto de las
│  │  │  │  fibras de la raíz dorsal, generado por fibras rápidas Aα y Aβ; su amplitud NO se
│  │  │  │  reduce con estimulación de alta frecuencia
│  │  │  ├─ N1: onda negativa = potenciales POSTSINÁPTICOS generados en las neuronas del asta
│  │  │  │  dorsal. Duración más larga por la descarga repetitiva y el relevo neuronal, y SÍ
│  │  │  │  se reduce con estimulación de alta frecuencia
│  │  │  └─ P2: onda positiva lenta y de bajo voltaje = despolarización de las terminales de
│  │  │     las fibras aferentes
│  │  ├─ Registrados de la superficie VENTRAL INVIERTEN su polaridad, porque sus dipolos
│  │  │  generadores están dispuestos en el plano SAGITAL
│  │  └─ Nomenclatura por nervio: tras mediano o cubital, las respuestas segmentarias son
│  │     P9/N13; tras tibial, P17/N22
│  └─ EL TEST QUE LOS SEPARA: subir la frecuencia de estimulación. Las ondas viajeras y el P1
│     resisten; el N1, por ser postsináptico, se reduce
├─ MAPEO DE COLUMNA DORSAL (DCM) — tres métodos, no uno
│  ├─ Por qué hace falta: la disfunción de columna dorsal tras cirugía intramedular causa
│  │  déficits importantes —adormecimiento generalizado, parestesias dolorosas, pérdida de
│  │  propiocepción, inestabilidad de la marcha— y la incapacidad de identificar con certeza
│  │  la línea media por EDEMA, ROTACIÓN del cordón y DESPLAZAMIENTO de los tractos es lo que
│  │  contribuye a esas lesiones
│  ├─ MÉTODO 1 — gradiente de amplitud del SEP con rejilla multicontacto
│  │  ├─ Rejilla miniatura de OCHO hilos paralelos de acero inoxidable, de 76 µm de diámetro y
│  │  │  separados 1 mm, colocada sobre la supuesta columna dorsal
│  │  ├─ Los hilos se orientan PARALELOS al eje largo del cordón, con aguja de referencia en un
│  │  │  músculo cercano
│  │  ├─ Estimulación de tibial o mediano derecho e izquierdo, hasta 40 mA, pulso de 0.2 ms y
│  │  │  frecuencia de 13.3 Hz
│  │  ├─ Registro: dos series de 100-200 barridos promediados desde cada una de las ocho
│  │  │  superficies. Filtros de 50-1700 Hz y época en torno a 20 ms
│  │  └─ CÓMO SE LEE: la línea media es el punto situado ENTRE los dos máximos de amplitud —
│  │     de las ondas viajeras del SEP tibial, o de las ondas estacionarias del SEP de mediano
│  ├─ MÉTODO 2 — SEP de inversión de fase registrados en el SCALP tras estimulación DIRECTA
│  │  de la columna dorsal expuesta: la línea isoeléctrica entre ambos potenciales invertidos
│  │  marca el surco medio funcional cuando el tumor lo ha distorsionado
│  └─ MÉTODO 3 — registro de respuestas ANTIDRÓMICAS sobre nervios periféricos tras estimular
│     la columna dorsal
├─ MAPEO DEL TRACTO CORTICOESPINAL — tres métodos y una advertencia
│  ├─ MÉTODO 1 — TÉCNICA DE COLISIÓN DE LA ONDA D, la más específica
│  │  ├─ Se estimula la médula expuesta con sonda de mano entregando un ESTÍMULO ÚNICO de
│  │  │  1-2 mA, SIMULTÁNEAMENTE con estimulación transcraneal que elicita una onda D
│  │  ├─ Como ambas señales viajan por los MISMOS axones del CST, la onda D descendente COLISIONA
│  │  │  con la señal que asciende antidrómicamente
│  │  ├─ Resultado: descenso de la amplitud de la onda D registrada CAUDAL al punto de
│  │  │  colisión, con un máximo del 50% → eso indica que la sonda está en proximidad estrecha
│  │  │  con el CST
│  │  ├─ REQUISITO TÉCNICO: el timing es crítico. Hay que disparar SIMULTÁNEAMENTE un
│  │  │  estimulador de alta intensidad (para la transcraneal) y otro de baja (para la medular)
│  │  ├─ Es altamente específica para las fibras RÁPIDAS del CST, que son justamente las que
│  │  │  hay que preservar para permitir la recuperación motora a largo plazo
│  │  └─ USO AVANZADO: separar fibras sanas, desincronizadas y bloqueadas
│  │     ├─ ANTES de la colisión, la amplitud de la onda D CRANEAL representa
│  │     │  semicuantitativamente el total de fibras rápidas que llegan a la lesión, y la CAUDAL
│  │     │  solo las fibras INDEMNES que la atraviesan → la diferencia craneal menos caudal es
│  │     │  el total de fibras bloqueadas MÁS desincronizadas
│  │     ├─ DESPUÉS de la colisión, la amplitud craneal representa solo las fibras BLOQUEADAS,
│  │     │  porque la estimulación medular caudal activa tanto las indemnes como las
│  │     │  desincronizadas, pero no las bloqueadas, que no pueden conducir a través de la lesión
│  │     └─ Matiz clínico decisivo: las fibras DESINCRONIZADAS, aunque no contribuyan a la onda
│  │        D caudal, SÍ pueden elicitar MEP muscular — es decir, siguen siendo FUNCIONALES
│  ├─ MÉTODO 2 — estimulación directa de la médula dentro de la cavidad de resección
│  │  ├─ Protocolo publicado (Gandhi): pulsos BIFÁSICOS de 1 ms a 60 Hz por sonda bipolar
│  │  │  concéntrica, con registro en músculos de extremidades e intensidad de 0.1 a 1 mA
│  │  └─ ⚠️ ADVERTENCIA EXPLÍCITA del capítulo: esos autores PRESUPUSIERON que esa estimulación
│  │     activa exclusivamente las fibras rápidas del CST — y ese supuesto es precisamente el
│  │     que el capítulo cuestiona
│  ├─ MÉTODO 3 — mapeo CONTINUO con aspirador ultrasónico (CUSA), que permite estimular
│  │  simultáneamente mientras se extirpa el tumor
│  │  └─ Protocolo (Barzilai): estimulación monopolar a través del CUSA con tren corto de
│  │     pulsos CATÓDICOS — 3 pulsos, 0.2 ms de anchura, ISI de 3 ms — e intensidad de 0.5 a
│  │     2 mA, con registro en músculos de extremidades
│  └─ "¿QUÉ ESTAMOS ESTIMULANDO REALMENTE?" — la pregunta que invalida el supuesto ingenuo
│     ├─ Primer hallazgo: las respuestas musculares obtenidas al estimular la médula expuesta
│     │  TAMBIÉN pueden conseguirse estimulando la COLUMNA DORSAL, y no exclusivamente el CST
│     ├─ Segundo hallazgo: las respuestas musculares tras estimular CST o columna dorsal tienen
│     │  rasgos DISTINGUIBLES si se usa estimulación de DOBLE TREN
│     └─ El discriminador: doble tren con intervalo INTERTREN de 60 ms. Las interneuronas donde
│        termina el CST tienen recuperación sináptica menor de 60 ms y responden también al
│        segundo tren; las de columna dorsal, no
│        └─ Consecuencia práctica: una respuesta muscular al estimular dentro de la cavidad NO
│           prueba por sí sola que se esté tocando el CST
└─ Referencia
   └─ Deletis cap.12 (Deletis/Seidel, "Neurophysiological identification of long sensory and
      motor tracts within the spinal cord") pp.163-174 — **fuente primaria del mapeo**:
      §12.1 monitorización frente a mapeo, §12.2.1 generadores de los potenciales espinales
      conducidos y segmentarios, §12.2.2 rejilla multicontacto de ocho hilos y los tres
      métodos de mapeo de columna dorsal (Fig. 12.1), §12.3.1 técnica de colisión de la onda
      D y separación de fibras sanas, desincronizadas y bloqueadas (Figs. 12.5-12.6),
      §12.3.2 estimulación directa con los protocolos de Gandhi y de Barzilai con CUSA,
      §12.3.2.1 "¿qué estamos estimulando realmente?" y el doble tren · cap.26
      (Frank/Kothbauer) pp.351-364 — contexto quirúrgico, fases, protocolo TIP · cap.2
      (Deletis) pp.23-32 — onda D,
      catéter epidural, amplitudes por nivel, límite T10, desincronización, y Tabla 2.1 de
      interpretación combinada con la serie de 100 cirugías consecutivas · cap.3
      (MacDonald) pp.35-46 — parámetros de SEP y controles periféricos · Boaro2026
      secciones 1-9

## Ampliación — profundizar

```
IMSCT — ampliación
├─ Controversia: ¿la IONM previene la lesión o solo la predice?
│  └─ Evidencia sólida clase I-II para capacidad DIAGNÓSTICA; evidencia de que la
│     monitorización EVITA directamente lesión permanente se limita mayoritariamente a
│     clase II-III — barrera ética/metodológica casi insalvable para un ensayo
│     aleatorizado en este contexto
├─ Evolución de la práctica en 20 años: de aceptar la pérdida de MEP como transitoria
│  (con solo preservar la D-wave) a una estrategia conservadora que busca preservar
│  AMBAS señales durante todo el procedimiento
├─ Caso ilustrativo 1: astrocitoma T7-T8, pérdida bilateral progresiva de MEP casi
│  hasta desaparecer, D-wave estable → TIP → recuperación casi completa → resección
│  continuada por estabilidad de D-wave → McCormick I a los 3 meses — jerarquía
│  D-wave > MEP como predictor de pronóstico motor
└─ Caso ilustrativo 2: glioma bajo grado con siringomielia, DCM no permitió identificar
   la línea media → caída de SEP ~90%/abolición contralateral sin recuperación completa
   → D-wave y MEP estables todo el procedimiento → sin empeoramiento motor relevante,
   déficit predominantemente sensitivo — disociación SEP (columna dorsal) vs. D-wave/
   MEP (CST) como vías que no se sustituyen entre sí
Referencia: Boaro2026, §6-7 · Deletis, cap. 26, §26.9, p.363
