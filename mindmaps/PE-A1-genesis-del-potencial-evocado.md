# PE-A1 — Génesis del potencial evocado

```
Génesis del potencial evocado
├─ Definición y alcance
│  ├─ PE = actividad eléctrica TIME-LOCKED: sigue al estímulo con un intervalo
│  │  temporal fijo — frente a la actividad espontánea del EEG, que no lo está
│  ├─ Relacionados con el ESTÍMULO: latencia corta, estímulo estereotipado de
│  │  modalidad específica (PEATC, PEV, PESS, PEM)
│  ├─ Relacionados con el EVENTO (P300): dependen del contenido informativo y de la
│  │  "relevancia de la tarea", no de la modalidad del estímulo
│  └─ "Latencia corta" en PESS tiene definición numérica: <25 ms para mediano en
│     muñeca y <45 ms para tibial posterior en tobillo
├─ Fundamento fisiológico — las DOS fuentes físicas del registro
│  ├─ 1. Potenciales de acción propagados (potenciales de fibra o de tracto)
│  │  ├─ La zona excitada se comporta como un TRIPOLO (+ − +): despolarización
│  │  │  central precedida y seguida de hiperpolarización
│  │  ├─ Da un potencial TRIFÁSICO: positividad de aproximación → negatividad grande
│  │  │  bajo el electrodo → positividad de salida
│  │  ├─ La morfología depende de dónde esté el electrodo: en medio de la fibra →
│  │  │  trifásico (+ − +) · en el punto de excitación inicial → bifásico (− +) ·
│  │  │  cerca del final de la vía → bifásico (+ −), porque la hiperpolarización
│  │  │  rezagada nunca llega a cruzar el electrodo (por eso el N9 de Erb suele ser
│  │  │  bifásico)
│  │  └─ Caída de amplitud con la distancia ≈ proporcional a distancia⁻³ — muy rápida
│  ├─ 2. Potenciales postsinápticos (EPSP/IPSP) por activación de núcleos y corteza
│  │  ├─ Solo se registran si la estructura tiene CAMPO ABIERTO (open field)
│  │  ├─ Campo abierto: neuronas piramidales corticales, dispuestas en paralelo y en
│  │  │  columnas → la activación sincronizada genera un dipolo funcional
│  │  │  perpendicular al cuero cabelludo
│  │  ├─ Regla de polaridad cortical: actividad sináptica EXCITATORIA en dendritas
│  │  │  apicales → NEGATIVIDAD en el electrodo suprayacente; la inhibitoria en
│  │  │  dendritas apicales hace lo contrario
│  │  └─ Campo CERRADO: en muchos núcleos del tronco y hemisféricos los dipolos
│  │     individuales apuntan en direcciones distintas, se cancelan entre sí y NO
│  │     generan potencial registrable fuera del núcleo
│  ├─ ¿Cuál domina? No está establecido de forma concluyente para el PEATC: se cree
│  │  que es una COMBINACIÓN de ambas
│  │  └─ Argumento a favor del peso de los tractos: los PEATC son notablemente
│  │     resistentes a hipotensión, anestesia y anoxia — factores que afectan mucho
│  │     más a la función sináptica que a la conducción axonal
│  └─ Papel de la SINCRONÍA
│     ├─ La amplitud de los picos depende del grado de coherencia temporal de la
│     │  actividad neural; la dispersión temporal ensancha los picos y baja amplitud
│     ├─ Si todas las fibras descargan a la vez, la amplitud del pico negativo del PAC
│     │  es una medida del NÚMERO de fibras activadas
│     ├─ Vías largas entregan actividad menos coherente → los picos precoces del PESS
│     │  de MMII son menos definidos que los de MMSS
│     ├─ Envejecimiento del PEATC: la amplitud baja porque el diámetro axonal del VIII
│     │  par se hace más variable (media 2.5 µm en niños con distribución estrecha,
│     │  frente a 0.5-7 µm a los 40-50 años) → más dispersión temporal
│     └─ Prematuros <30 semanas de edad concepcional: la ausencia de PEATC bien
│        resueltos se atribuye a FALTA DE SINCRONIZACIÓN de las vías auditivas del
│        tronco, no a hipoacusia (los potenciales corticales tardíos sí se obtienen)
├─ Dipolo y conducción de volumen
│  ├─ Los potenciales generados en cualquier punto del neuroeje se propagan a las
│  │  áreas circundantes por conducción de volumen
│  │  └─ Consecuencia radical: NO EXISTE una localización completamente inactiva en el
│  │     cuerpo. Cualquier derivación de dos electrodos está influida por el potencial;
│  │     lo que cambia es la magnitud en cada electrodo según su distancia al generador
│  ├─ Muchas células piramidales activadas casi sincrónicamente suman sus dipolos en un
│  │  dipolo "equivalente" grande; el electrodo del scalp registra negatividad por estar
│  │  más cerca del extremo negativo
│  ├─ Nervios, tractos y núcleos pueden tratarse como fuentes equivalentes a un dipolo
│  │  └─ El dipolo de un NERVIO no es estacionario: se mueve con la propagación. Los de
│  │     los NÚCLEOS son mayoritariamente estacionarios, aunque pueden cambiar porque
│  │     distintas partes del núcleo se activan secuencialmente
│  └─ La amplitud registrada depende de: fuerza del dipolo + ORIENTACIÓN tridimensional
│     respecto a los electrodos + distancia + propiedades eléctricas del medio
│     interpuesto (la resistencia del hueso craneal atenúa el campo lejano)
├─ Sustrato anatómico
│  ├─ Campo abierto → corteza cerebral (árboles dendríticos grandes y paralelos) →
│  │  contribuye mucho al campo lejano
│  ├─ Campo cerrado → núcleo con dendritas en todas direcciones → campo lejano pequeño
│  │  o inmedible
│  ├─ Paradoja importante: un núcleo con GRAN potencial de campo cercano puede no
│  │  contribuir de forma medible al campo lejano por su organización interna, mientras
│  │  otro con dendritas alineadas contribuye mucho al campo lejano aunque su potencial
│  │  de campo cercano sea menor
│  │  └─ En la práctica casi no hay núcleos puros de un tipo: la mayoría están entre
│  │     los dos extremos
│  ├─ Ejemplos de campo cerrado: núcleos de las columnas dorsales (contribuyen poco al
│  │  campo lejano) y colículo inferior (respuesta de campo lejano muy pequeña pese a
│  │  registrarse un potencial grande desde su superficie)
│  ├─ Excepción registrable: los núcleos de la sustancia gris central cervical y lumbar
│  │  SÍ son fuente registrable → dan el N13 y el N22
│  └─ Respuesta típica de un núcleo (registro monopolar de superficie): complejo rápido
│     positivo-negativo inicial (0.5-2 ms, generado por la TERMINACIÓN del nervio en el
│     núcleo) seguido de un potencial LENTO generado por las dendritas, sobre el que
│     pueden cabalgar espigas de los somas (somaspikes), más tardías por el retardo
│     sináptico
│     └─ El potencial lento tiene propiedad de dipolo: negativo desde un lado del
│        núcleo, positivo desde el opuesto y NULO en el punto equidistante (demostrado
│        atravesando el núcleo cuneiforme del gato con un electrodo: la polaridad se
│        invierte en un punto)
├─ Parámetros y magnitudes clave
│  ├─ Amplitud del PE: 0.1 µV - 10 µV
│  ├─ Amplificación necesaria: 10³-10⁶ (el conversor A/D necesita hasta 1 V de
│  │  entrada) · para PEATC en concreto, 500.000 a 1.000.000×
│  ├─ Ruido = TODO lo que no es el PE: EEG, EMG, EOG, ECG, ruido de electrodo y ruido
│  │  electrónico
│  ├─ Relación señal/ruido: de 1/5 a 1/100 según la modalidad
│  ├─ Promediado: el ruido decrece proporcionalmente a 1/√N
│  │  ├─ Mejora ×5 con 25 promedios; para mejorar ×10 hacen falta 75 más (100 en
│  │  │  total) — la mayor ganancia está al principio de la serie
│  │  └─ Clave conceptual: el promediado mejora la S/N REDUCIENDO la amplitud del
│  │     ruido, no aumentando la señal en absoluto
│  └─ Dimensionado del conversor A/D: nº de niveles ≈ amplitud de fondo / amplitud del
│     componente más pequeño. Con un PE de 0.1 µV sobre señal global de 100 µV hacen
│     falta ≥1000 niveles → conversor de 10 bits (2¹⁰=1024); los equipos usan 11-12 bits
├─ Componente "obligado" (obligate component)
│  ├─ Son los presentes de forma constante en todos los sujetos normales y los
│  │  clínicamente relevantes; sobre ellos se miden latencias absolutas, IPL y amplitud
│  ├─ PEATC: obligadas = ondas I, III y V. Las ondas II, IV, VI y VII son inconstantes
│  │  incluso en normales y no se usan para interpretación clínica
│  │  ├─ Consistencia: I, II, III, IV y V se encuentran en todos los adultos normales;
│  │  │  VI en el 84% y VII en el 43% de los oídos estimulados
│  │  └─ La onda I es la más frágil de las tres obligadas y la más frecuentemente
│  │     ausente o mal delineada — y es esencial, porque la conducción central se mide
│  │     desde su pico
│  ├─ PESS mediano: obligados = N9, N13/P13, P14, N18, N20
│  ├─ PESS tibial: obligados = N7, N22, P31, N34, P37
│  ├─ PEV: los tres picos son N75, P100 y N145; el clínicamente relevante es el P100
│  │  (mayor amplitud, menor variabilidad interindividual, mínima asimetría interocular)
│  └─ Por qué importa la distinción: define qué se mide y qué puede llamarse anormal —
│     si falta un componente NO obligado, no es una anormalidad. Ejemplo: en un tercio
│     de los normales las ondas IV y V no se reconocen separadas y se designan
│     "complejo IV/V", con latencia intermedia
├─ Cómo se traduce en el registro
│  ├─ La POLARIDAD de un componente depende de la derivación, no es una propiedad
│  │  absoluta: el mismo componente es N13 en un electrodo sobre la apófisis espinosa de
│  │  C5 y P13 en un electrodo sobre el cuello anterior
│  │  └─ Corolario: sin conocer la derivación, la polaridad no significa nada
│  ├─ Tres sistemas de nomenclatura
│  │  ├─ Ordinal: números romanos (ondas I-VII del PEATC)
│  │  ├─ Polaridad-ordinal: N1, P1, N2, P2
│  │  ├─ Polaridad-latencia: N9, P37, P100 — es el convenio PREFERIDO, porque aporta
│  │  │  polaridad y latencia media a la vez
│  │  ├─ Problema de los dos primeros: si los componentes iniciales faltan por patología
│  │  │  o por problema técnico, la identificación se DESPLAZA (si falta P1, P2 puede
│  │  │  tomarse por un P1 retrasado); además los ordinales no informan de latencia
│  │  ├─ Problema residual del tercero: la latencia del P37 depende de edad, talla y
│  │  │  sitio de estimulación (tobillo vs. rodilla)
│  │  └─ Muchos componentes se nombran además por su fuente: "potencial de Erb" o
│  │     "potencial del plexo braquial" para N9, "potencial poplíteo" para N7
│  ├─ Mediciones
│  │  ├─ Latencia absoluta: del estímulo al pico del componente
│  │  ├─ Latencia interpico (IPL): intervalo entre dos picos — es la RECOMENDADA para
│  │  │  valorar anormalidad clínicamente relevante, porque la latencia absoluta está
│  │  │  influida por muchos factores y la IPL lo está mucho menos
│  │  ├─ Amplitud: mal estandarizada (¿respecto a una línea de base indefinible, al pico
│  │  │  previo, al posterior, o área bajo la curva?). Convenio práctico: en PEATC y
│  │  │  PESS se mide al pico SIGUIENTE; en PEV se mide al pico ANTERIOR (N75)
│  │  └─ La amplitud es en general menos útil que la latencia por su variabilidad
│  │     intersujeto mucho mayor; una diferencia interlado significativa es como mucho
│  │     una anormalidad "blanda"
│  └─ Obligatorio ≥2 RÉPLICAS superpuestas: solo los componentes consistentes entre
│     réplicas pueden considerarse inequívocamente relacionados con el estímulo. Los
│     picos no reproducibles son probablemente ruido, y con una sola réplica se
│     confundirían con componentes reales del PE
├─ Aplicación práctica — datos normativos
│  ├─ Es preferible obtener los normativos en el propio laboratorio; si se "toman
│  │  prestados", hay que replicar instrumentación y técnica lo más fielmente posible
│  │  └─ Para el PEV los valores normales deben obtenerse SIEMPRE en el propio
│  │     laboratorio, por la gran variabilidad entre laboratorios
│  ├─ Muestra habitual ≥30 sujetos normales; límite superior en media + 2.5 SD o + 3.0
│  │  SD; estadística de UNA COLA (solo las latencias largas son clínicamente
│  │  relevantes). Con muestra muy grande, 2/2.5/3 SD cubren ~97.7%/99.4%/99.9%
│  ├─ Límites de tolerancia (recomendación ACNS 2006): intervalo que incluye una
│  │  proporción de la población con un nivel de confianza dado. Habitual: límite de
│  │  tolerancia del 99% con confianza ≥95%, de un solo lado
│  │  └─ Con n=30 el factor K ≈ 3.064, es decir media + 3 SD ≈ límite de tolerancia del
│  │     99% al 95% de confianza
│  ├─ Las AMPLITUDES no siguen distribución normal, así que media+3SD no sirve para
│  │  ellas: se considera anormal una asimetría interlado >50%; en PEATC se usa la
│  │  razón V/I
│  └─ Calcular media y SD por lado POR SEPARADO (o promediar los dos lados de cada
│     sujeto antes de promediar entre sujetos): las latencias de los dos lados de un
│     mismo individuo están correlacionadas, y agruparlas infraestima la SD
├─ Utilidad clínica de los PE
│  └─ Detectar disfunción clínicamente inaparente · confirmar y localizar el defecto de
│     conducción responsable de síntomas sensitivos · apoyar un origen psicógeno cuando
│     el PE es normal · confirmar muerte encefálica y/o pronosticar tras insulto
│     cerebral grave (anoxia, TCE grave) · monitorización intraoperatoria de la vía
│     sensitiva en riesgo
├─ Errores y confusiones frecuentes
│  ├─ PE no registrable: estimulación inadecuada, electrodos de alta impedancia,
│  │  artefactos de gran amplitud, electrodos de registro incorrectos o mal colocados
│  │  ├─ En PESS: verificar que los electrodos de estimulación están sobre el nervio y
│  │  │  que la intensidad produce una CONTRACCIÓN MUSCULAR VISIBLE
│  │  └─ En PEATC: auricular mal sujeto o deslizado sobre la mandíbula
│  ├─ Calidad subóptima por artefacto: con paciente tenso o en movimiento, NI aumentar
│  │  el número de promedios NI el rechazo automático de artefacto lo arreglan
│  ├─ "Los PE se ven raros" → causa frecuente: electrodos de uno o más canales
│  │  INVERTIDOS (registrar Cz-A2 en vez de A2-Cz). Truco: mirar la copia en papel a
│  │  contraluz por el reverso, que equivale a invertir la derivación
│  ├─ Confundir ruido con componentes del PE por hacer una sola réplica
│  ├─ Confundir la polaridad por desconocer la derivación (N13 vs P13)
│  └─ Deriva del sistema ordinal: tomar P2 por un P1 retrasado cuando P1 falta
├─ Limitaciones — los cinco límites del promediado
│  ├─ A. El ruido puede NO ser aleatorio, y entonces no se elimina según la raíz de N
│  ├─ B. Si la frecuencia de estimulación es armónico o subarmónico de un artefacto
│  │  (p. ej. 60 Hz), el artefacto se REALZA en vez de cancelarse
│  ├─ C. Señales irrelevantes pueden ocurrir time-locked al estímulo (p. ej. EMG
│  │  disparado por el propio estímulo) y contaminar el PE
│  ├─ D. Artefactos excesivos (movimientos oculares, parpadeo, EMG) pueden no
│  │  eliminarse aunque se aumente el número de promedios
│  ├─ E. Si el PE VARÍA entre estímulos, el promediado DEGRADA la señal: por jitter de
│  │  latencia, por variación de amplitud, o por ambas
│  └─ Límite específico de quirófano: el promediado asume que todas las respuestas
│     sumadas tienen la misma forma y la misma relación temporal con el estímulo — deja
│     de ser cierto cuando el sistema está siendo afectado por manipulación quirúrgica,
│     calor o anoxia, y si las respuestas cambian durante la adquisición la respuesta
│     promediada queda distorsionada
├─ Estrategias para mejorar el registro
│  ├─ Reducir el ruido de entrada: aplicación correcta de electrodos, comodidad del
│  │  paciente, sedación si hace falta para PEATC/PESS
│  ├─ Usar frecuencias de estimulación NO relacionadas con 60 Hz: PEV 2.1/s,
│  │  PEATC 11/s, PESS 4.7/s
│  ├─ Rechazo automático de artefacto por ventana discriminadora, filtrado adecuado y
│  │  ≥2 réplicas
│  ├─ En PEATC, el artefacto de estímulo a alta intensidad se elimina eficazmente con
│  │  clics de polaridad ALTERNANTE
│  └─ Aun así, en el 2-5% de los casos no hay forma de obtener un registro óptimo y hay
│     que reprogramar al paciente
└─ Referencia
   └─ Markand2020 cap.1 pp.1-14 y p.23 · cap.2 pp.28, 32, 34, 38 · cap.3 pp.90-91 ·
      cap.4 pp.139, 148-157 · Moller2011 cap.3 pp.23-24, 29, 35-39 · cap.5 pp.72-73,
      84-85
```
