# A1 — PESS / SSEP

```
PESS/SSEP
├─ Vía anatómica
│  ├─ N. mediano / n. tibial posterior → cordón posterior → núcleos gracilis/cuneatus
│  │  (bulbo) → lemnisco medial → tálamo (VPL) → corteza somatosensorial (S1)
│  └─ N9 (punto de Erb) — marcador de conducción periférica pura
├─ Estimulación
│  ├─ N. mediano (MMSS) / n. tibial posterior (MMII)
│  ├─ ~20-40 mA, 0.2-0.3 ms, 2.7-4.7 Hz (evitar armónicos de red)
│  └─ Confirmar twitch motor visible como control de intensidad efectiva
├─ Registro / montaje
│  ├─ Cortical: C3'/C4'-Fz (MMSS) · CPz/Cz'-Fz (MMII)
│  ├─ Subcortical: Erb's point (N9) · cervical (Cv2-Fz)
│  └─ Requiere promediado — señal pequeña, ruido de fondo alto
├─ Morfología normal
│  └─ N20 (mediano, cortical) / P37 (tibial, cortical)
│     └─ Línea base tras posicionamiento final
├─ Efecto anestesia/fisiología
│  ├─ Muy sensible a halogenados (dosis-dependiente) → preferir TIVA
│  ├─ N2O: efecto aditivo negativo con halogenados
│  ├─ Hipotensión / hipotermia / hipocapnia → ↓ amplitud, ↑ latencia
│  └─ Relajante muscular → sin efecto (vía sensitiva pura)
├─ Criterios de alarma
│  └─ Clásico: ↓ amplitud >50% o ↑ latencia >10% vs. basal
│     └─ MacDonald: criterios adaptativos más recientes
├─ Causas de cambio no quirúrgico
│  ├─ Técnico: desconexión, impedancia, artefacto de bisturí eléctrico
│  ├─ Anestésico: bolo de halogenado, cambio brusco de plano
│  └─ Sistémico: PAM, Hb, temperatura, compresión de plexo/nervio por posición
├─ Troubleshooting
│  └─ Técnico → anestésico → correlacionar con MEP/onda D si hay riesgo motor
│     → avisar a cirugía si persiste
├─ Limitaciones
│  └─ Columnas dorsales ≠ tracto corticoespinal
│     └─ SEP normal NO garantiza indemnidad motora
└─ Referencia
   └─ Nuwer2012 (AAN/ACNS) · MacDonald2019 (ISION) · Toleikis2024 (ASNM)
```

## Ampliación — profundizar

```
PESS/SSEP — ampliación
├─ Criterios adaptativos más allá del 50%/10% clásico
│  ├─ Crítica al clásico: sobrestima la latencia, no considera el drift fisiológico de
│  │  la basal ni la reproducibilidad real de la señal
│  ├─ Deriva basal benigna: la amplitud cae por debajo del 50% de la basal inicial en
│  │  ~20% de las cirugías de escoliosis SIN que sea patológico
│  └─ Criterio adaptativo real: comparar con el valor RECIENTE pre-cambio (no la basal
│     inicial), que exceda claramente la variabilidad trial-a-trial, sobre todo si el
│     cambio es abrupto y focal
├─ Reproducibilidad de la señal como base del criterio (Tabla 3.1)
│  └─ Clasificación Alta/Media/Baja/No-reproducible según % de variación entre
│     barridos → determina qué decremento es detectable como patológico (alta
│     reproducibilidad detecta caídas >30%; señal no-reproducible solo es fiable si
│     desaparece del todo)
└─ Límites reales de detección
   ├─ Anomalía de no-decusación de la vía sensitiva invalida montajes fijos — 2.3% de
   │  una serie de escoliosis en Oriente Medio, asociada a parálisis congénita de la
   │  mirada horizontal
   └─ Encuesta SRS/ESDS (51.263 cirugías de columna): 34 falsos negativos (0.063% del
      total) — pero esos 34 representan el 18.5% de los 184 pacientes con déficit
      postoperatorio real → cuantifica la limitación "SEP normal no garantiza
      indemnidad motora"
Referencia: Deletis, cap. 3 (MacDonald), §3.3.3.1 y 3.4.1-3.4.2, Tabla 3.1, pp.39-46 ·
Nuwer et al., citado en Moller2011 cap. 6, p.96
```
