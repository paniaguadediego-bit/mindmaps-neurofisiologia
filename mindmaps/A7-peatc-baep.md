# A7 — PEATC / BAEP

```
PEATC / BAEP
├─ Vía anatómica (generadores)
│  ├─ Onda I: porción distal del n. auditivo (cóclea) · onda III: núcleo coclear
│  │  (protuberancia)
│  └─ Onda V: terminación del lemnisco lateral en el colículo inferior CONTRALATERAL
│     — ondas I-III generadas ipsilateralmente, IV en adelante mixtas/contralaterales
├─ Estimulación
│  ├─ Click monoaural con enmascaramiento del oído contralateral, ~105 dB PeSPL
│  │  (≈65-70 dB HL)
│  ├─ Tasa práctica hasta 50-70 pps (límite absoluto 100 pps) — a mayor tasa, las
│  │  ondas I-III caen más que la V
│  └─ Polaridad rarefacción o condensación, NO alternante — distorsiona la forma de
│     onda en hipoacusia, aunque cancele el artefacto de estímulo
├─ Registro / montaje
│  ├─ Dos canales: vértex-nuca (realza onda V) · lóbulo-lóbulo (realza ondas I-III)
│  └─ Electrodos cortos y trenzados — minimizar interferencia de transformadores y del
│     microscopio quirúrgico
├─ Morfología normal
│  └─ Secuencia de picos I-VII, atención clínica centrada en I/III/V
│     └─ Intervalo interpico I-II ≈1.04-1.08 ms (coherente con la longitud/velocidad
│        de conducción del VIII par)
├─ Efecto anestesia/fisiología
│  ├─ Notablemente INSENSIBLE a la anestesia — el tipo de anestésico puede elegirse
│  │  sin ninguna consideración sobre el BAEP (a diferencia de SEP/EEG)
│  └─ Sí sensible a temperatura: por debajo de 35.0 °C aumenta notablemente las
│     latencias
├─ Criterios de alarma
│  └─ Dependen del contexto quirúrgico — en cirugía de tronco/ángulo pontocerebeloso:
│     ↓50% amplitud onda V + ↑latencia >0.5 ms (ver B8)
├─ Causas de cambio no quirúrgico
│  └─ Interferencia eléctrica/magnética del quirófano (transformadores, luz del
│     microscopio) · impedancia de electrodo · ruido EEG de fondo (reduce SNR, obliga
│     a promediar más)
├─ Troubleshooting
│  └─ Inspeccionar la forma de onda CRUDA (no solo el promedio) para identificar la
│     fuente de interferencia antes de asumir patología
├─ Limitaciones
│  ├─ Requiere promediado (≥1000 respuestas en condiciones óptimas) → demora
│  │  inherente; la hipoacusia previa exige aún más barridos, retrasando la detección
│  └─ No capta actividad más allá del colículo inferior — no informa de tálamo ni
│     corteza
└─ Referencia
   └─ Deletis, cap. 5 (Møller), §5.1-5.9, pp.65-82 · Moller2011, cap. 7 "Monitoring of
      Auditory Evoked Potentials", p.158
```
