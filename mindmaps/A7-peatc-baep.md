# A7 — PEATC / BAEP

```
PEATC / BAEP
├─ Para qué se usa y cuál es su problema estructural
│  ├─ El registro de potenciales auditivos de CAMPO LEJANO es el método más usado para
│  │  monitorizar la función del nervio auditivo en cirugía de ángulo pontocerebeloso; el
│  │  VIII fue uno de los primeros pares craneales que se monitorizaron
│  ├─ Se usa también para monitorizar el efecto de la MANIPULACIÓN DEL TRONCO
│  └─ EL PROBLEMA DE FONDO: la respuesta tiene amplitud mínima y aparece sobre un fondo
│     intenso de actividad biológica (EEG) y a veces de interferencia eléctrica y magnética
│     ├─ Por eso hay que promediar muchas respuestas, y eso lleva tiempo
│     └─ En el laboratorio ese tiempo es una molestia; en monitorización es un OBSTÁCULO
│        GRAVE, porque lo vital es tener una respuesta interpretable en poco tiempo
├─ LAS CUATRO PALANCAS PARA ACORTAR EL TIEMPO
│  ├─ 1. Intensidad y frecuencia de estimulación óptimas
│  ├─ 2. Reducción de la interferencia eléctrica y magnética
│  ├─ 3. Colocación óptima de los electrodos de registro
│  └─ 4. Filtrado óptimo de los potenciales registrados
├─ ESTIMULACIÓN
│  ├─ Clics, monoaurales, con enmascaramiento del oído contralateral
│  ├─ FRECUENCIA — el compromiso, con su punto de equilibrio medido
│  │  ├─ Duplicar la frecuencia podría reducir a la mitad el tiempo necesario SI la
│  │  │  respuesta a cada estímulo se mantuviera igual, cosa que no ocurre
│  │  ├─ La ganancia por subir la frecuencia solo supera la pérdida por caída de amplitud
│  │  │  HASTA CIERTA frecuencia
│  │  ├─ Hasta 70 pps la amplitud del pico V baja MUY POCO; las amplitudes de los picos
│  │  │  I-III bajan MÁS que la del V → es ventajoso usar frecuencias incluso de 70 pps
│  │  ├─ LÍMITE ABSOLUTO: 100 pps para una ventana de observación de 10 ms
│  │  └─ En la práctica, 50 pps es probablemente lo más práctico
│  ├─ NÚMERO DE RESPUESTAS Y TIEMPO REAL
│  │  ├─ En las mejores circunstancias —audición normal e interferencia baja— hacen falta
│  │  │  al menos 1000 respuestas promediadas para un registro interpretable
│  │  └─ A 10 pps eso son 100 segundos; a 40 pps, 25 segundos. Ahí está el valor de subir
│  │     la frecuencia
│  ├─ INTENSIDAD: aproximadamente 105 dB PeSPL, que corresponde a 65-70 dB de nivel de
│  │  audición cuando se presenta a 20 pps
│  │  └─ Seguridad: los clics de 105 dB PeSPL se han usado durante muchos años sin que se
│  │     haya reportado ningún signo de hipoacusia por exposición sonora
│  └─ POLARIDAD — por qué NO alternante
│     ├─ El clic de RAREFACCIÓN tira de la membrana timpánica hacia AFUERA del conducto; el
│     │  de CONDENSACIÓN la empuja hacia ADENTRO
│     ├─ Las respuestas a condensación son DISTINTAS de las de rarefacción, y la diferencia
│     │  es especialmente marcada en la persona con hipoacusia
│     ├─ Por eso NO es aconsejable usar clics alternantes: es mejor elegir rarefacción o
│     │  condensación y quedarse con una
│     └─ La razón por la que el alternante se usa tanto es que cancela el artefacto de
│        estímulo — pero ese artefacto, con clics de polaridad única, puede reducirse con
│        una rutina informática sencilla
├─ REGISTRO Y MONTAJE — dos canales, y por qué dos
│  ├─ Los generadores de los distintos componentes están en localizaciones anatómicamente
│  │  distintas, con dipolos equivalentes de distinta orientación — unos estacionarios (los
│  │  de núcleos) y otros móviles (los de nervios y tractos)
│  ├─ Por eso conviene registrar en DOS canales, con dos pares de electrodos conectados a
│  │  amplificadores separados y promediados y mostrados por separado
│  │  ├─ Par VÉRTEX + NUCA ALTA → registra el pico V con MAYOR amplitud
│  │  └─ Par LÓBULO-LÓBULO → registra preferentemente los picos I-III con mayor amplitud
│  └─ Cada par registra TODOS los componentes; lo que cambia es cuál realza
├─ REDUCCIÓN DE INTERFERENCIA — la palanca con mejor rendimiento
│  ├─ ARITMÉTICA QUE JUSTIFICA EL ESFUERZO: reducir el nivel de ruido a la mitad duplica la
│  │  relación señal/ruido, y eso reduce el número de respuestas necesarias por un factor
│  │  de CUATRO
│  ├─ Cómo estudiar el quirófano: hacerlo cuando NO hay cirugía, típicamente a última hora
│  │  de la tarde, encendiendo y apagando equipos mientras se observa su efecto sobre
│  │  potenciales registrados de un maniquí o de un voluntario cableado como un paciente
│  ├─ Una ANTENA conectada a la entrada de uno de los amplificadores es un medio eficaz
│  │  para identificar la fuente de interferencia ELÉCTRICA
│  ├─ INTERFERENCIA MAGNÉTICA: procede de los transformadores de las fuentes de alimentación
│  │  de los equipos, o del transformador principal de la sala
│  │  ├─ La FUENTE DE LUZ DEL MICROSCOPIO QUIRÚRGICO es a menudo una fuente de interferencia
│  │  │  magnética intensa
│  │  ├─ Afecta al registro porque INDUCE corrientes eléctricas en los cables de electrodo
│  │  └─ Se localiza con una BOBINA de cable conectada a la entrada de uno de los
│  │     amplificadores fisiológicos, observando la pantalla
│  ├─ Manejo de cables: mantenerlos lo MÁS CORTOS posible y TRENZADOS, lo que reduce la
│  │  captación tanto eléctrica como magnética
│  │  └─ EVITAR BUCLES en los cables de electrodo, porque captan interferencia magnética
│  └─ MIRAR EL CRUDO, no solo el promedio: si solo se observan las respuestas promediadas,
│     la interferencia se manifiesta únicamente como un aumento del número de respuestas
│     rechazadas; y si es intensa, provoca el rechazo de TODAS las respuestas, sin dejar
│     ninguna firma útil para identificar su origen
├─ FILTRADO
│  ├─ Los filtros del PEATC buscan reducir el ruido MÁS que la señal, y un filtrado bien
│  │  diseñado acorta el tiempo hasta el registro interpretable
│  ├─ El filtrado DIGITAL es la forma más eficaz y práctica de filtrar potenciales evocados
│  │  en monitorización intraoperatoria
│  ├─ Dos clases de filtros digitales
│  │  ├─ Los que EMULAN filtros electrónicos de paso alto y paso bajo, descritos por
│  │  │  frecuencias de corte y pendiente de atenuación — hoy los más usados
│  │  └─ Los que operan sobre el PATRÓN TEMPORAL de la señal, descritos por sus funciones de
│  │     respuesta al impulso: más flexibles, con ventajas que los electrónicos no pueden dar
│  ├─ Ventaja decisiva de estos últimos: pueden diseñarse para REALZAR la forma de onda del
│  │  PEATC al mismo tiempo que reducen el ruido, lo que acorta el tiempo de adquisición
│  ├─ Dos propiedades que importan y que los filtros analógicos no tienen
│  │  ├─ FASE CERO: los filtros analógicos desplazan los componentes en el tiempo, y ese
│  │  │  desplazamiento de fase CAMBIA LAS LATENCIAS registradas — que es justo lo que se
│  │  │  está midiendo. Los filtros digitales de fase cero lo evitan
│  │  └─ RESPUESTA AL IMPULSO FINITA: los analógicos emborronan en el tiempo los impulsos
│  │     agudos, como el artefacto de estímulo, que puede así interferir con la respuesta
│  │     biológica. Los de respuesta al impulso finita pueden diseñarse para no hacerlo
│  └─ Ejemplos concretos: el filtro W25 realza TODOS los picos del PEATC; el W50 suprime
│     mejor el ruido pero realza solo los picos I, III y V
├─ MORFOLOGÍA Y GENERADORES
│  ├─ Secuencia de picos I a VII; la atención clínica se centra en I, III y V
│  ├─ Onda I: porción DISTAL del nervio auditivo, dentro del oído
│  ├─ Onda II: porción PROXIMAL del nervio auditivo
│  │  └─ Cómo se dedujo: el componente negativo precoz del registro del núcleo coclear
│  │     aparece con casi la misma latencia que el pico negativo del registro de la porción
│  │     proximal del VIII expuesto, y aproximadamente con la misma latencia que el pico II
│  ├─ Onda III: núcleo coclear, a nivel protuberancial
│  ├─ Onda V: porción rostral del LEMNISCO LATERAL CONTRALATERAL al oído estimulado
│  │  └─ Todos los generadores ipsilaterales están en la parte CAUDAL del tronco; de la IV
│  │     en adelante las contribuciones son mixtas o contralaterales
│  └─ Intervalo interpico I-II de aproximadamente 1.04-1.08 ms, coherente con la longitud y
│     la velocidad de conducción del VIII par
├─ EFECTO DE LA ANESTESIA Y LA FISIOLOGÍA
│  ├─ Notablemente INSENSIBLE a la anestesia: el tipo de anestésico puede elegirse sin
│  │  ninguna consideración sobre el PEATC, a diferencia del SEP cortical y del EEG
│  │  └─ Es del Grupo 1 farmacológico: insensible a halogenados y a relajante. De hecho el
│  │     relajante puede MEJORAR la relación señal/ruido al eliminar el EMG de fondo
│  └─ SÍ sensible a la TEMPERATURA: por debajo de 35 °C las latencias aumentan de forma
│     notable
├─ LO QUE SIGNIFICA UN CAMBIO — el patrón de lesión del nervio auditivo
│  ├─ El signo típico de lesión del nervio auditivo por manipulación quirúrgica o por CALOR
│  │  de la electrocoagulación es el descenso de la velocidad de conducción
│  ├─ Eso produce aumento de la latencia de TODOS los componentes EXCEPTO el pico I — y ese
│  │  patrón es el signo distintivo de lesión del nervio auditivo
│  └─ Razón anatómica: el pico I lo genera la porción distal del nervio, situada en el oído,
│     es decir DISTAL a la parte del nervio que el tumor o la cirugía afectan
├─ QUÉ REPORTAR AL CIRUJANO — el debate y el experimento natural que lo resuelve
│  ├─ Las dos posturas extremas
│  │  ├─ No reportar ningún cambio hasta que el PEATC ya no pueda identificarse
│  │  └─ Reportar cualquier cambio mayor que las pequeñas variaciones aleatorias habituales
│  │     — lo que significa comunicar cambios de latencia del pico V de 0.25 ms
│  ├─ EL EXPERIMENTO NATURAL: en un hospital especializado en descompresión microvascular,
│  │  dos cirujanos operaron números similares de pacientes, todos con monitorización de
│  │  PEATC y registro directo del nervio auditivo por el MISMO neurofisiólogo, y todos con
│  │  audiometría documentada antes y al alta
│  │  ├─ CIRUJANO A: más de 350 pacientes; SIEMPRE actuaba ante el primer cambio de latencia
│  │  │  perceptible, habitualmente de 0.25 ms → NINGUNO de esos pacientes tuvo hipoacusia
│  │  │  mayor de 20 dB en dos frecuencias
│  │  └─ CIRUJANO B: número similar de operaciones parecidas; NO siempre actuaba ante
│  │     cambios tan pequeños y a menudo esperaba a que el cambio de latencia aumentara →
│  │     tuvo incidencias apreciables de hipoacusia postoperatoria
│  ├─ HIPÓTESIS QUE SE DERIVA: NO existe un umbral de cambio de latencia por debajo del cual
│  │  no haya riesgo de hipoacusia permanente — el símil que usa la fuente es el riesgo de
│  │  cáncer por radiación ionizante
│  ├─ Por tanto la intervención del cirujano está justificada ante CUALQUIER cambio
│  │  detectable, entendiendo por tal el que supera las variaciones que ocurren cuando no se
│  │  está operando
│  ├─ Honestidad de la fuente: NO está científicamente demostrado que reportar cambios
│  │  mínimos beneficie al paciente — es una hipótesis apoyada por la experiencia práctica
│  └─ Probablemente también influyen el TIEMPO durante el cual la latencia está aumentada y
│     un descenso concomitante de la amplitud de los componentes
├─ REGISTRO DIRECTO DEL VIII EXPUESTO (CAP) — cuando hace falta ir más rápido
│  ├─ El potencial de acción compuesto registrado de la porción intracraneal expuesta del
│  │  VIII tiene amplitud MUCHO MAYOR que el PEATC
│  ├─ Consecuencia: es interpretable SIN promediar, o tras solo 10-20 respuestas → da
│  │  monitorización instantánea o casi instantánea de la conducción
│  ├─ Morfología: deflexión positiva inicial, seguida de un gran pico negativo, seguido de
│  │  un potencial positivo menor — el patrón típico de un nervio largo con electrodo
│  │  monopolar
│  ├─ CÓMO SE LEE EL DAÑO, que es más directo que con el PEATC
│  │  ├─ ESTIRAMIENTO del nervio → reduce la velocidad de conducción → aumenta la latencia
│  │  │  del pico negativo
│  │  ├─ BLOQUEO DE CONDUCCIÓN en algunas fibras → disminuye la amplitud del pico negativo y
│  │  │  AUMENTA la del pico positivo inicial
│  │  └─ BLOQUEO TOTAL → ausencia completa del pico negativo; el CAP queda reducido a una
│  │     sola deflexión positiva: el llamado potencial de "extremo cortado" (cut end)
│  ├─ La colocación del electrodo cambia lo registrado: sobre la aracnoides íntegra la
│  │  amplitud es menor que sobre el nervio expuesto, y el registro más distal tiene latencia
│  │  MÁS CORTA que el registrado cerca del tronco
│  │  └─ Esa progresión de latencias con la distancia es lo que demuestra que el potencial
│  │     registrado corresponde a actividad neural PROPAGADA
│  ├─ La segunda deflexión negativa del registro NO es del nervio: es la respuesta del
│  │  NÚCLEO COCLEAR, conducida pasivamente (electrotónicamente) hasta el punto de registro,
│  │  porque el VIII se comporta como conductor eléctrico
│  ├─ SEGURIDAD: la porción intracraneal del VIII es extremadamente FRÁGIL —la zona de
│  │  Obersteiner-Redlich está en el conducto auditivo interno— así que el electrodo debe ser
│  │  BLANDO y ejercer una presión mínima
│  │  └─ Electrodo de mecha: hilo de plata multifilamento aislado con teflón, al que se sutura
│  │     una punta de algodón sin aislar
│  └─ La forma de onda del CAP se altera con la hipoacusia del paciente: es típicamente más
│     compleja que en la persona con audición normal
├─ REGISTRO DEL NÚCLEO COCLEAR — la alternativa estable
│  ├─ Problema que resuelve: el electrodo colocado sobre el VIII expuesto puede DESPLAZARSE
│  │  con la manipulación quirúrgica, tanto en descompresión microvascular como en resección
│  │  de schwannoma vestibular
│  ├─ La superficie del núcleo coclear ES el suelo del RECESO LATERAL del IV ventrículo, así
│  │  que se registra colocando un electrodo ahí, empujándolo a través del FORAMEN DE LUSCHKA
│  ├─ Se usa un electrodo de mecha de algodón similar al del nervio expuesto
│  ├─ VENTAJA DECISIVA: el electrodo queda FUERA del campo quirúrgico y no lo perturban las
│  │  manipulaciones. Con el cable metido bajo las suturas que retiran la duramadre se
│  │  obtienen registros estables durante muchas horas
│  ├─ Ni siquiera es necesario introducirlo dentro del receso lateral: colocarlo cerca del
│  │  nervio VAGO donde entra en el tronco da registros excelentes
│  ├─ Morfología típica de un núcleo: tríada rápida inicial positivo-negativa, generada por
│  │  la TERMINACIÓN del nervio, seguida de un potencial LENTO generado sobre todo por las
│  │  dendritas, sobre el que pueden cabalgar picos
│  └─ Jerarquía de amplitudes: el registro del VIII expuesto es MAYOR que el del núcleo
│     coclear, y el PEATC es el de amplitud MÁS PEQUEÑA de los tres
├─ LOS REGISTROS DIRECTOS NO SUSTITUYEN AL PEATC
│  ├─ Solo pueden hacerse cuando el VIII está quirúrgicamente EXPUESTO
│  └─ Antes de que eso ocurra, la función del nervio auditivo debe monitorizarse con PEATC
├─ CAUSAS DE CAMBIO NO QUIRÚRGICO
│  ├─ Interferencia eléctrica y magnética del quirófano: transformadores, luz del microscopio
│  ├─ Impedancia de electrodo, cables largos o con bucles
│  ├─ Ruido EEG y EMG de fondo, que baja la S/N y obliga a promediar más
│  └─ Temperatura por debajo de 35 °C
├─ TROUBLESHOOTING
│  ├─ Inspeccionar la forma de onda CRUDA antes de asumir patología: es la única forma de
│  │  identificar la naturaleza y la fuente de una interferencia
│  ├─ Si aumenta bruscamente el número de respuestas rechazadas, sospechar interferencia
│  │  antes que cambio biológico
│  ├─ Revisar longitud, trenzado y bucles de los cables; alejarlos del microscopio
│  └─ Si el registro es demasiado lento para ser útil, valorar el registro directo del VIII
│     o del núcleo coclear cuando la exposición lo permita
├─ LIMITACIONES
│  ├─ Exige promediado: al menos 1000 respuestas en las mejores condiciones, así que hay una
│  │  demora inherente entre el evento y su detección
│  ├─ El paciente con schwannoma vestibular tiene PEATC de baja amplitud y latencias
│  │  prolongadas en todos los componentes salvo el pico I → hacen falta MÁS promedios →
│  │  MÁS tiempo → detección más tardía, justo en el paciente de más riesgo
│  ├─ No informa más allá del colículo inferior: nada dice de tálamo ni de corteza
│  ├─ El ECoG registrado del oído NO se afecta por cambios de conducción del nervio auditivo
│  │  — se afecta por la función del oído y por el compromiso del riego coclear, así que no
│  │  sirve para lo que se busca aquí
│  └─ No existe un umbral de cambio demostradamente seguro, y el propio criterio de alarma
│     depende de qué considere "aceptable" cada cirujano
└─ Referencia

      techniques") pp.65-82 — §5.4 monitorización del PEATC y las cuatro palancas, §5.4.3
      frecuencia e intensidad óptimas con el límite de 70 y 100 pps y los 105 dB PeSPL,
      §5.4.4 interferencia eléctrica y magnética y la regla del factor cuatro, §5.4.5 montaje
      de dos canales (Fig. 5.2), §5.4.6 filtrado digital, fase cero y respuesta al impulso
      finita (Fig. 5.3), §5.4.7 registro práctico y el paciente con schwannoma (Fig. 5.4),
      §5.5 signo distintivo de lesión, §5.6 CAP del VIII expuesto y potencial de extremo
      cortado (Figs. 5.5-5.7), §5.7 registro del núcleo coclear por el foramen de Luschka
      (Figs. 5.8-5.9), §5.8 qué reportar y la comparación entre los dos cirujanos, §5.9
      generadores · Moller2011 cap.7 "Monitoring of Auditory Evoked Potentials" pp.141-150 y
      158
```
