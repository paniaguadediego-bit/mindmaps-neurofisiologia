# B5 — Fosa posterior / tronco encefálico

> Este es el nivel introductorio/general. Para mapeo detallado del suelo del IV
> ventrículo, criterios BAEP/reflejos y jerarquía de alarma por núcleo, ver **B8**.
> Pendiente: criterios de elección entre park-bench/decúbito lateral, prono y
> semisentada más allá de los dos ejemplos citados — no detallado en las fuentes.

```
Fosa posterior / tronco encefálico
├─ Modalidades combinadas
│  ├─ Batería estándar: SEP + BAEP + MEP corticoespinal/corticobulbar (parámetros de
│  │  cada uno en A1/A3/A6/A7)
│  └─ SEP + BAEP juntos solo evalúan la integridad funcional de MENOS del 20% del
│     territorio del tronco — de ahí la necesidad de añadir mapeo y reflejos (ver B8)
├─ Fases del procedimiento
│  ├─ El tronco mide ~6 cm de alto × 3.5 cm de ancho a nivel protuberancial, sin
│  │  demarcación anatómica clara con diencéfalo o médula
│  ├─ Clasificación por patrón de crecimiento en RM determina el objetivo quirúrgico:
│  │  focal (74% benignos) · cervicomedular · exofítico dorsal · difuso (88% malignos)
│  ├─ Tumor exofítico crea su propio punto de entrada; tumor puramente intrínseco
│  │  exige mapa mental de la anatomía funcional para elegir la zona más segura
│  └─ Abordajes según nivel (cirujano que los popularizó): mesencéfalo —
│     infratentorial-supracerebeloso (Stein), transtentorial occipital, pterional
│     transilviano (Yasargil) · protuberancia — retrosigmoideo, petroso combinado
│     (Al-Mefty/Spetzler), suboccipital transventricular · bulbo/UCM — suboccipital
│     baja ± laminotomía cervical, dorsolateral (Heros/Spetzler-Grahm)
├─ Riesgo neurológico específico
│  ├─ El tronco es un "campo minado": densidad de núcleos de pares craneales,
│  │  fascículos ascendentes/descendentes y formación reticular en muy poco volumen
│  ├─ Zonas de entrada dorsal peligrosas: colículo superior (visual/oculomotor) ·
│  │  colículo inferior (auditivo) · fascículo longitudinal medial (oftalmoplejía
│  │  internuclear) · colículo facial · calamus scriptorius/núcleos IX-X-XII (disfagia
│  │  + alteración cardiorrespiratoria) · tubérculos grácil/cuneiforme (ataxia)
│  └─ La complicación más peligrosa de toda la cirugía de tronco: parálisis de pares
│     bajos (IX-XII) → disnea + disfagia severa → riesgo de neumonía aspirativa
├─ Posicionamiento
│  ├─ Semisentada: abordaje transtentorial occipital y suboccipital transventricular
│  │  dorsal (cabeza flectada)
│  └─ Retrosigmoideo lateral con cabeza rotada hacia el lado del tumor: tumores
│     ventrolaterales protuberanciales
├─ Jerarquía de alarma
│  └─ Nivel conceptual — para los criterios cuantitativos completos ver B8. Dato de
│     encuadre: el mapeo directo del tronco cambió la vía de entrada quirúrgica
│     planificada en ~10% de una serie propia
├─ Protocolo de reacción
│  └─ Ver B8 para el protocolo específico (pausa ante Blink Reflex + CoMEP, LAR >60%,
│     etc.) — sin contenido adicional distinto en esta fuente para el nivel base
├─ Técnica de mapeo específica
│  └─ Ver B8/A6/A9 para los parámetros completos de mapeo del suelo del IV ventrículo
│     y reflejos de tronco. El papel del DTI aquí es "más controvertido y con
│     experiencia más limitada" que en supratentorial — su utilidad para guiar el
│     mapeo aún no está establecida
└─ Referencia
   └─ Deletis, cap. 22 (Sala/D'Amico/Bricolo), §22.1-22.5, pp.295-305 — para el nivel
      avanzado (mapeo detallado, criterios BAEP/reflejos, jerarquía por núcleo) ver B8
```
