# B7 — Craneotomía despierta / mapeo cortical-subcortical

```
Craneotomía despierta / mapeo cortical-subcortical
├─ EL OBJETIVO, QUE DEFINE TODO LO DEMÁS
│  ├─ Maximizar la resección tumoral y minimizar el déficit neurológico, a la vez
│  └─ La pregunta inminente durante la extirpación es siempre la misma: a qué DISTANCIA está
│     la cavidad de resección del tracto corticoespinal en este punto concreto
├─ MODALIDADES COMBINADAS
│  ├─ Estimulación eléctrica directa (DES) cortical y subcortical, con dos paradigmas
│  ├─ ECoG de 3-4 canales para detectar afterdischarges y el inicio precoz de una crisis
│  │  ├─ Obligatoria en el protocolo americano, que busca el umbral de afterdischarge
│  │  └─ No obligatoria en el europeo. En la encuesta europea, solo la MITAD de los 20
│  │     centros usaba ECoG o EEG durante la cirugía despierta
│  ├─ MEP y SEP continuos: evalúan integridad VASCULAR y NO sustituyen al mapeo
│  │  └─ Razón: una lesión por coagulación de perforantes REMOTA al punto estimulado solo la
│  │     detecta la monitorización continua, nunca el mapeo puntual
│  └─ EMG libre de cara simultáneo, para no perder movimientos pequeños o a distancia durante
│     la vigilia
├─ ELECTRÓNICA — por qué corriente constante y qué polaridad
│  ├─ Para mapeo cerebral, los estimuladores de CORRIENTE CONSTANTE se consideran más seguros
│  │  y fiables, porque entregan la corriente prefijada con independencia de la impedancia de
│  │  la superficie cortical o subcortical
│  ├─ Con voltaje constante la corriente entregada depende de la impedancia: si la impedancia
│  │  DISMINUYE, la corriente entregada puede aumentar DRAMÁTICAMENTE y comprometer la
│  │  seguridad del procedimiento
│  │  └─ Esa limitación puede además confundir la discusión sobre la correlación entre valores
│  │     absolutos de mapeo subcortical y distancia al CST — otra razón para preferir
│  │     corriente constante en mapeo subcortical
│  ├─ Los pulsos son rectangulares, monofásicos o bifásicos
│  └─ POLARIDAD, con regla distinta arriba y abajo, e independiente del paradigma
│     ├─ CORTEZA: la estimulación es más efectiva con corriente ANÓDICA
│     ├─ SUBCORTEZA: debe preferirse la corriente CATÓDICA
│     └─ En la práctica: con técnica de Penfield, sonda monopolar y estímulos monofásicos, la
│        polaridad debe ser anódica (positiva); si se usa pulso bifásico, en modo
│        anódico/catódico
├─ LOS DOS PARADIGMAS DE ESTIMULACIÓN
│  ├─ PENFIELD, o baja frecuencia — el clásico
│  │  ├─ Frecuencia de 50 o 60 Hz con pulsos de 1 ms, aplicados durante 1-4 segundos según
│  │  │  el tejido de interés
│  │  ├─ Para corteza MOTORA puede bastar 1 segundo; para lenguaje y otras funciones
│  │  │  corticales superiores se usan habitualmente 3-4 segundos
│  │  └─ SU LIMITACIÓN TÉCNICA: bajo anestesia general induce una CONTRACCIÓN TÓNICA que
│  │     empieza tras varios milisegundos (según la intensidad) y va AUMENTANDO de amplitud
│  │     mientras dura la estimulación → eso impide medir con precisión el umbral motor
│  ├─ TREN CORTO, o alta frecuencia — el moderno
│  │  ├─ Trenes de 4 a 9 pulsos rectangulares monofásicos de 200-500 µs de anchura, con ISI
│  │  │  de 2-4 ms, lo que equivale a 250-500 Hz
│  │  ├─ Bajo anestesia general, la sumación temporal de múltiples volleys descendentes acaba
│  │  │  disparando un MEP TIME-LOCKED, con latencia definida y amplitud fácil de cuantificar
│  │  └─ Por eso es superior para el análisis cuantitativo de latencias, amplitudes y umbrales
│  │     motores, y hace más fácil establecer criterios de alarma cuantificables
│  ├─ SU LIMITACIÓN MAYOR: el tren corto ha sido muy rara vez efectivo para algo que no sea
│  │  mapeo MOTOR
│  │  ├─ Solo unos pocos centros lo han aplicado a mapeo de lenguaje, modificando el paradigma
│  │  │  al SUBIR la frecuencia de repetición de los trenes a 3.0 Hz
│  │  └─ Si se usa para M1 o CST en cirugía despierta, el número de pulsos puede reducirse a
│  │     dos o tres, o incluso puede bastar un pulso único
│  └─ CUÁNDO EL PENFIELD FALLA Y SOLO SIRVE EL TREN CORTO: en pacientes con historia larga de
│     crisis preoperatorias, con infiltración tumoral del CST, o con tumores recurrentes ya
│     operados o irradiados, el paradigma de Penfield puede fallar y solo el tren corto
│     elicita respuestas fiables
├─ ELECCIÓN DE SONDA — sensibilidad frente a especificidad
│  ├─ SONDA BIPOLAR: dos electrodos esféricos separados 5 mm. Muy selectiva para activar el
│  │  tejido situado ENTRE las dos puntas
│  │  └─ Si la región de interés NO está directamente entre las puntas y queda más lejos, el
│  │     campo eléctrico no es homogéneo y la activación a distancia es menos probable
│  ├─ SONDA MONOPOLAR tipo finger-stick: la sonda es la parte activa y dispersa la corriente
│  │  hacia un electrodo de referencia lejano
│  │  └─ La dispersión RADIAL del campo permite que la corriente entre PERPENDICULARMENTE en
│  │     el axón, lo que resulta en una estimulación más efectiva y la hace más fiable para
│  │     trabajar con umbrales cuantitativos y predecir distancia
│  ├─ REGLA QUE RESUME LA ELECCIÓN, a igual paradigma e intensidad
│  │  ├─ Monopolar (referencial) = test SENSIBLE: da aviso precoz, pero estimulación menos
│  │  │  focal
│  │  └─ Bipolar = test ESPECÍFICO: estimulación muy selectiva y focal, pero solo responde si
│  │     el punto estimulado está muy cerca de la estructura de interés
│  ├─ Combinación tradicional: sonda bipolar con 50-60 Hz, y sonda monopolar con tren corto —
│  │  aunque son practicables otras combinaciones según el interés quirúrgico
│  └─ CUATRO OBSERVACIONES PUBLICADAS que orientan la elección
│     ├─ Las intensidades necesarias para disparar un MEP en el anestesiado son MENORES con
│     │  monopolar más tren corto que con la bipolar clásica a 50 Hz
│     ├─ La monopolar con tren corto es MÁS PREDICTIVA de estimulación positiva en la corteza
│     │  motora PRIMARIA; la bipolar a 50 Hz es más sensible en corteza PREMOTORA frontal y en
│     │  el área motora SUPLEMENTARIA
│     ├─ La monopolar con tren corto es más efectiva en tumores recurrentes, infiltración del
│     │  CST o historia larga de crisis
│     └─ Con corriente constante, sonda monopolar y tren corto de estímulos CATÓDICOS puede
│        desarrollarse una correlación sonda-tracto basada en valores cuantitativos de umbral
├─ FASES DEL PROCEDIMIENTO
│  ├─ PREOPERATORIO: evaluación neuropsicológica extensa, valoración psicooncológica y
│  │  neuroimagen avanzada (RM funcional, tractografía)
│  │  └─ Aviso explícito: la tractografía NO debe usarse para predecir la extensión de
│  │     resección a nivel individual
│  ├─ Protocolo anestésico sin estándar único: sedación consciente con solo bloqueo de scalp
│  │  en el 20% de los centros, frente a dormido-despierto-dormido (AAA) con mascarilla
│  │  laríngea en el 80%
│  ├─ FASE CORTICAL (5-15 minutos): identifica los límites funcionales del borde tumoral, los
│  │  puntos de entrada y el diseño de la corticotomía
│  └─ FASE SUBCORTICAL, la más crítica (de 20 minutos a varias horas): es la que determina la
│     extensión de la resección y el resultado funcional, con estimulación continua o alterna
│     acoplada al aspirador
├─ MAPEO SUBCORTICAL Y DISTANCIA AL CST
│  ├─ La física del asunto: elicitar una respuesta motora depende de la CARGA aplicada al
│  │  tejido, que a su vez depende de intensidad y anchura de pulso; y la densidad de corriente
│  │  DECRECE con la distancia
│  │  └─ Consecuencia: cuanto MAYOR la intensidad, MAYOR el área donde puede generarse un MEP,
│  │     y por tanto una estimulación positiva puede encontrarse a MAYOR distancia del CST. La
│  │     intensidad no es un ajuste de sensibilidad: es una medida de distancia
│  ├─ LAS SERIES QUE HAN INTENTADO CUANTIFICARLO (Tabla 9.2), que no coinciden
│  │  ├─ Kamada (monopolar catódica, tren de 5, 0.2 ms, frente a RM postoperatoria):
│  │  │  correlación NO LINEAL convergente, y postula 1.8 mA como umbral eléctrico de CONTACTO
│  │  │  DIRECTO con el CST
│  │  ├─ Nossek (monopolar, tren de 5-7, 0.5 ms, 300 Hz, frente a navegación con corrección de
│  │  │  brain shift por ecografía intraoperatoria): correlación LINEAL, con 0.97 mA por cada
│  │  │  1 mm de tejido cerebral — de ahí nace la regla del pulgar "1 mA ≈ 1 mm"
│  │  ├─ Ohue (tren de 5, 0.2 ms, 500 Hz, frente a DTI postoperatoria precoz): también lineal
│  │  ├─ Maesawa (BIPOLAR, tren de 5, 0.4 ms, 500 Hz, frente a tractografía por RM
│  │  │  intraoperatoria): correlación lineal
│  │  ├─ Prabhu (monopolar, tren de 5, 0.3-0.5 ms, 500 Hz): NO encontró correlación, solo una
│  │  │  TENDENCIA a peor déficit si la distancia sonda-CST era corta, menor de 5 mm
│  │  └─ Shiban: marcó el punto de estimulación con un CLIP DE TITANIO al final de la
│  │     resección y probó estimulación catódica y anódica a 0.3, 0.5 y 0.7 ms; midió después
│  │     la distancia del clip al CST en DTI postoperatoria → correlación NO LINEAL, y la
│  │     estimulación CATÓDICA de 0.5 ms resultó la mejor para mapeo subcortical
│  ├─ CONCLUSIÓN HONESTA de la comparación: hasta ahora NO es posible ninguna afirmación
│  │  definitiva sobre esta relación. La regla del pulgar de "1 mA ≈ 1 mm" se usa cada vez más
│  │  con estimulación subcortical monopolar de tren corto, pero es explícitamente VAGA
│  ├─ Lo que sí es recomendable: mantener CONSTANTES el número de estímulos y la anchura de
│  │  pulso, y usar estimulación catódica de corriente constante — porque el número de
│  │  estímulos, la anchura, la polaridad y sobre todo la CARGA son lo que hace incomparables
│  │  unas series con otras
│  └─ "RADAR ELÉCTRICO DE DISTANCIA" — cómo se usa en la práctica
│     ├─ Se empieza el mapeo subcortical con intensidad alta, por ejemplo 10-15 mA de tren
│     │  corto catódico monopolar
│     ├─ Tras retirar cierta cantidad de tumor se aproxima el tracto y aparece un MEP
│     ├─ Se REDUCE la intensidad en 2 mA y se continúa resecando en los puntos negativos para
│     │  esa corriente
│     └─ Cuando vuelve a aparecer un MEP a esa intensidad menor, significa distancia menor al
│        CST: se repite el descenso escalonado hasta alcanzar un umbral mínimo, que es donde
│        se detiene la resección
├─ RIESGO NEUROLÓGICO ESPECÍFICO
│  ├─ Déficit motor o de lenguaje nuevo o empeorado en el postoperatorio inmediato: 65-92.8%
│  │  según series, mayoritariamente TRANSITORIO y resuelto en menos de un mes
│  ├─ Con estimulación subcortical sistemática, los resultados a largo plazo cambian por
│  │  completo: solo 2.3% de déficit de lenguaje a largo plazo en tumores de área de lenguaje,
│  │  0.5% de déficit motor a largo plazo cerca de vías motoras, y 95.8% de vuelta al trabajo
│  │  a los 3 meses
│  ├─ Síndrome del área motora suplementaria: aparición progresiva intraoperatoria por
│  │  desconexión de la SMA del sistema motor
│  └─ Lesión vascular por coagulación de perforantes: causa hasta el 40% de los cambios de
│     MEP, y esos cambios pueden ser ABRUPTOS e IRREVERSIBLES
├─ POSICIONAMIENTO
│  ├─ Debe permitir contacto visual y verbal CONTINUO con el neuropsicólogo durante la fase
│  │  despierta; mascarilla laríngea en las fases dormidas del protocolo AAA
│  └─ Detalles de protección de vía aérea, ángulo de cabeza y sujeción **(verificar — no
│     detallados en estas fuentes)**
├─ CRISIS INTRAOPERATORIA — el riesgo propio de esta cirugía
│  ├─ POR QUÉ importa tanto: afecta negativamente no solo a la seguridad del paciente durante
│  │  la cirugía, sino también a poder completar una resección satisfactoria
│  ├─ Tasas según paradigma, explicadas por la CARGA total aplicada
│  │  ├─ Penfield / baja frecuencia: 5-20%
│  │  └─ Tren corto / alta frecuencia: 1-4%
│  ├─ Encuesta europea de 20 centros de glioma de bajo grado: la tasa en cirugía DESPIERTA
│  │  casi DOBLA la de cirugía dormida (15% frente a 8.8%) — aunque el diseño de la encuesta
│  │  no permitía sacar una conclusión definitiva
│  ├─ Variabilidad entre centros pese a protocolos similares: Nossek 12.6% en 549 cirugías
│  │  despiertas · Deras 0% en 140 · Boetto 3.4% en 374
│  ├─ Estímulos MÁS LARGOS y corriente MÁS ALTA durante la cirugía despierta correlacionan con
│  │  descargas intraestimulación, que facilitan los afterdischarges y las crisis
│  └─ ANTECEDENTE DE CRISIS PREOPERATORIAS
│     ├─ Aumenta el riesgo especialmente con el paradigma de Penfield
│     ├─ Con tren corto, en cambio, un estudio encontró tasas SIMILARES en pacientes con
│     │  epilepsia sintomática y sin historia previa de crisis: 1.6% frente a 1.5%
│     └─ Aun así, con historia previa de crisis y mapeo cortical con tren corto es aconsejable
│        BAJAR la frecuencia de repetición de los trenes hasta 0.4 Hz
├─ PROFILAXIS ANTIEPILÉPTICA — lo que dice la evidencia frente a lo que se hace
│  ├─ En la encuesta europea, la aparición de crisis intraoperatorias fue SIMILAR en pacientes
│  │  con y sin antiepiléptico preoperatorio
│  ├─ El riesgo dependió además de la HISTOPATOLOGÍA: los tumores de bajo grado presentaron
│  │  una frecuencia DOBLE respecto a los de alto grado
│  ├─ Varios metaanálisis: no hay evidencia de eficacia de la profilaxis para prevenir crisis
│  │  postoperatorias, y el consenso del Quality Standards Subcommittee de la AAN DESACONSEJA
│  │  el uso rutinario de profilaxis antiepiléptica en pacientes con tumor cerebral
│  ├─ Explicación propuesta del fallo: la mayoría de los antiepilépticos bloquean mecanismos
│  │  EXCITATORIOS, mientras que las crisis en el paciente con tumor pueden ser consecuencia de
│  │  otros mecanismos; una concentración sérica insuficiente también podría explicarlo
│  └─ Realidad de la práctica: pese a todo lo anterior, más del 70% de los neurocirujanos usa
│     profilaxis de forma regular en cirugía despierta de gliomas
├─ JERARQUÍA DE ALARMA — los dos protocolos que compiten
│  ├─ El dilema: la corriente debe ser tan baja como sea posible pero tan alta como sea
│  │  necesario, y la fuente reconoce que no es fácil de resolver
│  ├─ PROTOCOLO AMERICANO (Berger), confiado en el mapeo negativo: el límite es el UMBRAL DE
│  │  AFTERDISCHARGE, lo que obliga a llevar ECoG
│  ├─ PROTOCOLO EUROPEO (Duffau): el límite es el UMBRAL MOTOR de M1, sin buscar afterdischarge
│  └─ Se traduce en corrientes de trabajo distintas sobre área premotora ventral: el americano
│     usa la más alta SIN afterdischarge (3.5-15 mA), el europeo la más baja que produce
│     anartria durante conteo o nombrado (2-5.5 mA, notablemente menor)
├─ PROTOCOLO DE REACCIÓN
│  ├─ Ante crisis: irrigar la corteza expuesta con suero Ringer o NaCl isotónico FRÍO, y NO
│  │  reestimular inmediatamente
│  ├─ Si la irrigación fría no aborta la crisis: bolo de propofol de 0.5-1 mL
│  ├─ En pacientes con historia de crisis y mapeo con tren corto: bajar la frecuencia de
│  │  repetición a 0.4 Hz
│  └─ Los sitios NEGATIVOS al inicio deben reevaluarse tras la descompresión, porque el edema
│     y la compresión pueden haber dado un falso negativo
├─ TÉCNICA DE MAPEO DE LENGUAJE
│  ├─ Tareas por lóbulo: FRONTAL (conteo, nombrado, lectura y escritura) · TEMPORAL (conteo,
│  │  nombrado, asociación semántica) · PARIETAL e INSULAR (además, reconocimiento de números
│  │  y tarea visual)
│  ├─ Definición de sitio elocuente: error en al menos 3 estimulaciones NO CONSECUTIVAS de 3
│  └─ Tipos de error que cuentan: anartria, disartria, parafasia fonémica, semántica o verbal,
│     anomia, latencia, neologismo y circunlocución
├─ MAPEO SUBCORTICAL DINÁMICO CONTINUO
│  └─ Aspirador con alarma acústica: en la serie propia, 3% de déficit motor permanente —
│     TODOS por lesión vascular remota y NINGUNO por lesión mecánica directa del CST, lo que
│     refuerza que el mapeo puntual no puede sustituir a la monitorización continua
└─ Referencia
   └─ Deletis cap.9 (Seidel/Raabe, "Cortical and subcortical brain mapping") pp.121-134 —
      §9.4 corriente constante frente a voltaje y polaridad anódica/catódica, §9.5 los dos
      paradigmas con sus tasas de crisis y los protocolos de Duffau y Berger (Fig. 9.2),
      profilaxis antiepiléptica y encuesta europea, §9.6 elección de sonda y las cuatro
      observaciones (Fig. 9.3), §9.7 distancia al CST con la Tabla 9.2 y el radar eléctrico
      (Fig. 9.4), §9.8 mapeo subcortical continuo, §9.9 pitfalls · cap.7 (Bello et al.,
      neurofisiología del mapeo de lenguaje y cognición) pp.101-112 · cap.19 (Bello et al.,
      cirugía funcional despierta de tumor cerebral) pp.257-268 · Moller2011 cap.14 pp.289-291

## Ampliación — profundizar

```
Craneotomía despierta — ampliación
├─ Por qué la sonda monopolar estimula mejor pese a ser menos focal
│  └─ La dispersión RADIAL de su campo hace que la corriente entre PERPENDICULARMENTE en el
│     axón, y esa geometría es más eficaz para despolarizarlo que el campo homogéneo y
│     tangencial que queda entre las dos puntas de una bipolar
├─ La contradicción práctica entre sensibilidad y localización
│  ├─ Monopolar: avisa antes, pero no dice exactamente dónde está la estructura
│  ├─ Bipolar: localiza con precisión, pero solo responde si ya estás muy cerca
│  └─ Por eso la combinación tradicional reparte funciones — bipolar con 50-60 Hz para
│     delimitar corteza elocuente, monopolar con tren corto para medir distancia subcortical
├─ Corticobulbar MEP desde músculo cricotiroideo o vocal bajo estimulación cortical directa
│  └─ Respuesta corta (tipo SLR) = corteza motora primaria · respuesta larga (tipo LLR) =
│     premotora — permite diferenciar el origen cortical exacto del control laríngeo
└─ La advertencia que atraviesa todo el capítulo
   └─ Ninguna de las correlaciones intensidad-distancia publicadas es directamente comparable
      con otra si cambian el número de estímulos, la anchura de pulso o la polaridad, porque
      lo que despolariza es la CARGA — y esa es la razón de fondo de que unas series
      encuentren correlación lineal y otras no lineal, sin que ninguna esté equivocada
Referencia: Deletis cap.9 (Seidel/Raabe) §9.6-9.7, pp.126-129, Tabla 9.2 · Moller2011 cap.14
pp.289-291
