# B7 — Craneotomía despierta / mapeo cortical-subcortical

```
Craneotomía despierta / mapeo cortical-subcortical
├─ Modalidades combinadas
│  ├─ DES cortical y subcortical, dos paradigmas de estimulación:
│  │  · Penfield/baja frecuencia (LF): 50-60 Hz, 1 ms de pulso, 1-4 s según tejido
│  │    (motor ~1 s, lenguaje/cognición 3-4 s), sonda bipolar
│  │  · Tren corto/alta frecuencia (HF): 4-9 pulsos de 0.2-0.5 ms, ISI 2-4 ms
│  │    (=250-500 Hz), sonda monopolar catódica — preferido para mapeo motor, genera
│  │    un MEP time-locked fácil de cuantificar
│  ├─ ECoG (3-4 canales) para detectar afterdischarges — obligatoria en el protocolo
│  │  americano (busca el umbral de afterdischarge), no obligatoria en el europeo
│  ├─ MEP/SEP continuos evalúan integridad VASCULAR y NO sustituyen al mapeo — una
│  │  lesión por coagulación de perforantes remota al punto estimulado solo la
│  │  detecta la monitorización continua, nunca el mapeo puntual
│  └─ EMG libre de cara simultáneo — para no perder movimientos pequeños o a
│     distancia durante la vigilia
├─ Fases del procedimiento
│  ├─ Preoperatorio: evaluación neuropsicológica extensa + psicooncológica +
│  │  neuroimagen avanzada (fMRI, tractografía — aviso explícito: la tractografía NO
│  │  debe usarse para predecir la extensión de resección a nivel individual)
│  ├─ Protocolo anestésico sin estándar único: sedación consciente con solo bloqueo de
│  │  scalp (20% de centros) vs. asleep-awake-asleep/AAA con mascarilla laríngea (80%)
│  ├─ Fase cortical (5-15 min): identifica límites funcionales del borde tumoral,
│  │  puntos de entrada y diseño de la corticotomía
│  └─ Fase subcortical (la más crítica, 20 min a varias horas): determina la extensión
│     de resección y el resultado funcional — estimulación continua o alterna
│     acoplada al aspirador
├─ Riesgo neurológico específico
│  ├─ Déficit motor/lenguaje nuevo o empeorado en el postoperatorio inmediato:
│  │  65-92.8% según series — mayoría transitorio, resuelto en <1 mes
│  ├─ Con estimulación subcortical sistemática: solo 2.3% de déficit de lenguaje a
│  │  largo plazo en tumores de área de lenguaje · 0.5% de déficit motor a largo plazo
│  │  cerca de vías motoras · 95.8% vuelven al trabajo a los 3 meses
│  ├─ Síndrome del área motora suplementaria: aparición progresiva intraoperatoria por
│  │  desconexión de la SMA del sistema motor
│  └─ Lesión vascular por coagulación de perforantes: causa hasta el 40% de los
│     cambios de MEP, que pueden ser abruptos e irreversibles
├─ Posicionamiento
│  ├─ Debe permitir contacto visual/verbal continuo con el neuropsicólogo durante la
│  │  fase despierta; mascarilla laríngea en las fases dormidas del protocolo AAA
│  └─ Detalles específicos de protección de vía aérea/ángulo de cabeza/sujeción más
│     allá del principio general (verificar — no detallado en estas fuentes)
├─ Jerarquía de alarma
│  ├─ Afterdischarges en ECoG como aviso de crisis inminente — protocolo americano
│  │  (Berger): límite = umbral de afterdischarge · protocolo europeo (Duffau): límite
│  │  = umbral motor de M1, sin buscar afterdischarge
│  ├─ Tasas de crisis intraoperatoria: Penfield/LF 5-20% vs. tren corto/HF 1-4%; con
│  │  LF en mapeo de lenguaje, 2-25% según protocolo de umbral usado
│  └─ Encuesta europea: crisis casi el doble en cirugía despierta vs. dormida
│     (15% vs. 8.8%) — series individuales entre 0% y 12.6%
├─ Protocolo de reacción
│  ├─ Ante crisis: irrigar con suero Ringer/NaCl isotónico FRÍO sobre la corteza
│  │  expuesta — no reestimular inmediatamente
│  ├─ Si la irrigación fría no aborta la crisis: bolo de propofol (0.5-1 mL)
│  ├─ En pacientes con historia de crisis y mapeo con tren corto: bajar la tasa de
│  │  repetición a 0.4 Hz
│  └─ Sitios negativos al inicio deben reevaluarse tras la descompresión (falso
│     negativo por edema/compresión)
├─ Técnica de mapeo específica
│  ├─ Corriente de trabajo sobre área premotora ventral: protocolo americano = la más
│  │  alta SIN afterdischarge (3.5-15 mA) · protocolo europeo = la más baja que
│  │  produce anartria durante conteo/nombrado (2-5.5 mA, notablemente menor)
│  ├─ Tareas de mapeo subcortical de lenguaje por lóbulo: frontal (conteo, nombrado,
│  │  lectura/escritura) · temporal (conteo, nombrado, asociación semántica) ·
│  │  parietal/insular (+ reconocimiento de números, tarea visual)
│  ├─ Sitio elocuente = error en ≥3 estimulaciones no consecutivas de 3 — tipos de
│  │  error: anartria, disartria, parafasia fonémica/semántica/verbal, anomia,
│  │  latencia, neologismo, circunlocución
│  ├─ Correlación distancia-al-CST con intensidad de estimulación subcortical: regla
│  │  práctica generalizada "1 mA ≈ 1 mm"
│  ├─ Mapeo subcortical dinámico continuo (aspirador con alarma acústica): serie
│  │  propia con 3% de déficit motor permanente, TODOS por lesión vascular remota,
│  │  NINGUNO por lesión mecánica directa del CST
│  └─ Corteza: mejor con corriente anódica · subcorteza: mejor con corriente catódica
└─ Referencia
   └─ Deletis, cap. 7 (Bello et al.), pp.101-112 · cap. 9 (Seidel/Raabe), pp.121-134 ·
      cap. 19 (Bello et al.), pp.257-268 · Moller2011, cap. 14, pp.289-291
```

## Ampliación — profundizar

```
Craneotomía despierta — ampliación
├─ Sonda bipolar vs. monopolar: bipolar (5 mm entre puntas, campo homogéneo) más
│  focal/específica · monopolar (spreading radial) más sensible, aviso más precoz
│  pero menos localizador
├─ Series individuales de tasa de crisis: Nossek 12.6% (549 cirugías) · Deras 0%
│  (140 cirugías) · Boetto 3.4% (374 cirugías) — variabilidad amplia entre centros
│  pese a protocolos similares
└─ Corticobulbar MEP desde músculo cricotiroideo/vocal bajo estimulación cortical
   directa: respuesta corta (~SLR) = M1 primaria · respuesta larga (~LLR) = premotora
   — permite diferenciar el origen cortical exacto del control laríngeo
Referencia: Deletis, cap. 9, §9.6-9.7, pp.126-127 · Moller2011, cap. 14, pp.289-291
```
