# PE-V7 — Estimulación por hemicampos y distribución paradójica

```
Estimulación por hemicampos y distribución paradójica
├─ Para qué sirve — y por qué el campo completo no basta
│  ├─ La estimulación de campo completo evalúa esencialmente la vía visual PREQUIASMÁTICA
│  ├─ La estimulación por hemicampos puede detectar anormalidades en el QUIASMA y en la
│  │  vía POSTQUIASMÁTICA
│  └─ Razón anatómica: por detrás del quiasma la organización es por HEMICAMPO, no por
│     ojo. Una lesión retroquiasmática unilateral, incluso con hemianopsia homónima
│     densa, NO produce PEV asimétrico en medio-occipital con estimulación monocular de
│     campo completo, porque la vía intacta del otro hemicampo sigue dando una respuesta
│     normal
├─ La distribución (lateralización) paradójica — el fenómeno central
│  ├─ La estimulación de un hemicampo activa la corteza estriada CONTRALATERAL
│  ├─ Pero el VECTOR NETO de la excitación cortical se dirige contralateralmente, lo que
│  │  resulta en una respuesta evocada de MAYOR amplitud registrada IPSILATERALMENTE
│  ├─ Base anatómica: gran parte de la corteza visual primaria está embebida en la
│  │  superficie MEDIAL del lóbulo occipital — no es un artefacto de registro, es
│  │  geometría del generador
│  ├─ Hemicampo IZQUIERDO → estimula corteza occipital medial DERECHA → respuesta máxima
│  │  en MO y en LO (occipital izquierdo)
│  ├─ Hemicampo DERECHO → estimula corteza occipital medial IZQUIERDA → respuesta máxima
│  │  en MO y en RO (occipital derecho)
│  └─ Campo completo = sumación matemática de las dos respuestas de hemicampo → máxima
│     amplitud en MO y respuestas simétricas de menor amplitud en LO y RO
├─ Morfología de las respuestas de hemicampo
│  ├─ Onda NPN (N75, P100, N145): registrable sobre MO y sobre los electrodos occipital
│  │  y temporal IPSILATERALES al hemicampo estimulado
│  ├─ Onda PNP (P75, N105, P135): registrable sobre los electrodos occipital y temporal
│  │  CONTRALATERALES al hemicampo estimulado
│  └─ Consecuencia elegante: como el campo completo produce la suma algebraica de las dos
│     respuestas de hemicampo, la morfología más SIMPLE del PEV de campo completo se debe
│     al efecto de CANCELACIÓN entre ondas de polaridad opuesta (NPN y PNP) sobre los
│     electrodos laterales
├─ Parámetros de registro específicos
│  ├─ Se estimulan el hemicampo izquierdo y el derecho de CADA ojo
│  ├─ Tamaño de cuadro grande (~1°)
│  ├─ El paciente fija un punto situado a UN TAMAÑO DE CUADRO del borde interno del
│  │  patrón — así se evita estimular el hemicampo contralateral por movimientos oculares
│  │  involuntarios de deriva
│  ├─ No hace falta campo cuadrado, pero la razón anchura/altura no debe pasar de 4:3 y
│  │  la dimensión menor debe subtender un ángulo >15°
│  ├─ Frecuencia de inversión <4/s
│  └─ Montaje preferido de CINCO canales (sistema Queen Square): LT-MF, LO-MF, MO-MF,
│     RO-MF, RT-MF
│     └─ Si solo hay cuatro canales: para hemicampo izquierdo usar LT, LO, MO y RO; para
│        hemicampo derecho usar LO, MO, RO y RT — así se asegura el registro desde los
│        electrodos ipsilaterales, occipitales y temporales, que son los que se activan
│        preferentemente
├─ Técnica secuencial (alternativa que ahorra tiempo)
│  ├─ Los dos hemicampos se estimulan ALTERNANDO, manteniendo el otro hemicampo constante
│  │  para conservar la luminancia total
│  ├─ Ejemplo: los dos hemicampos se invierten secuencialmente cada 245 ms con un tiempo
│  │  de análisis total de 512 ms, de modo que un solo barrido registra las respuestas de
│  │  ambos hemicampos
│  └─ Ventajas: reduce a la mitad el tiempo de exploración, asegura mejor esfuerzo de
│     fijación, mantiene más estable la alerta del paciente y da menos variabilidad en
│     las respuestas
├─ Análisis y comparaciones que se hacen
│  ├─ Primero hay que identificar el P100 de forma inequívoca; latencia y amplitud se
│  │  miden en MO o en la derivación occipital ipsilateral
│  └─ Comparaciones habituales: campo completo ojo izquierdo vs. derecho · hemicampo
│     izquierdo ojo izquierdo vs. derecho · hemicampo derecho ojo izquierdo vs. derecho ·
│     ojo izquierdo hemicampo izquierdo vs. derecho · ojo derecho hemicampo izquierdo vs.
│     derecho
├─ Criterios de anormalidad
│  ├─ Son similares a los del campo completo
│  ├─ ADVERTENCIA ESTADÍSTICA: al evaluarse más de una docena de parámetros, uno o más
│  │  pueden salir fuera del rango normal solo por azar. Hay que evitar la
│  │  sobreinterpretación y dar significado clínico solo a las anormalidades claras
│  ├─ La AUSENCIA TOTAL de respuestas en la estimulación de un hemicampo debe
│  │  considerarse inequívocamente anormal, incluso por un intérprete con experiencia
│  │  limitada en hemicampos
│  └─ Los intérpretes experimentados pueden además considerar anormal una respuesta que
│     sigue siendo registrable pero está disminuida en amplitud por una razón de 3 o más
├─ Qué patologías detecta
│  ├─ Hemianopsia homónima total (la condición postquiasmática clásica): en la evaluación
│  │  por hemicampos muestra un descenso marcado o la ausencia total de respuestas al
│  │  estimular los hemicampos afectados
│  ├─ Se han descrito anormalidades en desmielinización, en lesiones compresivas del
│  │  quiasma y en diversas patologías focales del lóbulo occipital
│  └─ Utilidad diagnóstica añadida sobre el campo completo: confirmar un defecto de
│     conducción POSTquiasmático sospechado por una asimetría interhemisférica de
│     amplitud similar con ambos ojos — algo que solo puede establecerse firmemente con
│     hemicampos
├─ También sirve para desenredar un P100 en "W"
│  └─ Cuando el P100 bífido no se resuelve cambiando el tamaño de cuadro, la estimulación
│     por hemicampos o por campos parciales permite determinar si los dos picos se deben a
│     un defecto de conducción en la vía de un solo hemicampo
├─ Por qué se hace poco — las cuatro razones
│  ├─ Es exigente, consume tiempo y resulta fatigoso para el paciente mantener la fijación
│  │  sobre un damero de medio campo
│  ├─ Las respuestas son de BAJA amplitud
│  ├─ Hay mucha más variabilidad intra e interindividual
│  └─ Las respuestas sobre los electrodos occipitales laterales y temporales de ambos
│     lados son diferentes entre sí y complejas
├─ Limitaciones
│  ├─ En la práctica clínica la estimulación por hemicampos tiene una utilidad MUY
│  │  LIMITADA
│  ├─ Para las lesiones compresivas del quiasma (craneofaringioma, adenoma hipofisario con
│  │  extensión supraselar), las alteraciones campimétricas se evalúan MEJOR con
│  │  campimetría formal y otras pruebas neurooftalmológicas
│  └─ El sistema Queen Square ha mostrado cierta superioridad frente al 10-20 precisamente
│     al investigar defectos de hemicampo
└─ Referencia
   └─ Markand2020 cap.3 pp.106-109 (Tabla 3.8, Fig. 3.13), pp.92-93 (lateralización
      paradójica, Fig. 3.7), pp.98-99 (P100 en "W")
```
