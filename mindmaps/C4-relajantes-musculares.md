# C4 — Relajantes musculares en MIO

```
Relajantes musculares en MIO
├─ Concepto central
│  └─ Fármacos que bloquean la transmisión en la unión neuromuscular para lograr
│     inmovilidad quirúrgica — incompatibles con cualquier modalidad basada en
│     respuesta muscular. Contrapartida de C3: mientras C3 gestiona amnesia/
│     inconsciencia/antinocicepción, este nodo gestiona el 4º pilar (inmovilidad) y
│     su coste para el EMG/mMEP
├─ A qué modalidades afecta
│  └─ Bloquea/reduce EMG libre (A4), EMG estimulado-umbral de tornillo (A5), mMEP
│     (A2), CoMEP (A6) — Grupos 3 y 4 de C3. NO afecta SEP (A1), onda D (A3, potencial
│     asináptico), BAEP (A7), EEG (A8, actividad cortical no neuromuscular)
├─ Parámetros clave
│  ├─ Dos familias: despolarizantes (succinilcolina — acción ultra-corta, solo para
│  │  intubación) vs. no despolarizantes (rocuronio, vecuronio, atracurio — 30 min a
│  │  varias horas de duración)
│  ├─ TOF (train-of-four): estimulación del n. peroneo en cabeza de fíbula, 2 Hz,
│  │  0.2-0.3 ms, registro CMAP en tibial anterior — T4 desaparece con 75% de
│  │  bloqueo, T3 con 80%, T2 con 90%, T1 con 100%
│  ├─ Ratio T4/T1 ≥0.1-0.2 = mínimo aceptable para testear tornillo pedicular (A5)
│  └─ Reversión: neostigmina (inhibidor de acetilcolinesterasa, requiere recuperación
│     parcial previa, efecto no instantáneo) o sugammadex (secuestrante específico de
│     rocuronio/vecuronio, reversión más completa y predecible)
├─ Aplicación práctica
│  ├─ Relajante de acción corta SOLO para intubación si se van a monitorizar
│  │  potenciales musculares, sin redosificar — permite recuperación funcional en
│  │  30-45 min
│  ├─ El TOF que valida el test de tornillo pedicular debe hacerlo el propio equipo
│  │  de neurofisiología, en musculatura de PIERNA con electrodos propios — no fiarse
│  │  del TOF del anestesiólogo (dispositivo portátil, evaluación subjetiva, hecho
│  │  típicamente en mano/cara, sensibilidad distinta a la de la pierna)
│  └─ Bloqueo parcial monitorizado (3-4/4 en TOF) puede aceptarse para EMG estimulado,
│     más controvertido para mMEP: puede elevar el umbral de TES necesario,
│     desplazando el origen de la respuesta hacia cápsula interna/tronco en vez de
│     corteza motora, enmascarando así una isquemia cortical por clip temporal
├─ Errores frecuentes
│  ├─ Confiar en el TOF hecho por anestesia en mano/cara cuando el test relevante es
│  │  en pierna (tornillo pedicular)
│  ├─ Relajación excesiva no advertida → elevación artefactual del umbral de tornillo
│  │  → falso negativo (caso ilustrativo en A5: 50 mA con 1 twitch → 12 mA con 4)
│  ├─ Bloqueo parcial NO monitorizado durante EMG libre → puede mimetizar lesión de
│  │  nervio periférico/craneal por simple reducción de amplitud, sin lesión real
│  ├─ La respuesta de lateral spread (cirugía de espasmo hemifacial) es
│  │  particularmente sensible incluso a dosis pequeñas de NMB
│  └─ Asumir que revertir con neostigmina normaliza la función muscular de inmediato
│     — el efecto es gradual
├─ Conexión con otros nodos
│  └─ A2 (mMEP, relajación completa prohibida), A4/A5 (EMG, sensibilidad crítica al
│     bloqueo), A6 (CoMEP), C3 (la otra cara farmacológica), C5/C6 (relajación no
│     monitorizada como causa no quirúrgica de cambio de señal/falso negativo)
└─ Referencia
   └─ Deletis, cap. 40 (Sloan & Koht), §40.4.1, Fig. 40.2 · Deletis, cap. 13
      (Toleikis), §13.2.4.1, pp.185-186 · Moller2011, cap. 16, sección "Muscle
      Relaxants", pp.324-326
```
