# A2 — PEM / MEP transcraneal (miogénico)

> Pendiente: confirmar el umbral cuantitativo de caída de amplitud en MacDonald 2013 /
> Legatt 2016 antes de darlo por definitivo.

```
PEM/MEP transcraneal (miogénico)
├─ Vía anatómica
│  └─ M1 → cápsula interna → decusación piramidal bulbar → tracto corticoespinal
│     → asta anterior → n. periférico → músculo
├─ Estimulación
│  ├─ TES, electrodos C1/C2 o C3/C4 (10-20), tren de pulsos (train-of-five habitual)
│  ├─ Estimulación anodal — ánodo sobre el hemisferio a estimular
│  └─ Umbral de estimulación — parámetro clave a vigilar (↑ umbral = alerta precoz)
├─ Registro / montaje
│  ├─ EMG miogénico en músculos diana según nivel en riesgo (APB/ADM · TA/AH)
│  └─ Alternativa epidural → onda D (ver A3)
├─ Morfología normal
│  └─ Respuesta polifásica muscular
│     └─ Presencia/ausencia como criterio cualitativo principal
├─ Efecto anestesia/fisiología
│  ├─ Muy sensible a halogenados y a relajante muscular (a diferencia de SEP y onda D)
│  ├─ TIVA (propofol + opioide) de elección — evitar bolo antes de un test crítico
│  └─ Si se relaja: solo relajación parcial monitorizada (TOF), nunca bloqueo completo
├─ Criterios de alarma
│  ├─ Cualitativo: pérdida/ausencia de respuesta
│  ├─ Umbral: aumento significativo del umbral de estimulación
│  └─ Cuantitativo (más discutido): caída de amplitud — (verificar rango exacto en
│     MacDonald2013 / Legatt2016)
├─ Causas de cambio no quirúrgico
│  ├─ Anestésico: profundización brusca, bolo de relajante
│  ├─ Técnico: desplazamiento de electrodo TES, mal contacto
│  └─ Sistémico: hipotermia, hipotensión
├─ Troubleshooting
│  └─ Descartar anestesia/técnico → correlacionar con onda D (jerarquía onda D > MEP)
│     → comunicar a cirugía
├─ Limitaciones
│  └─ Alta sensibilidad a anestesia/relajación
│     └─ Riesgo de falsos positivos si el plano no está controlado
└─ Referencia
   └─ MacDonald2013 (ASNM) · Legatt2016 (ACNS) · Sloan2012 (relajantes)
```
