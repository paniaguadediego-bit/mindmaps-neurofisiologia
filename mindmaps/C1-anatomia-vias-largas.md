# C1 — Anatomía funcional de las vías largas (corticoespinal vs. columnas dorsales)

```
Anatomía funcional de las vías largas
├─ Concepto central
│  ├─ Dos sistemas de fibras largas comparten el mismo cordón medular pero son
│  │  anatómica y fisiológicamente INDEPENDIENTES: distinto origen, distinto nivel de
│  │  decusación, distinta posición en el cordón, distinta irrigación funcional
│  ├─ No son redundantes ni paralelos: son ORTOGONALES. La indemnidad de uno no dice
│  │  nada sobre el otro, ni en un sentido ni en el contrario
│  └─ Consecuencia operativa de todo el tema: cada vía necesita SU modalidad. Ninguna
│     modalidad interroga las dos
├─ SISTEMA LATERAL — la vía corticoespinal (CST)
│  ├─ También llamado sistema dorsolateral. Comprende el tracto corticoespinal y el
│  │  rubroespinal; es el más desarrollado en primates
│  ├─ Origen cortical, más repartido de lo que sugiere el nombre "corteza motora"
│  │  ├─ M1 (área 4 de Brodmann), SMA y PMA (área 6) y corteza somatosensorial primaria
│  │  │  S1 (áreas 1-3); también contribuyen neuronas de las áreas 23 y 24 del cíngulo
│  │  ├─ La capa 5 de M1 contiene las células piramidales gigantes de BETZ, pero son
│  │  │  POCAS frente al total de fibras corticoespinales — obligadamente hay otras
│  │  │  regiones aportando
│  │  └─ El reparto exacto está en disputa: una versión dice que M1 aporta la MITAD de
│  │     las fibras y el resto viene sobre todo de SMA, menos de PMA lateral y de S1;
│  │     otra versión reparte en TERCIOS entre M1, SMA+PMA y S1
│  ├─ Número de fibras: aproximadamente DOS MILLONES
│  │  └─ El propio capítulo menciona en otro punto la cifra de "alrededor de un millón"
│  │     — incoherencia interna de la fuente, quedarse con el orden de magnitud
│  │     **(verificar contra otra fuente si hace falta la cifra exacta)**
│  ├─ Recorrido: cortezas motoras → cápsula interna → PIRÁMIDES bulbares → decusación
│  │  piramidal → cordón LATERAL de la médula
│  ├─ La fracción que NO cruza: aproximadamente el 10% de las fibras forma el tracto
│  │  corticoespinal VENTRAL, que baja cerca de la línea media (fisura media anterior)
│  │  ├─ Se asume que termina BILATERALMENTE en el asta ventral
│  │  ├─ Su importancia funcional es poco conocida
│  │  └─ Hay grandes variaciones individuales en esa proporción
│  ├─ Por qué se llamaba "piramidal": el CST es el ÚNICO tracto que pasa por las
│  │  pirámides; los demás descendentes atraviesan otras partes del bulbo. De ahí la
│  │  vieja pareja "piramidal / extrapiramidal", una distinción que YA NO ES VÁLIDA
│  ├─ Terminación en la médula — el detalle que explica el efecto de la anestesia
│  │  ├─ Solo un PEQUEÑO PORCENTAJE de las fibras conecta directa y monosinápticamente
│  │  │  con la alfa motoneurona
│  │  └─ La mayoría termina en INTERNEURONAS PROPIOESPINALES que a su vez conectan con
│  │     la alfa motoneurona — es decir, hay sinapsis interpuesta, y por eso el MEP
│  │     miogénico es vulnerable a todo lo que deprima la transmisión sináptica
│  ├─ Terminación por origen cortical: las fibras que vienen de M1 terminan en el asta
│  │  VENTRAL; las que se originan en S1 terminan en el asta DORSAL; unas pocas fibras
│  │  no cruzadas terminan en la parte media del asta ipsilateral
│  ├─ Función: miembros DISTALES y control fino, especialmente de los dedos
│  ├─ Tracto rubroespinal: se origina en el núcleo rojo, que recibe input indirecto de
│  │  la corteza motora. En humanos se estima en torno al 1% del número de fibras del
│  │  CST en primates → su importancia funcional está cuestionada y NO juega ningún
│  │  papel relevante para monitorización
│  └─ DOS VARIACIONES ANATÓMICAS QUE IMPORTAN EN QUIRÓFANO
│     ├─ Asimetría: el CST es asimétrico en aproximadamente el 75% de la población, y
│     │  el lado DERECHO suele ser mayor que el izquierdo
│     └─ Escoliosis y hemiparesia congénita: se han descrito anomalías anatómicas
│        importantes de las vías motoras, hasta el punto de que en algunos individuos
│        las vías corticoespinales pueden ser mayoritariamente NO CRUZADAS
│        └─ Lectura para el monitor: en cirugía de deformidad no puede darse por
│           supuesta la lateralidad estándar del MEP
├─ SISTEMA MEDIAL — lo que el TES no interroga bien
│  ├─ También llamado sistema no específico; es lo que antes se agrupaba como
│  │  "extrapiramidal"
│  ├─ Componentes: tractos VESTIBULOESPINAL, RETICULOESPINAL y TECTOESPINAL, originados
│  │  respectivamente en el núcleo vestibular, el colículo superior y la formación
│  │  reticular pontina
│  ├─ El núcleo vestibular recibe su input principal del sistema vestibular y poco o
│  │  nada de las cortezas motoras; los otros dos sí reciben input cortical
│  ├─ Son en gran medida BILATERALES: dan tractos descendentes cruzados y no cruzados,
│  │  y por tanto controlan músculos de AMBOS lados del cuerpo
│  ├─ Función: músculos PROXIMALES de los miembros y sobre todo músculos del TRONCO,
│  │  incluidos los antigravitatorios
│  ├─ Filogenéticamente son las vías motoras MÁS ANTIGUAS, y vías menos directas que
│  │  las del sistema lateral
│  └─ Consecuencia práctica: el MEP miogénico de un músculo distal interroga el sistema
│     lateral con nitidez; la musculatura proximal y de tronco está sostenida por un
│     sistema bilateral que la estimulación transcraneal no aísla igual de bien
├─ COLUMNAS DORSALES — lo que realmente se monitoriza con SEP
│  ├─ Advertencia de partida: la columna dorsal es una ESTRUCTURA ANATÓMICA con muchas
│  │  clases de fibras, NO un tracto único
│  ├─ La mayoría de sus fibras son aferentes primarias y colaterales de aferentes
│  │  primarias procedentes de receptores sensitivos
│  ├─ Dos partes, con reparto somatotópico
│  │  ├─ Fascículo CUNEATUS: fibras del cuerpo SUPERIOR (segmentos torácicos y
│  │  │  cervicales) → núcleo cuneatus
│  │  └─ Fascículo GRACILIS: fibras de receptores del cuerpo INFERIOR → núcleo gracilis
│  ├─ Recorrido de primer orden: las aferentes entran por la raíz dorsal, algunas hacen
│  │  sinapsis en distintas láminas del asta dorsal, y otras ascienden ININTERRUMPIDAS
│  │  por el mismo lado formando la columna dorsal hasta los núcleos bulbares
│  ├─ Vía de la columna dorsal de SEGUNDO ORDEN
│  │  ├─ Fibras ascendentes que se originan en cuerpos celulares del asta dorsal
│  │  ├─ Proceden sobre todo de la lámina IV en el engrosamiento cervical y de las
│  │  │  láminas V y VI en la médula lumbosacra
│  │  └─ Muchas de ellas son activadas por receptores articulares y musculares
│  ├─ Qué median las aferentes primarias: TACTO FINO (receptores cutáneos) y
│  │  PROPIOCEPCIÓN INCONSCIENTE (husos musculares y órganos tendinosos)
│  ├─ Núcleos y decusación
│  │  ├─ Núcleo cuneatus y núcleo gracilis, juntos los núcleos de las columnas dorsales,
│  │  │  están en la porción CAUDAL DEL BULBO
│  │  ├─ El NÚCLEO Z está ligeramente rostral y medial a ellos; recibe fibras
│  │  │  propioceptivas del cuerpo inferior y de receptores cutáneos de bajo umbral
│  │  └─ Las fibras que salen de los núcleos de columnas dorsales y del núcleo Z CRUZAN
│  │     al otro lado del BULBO y ascienden formando el LEMNISCO MEDIAL
│  ├─ Lemnisco medial: asciende por el tronco primero cerca de la LÍNEA MEDIA y después
│  │  más LATERALMENTE, hasta terminar en el núcleo ventral posterolateral (VPL) del
│  │  tálamo — el tálamo ventrobasal (VB) comprende VPL y VPM y es el segundo relevo
│  │  principal del sistema somatosensorial
│  ├─ Precisión de la vía: la columna dorsal tiene una razón sináptica casi 1:1, lo que
│  │  da una localización y una discriminación mucho más precisas que el sistema
│  │  anterolateral
│  └─ LA ASIMETRÍA MMSS / MMII QUE CAMBIA LA INTERPRETACIÓN DEL SEP DE TIBIAL
│     ├─ Las aferentes musculares RÁPIDAS del grupo I procedentes de los miembros
│     │  INFERIORES probablemente NO viajan por la columna dorsal: atraviesan el
│     │  funículo POSTEROLATERAL, ascienden ipsilateralmente por los fascículos
│     │  laterales y terminan en el NÚCLEO Z
│     ├─ Las fibras que salen del núcleo Z cruzan la línea media y se unen al lemnisco
│     │  medial, reincorporándose a la vía clásica ya en el bulbo
│     ├─ En el gato, el núcleo Z actúa como relevo entre la médula espinal y el núcleo
│     │  ventral lateral (VL) del tálamo motor; las aferentes del grupo I de la
│     │  extremidad posterior entran en los fascículos dorsolaterales a nivel L3
│     └─ Consecuencia: el trayecto medular de lo que se monitoriza con SEP de MMII NO es
│        idéntico al de MMSS, y esto tiene implicaciones directas para interpretar dónde
│        está la lesión cuando cae un SEP de tibial posterior
├─ SISTEMA ANTEROLATERAL — el que NINGUNA modalidad habitual vigila
│  ├─ Compuesto por los tractos espinotalámico, espinomesencefálico y espinorreticular;
│  │  el ESPINOTALÁMICO es el mayor y probablemente el más importante
│  ├─ Conduce TEMPERATURA y DOLOR, y una sensación táctil menos localizada y más general
│  └─ Regla que hay que tener explícita: un cordón anterolateral íntegro no lo garantiza
│     ningún potencial evocado de los que se usan de rutina. Su integridad simplemente
│     no se está monitorizando
├─ Cómo se traduce en las modalidades
│  ├─ Columnas dorsales → SEP. "Es principalmente la columna dorsal lo que se monitoriza
│  │  cuando se usan SEP"
│  ├─ CST → MEP transcraneal, onda D epidural, y la vía corticobulbar paralela para los
│  │  CoMEP de pares craneales
│  └─ La posición en el cordón (CST lateral/anterolateral frente a columna dorsal
│     posterior en línea media) es lo que define DÓNDE colocar el electrodo de mapeo o
│     de registro dentro de la médula
├─ Aplicación práctica — las dos disociaciones documentadas
│  ├─ SEP normal con déficit motor real: en la serie de Nuwer, el SEP no detectó
│  │  anormalidad en 34 pacientes. Sobre el total de cirugías es una incidencia mínima
│  │  (34 de 51.263 operaciones, 0.063%), pero sobre los pacientes que SÍ tuvieron
│  │  déficit postoperatorio la tasa de falsos negativos es alta: 34 de 184, el 18.5%
│  │  └─ Ese 18.5% es la cuantificación exacta de "un SEP normal no garantiza indemnidad
│  │     motora"
│  ├─ La disociación inversa: caída de SEP sin déficit motor, con onda D y MEP estables —
│  │  la vía motora estaba intacta y el SEP estaba informando de otra cosa
│  └─ En mielotomía de tumor intramedular la independencia de las vías se explota
│     activamente: el mapeo de columna dorsal localiza el rafe medio real cuando el
│     tumor lo ha rotado, y el mapeo del CST lo distingue de la columna dorsal por la
│     recuperación sináptica de las interneuronas interpuestas
├─ Errores y confusiones frecuentes
│  ├─ Tratar SEP y MEP como confirmación mutua: son sistemas ortogonales, no una segunda
│  │  opinión el uno del otro
│  ├─ Asumir decusación estándar en cirugía de escoliosis, donde el CST puede ser
│  │  mayoritariamente no cruzado
│  ├─ Olvidar que la columna dorsal decusa en el BULBO y no en la médula: una lesión
│  │  medular de columna dorsal da clínica IPSILATERAL, al revés que la del CST
│  ├─ Hablar de "tracto extrapiramidal" como si fuera una entidad: la distinción
│  │  piramidal/extrapiramidal ya no es válida
│  ├─ Interpretar el SEP de tibial con el mismo mapa medular que el de mediano
│  └─ Dar por monitorizado el cordón anterolateral
├─ Limitaciones — de la propia anatomía, no de la técnica
│  ├─ Muchos aspectos del sistema corticoespinal humano son incompletamente conocidos,
│  │  por el número limitado de estudios en primates y por las diferencias posibles
│  │  entre el humano y otros primates
│  ├─ El sistema lateral está muy poco desarrollado en el gato, que es el animal de
│  │  muchos de los estudios clásicos del sistema motor → hay que desconfiar de la
│  │  extrapolación
│  ├─ La importancia del tracto corticoespinal ventral es, literalmente, poco conocida
│  └─ La anatomía descrita es la representativa de la mayoría, pero existen desviaciones
│     grandes, especialmente en escoliosis y hemiparesia congénita
└─ Referencia
   └─ Moller2011 cap.9 (Anatomy and Physiology of Motor Systems) pp.178-181 — sistema
      lateral y medial, origen y número de fibras del CST, decusación piramidal, tracto
      ventral ~10%, terminación por láminas, asimetría 75%, anomalías en escoliosis,
      Figs. 9.8-9.10 · cap.5 (Anatomy and Physiology of Sensory Systems) pp.93-96 —
      columna dorsal como estructura no-tracto, cuneatus/gracilis, vía de segundo orden,
      núcleo Z, lemnisco medial y VPL, grupo I de MMII por funículo posterolateral,
      sistema anterolateral, Figs. 5.1-5.3 · cap.6 p.96 (serie de Nuwer: 34/51.263
      falsos negativos, 34/184 = 18.5% de los déficits reales)
```
