# C1 — Anatomía funcional de las vías largas (corticoespinal vs. columnas dorsales)

> Tema de síntesis: anatomía clásica ya reflejada en A1/A2/A3/A5/B3 de este proyecto,

> neuroanatomía básica si se necesita cita formal)`.

```
Anatomía funcional de las vías largas
├─ Concepto central
│  ├─ Dos sistemas de fibras largas que comparten el mismo cordón medular pero son
│  │  anatómica y fisiológicamente INDEPENDIENTES
│  ├─ CST: motor, eferente, decusa en la PIRÁMIDE BULBAR (~90% de fibras), viaja
│  │  lateral/anterolateral
│  └─ Columnas dorsales: sensitivo (propiocepción/vibración), aferente, decusa en el
│     BULBO (núcleos gracilis/cuneatus, NO a nivel espinal), viaja posterior en línea
│     media — indemnidad de una vía NO implica indemnidad de la otra, son sistemas
│     ortogonales, no redundantes
├─ A qué modalidades afecta
│  ├─ Columnas dorsales → SEP (A1)
│  └─ CST → MEP transcraneal (A2), onda D (A3), CoMEPs vía corticobulbar paralela
│     (A6) — ambas vías son la base de las dos técnicas de mapeo intramedular: DCM
│     (columna dorsal) y mapeo CST (B3)
├─ Parámetros clave
│  └─ La localización dentro del cordón (CST lateral/anterolateral vs. columna dorsal
│     posterior en línea media) define dónde colocar el electrodo de mapeo/registro
│     en IMSCT — ambas son fibras mielinizadas gruesas y rápidas, pero con generadores
│     y sinapsis en niveles distintos del neuroeje
├─ Aplicación práctica
│  └─ En mielotomía de tumor intramedular: el DCM localiza el rafe medio real cuando
│     el tumor lo ha rotado/distorsionado, y el mapeo CST (doble tren, intervalo
│     intertren 60 ms) diferencia CST de columna dorsal por la recuperación sináptica
│     de las interneuronas (ver B3)
├─ Errores frecuentes
│  ├─ Asumir que un SEP normal garantiza indemnidad motora — encuesta SRS/ESDS: 18.5%
│  │  de los déficits reales tuvieron SEP falso negativo (A1)
│  └─ Asumir lo contrario, que una caída de SEP predice déficit motor — caso B3
│     (SEP caído ~90%, D-wave/MEP estables, sin empeoramiento motor) es la disociación
│     inversa documentada
├─ Conexión con otros nodos
│  └─ A1, A2, A3, A5 (vía anatómica de cada modalidad) · B3 (aplicación quirúrgica de
│     la distinción)
└─ Referencia
   └─ Síntesis de A1/A2/A3/B3 del proyecto — anatomía general, sin cita ION específica
      nueva
```
