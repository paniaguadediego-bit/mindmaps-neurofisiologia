# PE-A2 — Campo cercano vs. campo lejano

```
Campo cercano vs. campo lejano
├─ Definición y alcance
│  ├─ Campo cercano (NFP): potencial registrado con el electrodo DIRECTAMENTE SOBRE o
│  │  muy cerca de la estructura generadora (nervio, tracto, núcleo, región cortical).
│  │  Refleja la actividad de muchas fibras o células de UNA SOLA estructura
│  ├─ Campo lejano (FFP): potencial registrado desde electrodos situados a distancia
│  │  (larga) de las estructuras que lo generan, dentro de un medio conductor
│  ├─ Origen histórico del término: "campo lejano" lo usaron por primera vez Jewett y
│  │  Williston (1971) para describir los PEATC — generados en estructuras auditivas
│  │  del tronco y registrados desde el vértex
│  └─ AVISO CONCEPTUAL: "campo lejano" designa DOS MECANISMOS DISTINTOS bajo el mismo
│     nombre
│     ├─ (a) Potenciales estacionarios generados por actividad PROPAGADA en nervios o
│     │  tractos al encontrar discontinuidades del conductor de volumen
│     └─ (b) Potenciales generados por activación SINÁPTICA de núcleos del tronco o de
│        tractos subcorticales, registrados a distancia
├─ El criterio operativo — gradiente y cambio de latencia al mover el electrodo
│  ├─ NFP propagado (viajero): la LATENCIA AUMENTA conforme se desplaza el electrodo a
│  │  lo largo de la vía nerviosa; la amplitud cae muy rápido al alejarse de la fuente
│  │  (≈ distancia⁻³)
│  ├─ FFP: baja amplitud, LATENCIA FIJA (estacionaria), ampliamente distribuido en el
│  │  volumen conductor
│  └─ NFP ESTACIONARIO — la categoría intermedia que rompe la equivalencia simplista
│     "estacionario = campo lejano"
│     ├─ N13 y N22 son campo CERCANO y a la vez ESTACIONARIOS: no son propagados
│     ├─ N22 está ampliamente distribuido sobre columna dorsolumbar, es máximo en
│     │  T12/L1, decrece en amplitud por encima y por debajo, pero SU LATENCIA NO CAMBIA
│     └─ N13 igual: máximo en cervical medio-bajo, registrable arriba y abajo con menor
│        amplitud pero con latencia fija
├─ Fundamento físico — cómo un potencial propagado genera un pico estacionario a
│  distancia
│  ├─ Punto de partida: la actividad propagada en un nervio NO genera picos
│  │  estacionarios en un registro de campo lejano salvo que se cumplan condiciones
│  ├─ Las cuatro condiciones (Kimura et al. 1984, 1986; Dumitru y King 1993) — se
│  │  registra FFP cuando el nervio:
│  │  ├─ 1. Cruza un límite entre volúmenes de distinta impedancia o conductividad
│  │  ├─ 2. Encuentra un cambio en la FORMA del volumen circundante (p. ej. pasar de un
│  │  │  cilindro pequeño a otro mayor)
│  │  ├─ 3. Se dobla o hace un giro
│  │  └─ 4. TERMINA (la propagación se detiene, como al terminar el nervio en un núcleo)
│  ├─ Mecanismo del CUADRIPOLO DESEQUILIBRADO (Dumitru y King 1993; Stegeman et al.
│  │  1997) — la explicación del "potencial de unión"
│  │  ├─ La base eléctrica del potencial de acción es un tripolo fuente-sumidero-fuente
│  │  │  (+ − +)
│  │  ├─ Equivale a un cuadripolo lineal (+ − − +), es decir DOS DIPOLOS espalda con
│  │  │  espalda: un dipolo "LÍDER" (− +) y un dipolo "REZAGADO" (+ −)
│  │  ├─ En un volumen HOMOGÉNEO los dos dipolos son iguales y opuestos, están
│  │  │  equilibrados → NO se genera FFP en un electrodo distante
│  │  └─ Al encontrar una discontinuidad los dos dipolos se DESEQUILIBRAN: predomina el
│  │     líder o el rezagado, la fuente cuadripolar pasa a comportarse como fuente
│  │     dipolar equivalente, y entonces el electrodo distante SÍ registra un FFP
│  ├─ Polaridad del FFP — corrección de un error histórico
│  │  ├─ La idea antigua de que los campos lejanos son siempre POSITIVOS es INCORRECTA
│  │  └─ Pueden ser positivos o negativos, y la polaridad la determinan (a) la fuerza
│  │     relativa de los dipolos líder y rezagado y (b) la ORIENTACIÓN del electrodo
│  │     respecto a ellos: si el electrodo distante "ve" el extremo positivo del líder
│  │     registra positividad; si "ve" el negativo del rezagado, negatividad
│  ├─ Casos concretos del modelo
│  │  ├─ Volumen de conductividad uniforme → no hay potencial por cancelación de los
│  │  │  dipolos equilibrados; solo el trifásico de campo cercano al pasar por debajo
│  │  ├─ Transición a un medio de MENOR resistencia (mayor conductividad) → FFP NEGATIVO
│  │  ├─ Paso de volumen estrecho a volumen grande → predomina el dipolo líder → FFP
│  │  │  POSITIVO
│  │  ├─ Nervio que hace un giro de 180° → el electrodo distante ve el extremo negativo
│  │  │  de ambos dipolos → FFP negativo grande
│  │  ├─ Giro menos brusco (120°) → dos electrodos distantes registran POLARIDADES
│  │  │  OPUESTAS para el mismo evento: la polaridad depende también de dónde está el
│  │  │  electrodo, no solo de qué dipolo predomina
│  │  └─ Registro más allá de la TERMINACIÓN de una vía → FFP negativo, porque al
│  │     disiparse el dipolo líder el electrodo ve el extremo negativo del rezagado
│  └─ Ejemplos anatómicos de "paso de un compartimento a otro": un nervio o tracto que
│     atraviesa un canal óseo pasando de un espacio lleno de líquido a otro — la médula
│     al atravesar el foramen magnum, o el nervio auditivo al emerger del meato acústico
│     interno (porus acusticus)
├─ Sustrato anatómico — qué componente es de qué tipo
│  ├─ PESS de nervio mediano
│  │  ├─ N9 (Erb) → NFP PROPAGADO · generador: plexo braquial en el punto de Erb
│  │  ├─ P9 → FFP de nervio periférico · se genera ligeramente distal al plexo braquial,
│  │  │  al pasar el volley del volumen cambiante del brazo a la axila/hombro
│  │  ├─ N13/P13 → NFP ESTACIONARIO · sustancia gris dorsal del cordón cervical en la
│  │  │  zona de entrada radicular
│  │  ├─ P14 → FFP · lemnisco medial caudal
│  │  ├─ N18 → FFP · múltiples fuentes en tronco, contribución bulbar principal
│  │  └─ N20 → NFP · neuronas de la corteza sensitiva primaria (área del brazo)
│  ├─ PESS de tibial posterior
│  │  ├─ N7 (poplíteo) → NFP propagado · n. tibial en hueco poplíteo
│  │  ├─ N22 → NFP ESTACIONARIO · sustancia gris dorsal del cordón lumbar en zona de
│  │  │  entrada radicular
│  │  ├─ P31 y N34 → FFP · P31 = lemnisco medial; N34 = postsináptico de múltiples
│  │  │  generadores del tronco
│  │  └─ P37 → NFP · neuronas de la corteza sensitiva primaria (área del pie)
│  ├─ PEATC — es la modalidad de campo lejano por excelencia
│  │  ├─ Los PEATC en su conjunto son potenciales de CAMPO LEJANO, por generarse a
│  │  │  distancia (tronco) de los electrodos de registro
│  │  ├─ Contraste explícito: los componentes de latencia MEDIA y TARDÍA de la respuesta
│  │  │  auditiva, y el EEG convencional, son potenciales de CAMPO CERCANO, generados
│  │  │  localmente en la corteza muy cerca de los electrodos
│  │  ├─ Onda I: es en realidad un potencial negativo de superficie registrado desde una
│  │  │  región PEQUEÑA del scalp próxima al oído estimulado (corresponde al N1 del
│  │  │  electrococleograma); con referencia no cefálica muestra negatividad muy
│  │  │  localizada periauricular y una positividad de distribución más amplia
│  │  └─ Todos los componentes POSTERIORES a la onda I son positivos de superficie y de
│  │     distribución amplia sobre el scalp — el sello del campo lejano
│  └─ PEV — la excepción: son potenciales CORTICALES, no de campo lejano
│     ├─ No hay evidencia de que ningún componente del PEV por damero se deba a
│     │  actividad excitatoria del nervio óptico, quiasma, cintilla óptica ni cuerpos
│     │  geniculados laterales: N75 y P100 se generan en la corteza visual
│     └─ POR QUÉ el nervio óptico no da campo lejano: el medio que rodea al nervio y a
│        la cintilla óptica es relativamente HOMOGÉNEO en conductividad eléctrica, y el
│        cambio abrupto de conductividad —prerrequisito para generar picos estacionarios
│        de campo lejano— no parece existir para el nervio óptico
├─ Las cuatro propiedades que separan NFP de FFP
│  ├─ Amplitud: alta en NFP · baja en FFP
│  ├─ Distribución: localizada en NFP · amplia en FFP
│  ├─ Gradiente: EMPINADO en NFP · SUPERFICIAL (poco cambio con la distancia) en FFP
│  ├─ Latencia al mover el electrodo: aumenta si el NFP es propagado, fija si es
│  │  estacionario · siempre FIJA en FFP
│  └─ Derivación que lo registra: bipolar scalp-scalp para NFP · referencial con
│     REFERENCIA NO CEFÁLICA para FFP
├─ Cómo se traduce en el registro — los cuatro principios de montaje
│  ├─ 1. Colocar el electrodo activo (grid I) lo más cerca posible del generador y la
│  │  referencia (grid II) lo más lejos posible
│  │  └─ Límite: si la distancia interelectrodo es demasiado grande, la derivación se
│  │     contamina de ECG y artefacto muscular y queda ruidosa
│  ├─ 2. Decidir primero si el potencial buscado es NFP o FFP
│  │  ├─ NFP: electrodo sobre el generador; si la actividad de campo cercano está en el
│  │  │  scalp (potencial cortical), la segunda entrada se pone TAMBIÉN en el scalp, en
│  │  │  un punto donde el potencial haya caído sustancialmente. Al ser los NFP de gran
│  │  │  amplitud y gradiente empinado, esta derivación bipolar los registra de forma
│  │  │  óptima y con mínimo ruido, sin efecto de cancelación
│  │  └─ FFP: por su baja amplitud, distribución amplia y gradiente superficial, y por
│  │     el efecto de cancelación inherente al amplificador diferencial, la derivación
│  │     bipolar scalp-scalp NO CONSIGUE registrarlos. La derivación referencial con
│  │     referencia NO CEFÁLICA es la única técnica que los registra, aunque salga
│  │     ruidosa
│  ├─ 3. Evitar derivaciones donde los dos electrodos tienen potenciales de latencia
│  │  parecida pero de generadores distintos; idealmente cada derivación debe registrar
│  │  la actividad de un solo generador
│  │  └─ Excepción admisible: si los dos potenciales están suficientemente separados en
│  │     el tiempo y no se confunden entre sí
│  └─ 4. Usar eficientemente los pocos electrodos disponibles — p. ej. registrar los FFP
│     subcorticales con CPi-EPc en vez de gastar otro electrodo del scalp y otra
│     referencia, porque CPi y EPc permanecen relativamente "silentes" para la actividad
│     de campo cercano del nervio periférico estimulado
├─ El montaje determina qué se ve — casos concretos
│  ├─ PESS de mediano, montaje ACNS de 4 canales
│  │  ├─ EPi-EPc → N9, potencial de acción viajero por el plexo braquial (NFP propagado)
│  │  ├─ C5S-EPc → N13, potencial cervical estacionario
│  │  ├─ CPi-EPc → referencia NO CEFÁLICA: registra preferentemente los FFP
│  │  │  subcorticales P14 y N18
│  │  └─ CPc-CPi → N20 cortical
│  ├─ Por qué CPc-CPi da un N20 "puro": muestra el potencial somatosensorial localizado
│  │  SIN contaminación de P14 ni N18, porque estos son equipotenciales en CPc y CPi y
│  │  prácticamente se cancelan
│  ├─ Variante con canal 1 = EPi-CPi: registra N9 (desde EPi) y también P14 (desde CPi,
│  │  por su distribución amplia). Viola deliberadamente el principio 3, pero se
│  │  justifica porque N9 y P14 están muy separados en el tiempo
│  │  ├─ Ventaja: registrar P14 en dos canales da REDUNDANCIA para identificar este
│  │  │  potencial de baja amplitud si uno de los canales se pone ruidoso
│  │  └─ Ojo: en ese canal el P14 aparece INVERTIDO, porque el electrodo activo CPi está
│  │     en el terminal de entrada opuesto
│  ├─ PESS de tibial
│  │  ├─ T12S-ICc (referencia en cresta ilíaca contralateral) → N22. Se prefiere
│  │  │  referencial a bipolar porque registrar N22 con electrodos muy próximos sobre la
│  │  │  columna lo ATENÚA mucho por cancelación en fase
│  │  ├─ FPz-C5S → FFP subcorticales P31 y N34: aquí FPz es el activo y C5S el inactivo
│  │  └─ CPz-FPz → P37 cortical: bipolar scalp-scalp, ideal porque la respuesta cortical
│  │     localizada se registra pura, mientras el potencial subcortical difuso se cancela
│  │     por ser esencialmente equipotencial en los dos electrodos
│  └─ PEATC — por qué Ai-Cz y Ac-Cz enseñan cosas distintas
│     ├─ Los componentes posteriores a la onda I están ampliamente distribuidos, pero su
│     │  distribución de campo es LIGERAMENTE distinta, y eso explica las diferencias
│     ├─ Onda I: negatividad muy localizada periauricular ipsilateral + positividad más
│     │  amplia → Ai-Cz es la mejor derivación, por suma en oposición de fase. En Ac-Cz
│     │  la onda I está AUSENTE
│     ├─ Onda II: positividad amplia, máxima en vértex y mínima en región auricular
│     │  contralateral → se registra mejor con Ac-Cz; en Ai-Cz es menor por cancelación
│     │  parcial en fase
│     ├─ Onda III: positividad amplia con ligero énfasis contralateral → mejor en Ai-Cz
│     ├─ Onda V: positiva de superficie, mayor en vértex, con distribución favorable al
│     │  scalp ipsilateral → en Ai-Cz queda variablemente atenuada
│     ├─ En Ac-Cz las ondas IV y V se separan mejor en picos distintos; en Ai-Cz suelen
│     │  aparecer fusionadas
│     └─ Consecuencia práctica: COMPARAR las dos derivaciones ayuda a identificar
│        correctamente los componentes, sobre todo cuando el PEATC es anormal
├─ El papel de la referencia no cefálica
│  ├─ En el registro ideal de campo lejano un electrodo debe estar lo más cerca posible
│  │  de la fuente (aunque esa distancia sea considerable) y el otro lo más lejos
│  │  posible, para que registre lo menos posible del sistema estudiado
│  ├─ Para registrar del encéfalo, la mejor forma de lograrlo es poner la referencia
│  │  FUERA de la cabeza. Esto facilita la interpretación, da mejor correspondencia
│  │  entre potenciales de campo lejano y de campo cercano, y facilita identificar los
│  │  generadores
│  ├─ Cuando no es posible, ambos electrodos registran potenciales considerables del
│  │  sistema estudiado y el registro muestra solo la DIFERENCIA entre las dos
│  │  localizaciones — de ahí buena parte de la dificultad de interpretar los PE de
│  │  campo lejano
│  └─ Históricamente, la introducción de la referencia no cefálica para el PESS de MMSS
│     (Desmedt y Chéron; Cracco y Cracco 1976) fue un avance decisivo en el estudio de
│     los generadores: hizo posible identificar los componentes precoces y estudiar su
│     origen en detalle
├─ Orientación del dipolo y plano de registro (PEATC)
│  ├─ Los generadores del PEATC se sintetizan con seis dipolos aproximadamente en el
│  │  plano coronal (Scherg y von Cramon 1985)
│  ├─ Los dipolos de los picos I y III están orientados aproximadamente en HORIZONTAL, y
│  │  el del pico V casi en VERTICAL
│  ├─ Consecuencia: electrodos en el plano horizontal registran óptimamente I y III; el
│  │  pico V se registra mejor con electrodos en el plano vertical
│  │  └─ Aplicación de dos canales: el par lóbulo-lóbulo registra I-III con más amplitud
│  │     y el par vértex-nuca (referencia no cefálica) registra el pico V con más
│  │     amplitud; cada par registra todos los componentes, pero no igual de bien
│  └─ Trayectoria de Lissajous de tres canales (3CLT): tres pares de electrodos
│     ortogonales y tres amplificadores independientes, representando los potenciales
│     uno en función de otro con el tiempo como parámetro. Da una descripción completa
│     del PEATC porque tiene en cuenta la ORIENTACIÓN de los distintos dipolos, aunque
│     su interpretación sigue teniendo incertidumbre
├─ Aplicación práctica — la regla que resume el tema
│  ├─ Si quieres ver un CAMPO LEJANO, necesitas referencia no cefálica. Si quieres ver
│  │  un CAMPO CERCANO limpio, usa bipolar scalp-scalp y deja que el campo lejano se
│  │  cancele
│  ├─ P14 y N18 solo existen en el registro clínico gracias al canal CPi-EPc; el N20
│  │  solo se ve puro gracias a CPc-CPi. Mismo paciente, mismo estímulo: montajes
│  │  distintos enseñan cosas distintas
│  └─ En monitorización intraoperatoria el principio es el mismo: o se registra campo
│     cercano con electrodo sobre una estructura expuesta, o —lo habitual— campo lejano
│     desde electrodos en el scalp
├─ Errores y confusiones frecuentes
│  ├─ Creer que los campos lejanos son siempre POSITIVOS: error histórico explícitamente
│  │  corregido, pueden ser positivos o negativos
│  ├─ Creer que la polaridad de un FFP identifica el generador: depende de qué dipolo
│  │  predomina Y de la posición del electrodo; dos electrodos distantes pueden registrar
│  │  polaridades opuestas para el mismo evento
│  ├─ Intentar registrar P14/N18 (o P31/N34) con derivación bipolar scalp-scalp: se
│  │  cancelan y "desaparecen" — no es una anormalidad, es un error de montaje
│  ├─ Registrar N22 con electrodos próximos sobre la columna: lo atenúa mucho por
│  │  cancelación en fase
│  ├─ Confundir "estacionario" con "campo lejano": N13 y N22 son estacionarios pero de
│  │  campo CERCANO
│  ├─ Confundir el campo lejano de NERVIO con el campo lejano de NÚCLEO: son dos
│  │  mecanismos distintos bajo el mismo nombre
│  ├─ Suponer que un potencial ausente en el scalp implica que la estructura no está
│  │  activa: es la paradoja del campo cerrado — un núcleo con gran potencial de campo
│  │  cercano puede no contribuir de forma medible al campo lejano
│  └─ En PEV, interpretar el N100 frontal como un P100 invertido: no son un único
│     generador orientado horizontalmente, se comportan de forma independiente. Si el
│     P100 falta y el N100 se conserva, la derivación MO-MF muestra un pico hacia abajo
│     que puede confundirse con el P100 — hay que registrar MF-A1 y comparar
├─ Limitaciones
│  ├─ La generación del campo lejano es compleja y no se comprende del todo
│  ├─ Los FFP casi siempre son MEZCLAS de potenciales generados por varias estructuras
│  │  anatómicas distintas, con contribuciones ponderadas por la distancia y por la
│  │  velocidad a la que cada fuente cae con la distancia
│  ├─ Los componentes de distintas fuentes pueden SOLAPARSE en el tiempo si aparecen con
│  │  la misma latencia; entonces las contribuciones individuales no son discernibles
│  ├─ Por su pequeña amplitud, los FFP no son directamente discernibles del ruido de
│  │  fondo y obligan siempre a promediar
│  ├─ La resistencia del hueso craneal atenúa los potenciales de campo lejano del scalp
│  ├─ No existe una localización completamente inactiva en el cuerpo por la conducción
│  │  de volumen: toda derivación está influida por el potencial
│  └─ Límite práctico de la referencia no cefálica: cuanto mayor la distancia
│     interelectrodo, más contaminación por ECG y artefacto muscular — el registro de
│     FFP es intrínsecamente ruidoso. En quirófano, los canales subcorticales con
│     referencia no cefálica tienen S/N media de −22 dB, exigen promediar 500-1000
│     barridos y aun así pueden carecer de reproducibilidad

      §5.3 pp.68-71 · cap.3 p.46 · cap.4 p.57
```
