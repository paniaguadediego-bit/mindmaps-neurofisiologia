# A6 — Corticobulbares / MEP de pares craneales (CoMEPs)

> Pendiente: no hay umbral numérico de alarma consolidado en las fuentes consultadas —
> distintos autores usan criterios distintos, ver Ampliación.

```
Corticobulbares / MEP de pares craneales (CoMEPs)
├─ Qué es / vía anatómica
│  └─ MEP registrado en músculos inervados por pares craneales motores (facial,
│     trigémino motor, hipogloso) tras TES
│     └─ Vía corticobulbar en paralelo a la corticoespinal, pero termina en núcleos
│        de tronco, no en asta anterior medular
├─ Estimulación
│  ├─ TES igual que MEP de miembro
│  │  └─ Montaje C3(+)/Cz(-) para hemisferio izquierdo, C4(+)/Cz(-) para derecho
│  │     (Verst propone C5/C6 por mejor correspondencia con M1 corticobulbar)
│  ├─ Tren corto de 3-5 estímulos, 0.5 ms, ISI 2 ms, 2 Hz, 50-150 mA
│  └─ Estímulo único 90 ms después del tren, como control
│     └─ Solo el TREN activa la vía central; si responde al estímulo ÚNICO, la
│        respuesta es periférica por difusión de corriente
├─ Registro / montaje
│  ├─ Músculos diana: orbicularis oculi/oris y mentalis (facial) · masetero (trigémino
│  │  motor) · lengua (hipogloso)
│  └─ Electrodos de aguja o hook-wire intramusculares
├─ Pitfall característico
│  ├─ El CoMEP de orbicularis oculi puede ser en realidad un Blink Reflex R1
│  │  contaminante — misma latencia, mismo comportamiento
│  │  └─ Origen: la corriente del TES se propaga por cuero cabelludo anterior y activa
│  │     ramas del n. supraorbitario (aferentes trigeminales)
│  ├─ Estrategia: correr Blink Reflex EN PARALELO al CoMEP para diferenciar origen
│  │  cortical real de reflejo trigémino-facial (ver A9)
│  └─ Núcleo facial superior con inervación bicortical → lesión unilateral
│     cortical/subcortical no siempre da parálisis facial superior clínica, aunque
│     el CoMEP cambie
├─ Efecto anestesia/fisiología
│  └─ Igual que MEP miogénico — sensible a halogenados y relajante; TIVA de elección
├─ Criterios de alarma
│  ├─ Misma lógica que MEP de miembro (presencia/ausencia, cambio de amplitud)
│  ├─ Sin umbral numérico consolidado en las fuentes disponibles (verificar)
│  └─ Serie de 100 cirugías de base de cráneo (facial):
│     ├─ Sin cambios → sin déficit
│     ├─ Caída >80% vs. basal → déficit transitorio o ausente
│     └─ Pérdida → parálisis completa permanente (HB IV-VI)
├─ Causas de cambio no quirúrgico
│  └─ Comportamiento errático del CoMEP facial → sospechar activación periférica por
│     corriente dispersa a intensidad sub/cercana al umbral
├─ Troubleshooting
│  └─ Comprobar respuesta a estímulo único vs. tren → correlacionar con Blink Reflex
│     → pausa de manipulación + irrigación templada (puede revertir el bloqueo temporal
│     de conducción del facial)
├─ Limitaciones
│  ├─ Difícil de interpretar en infratentorial si no se corre Blink Reflex en paralelo
│  └─ Sensible a corriente dispersa por cuero cabelludo, no solo a la vía corticobulbar
└─ Referencia
   └─ Deletis&FernándezConejero (Neurophysiology in Neurosurgery 2ª ed., caps. 10 y 17)
      · Téllez2016 (activación periférica confundente)
```

## Ampliación — profundizar

```
Corticobulbares / CoMEPs — ampliación
├─ VCoMEPs (CoMEP vagal/laríngeo) — subtipo no cubierto arriba
│  ├─ Vocalis (n. laríngeo recurrente): hook-wire vía laringoscopio suspensorio
│  │  (requiere ORL) · Cricotiroideo/CTHY (rama externa del laríngeo superior):
│  │  electrodo colocado con el paciente DESPIERTO antes de intubar, guiado por EMG
│  │  durante fonación de sonido agudo
│  └─ TES hemisférico UNILATERAL → VCoMEP BILATERAL — evidencia de inervación
│     corticobulbar bilateral de los músculos vocales
├─ Discrepancia de criterios de alarma entre autores (por eso no hay umbral único)
│  ├─ Dong/Fukuda: decremento 50% · Acioly: 80% · Sarnthein: ↑umbral de estimulación
│  │  >20 mA vs. basal como predictor de déficit facial
│  └─ Filtro pasa-alto óptimo para CoMEP: 50 Hz (no 5 Hz, el estándar de MEP de miembro)
├─ Limitación adicional
│  └─ No detecta daño en raíces aferentes intramedulares ni conexiones internucleares
│     → puede haber disfagia o reflejo nauseoso ausente con CoMEP mantenido toda la
│     cirugía
└─ Referencia: Deletis&FernándezConejero, cap. 10, pp.142-147
```
