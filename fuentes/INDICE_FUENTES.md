# Índice de fuentes

Mantenido a mano. Cada vez que se añada un PDF a `fuentes/`, se añade aquí una fila.

El objetivo es poder ir directo a la sección correcta de una fuente sin tener que abrir
un libro entero (algunos tienen 500+ páginas) cada vez que se rellena un mindmap. Las
claves de cita (formato Autor+Año) son las mismas que se usan en la rama `Referencia`
de cada mindmap.
